## 前置步骤：公司理解、财报可信度初判与关键变量搜索

### Step 1：理解公司的生意并初判生意质量

**天山铝业靠什么赚钱？**

天山铝业是一家一体化铝产业链企业，核心业务为电解铝（原铝）的生产和销售。根据最新数据，其收入结构为：

| 产品           | 收入占比 | 说明                 |
| -------------- | -------- | -------------------- |
| 销售自产铝锭   | 64.57%   | 绝对核心，电解铝冶炼 |
| 销售氧化铝     | 23.14%   | 上游原料，部分外售   |
| 铝箔及铝箔坯料 | 7.77%    | 下游深加工，快速增长 |
| 其他           | 4.53%    | 高纯铝等             |

**生意质量三重过滤：**

1. **可理解性（通过）**：天山铝业的生意模式清晰——挖铝土矿→生产氧化铝→电解铝冶炼→（部分）深加工为铝箔/高纯铝。同时配套自备电厂（6台发电机组，满足80%-90%用电需求）和预焙阳极（100%自给），核心逻辑是"低成本电力+一体化配套=成本优势"。

2. **收入/客户可证实性（通过）**：电解铝、氧化铝均为标准化大宗商品，有公开市场报价（长江有色、SMM等），价格透明，收入可验证。客户分散，不存在单一客户依赖。但大宗商品属性意味着定价权弱，利润受行业周期影响大。

3. **模式依赖融资吗？（偏正面）**：公司经营性现金流持续改善（2025年达80.5亿元），资本支出有节制，自由现金流自2020年后持续为正。不存在"必须持续融资才能存活"的舞弊动机。

### 综合定级

**财报可信度评级：高可信 ✅**

天山铝业的财务报表展现出一种"干净的周期性"特征：

- 利润与现金流高度同步，经营现金流始终覆盖净利润；
- 核心利润占比极高，主业专注度好；
- 投入产出指标持续改善，资产质量健康；
- 作为大宗商品企业，毛利率随行业周期波动，但始终处于合理区间，无"反周期"的异常优异。

**唯一需注意的"弱信号"**：2016年扣非净利润仅占净利润的40%（当年存在重大非经常性损益），此后再未出现。考虑到天山铝业于2020年完成借壳上市（原为新界泵业），早期数据的口径可能存在特殊性，后续年份数据正常。

天山铝业的利润含金量在A股有色金属板块中属于**第一梯队**。经营现金流/净利润十年均值169%，意味着每赚1元账面利润，实际收回了1.69元现金。这在重资产制造业中极为罕见，核心原因在于公司的商业模式：

> **关键变量印证**：天山铝业的商业模式是"铝锭→现金"的快速周转，电解铝作为标准化大宗商品，销售回款快（应收周转天数仅39天），叠加折旧摊销占比高（折旧摊销虽不消耗现金但计入成本），导致经营现金流长期超越净利润。这与搜索到的"预焙阳极和氧化铝100%自给、自备电厂满足80%-90%用电"的一体化商业模式高度吻合——一体化降低了中间环节的资金占用。

2025年资本支出跳升至38.83亿元（+39%），这是因为公司启动了140万吨电解铝能效提升项目（建设20万吨新增产能），属于**有明确回报前景的扩张性资本支出**，与盲目投资有本质区别。

> **板块一结论**：天山铝业的盈利质量**优异**。利润高度聚焦主业，现金流全覆盖利润，自由现金流持续正流入。核心风险是周期性——盈利水平高度依赖铝价，但这不是财报质量问题，而是商业模式特征。

### 1. 毛利率趋势

天山铝业的毛利率呈现明显的周期性，但与行业基准相比展现了独特优势：

| 年份 | 毛利率 | 净利率 | 毛利率-净利率 | 行业背景                 |

| 2022 | 20.91% | 10.06% | 10.85%        | 铝价回落                 |

**关键特征**：

- **低谷不亏**：2018年是近年铝价低谷，天山铝业仍维持17.38%毛利率和7.11%净利率，未出现亏损——这是成本优势的直接证据；
- **毛利率-净利率差值收敛**：从2016年的12.73%收敛到2025年的11.52%，反映期间费用率的持续优化；
- **2025年毛利率25.20%**：铝价同比+4%，但电解铝生产成本同比-7%（自发电成本-23%），这是公司核心竞争力——新疆低电价优势的直接体现。

> **关键变量印证**：2025年电解铝毛利率达30.46%（来自年报拆分数据），氧化铝毛利率受铝土矿涨价影响有所回落。公司综合毛利率25.20%，在当前铝价水平下属行业优秀水平。

- 管理研发费用率近年稳定在6-7%，收入增长时费用率下降，呈规模效应。

### 3. 研发投入判断

研发费用率在3.8%-6.6%之间波动，2025年为3.79%。需结合业务特征理解：

- 天山铝业的研发主要投向：铝箔深加工技术、高纯铝偏析法工艺、电解槽节能技术；
- 均采用费用化处理，会计政策保守可信；
- 研发不仅是成本，更是向下游高附加值领域延伸的"期权费"。

> **板块二结论**：天山铝业的护城河在于**地理位置带来的结构性成本优势**（新疆低煤价→低电价→低电解铝成本），而非品牌或技术专利。期间费用率持续优化，财务费用转负，体现了管理层在成本控制上的执行力。

### 2. 增长趋势诊断

天山铝业的增长呈现**脉冲式**特征，不符合线性增长模型：

```
营收（亿元）
2016: 132 → 2017: 171（+29%）→ 2018: 202（+18%）
→ 2019: 215（+6%）→ 2020: 223（+4%）→ 2021: 287（+29%）
→ 2022: 350（+22%）→ 2023: 288（-17%）→ 2024: 335（+16%）
→ 2025: 346（+3%）
```

这种脉冲式增长与**铝价周期 + 产能投放节奏**高度相关：

- 2017年铝价上行+产能释放→营收+29%
- 2021年铝价暴涨+量增→营收+29%
- 2023年铝价大幅回调→营收-17%
- 2025年增速放缓至3.41%，主要因为氧化铝价格同比-14%对冲了电解铝量价增长

### 3. 增长模式识别

天山铝业的增长100%来自**内生扩张**：

- 商誉始终为零——从未进行过大额溢价收购；
- 资本支出投向自身产能建设（电解铝、氧化铝、铝箔产线）；
- 增长驱动因素：产能扩张 × 铝价周期。

**当前最关键的增长催化剂**：

- 20万吨电解铝新增产能2026H1全部投产→产能从120万吨→140万吨（+16.7%）；

> **关键变量印证**：搜索数据显示，券商对天山铝业2026年归母净利润预测已上调至79-94亿元区间（较2025年的48亿大幅增长），主要基于铝价高位运行+新增产能释放的双重利好。

> **板块三结论**：天山铝业过去十年实现了11.28%的营收年化增速和15.32%的净利润年化增速，但增长呈脉冲式（跟随铝价周期）。当前正处于新一轮产能释放+铝价上行的共振窗口期，2026年有望成为量价齐升的大年。但需清醒认识到：**这种高增长本质上是周期性的，而非永续增长。**

两个跃升节点对应铝价周期：

- 2021年ROE跳升至8.18%（铝价大幅上涨）；
- 2024年ROE达9.90%（铝价+氧化铝价格双涨）。

**现有ROE的可持续性评估**：

- 如果铝价维持20,000-21,000元/吨（2025年均价），ROE约9-10%；

## 最终总结：综合投资结论

### 1. 这是一门什么样的生意？

天山铝业是一体化电解铝生产企业。核心盈利模式是：**在新疆利用低价煤炭自发电 → 电解铝冶炼 → 销售标准化铝锭**。其护城河是地理禀赋带来的结构性成本优势（新疆煤价低→自发电成本仅为行业60-70%），而非品牌、技术或网络效应。这门生意的本质是"成本竞争的制造业 + 大宗商品价格周期"，盈利波动性天然较大，但在成本曲线上居于有利位置。

### 2. 财报可信度评级：**高可信 ✅**

天山铝业的财务数据展现出高度可信的特征：

- 经营现金流十年始终覆盖净利润（均值169%）；
- 扣非净利润占比持续90%以上，主业极其专注；
- 投入产出效率（WC、固定资产）持续改善，呈"干净的周期性"特征；
- 商誉始终为零，无不良并购历史。

核心支持证据：经营现金流与净利润高度同步、应收账款/收入持续下降、货币资金远超有息债务。

### 3. 历史财务表现如何？

**优秀但具有周期性。** 在可信的财务数据基础上：

- 十年营收年化增速11.28%，净利润年化增速15.32%；
- 利润含金量极高（经营现金流全面覆盖净利润）；
- 投入产出效率系统性改善（1元收入所需固定资产从2.17降至0.83）；
- 资产负债表从"借债扩张"成功转型为"现金为王"（有息负债率从13.5%降至7.3%）；
- 但盈利高度依赖铝价，2023年营收-17%、净利-1.3%即为明证。

| 2      | **20万吨新增产能释放** | 首批通电启槽，26H1全部投产       | 产能+16.7%，是2026年量增的核心来源                          |
| 3      | **自备电成本**         | 25年自发电成本-23%，煤炭价格低位 | 成本优势的护城河能否持续加深                                |

### 5. 主要风险点在哪里？

1. **铝价周期性下行风险**（⭐核心风险）：当前铝价24,000元/吨处于近年高位，若全球经济衰退、新能源需求不及预期，铝价可能大幅回落。按生产成本约12,700元/吨（2025年）计算，吨铝利润对价格极为敏感。

2. **海外项目执行风险**（⭐重要风险）：印尼200万吨氧化铝项目投资15.56亿美元，几内亚铝土矿运营复杂，均面临地缘政治、基建配套、当地社区关系等多重不确定性。

3. **产能释放不及预期**：新增20万吨电解铝虽建设进展顺利，但通电启槽到满产需要时间，实际增量可能低于理论值。

4. **财报造假风险**（低）：基于板块〇的全面审查，天山铝业财务可信度高，造假风险极低。唯一需持续关注的是在铝价高位时公司的资本支出方向和资金使用效率。

### 6. 投资价值的初步判断

**天山铝业是一家"在成本曲线上有优势、在周期中值得配置、在当前时点有催化"的周期性标的。**

- **优势面**：全产业链一体化、新疆低电价、资产负债表健康、现金流充裕、高分红（2025年分红率52.4%）、2026年有明确的量价齐升催化剂；
- **局限面**：盈利高度依赖铝价（无法摆脱大宗商品属性）、ROIC仅勉强覆盖WACC（不创造显著超额利润）、铝箔/海外项目短期贡献有限；
- **当前时点**：26Q1业绩指引同比+108%，市场已部分定价。若铝价维持24,000元/吨以上，2026年全年净利润有望冲击80-94亿（券商一致预期），对应PE约8-10倍，在有色金属板块中处于合理偏低区间。

**定性评价**：天山铝业适合作为**铝价上行周期的配置标的**，其成本优势和产能弹性为长期持有提供了安全边际。但投资者需对铝价有独立判断——投资天山铝业本质上是在投资"中国电解铝行业的成本领先者"，同时也是在投资"铝价的方向"。在当前供给端天花板锁定、需求端新能源驱动的行业背景下，天山铝业有望在中期（1-3年）享受行业景气上行 + 自身产能扩张的双重红利。
