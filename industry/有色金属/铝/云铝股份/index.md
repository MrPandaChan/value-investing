# 云铝股份

## 综合信息

[一家“变身”的企业（2026.10.20 云铝股份）](https://mp.weixin.qq.com/s/v8sYK-MqUayIT9Z8cbhp8Q)

**全文主旨**

- **行业供给刚性**：国内电解铝产能锁死4500万吨上限，海外扩产受电力、碳关税、地缘和基建约束，供给端弹性明显下降。
- **周期弱化**：涨价不再引发大量新建产能砸价，行业周期仍在但盈利波动被熨平，现金流和分红稳定性提升。
- **供需格局**：未来5年全球电解铝增速约2.3%，需求受新能源车、储能、数据中心等新质生产力拉动。
- **公司画像**：云铝股份是云南水电铝龙头，电解铝产能308万吨，氧化铝权益自给率约29%，中铝集团合计控制42.10%表决权，国资委实控。
- **产品与收入**：电解铝占收入56.8%、铝加工约42%，主销国内；产品覆盖汽车轻量化、轨交、航空航天、军工、线缆、包装、家具电子。
- **护城河**：水电绿电占比高、吨铝电力成本低于火电，叠加全产业链ASI双认证，形成成本与绿色壁垒。
- **氧化铝双刃剑**：自给率低在“铝价涨、氧化铝跌”阶段双重受益，但极端氧化铝紧缺时成本会大幅飙升。
- **财务变身**：2018年后杠杆大降、经营现金流和自由现金流改善，分红率提升至约40%。
- **风险与跟踪**：当前铝价高位、氧化铝下行空间有限、云南水电波动、几内亚铝土矿依赖是主要风险，需跟踪价格、来水、中东复产、出口政策和库存。
- **结论**：长期经营改善值得纳入观察，但短期利润有波动，不能线性外推；回到2025年均价也不高估。

**核心洞见**

- **产能天花板改变旧循环**：国内合规产能稀缺，新增只能等量/减量置换，电解铝指标成为“无法复制的入场券”。
- **绿电成本优势**：吨铝耗电约13400度，电力占成本30%—40%；云铝丰水期电价约0.22元/度、枯水期约0.32元/度，低于火电约0.34元/度。
- **绿色认证壁垒**：云铝拥有9个国家级绿色工厂，2025年清洁能源比例约87.5%，是首家完成全产业链ASI绩效和CoC认证的企业。
- **低自给率常态受益**：氧化铝建设周期短、无产能天花板，常态下可形成对冲；今年上半年铝价涨18.7%、氧化铝跌21.8%时，低自给率企业最受益。
- **2018极端案例**：海德鲁巴西停产叠加美国制裁俄铝，氧化铝全球紧缺，云铝净利润从6.6亿转为-14.66亿，高杠杆放大财务压力。
- **2023限电案例**：云南两轮能效管理导致产量下降6.71%、销量下降6.32%，铝液不足使加工产品产量下降11.7%。
- **现金流改善**：经营现金流净额/净利润近十年除2018年外均超100%，2021年后自由现金流稳定，支撑分红提升。
- **分红提升**：分红率截至2025年达40%，股息约5%；若回到2025年均价，估值约12PE、股息3%出头。
- **当前价格高位**：电解铝约23000元/吨处于近十年高点，每跌1000元/吨税后利润减少约24亿元；2026H1净利+177.6%主要靠价格而非量。
- **氧化铝成本底部**：2026年8月氧化铝现金成本约2558元/吨、市价2680元/吨，吨现金贡献仅120元，继续下跌会触发高成本产能退出。
- **水电集中风险**：云铝产能全在云南，无火电对冲；超强厄尔尼诺预计压在枯水期，2023年干旱曾导致云南冶炼厂最高减产40%。
- **原材料地缘风险**：中国铝土矿对外依存度接近80%，高度依赖几内亚，出口政策变化会影响原材料端。
- **跟踪清单**：氧化铝价格、云南蓄水/来水、中东复产公告、几内亚铝土矿出口政策、铝锭社会库存。
- **读者补充**：镁价下跌推动镁代铝在汽车轻量化试用，可能影响铝需求；南山铝业、神火被提作同业观察；作者澄清氧化铝涨价对云铝是成本上升，短期不会买云铝。

**隐含推理**

- **分红非刚性**：高分红建立在自由现金流稳定和低负债上，若铝价或来水恶化，分红能力会承压。
- **低成本不等于低波动**：水电成本优势是长期平均优势，枯水期限电会转化为产量风险，短期利润仍会波动。
- **低自给率是波动放大器**：常态下享受铝价与氧化铝价差，极端紧缺时成本弹性更大，盈利对氧化铝价格高度敏感。
- **当前价格含事件溢价**：中东受损产能终将复产，当前高价有供给扰动成分，不能直接当作长期均价。
- **供给刚性提升现金流资产属性**：产能锁死使企业更难扩张，但也让盈利和分红更像稳定现金流资产，长期配置价值提升。
- **水电优势与限电风险同源**：绿电占比越高，枯水期产量不确定性越集中，气候和电力政策是同一枚硬币的两面。
- **海外复产是中期供给变量**：中东产能恢复会改变供需，当前高利润的持续性取决于复产进度和需求增速。
- **“不高估”不等于“不会跌”**：作者认可长期价值但短期不买，说明估值合理与交易时机是两回事，市场预期变化可能先于基本面。
