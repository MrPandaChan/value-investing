# 财务报表分析

## 前置步骤：公司理解、财报可信度初判与关键变量搜索

### Step 1: 理解公司的生意并初判生意质量

#### 这家公司靠什么赚钱？

紫金矿业是中国最大、全球前列的综合性矿业集团，核心盈利来源于**矿产资源的勘探、开采和冶炼**。根据 2025 年报：

| 业务板块 | 收入（亿元） | 收入占比 | 特征                            |
| -------- | ------------ | -------- | ------------------------------- |
| 冶炼产品 | 1,658.59     | 47.51%   | 加工费模式，毛利率低            |
| 矿产品   | 1,099.78     | 31.51%   | **核心利润来源**，毛利率~61.56% |
| 贸易收入 | 292.13       | 8.37%    | 赚差价，毛利率极薄              |
| 其他收入 | 440.30       | 12.61%   | 多元化补充                      |

**关键洞察**：矿产品收入仅占 31.51%，但贡献了绝大部分毛利。2025 年矿产金毛利占比 40.9%，矿产铜毛利占比 34.5%。这是一个**"以矿为本、冶炼为表"**的生意——冶炼和贸易做大了营收规模，但真正的盈利引擎在地下。

#### 商业模式特点

1. **资本驱动型**：矿山开发需要巨额前期投入（探矿、基建、设备），这是典型的重资产重资本行业
2. **全球资产布局**：业务覆盖中国、刚果（金）、塞尔维亚、澳大利亚、阿根廷、中亚等，海外利润占比 58%
3. **"矿石流五环归一"模式**：地勘 → 采矿 → 选矿 → 冶炼 → 环保全链条自营，形成成本优势
4. **逆周期并购+技改赋能**：在行业低谷并购问题矿山，通过技术和管理改造使其扭亏为盈

#### 生意质量三重过滤

**过滤一：可理解吗？** ✅  
"在全球买矿山，挖出金银铜，冶炼卖出赚钱"——一句话就能讲清楚。

**过滤二：收入/客户可证实吗？** ⚠️（中等风险）

- 产品为标准化大宗商品（金银铜），价格公开透明，**价格端可完全证实**
- 海外资产占比较高（58%利润来自海外），实地核查存在困难
- 矿山储量由第三方评估，但评估假设（长期价格）存在主观空间
- 无经销商压货风险——产品直接进入全球大宗商品市场

**过滤三：模式依赖漂亮报表吗？** ✅

- 自由现金流/净利润 2025 年达 85.84%，2026Q1 高达 109.56%
- 经营现金流持续远超净利润，**现金创造能力极强**
- 2025 年资产负债率 51.56%，降至近年最低，**不依赖持续融资生存**

- 费用率绝对水平极低，**不构成投资担忧**

### 3. 成本端：隐忧初现

根据搜索数据，2025 年矿产金单位成本 275 元/克（同比+19.3%），矿产铜单位成本 2.5 万元/吨（同比+11.1%）。成本上升原因：

1. 部分矿山品位下降、运距增加、剥采比上升（自然规律）
2. 金价大涨 → 权益金同步大幅提升（与价格挂钩的资源税）
3. 新并购矿山过渡期成本偏高
4. 员工薪酬福利提升

**管理层的回应**：有信心将未来成本涨幅控制在个位数以内。C1 现金成本仍处于全球行业前 20%分位。

### 关键变量印证

- 金价+49.4% vs 金成本+19.3% → **克金毛利+73%至 502 元/克**，毛利率从 55.7%升至 64.6%
- 铜价+11.8% vs 铜成本+11.1% → 铜毛利率 60.96%，同比微升 0.27pct
- **"金铜双牛"的核心逻辑被财务数据完全验证——价格上涨远快于成本上涨，剪刀差扩大**

### 2. 增长趋势诊断

```
营收增速趋势：
  14.96%(2021→2025近1年) ≈ 15.27%(2020→2025近5年) ≈ 17.98%(2016→2025近9年)

净利润增速趋势：
  61.55%(近1年) >> 51.40%(近5年) > 44.89%(近9年)
  → 加速增长！净利润增长在加速而非减速
```

**核心发现**：

- 营收增长高度稳定（~15%年化），体现**产能持续扩张+价格温和上涨**的稳健模式
- 净利润增速远超营收增速，**经营杠杆效应显著**——固定成本被摊薄，边际利润增长更快
- 2025 年净利润增速 61.55%远超营收增速 14.96%，核心驱动力是**金价+49.4%带来的价格弹性**
- 增长加速而非减速，公司仍处于**量价齐升的甜蜜期**

### 3. 增长模式：内生+外延双轮驱动

ROE 从 11.38%（2019）→33.04%（2025），驱动力发生了**质的变化**：

| 阶段          | ROE 驱动力                      | 特征         | 质量评价            |
| ------------- | ------------------------------- | ------------ | ------------------- |
| 2019-2020     | 高杠杆（权益乘数 2.17-2.44）    | 举债扩张     | ⚠️ 杠杆驱动         |
| 2021-2023     | 净利率提升+杠杆维持             | 转型期       | 中等                |
| **2024-2025** | **净利率飙升（12.97%→18.28%）** | **盈利驱动** | ✅✅✅ **极高质量** |

- 净利率从 3.72%（2019）飙升至 18.28%（2025），**盈利能力的质变是 ROE 提升的唯一引擎**
- 权益乘数从 2.48（2023）降至 2.06（2025），**杠杆率不升反降**
- 资产周转率从 1.15 降至 0.77——这反映的是**总资产增速（29.1%）远快于收入增速（14.96%）**，因为大规模并购带来了总资产的膨胀，但新增资产的产出效益尚未完全释放

**这恰恰是一个"积极信号"**：当前 ROE 是"低杠杆+高利润率"驱动，若未来新增资产（如藏格矿业、赤峰黄金、锂矿项目）开始贡献产出，资产周转率回升，ROE 还有进一步提升空间。

### 2. ROIC 与价值创造

- 2026Q1 年化 ROIC 约 23%，**历史最佳水平**

### 3. ROE 趋势展望

机构一致预期 2026 年净利润 778-835 亿元（同比+50%-61%），对应 ROE 有望达到 38%-40%，**再上台阶**。主要驱动力：

1. 金铜价格维持高位（当前 COMEX 金 4,096 美元/盎司 vs 2025 年均价约 2,700 美元）
2. 矿产金从 90 吨增至 105 吨（+16.7%）、铜从 109 万吨增至 120 万吨（+10.1%）
3. 碳酸锂从 2.55 万吨增至 12 万吨（+370%），将首次实质性贡献利润
4. 赤峰黄金并表贡献

### 关键变量印证

- 2026Q1 净利率 25.55%已反映一季度金铜价格的强劲表现——若 H2 价格回落，ROE 可能低于年化预期
- 机构目标价 A 股 43.84-62.40 元、H 股 47.70-66.03 港元，隐含 2026 年 PE 11-15 倍——**在当前增长确定性下，估值仍处于合理区间**
- 风险：若金价从 4,096 美元进一步回调至 3,500 美元以下，ROE 可能回落至 25%左右，但**仍然远超资本成本**

## 最终总结：综合投资结论

### 1. 这是一门什么样的生意？

紫金矿业是**全球领先的综合性矿业集团**，核心生意是"以低成本在全球开采金、铜、锂等稀缺矿产资源并出售"。

**商业模式的独特优势**：

- **"矿石流五环归一"**：地勘 → 采矿 → 选矿 → 冶炼 → 环保全链条自营，形成了难以复制的成本优势
- **逆周期并购能力**：在全球矿业低谷收购问题矿山，通过技术和管理改造使其扭亏为盈
- **多元化矿种布局**：金+铜双核心，锂为第三增长曲线，银/钼/锌为补充——比单一品种矿企抗周期能力更强
- **强大的现金流创造**：2025 年经营性现金流 754 亿，自由现金流 444 亿——是真正的"现金牛"

**竞争壁垒**：

1. 全球低成本运营能力（C1 成本全球前 20%分位）
2. 多元化的世界级矿山资产组合
3. 自主勘探能力和技术体系
4. 融资能力和并购执行力

### 2. 财报可信度评级：**高**

**支持证据**：

- 经营现金流持续远超净利润（2025 年 145.68%），利润是"真金白银"
- 扣非净利润占比 97.96%，几乎全部来自主营业务
- 应收账款仅占收入 3.32%，大宗商品交易、现金结算为主
- 资产负债率不升反降（51.56%），债务结构改善
- 历年标准无保留审计意见，无任何治理红灯

**唯一持续关注点**：

- 无形资产（采矿权）881.67 亿元，占净资产 47.6%。若金铜价格长期大幅下跌，存在减值风险——但这是矿业公司的**固有产业特征**，而非造假信号。

### 6. 投资价值的初步判断

**定性评价：成长型现金牛，但当前面临金价回调的周期性考验。**

**看多逻辑（长期）**：

1. 公司是全球矿业中少有的"量价齐升+现金流暴增+杠杆下降"三重奏选手
2. 三年增长路径清晰：金 130-140 吨、铜 150-160 万吨、锂 27-32 万吨（2028 年）
3. "矿石流五环归一"的低成本运营能力构成护城河
4. ROE 33%且由净利率驱动（非杠杆），质量极高
5. 分红+回购回报股东（2025 年分红率 30.8%、回购 15-25 亿元）

**谨慎因素（短期/中期）**：

1. 金价从 5,627 美元高位回调至 4,096 美元（-27%），2026H2 若金价继续下行，高增长预期可能被证伪
2. 市场一致性太强——18 家机构 100%买入评级，警惕"拥挤交易"风险
3. 无形资产（采矿权）881.67 亿元，金价若跌破 3,000 美元/盎司将触发实质性减值
4. 碳酸锂从 0 到 1 放量过程中存在不确定性——锂价 V 型反弹的持续性存疑
5. 大规模并购（赤峰黄金 183 亿）后整合效果有待验证

**综合投资定位**：

紫金矿业当前处于**"周期高位的成长股"**的独特位置——既有矿业周期股的价格敏感性，又有产量复合增长 13-16%的成长属性。这不是一个"低估买入"的机会（股价对应 2026 年 PE 11-15 倍），而是一个**"以合理价格买入优质资产"的机会——但前提是你要相信金铜价格的超级周期逻辑**。

**核心投资命题**：如果你相信（1）全球货币体系重构将持续推升金价中枢、（2）能源转型将支撑铜的长期需求、（3）紫金的低成本运营能力可以穿越周期——那么当前估值是合理的、甚至是偏低的机会。如果你对金铜价格持悲观预期，则应该等待更好的入场时机。

**建议策略**：在价格高位保持谨慎仓位，在金价回调至关键支撑位（如 3,500-3,800 美元/盎司）时逐步加仓——因为届时紫金矿业将同时具备"估值合理+成长确定+财报可信"三重优势。
