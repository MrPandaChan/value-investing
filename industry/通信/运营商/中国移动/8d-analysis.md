# 非财务信息“八问”

## 一、靠什么赚钱？核心驱动力是什么？

**生意本质一句话概括：** 中国移动靠的是规模效应——手握10亿移动用户的“连接服务”作为现金牛底座，同时向政企客户卖算力和AI解决方案赚增量钱。

**收入与利润结构拆解：**

中国移动2024年主营业务收入中，HBN（家庭、政企、新兴）占比已达45.6%，较往年进一步提升。从2025年开始，公司首次以“三大主业”口径披露财报：通信服务收入7148.65亿元（同比下降1.0%），算力服务收入898.32亿元（同比增长11.1%），智能服务收入908.33亿元（同比增长5.3%）。算力+智能服务在主营业务收入中的占比已达20.2%，同比提升1.4个百分点。

最赚钱的业务板块仍是核心通信服务（占大头，但增速已转负），算力和智能两大业务则是最具成长性的增长极。毛利率端，2024年达到29.02%，2025年前三季度达到31.09%，盈利能力整体稳中有升。

**核心驱动力：** 业绩增长真正的发动机是“向B端卖算力和AI能力”。个人市场移动ARPU从2023年的49.3元降至2024年的48.5元再降至2025年的46.8元，C端天花板已清晰可见，未来增量完全来自政企市场的数字化转型和AI算力变现。这不是“开店”或“提价”，而是根本性的**收入结构重构**——从按“GB”收费的传统流量模式，迈向按“Token”收费的AI算力+智能服务模式。

## 二、顺风还是逆风？外部大环境好不好？

**宏观定性：结构分化期。** 传统通信服务端承压下行，但AI驱动的算力、云服务处于高速增长通道，行业进入“新旧动能切换”阶段。

**顺风清单（5项）：**

1. **AI基础设施投资狂潮**：全球四大云厂商（亚马逊、谷歌、微软、Meta）2024年资本开支合计超过2300亿美元，仍在大幅加码。算力市场“供不应求”，中国移动凭借全国布局的算力基础设施卡住了关键位置。

2. **中国云计算市场高增**：2024年我国云计算市场规模达8288亿元，同比增长34.4%，预计到2027年突破2.1万亿元，AI大模型与大数据产品融合升级是核心驱动力。

3. **“AI+”成为国家级战略方向**：工信部等行业政策持续推动数字经济和人工智能与实体经济融合，为公司“AI+”行动计划提供了明确的政策背书。

4. **5G-Advanced和6G技术过渡期资本开支下降**：5G大规模建设高峰已过，2025年资本开支预计降至1512亿元，释放自由现金流，支撑持续高分红。

5. **卫星通信等新空间打开**：公司已获卫星移动通信业务经营许可，“地面+卫星”的立体网络雏形初现，通信服务的天花板正在被打破。

**逆风清单（5项）：**

1. **传统通信服务收入持续萎缩**：2025年通信服务收入同比下降1.0%，2026年Q1该部分营收进一步收缩1.1%，个人市场移动ARPU持续下滑至46.8元。

2. **增值税政策调整短期冲击**：增值税调整将在短期内对公司业绩造成一定影响，华泰证券据此将2026年归母净利润预测下调15%。

3. **行业竞争加剧**：公有云IaaS市场集中度同比下降1.0%，阿里巴巴、华为、电信、移动、腾讯五大厂商已形成胶着竞争态势，市场份额争夺激烈。

4. **上游产业链受国际环境影响**：通信设备和芯片全球化供应链面临地缘政治不确定性，国内替代虽在推进但短期内存在风险。

5. **网络安全风险持续攀升**：关键信息基础设施成为网络攻击重点目标，重要数据保护压力增大，潜在安全事故可能对业务连续性和市场形象造成冲击。

## 三、空间有多大？天花板在哪里？

**第一增长曲线见顶判断：** 个人通信市场的天花板已经清晰。截至2024年末，中国移动移动客户总数已达10.04亿户，我国5G移动电话用户普及率已超56%，总量增长空间极为有限。2025年无线上网业务收入同比下降4%至3691亿元，个人市场已成“存量博弈”阵地。

**第二增长曲线储备：**

公司的第二、第三增长曲线已经非常明确——

- **算力服务**：2025年收入898亿元，智算服务增速高达279%。“十五五”期间（至2030年），公司力争算力服务收入翻番，2026年算力网络资本开支预计同比增长36.4%至378亿元。
- **智能服务**：2025年收入908亿元，同比增长5.3%，九天基础大模型3.0已推出100多款AI+产品。“十五五”期间同样目标翻番。
- **国际业务**：2025年收入293亿元，同比增长28.5%，增速跑赢多个业务板块。

**天花板量化预估：**

- 算力服务：从2025年的898亿元到“十五五”末翻番至约1800亿元，CAGR约12-15%。
- 智能服务：从2025年的908亿元翻番至约1800亿元。
- 通信服务：预计维持在7000亿元规模横盘震荡，降幅逐步收窄。
- 合计营收：3-5年内有望从1.05万亿元扩张至约1.25万亿元，增量几乎全由算力和智能驱动。

更激进的指引来自公司自身的“AI+”行动计划——到2028年底，对AI领域投入翻一番，建成国内规模最大、技术领先的智算基础设施，探索十万卡智算集群建设，全国产智能算力规模突破100 EFLOPS。

## 四、竞争格局好不好？玩法是什么？

**行业梯队地图：** 中国移动居全球通信运营商收入规模第一。国内可比公司主要是中国电信和中国联通。

2024下半年公有云IaaS市场，排名前五为：阿里巴巴、华为、中国电信、中国移动、腾讯，合计市场份额69.8%。其中中国移动排名第四，较前几年持续上升（2021年排名第七，每年提升一位），显示强劲增长实力。

**竞争核心要素：**

这个行业拼的是**基础设施规模、政企客户渗透能力、以及AI时代的算力供给能力**：

- **牌照+网络覆盖**是准入门槛——公司累计开通5G基站超259.9万个，千兆宽带覆盖住户达5亿户，网络覆盖深度和广度形成天然护城河。
- **政企客户生态**是关键战场——政企客户数持续增长，2024年达到3259万家，持续深耕政企关系网。
- **算力资源卡位**是AI时代的核心竞争力——智算总规模达92.5 EFLOPS，省际骨干400G OTN网络基本覆盖全国，对外服务IDC标准机架超150万架。

**利润率密码：**

行业平均净利率在13-14%区间（2024年中国移动为13.31%），高于一般制造业。决定利润率的三个核心变量是：1）折旧摊销（约占营收17-18%，折旧年限调整可大幅释放利润）；2）网络运维成本（刚需，占成本约37%）；3）数字化转型业务毛利率显著高于传统连接业务（数字经济/云计算类业务毛利率普遍在25%以上）。公司毛利率从2022年27.78%提升至2024年29.02%，反映出高毛利的数字化转型业务占比提升带来的结构性优化效果。

## 五、有什么优势？护城河在哪？

**对比表格（2024/2025年数据对比）：**

| 维度       | 中国移动                      | 中国电信           | 中国联通           |
| ---------- | ----------------------------- | ------------------ | ------------------ |
| 移动用户数 | 10.04亿户                     | 约4.2亿户          | 约3.4亿户          |
| 移动ARPU   | 48.5元（2024）→46.8元（2025） | 约45元             | 约44元             |
| 云计算收入 | 移动云1004亿（+20.4%）        | 天翼云约900亿+     | 联通云约500亿+     |
| IDC机架数  | 47.8万架（2023年数据）        | 53.4万架（2023H1） | 超40万架（2023年） |
| 智算规模   | 92.5 EFLOPS                   | 约20+ EFLOPS       | 约10+ EFLOPS       |
| 分红率     | 2025年达75%，未来稳中有升     | 约72%              | 约55%              |
| 企业规模   | 全球收入规模第一              | 国内第二           | 国内第三           |

**独特护城河阐述（3项）：**

1. **全球最大规模的通信网络底座**：10亿移动用户、259.9万5G基站、66万IDC机架——这样的物理基础设施规模，任何竞争对手在10年之内都无法复制。每一分资本开支都转化为难以逾越的规模壁垒。

2. **从“通信商”向“算力商”跃迁的先发卡位**：当大多数运营商还在讨论转型时，中国移动已完成92.5 EFLOPS智算规模的布局，2025年智算服务收入同比暴增279%。公司明确“十五五”期间算力和智能服务收入翻番，“翻番”意味着在AI算力赛道的领先优势将进一步扩大。

3. **“九天”大模型+政企生态的垂直整合能力**：公司不仅有“九天”大模型3.0技术底座，还拥有覆盖86个国民经济大类的5G行业商用案例超5万个。这种“模型+场景+客户”三位一体的垂直整合能力，是纯技术公司（如云厂商）和纯客户关系公司（如传统集成商）都无法同时具备的护城河。

## 六、管理层行不行？治理有没有雷？

**管理层画像：**

董事长杨杰（2019年起任职），教授级高级工程师，曾长期担任中国电信集团董事长，在基础电信运营领域拥有丰富管理经验。首席执行官何飚（2024年4月获委任），曾历任中国联通副总裁等高管职务，兼具通信行业深厚背景。财务总监李荣华，2020年加入，曾任国家电网财务资产部主任。副总经理团队中多位来自技术、市场、国际业务等核心岗位，高管团队整体呈现“通信老将+跨界人才”的组合特色。2025年，公司研发人员达69788人，研发费用293亿元，占营收比重2.8%，显示出向科技企业的转型诚意。

**治理红灯预警：**

- ⚠️ 暂无明显的关联交易、股权质押风险信号。公司实际控制人中国移动通信集团有限公司持股约69.09%，股权结构稳定。
- ⚠️ 2025年净利润同比下降0.9%，略低于市场预期，主要受传统业务收入承压和增值税调整影响，但这属于行业性压力而非治理问题。
- ✅ 港股持续回购彰显管理层信心，2024年累计回购11次，共310.5万股，回购总金额2.05亿元。
- ✅ 股票期权激励覆盖10988位激励对象，将核心员工利益与公司长期发展深度绑定。

**一句话评价：** 国企体制内相对优质的管理团队，战略方向明确（从通信商到科技服务商），激励到位，治理结构可信，短期业绩承压不改长期可信度。

## 七、风险在哪里？薄弱环节是什么？

**风险矩阵（★★★★★至★★★）：**

| 风险项                     | 严重程度 | 说明                                                                                                                     |
| -------------------------- | -------- | ------------------------------------------------------------------------------------------------------------------------ |
| 转型速度不及预期           | ★★★★★    | 算力和智能收入翻番目标宏大，若商业化落地不及预期，“第二增长曲线”可能被证伪，公司股价将重新锚定“缓慢萎缩的传统运营商”估值 |
| 增值税+传统业务双重挤压    | ★★★★     | 2025年净利润已同比下降0.9%，若传统收入降幅超出预期，将冲击全年股息预期                                                   |
| 上游产业链国际风险         | ★★★★     | 高端芯片、AI算力设备等高度依赖全球供应链，地缘政治冲突可能导致供应中断或成本飙升                                         |
| AI基础设施投资过度回报不足 | ★★★      | 公司大举投入智算设施（2026年算力资本开支+36.4%至378亿），若未来AI推理需求释放不及预期或算力供过于求，投入产出比将承压    |
| 通信网络信息安全           | ★★★      | 关键信息基础设施成为攻击重点，一旦出现安全事故可能影响业务连续性和企业声誉                                               |

**最薄弱一环：** “AI商业化变现速度”是最可能导致逻辑证伪的关键变量。中国移动的AI+战略逻辑清晰（“通信稳盘，算力智能翻番”），但2025年算力服务898亿、智能服务908亿的体量相比整体营收仍较小。“十五五”翻番目标意味着平均每年需保持约10-15%的复合增速。若大模型商业化节奏不及预期、政企客户对AI+DICT方案的接受度低于预期、或云市场价格战持续加剧，将直接冲击公司从“价值股”向“成长股”估值切换的核心逻辑。

## 八、未来会怎样？预测与判断

**短中期展望（1-2年）：**

业绩趋势上，传统通信服务收入预计继续小幅下滑1-2%，算力与智能服务保持双位数增长拉动总营收小幅增长（预测2025-2027年营收CAGR约3.4-3.7%，净利润CAGR约4.6-5.2%）。核心催化剂包括：（1）2026年算力资本开支同比提升36.4%至378亿元对算力服务收入增长的兑现情况；（2）AI智能终端、智能网联汽车、智能机器人等信息消费“新三样”产品的放量节奏；（3）派息率持续提升至75%以上。潜在压力：增值税调整影响持续显现、传统业务降幅若超预期可能拖累分红预期。

**长期终局判断（3-5年）：**

公司最终将蜕变为 **“算力+通信”双轮驱动的全球级科技服务企业**。“十五五”期间算力+智能服务收入翻番的目标若实现，这两大业务合计将占总营收的30%以上（目前约20%），届时公司的业务结构和估值逻辑将完成根本性重塑——从“电信运营商”转向“算力基础设施+AI服务商”。通信服务作为“经营压舱石”维持7000亿体量，算力与智能成为驱动利润增长的主引擎。如果转型成功，中国移动将不再与国际电信运营商对标（PE 10-12倍），而是与全球云/算力服务商（PE 20-30倍）对标。

**估值锚定：**

当前市场给的是“价值股+成长期权”的混合定价。纯通信运营商PE约10-12倍，A股移动2025年PE约16-17倍（诚通/中泰研报测算），港股约12倍，估值中已经包含了市场对“AI+数字化转型”的溢价预期。若转型进展顺利，存在估值重塑可能：算力与智能收入翻番后，公司的成长属性会被重新定价。风险在于，若AI商业化不及预期，估值可能向传统运营商均值（PE约12-13倍）回归。

**一句话结论：** 高股息筑底安全边际，AI+算力看翻番空间，但核心风险在于转型落地节奏——13亿移动用户基本盘稳固，性价比取决于你对AI故事的信度。
