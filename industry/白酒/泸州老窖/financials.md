## 前置步骤：公司理解、财报可信度初判与关键变量搜索

### Step 1：理解泸州老窖的生意

**这家公司靠什么赚钱？**

泸州老窖是中国浓香型白酒的代表性企业，以"双品牌（国窖1573 + 泸州老窖）、三品系、大单品"策略经营。从业务构成表可以清晰看到：

- **酒类收入占比 99.51%（2025年报）**，其中**中高档酒类（国窖1573、特曲、窖龄等，含税价≥150元/瓶）收入229.68亿元，占酒类收入89.26%**，毛利率高达 **90.94%**。
- 低端产品（头曲、黑盖等，含税价＜150元/瓶）收入26.38亿元，占10.25%，毛利率50.07%。
- **国窖1573稳居200亿元阵营**，是绝对的利润中心。

**商业模式特征：**

1. **品牌消费品模式**：面向终端消费者的品牌驱动型商业模式，具有极强的定价权和消费者黏性。
2. **高毛利率、低资本开支**：2025年毛利率86.62%，1元收入需要固定资产仅0.41元，属于典型的轻资产高盈利模式。
3. **经销商体系驱动**：传统渠道（线下经销）占收入94.13%，通过全国1701家境内经销商（2024年末数据）分销。
4. **预收款模式**：合同负债（预收经销商货款）的存在体现了对下游的议价能力。

**生意质量三重过滤：**

| 过滤维度                 | 评估      | 说明                                                                                                             |
| ------------------------ | --------- | ---------------------------------------------------------------------------------------------------------------- |
| **业务可理解吗？**       | ✅ 极清晰 | "卖高端白酒赚钱"——国窖1573是中国四大名酒之一，拥有450年窖池群，品牌故事和文化价值一目了然                        |
| **收入/客户可证实吗？**  | ⚠️ 需注意 | 经销商体系天然存在压货空间；但公司已推进"五码合一"数字化，以"开瓶率"验证真实消费；应收款仅1897万元，现金回款极好 |
| **模式依赖漂亮报表吗？** | ✅ 不依赖 | 自由现金流充沛（2024年FCF 179.93亿），历史累计分红605.6亿元远超融资额，不依赖外部融资                            |

**初判结论**：这是一门**可理解、可验证、现金流充沛**的顶级消费品生意。但经销商模式下的渠道库存风险需要在后续分析中持续警惕。

**2025年现金流骤降原因分析**：

- 经营现金流从2024年的191.82亿骤降至71.23亿（-62.86%），但2026Q1又回升至45.43亿（同比+37.35%）

- **结论**：利润含金量没有问题，现金流波动是主动经营策略的结果，而非盈利质量恶化

**② 经营现金流/净利润的波动**——2025年骤降至65.77%看似触目惊心，但结合业务背景：

- **这恰恰证明了不是回款能力出了问题，而是发货节奏导致了现金流的季度错配**

**③ 2019年FCF骤降至5.09%**——对应资本支出炸裂至46.05亿（同比+214%），这是产能大扩建年份，属于一次性投资高峰，不是盈利质量恶化。

1. **62% → 88%的史诗级提升（2016-2023）**：七年毛利率累计提升26个百分点。这不是成本下降——营业成本从30亿增至35亿基本持平——而是产品结构从低端向高端跃迁的结果。国窖1573从几十亿体量做到200亿+，高端占比从不到50%提升至近90%。

2. **88.30%的峰值（2023年）**：在白酒行业仅次于贵州茅台（约92%），远超五粮液（约76%）、洋河（约75%）。这个数字背后是：450年国窖窖池的稀缺性 + "浓香鼻祖"的品牌溢价。

3. **2024-2025年的回落（87.54%→86.62%）**：并非品牌力下降，而是：
   - 产品结构阶段性下移（低度1573增速快于高度、腰部特曲放量）
   - 国窖扫码红包等促销投入抵减收入
   - 智能化包装中心转固，制造费用分摊增加

4. **关键在于回落的幅度极小**：在收入下滑17.52%的2025年，毛利率仅下降0.92个百分点至86.62%。**这说明即使在最艰难的年份，定价权没有崩溃。**


**不是"公司不行了"，而是"行业寒冬 + 主动调整"**。证据：

| 阶段                | ROE区间 | 驱动因素            | 质量判断           |
| ------------------- | :-----: | ------------------- | ------------------ |
| 2017-2019（成长期） | 20-26%  | 净利率提升为主      | 高质量             |
| 2020-2023（鼎盛期） | 28-35%  | 净利率+杠杆双轮驱动 | 高质量但有杠杆隐忧 |
| 2024-2025（调整期） | 22-30%  | 杠杆和周转率双降    | 健康回归           |

**杜邦分解揭示的核心故事：**

1. **净利率是ROE的绝对主力**：从25.03%一路攀升至43.95%，贡献了ROE提升的80%以上。这是最优质的增长来源——品牌力、产品结构、规模效应共同驱动的盈利能力提升。

2. **周转率在持续下降**：从0.62降至0.39。原因有二：
   - 分母端：总资产从140亿膨胀至648亿（产能大建设）
   - 分子端：收入增速放缓
   - 这不是经营恶化，而是**产能投产到满产之间的正常"磨合期"**

3. **杠杆从1.54回归至1.30**：2021-2023年ROE高达31-35%，部分得益于1.5+的权益乘数。2024-2025年公司主动去杠杆，ROE自然回落至22-30%。**这个ROE水平的下降是健康的——它意味着公司不再需要用杠杆来维持高ROE。**

### 7.2 ROE趋势展望

2025年ROE降至22.66%，但这是**暂时的**：

- 当收入恢复增长（预计2027年），ROE有望回升至25-30%
- 净利率维持在42%+的高位，ROE的底很厚
- 权益乘数已降至1.30，未来加杠杆空间充足（如果需要的话）

### 7.3 ROIC与价值创造

| 年份 |  ROIC  | 特征           |
| ---- | :----: | -------------- |
| 2017 | 19.80% | 优秀           |
| 2019 | 24.61% | 极优秀         |
| 2021 | 27.49% | 巅峰           |
| 2023 | 29.38% | 历史最高       |
| 2024 | 25.06% | 回落           |
| 2025 | 19.37% | 回归"优秀"区间 |

ROIC持续高于15-20%，意味着每一元投入资本能产生0.19-0.29元的税后回报。这不仅远高于WACC（估算5-7%），而且在A股所有公司中处于顶级水平。

**2025年ROIC回落至19.37%**——这是2017年以来的最低值，但放在全球消费品公司中仍然是顶尖水平（可口可乐ROIC约15%，帝亚吉欧约12%）。

## 最终总结：综合投资结论

### 1. 这是一门什么样的生意？

泸州老窖是一门**以不可复制的历史资源（450年国窖窖池群）为根基、以强大品牌心智（"浓香鼻祖"）为壁垒、以数字化渠道管控为利器的顶级高端消费品生意**。

它的商业模式极其简单：买粮食→酿酒→存酒→卖酒，却产生了86.62%的毛利率和42.21%的净利率。这背后是：名酒基因的定价权 + 少喝酒喝好酒的消费趋势 + 经销商体系的规模杠杆。

**一句话总结**：这是一门巴菲特会喜欢的企业——简单、可理解、有护城河、不需要大量资本再投入、产生大量自由现金流。

### 2. 财报可信度评级：高 ✅

**核心支持证据：**

- 扣非净利润/净利润连续11年>99%，利润极度纯净
- 应收账款/收入<0.6%，几乎不存在赊销
- 经营现金流/净利润在正常年份持续>100%
- 商誉为零，无并购风险
- 审计意见为标准无保留，管理层长期稳定

**需要持续关注的风险点：**

- 渠道库存累积（2025年末库存+30%），去库存进度需跟踪
- 存货周转天数持续上升（1506天），需关注成品酒积压情况

### 3. 历史财务表现如何？

**极其优秀，堪称A股消费品公司的标杆。**

| 维度     | 评价       | 数据支撑                           |

**唯一的美中不足**：2024-2025年进入深度调整，营收利润双降。但这是在行业寒冬 + 公司主动控量背景下的阶段性调整，并非商业模式或竞争力的恶化。

### 5. 主要风险点在哪里？

**风险一：白酒行业调整深度超预期（概率：中等）**

- 若宏观经济持续低迷，商务消费长期不振，高端白酒的终端动销可能进一步恶化
- 当前市场预期2027年拐点，但若推迟至2028年，估值将进一步承压
- **监测信号**：2026年中秋国庆动销数据、国窖1573开瓶率

**风险二：渠道库存去化不及预期，引发价格战（概率：中低）**

- 若经销商信心持续不足，降价甩货可能从局部蔓延至全局
- 国窖1573价格体系的崩溃将直接动摇品牌根基
- **监测信号**：国窖批价跌破800元且无反弹、经销商数量持续净减少

**风险三：财报可信度风险（概率：极低）**

- 目前未发现任何危险信号。但经销商模式天然存在"压货做收入"的空间，需持续监测合同负债与渠道库存的匹配度
- **监测信号**：应收账款突然大增（目前几乎为零）、合同负债断崖式下降

### 6. 投资价值的初步判断

**这是一家在错误的价格交易了错误的情绪的优秀公司。**

- **商业模式优秀度**：⭐⭐⭐⭐⭐（顶级消费品，仅次于茅台）
- **财务质量**：⭐⭐⭐⭐⭐（A股标杆级）
- **管理层能力**：⭐⭐⭐⭐⭐（数字化改革领先行业）
- **当前经营压力**：⚠️ 严重但可逆（行业周期+主动调整）
- **估值吸引力**：从305元跌至100元以下，静态PE约13倍（基于2025年EPS 7.36元）

**定性判断**：泸州老窖正处于白酒行业深度调整的底部区域。短期业绩压力（2025-2026年）是事实，但核心竞争力（品牌、窖池、渠道、管理）未受损伤。当行业周期回暖（预计2027年），公司凭借200亿+国窖1573 + 100亿+泸州老窖品牌 + 突破百亿的低度1573三大增长引擎，有望重拾15-20%的增长。

**投资逻辑的核心矛盾**：市场在为一个"可能会持续下行"的剧本定价，而公司在为一个"行业终将回暖"的剧本做准备。273亿现金+23%负债率+每年85亿分红承诺，为长期股东提供了坚实的安全边际和等待的耐心资本。
