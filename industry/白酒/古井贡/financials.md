# 财务报表分析

## 前置步骤：公司理解、财报可信度初判与关键变量搜索

### 前置步骤一：理解公司的生意

#### 这家公司靠什么赚钱？

古井贡酒是中国老八大名酒之一，徽酒绝对龙头，核心收入来源为**白酒的生产与销售**：

| 维度         | 具体内容                                                                 |
| ------------ | ------------------------------------------------------------------------ |
| **核心产品** | 年份原浆系列（占收入~77%）、古井贡酒系列（~10%）、黄鹤楼及其他（~11%）   |
| **核心市场** | 华中地区（主要是安徽省内）贡献88.4%的收入，华南5.9%、华北5.6%、国际<0.1% |
| **商业模式** | 传统白酒产销型企业，通过经销商体系实现深度分销，"三通工程"深耕终端       |
| **竞争地位** | 徽酒四家上市企业中稳固龙头，营收规模远超迎驾贡酒(60亿)和口子窖(40亿)     |

#### 生意质量三重过滤

**1. 业务可理解性：✅ 通过**

一家酿酒企业，把粮食酿成白酒，通过经销商卖到终端，赚品牌溢价和渠道效率的钱。能用"妈妈法则"两分钟讲清楚。

**2. 收入/客户可证实性：⚠️ 有瑕疵但可控**

- 下游经销商近5000家，较为分散，但渠道库存的真实情况依赖公司主动信息披露
- 白酒行业的经销商模式天然存在"压货"空间——这是行业通病，并非古井独有的问题
- 2025年公司主动去库存、净减经销商224家，渠道数据可追踪，**透明度在改善而非恶化**
- 但Q4亏损+商誉减值+收现下滑应被视为"主动出清"or"被迫爆雷"的边界信号，需持续观察

**3. 模式依赖漂亮报表：✅ 通过**

- 自由现金流历史上表现优异（2016-2024年累积极其正向），不依赖外部融资
- 2025年自由现金流骤降至2.84亿（自由现金流/净利润=8%），**但这是短期剧烈调整的结果，并非模式性缺陷**
- 账上有145亿现金，有息负债仅5.94亿，财务极端保守安全

### 二、财务异常信号扫描（第二道防线）

#### 2.1 利润质量扫描 — 运用"虚增利润=虚增资产"方程式

| 指标              | 历史表现                                    | 判断                      |
| ----------------- | ------------------------------------------- | ------------------------- |
| 经营现金流/净利润 | 2016-2024年均值约103%，但2025年骤降至54.86% | ⚠️ 2025年恶化，需分析原因 |
| 扣非净利润/净利润 | 历史均值96%+，2025年为98.32%                | ✅ 利润来源于主业         |
| 经营利润/净利润   | 历史均值93%+，2025年为100.68%               | ✅ 主业专注度高           |

**关于经营现金流骤降的分析：** 2025年经营现金流/净利润从2024年的85.69%降至54.86%，降幅显著。研报信息显示：①销售收现202.6亿，同比-12.7%，但降幅远小于收入降幅（-20.1%），说明回款质量尚可；②Q4亏损叠加商誉减值3.15亿，非现金流支出拉大了净利润与现金流的剪刀差；③2026Q1经营现金流/净利润已恢复至118.95%。**结论：2025年的现金流恶化是收入降速+非现金减值的叠加效应，不是系统性现金流危机。**

#### 2.2 收入与资产联动异常扫描

| 指标                         | 趋势                                       | 判断                         |
| ---------------------------- | ------------------------------------------ | ---------------------------- |
| 应收账款/营收                | 历史3-13%，2025年5.04%，2026Q1飙升至42.02% | ⚠️ Q1季节性+主动放宽回款所致 |
| 存货/营收                    | 从2020年33.20%升至2025年57.03%             | ⚠️ 库存积累显著              |
| 存货年化增速 vs 收入年化增速 | 5年存货CAGR 25.74% vs 收入CAGR 12.84%      | ⚠️ 存货增长远超收入          |

**2026Q1应收账款暴增的分析：** Q1应收占收入比42%，远高于历史5-13%。研报明确指出"公司主动放宽回款要求纾压经销商"，同时"应收款项融资同比增长239%"。**这是主动行为，非被动坏账积累**，但需要持续跟踪Q2-Q3是否回落。

**存货积累的分析：** 白酒行业存货增长具有特殊性——基酒越陈越值钱，不能简单等同于"积压"。但古井存货从2021年的46.63亿增至2025年的107.40亿（5年CAGR 25.74%），远超同期收入（5年CAGR 12.84%），值得警惕。如果是成品酒库存积累过快而非基酒储备，则对应渠道动销不畅。

#### 2.3 "存贷双高"扫描

| 指标     | 2025年末                                          | 判断    |
| -------- | ------------------------------------------------- | ------- |
| 现金     | 141.87亿                                          | 充裕    |
| 有息负债 | 5.82亿                                            | 极低    |
| 利息收入 | 公司确认2025年利息收入增长50%，因大额存单集中到期 | ✅ 正常 |

**结论：不存在"存贷双高"问题。** 有息负债率仅1.52%，管理层解释"借款为子公司用于项目投资"，负债规模相对于145亿现金微不足道。

#### 2.4 投入产出异常扫描

| 工具                  | 趋势                    | 判断                        |
| --------------------- | ----------------------- | --------------------------- |
| 1元收入需要的WC       | 2016年0.24→2025年0.42   | ⚠️ 持续上升，竞争力弱化信号 |
| 1元收入需要的固定资产 | 2016年0.32→2025年0.49   | ⚠️ 资产变重                 |
| 折旧摊销/收入         | 2016年4.09%→2025年4.24% | 相对稳定                    |

**"1元收入需要的WC"持续上升，从2016年的0.24升至2025年的0.42，5年CAGR 4.49%。** 这意味着每创造1元收入需要占用越来越多的营运资本——这是竞争力弱化或信用政策放宽的经典信号。但需结合白酒行业特殊性和2025年渠道调整来理解。

**"1元收入需要的固定资产"也持续上升。** 这与公司智慧园区等产能扩建项目有关，但固定资产增速（5年CAGR 34.87%）远超收入增速（5年CAGR 12.84%），需要警惕固定资产是否被高估，以及在收入减速背景下是否存在产能过剩风险。

#### 2.5 非经营科目异常

未发现"其他应收款"、"预付款项"等科目存在非商业性大额挂账。公司明确否认"控股股东侵占上市公司资金"。

### 三、业务异常信号扫描（第三道防线）

#### 3.1 商业常识检验

| 指标       | 古井贡酒2024 | 行业对比                                         |
| ---------- | ------------ | ------------------------------------------------ |
| 毛利率     | 79.90%       | 茅台~92%、五粮液~77%、老窖~87%、汾酒~76%         |
| 净利率     | 23.40%       | 茅台~49.5%、五粮液~35.7%、老窖~43.2%、汾酒~34.0% |
| 销售费用率 | 26.22%       | 茅台~3.2%、五粮液~12.0%、老窖~11.3%、汾酒~10.3%  |

**古井的毛利率在浓香型白酒中处于一流水平（79.9%），但净利率（23.4%）显著低于同梯队公司，核心原因是销售费用率高达26.22%**，远超五粮液（12%）、老窖（11.3%）、汾酒（10.3%）。这反映了古井"高投入高产出"的渠道驱动模式——利润空间大量消耗在地面推广和经销商激励上。这并非造假信号，而是一种商业模式的代价。

#### 3.2 经销商压货风险

这是白酒行业最大的"灰色地带"。古井的渠道模式意味着终端动销的真实性是所有数据可信度的命门。2025年的主动去库存（净减经销商+合同负债下降+放宽回款）可以被解读为"诚实出清"，也可能意味着此前的高增长在一定程度上依赖渠道囤货。

### 四、财报可信度综合定级

#### 评级：**中高可信（80分）**

**定级理由：**

1. **✅ 审计无问题**：标准无保留意见，无监管问询，无会计差错
2. **✅ 利润结构真实**：扣非/净利润>96%，经营利润/净利润>93%，主业绝对专注
3. **✅ 现金流历史优秀**：2016-2024年经营现金流/净利润均值~103%，赚的是真钱
4. **⚠️ 2025年出现阶段性压力信号**：现金流恶化+存货快速积累+应收飙升，但这些是行业周期下行+公司主动出清的结果
5. **⚠️ "1元收入需要的WC"持续上升**：最值得长期跟踪的负面信号
6. **⚠️ 经销商模式天然存在压货空间**：需要持续关注合同负债和渠道库存数据

**最终判断：财报基本可信，但行业周期下行的财务压力正在放大某些结构性问题。当前不存在系统性造假风险，但2025年的数据混乱期需要审慎解读。**

**核心解读：**

> ROE的未来取决于三个关键变量：
> ①**净利率能否回升**：取决于产品结构何时能重新升级、费用率在高基数上如何优化；

## 最终总结：综合投资结论

### 1. 这是一门什么样的生意？

**古井贡酒是一门"品牌×渠道×根据地"三重驱动的传统消费品生意。**

- **品牌端**：作为中国老八大名酒之一，"古井贡酒"四个字自带深厚的历史信用和品牌溢价能力。
- **渠道端**：通过10年以上"三通工程"的持续深耕，形成了对安徽市场近乎毛细血管级的终端掌控——这是古井最核心的护城河。
- **根据地板**：安徽大本营贡献88.4%的收入，省内消费者基础极其稳固，竞争对手（迎驾贡酒、口子窖）无论规模还是品牌力都存在明显差距。

这门生意的本质是"守正出奇"：守省内之正（稳如磐石的基本盘），出省外之奇（全国化是成长期权）。当前行业寒冬中，"守正"的能力经受住了考验，"出奇"的努力遭遇了重大挫折。

### 2. 财报可信度评级：中高可信（80分）

**支持证据：**

- ✅ 审计标准无保留意见，无监管负面记录
- ✅ 利润结构纯净：扣非/净利润>96%，主业专注度极高
- ✅ 2016-2024年经营现金流/净利润均值~103%，历史现金流质量优秀
- ✅ 无"存贷双高"，145亿现金 vs 5.94亿有息负债，财务极其安全

**关注信号：**

- ⚠️ 2025年经营现金流/净利润降至54.86%（2026Q1已恢复至118.95%）
- ⚠️ "1元收入需要的WC"从0.20升至0.42，竞争力效率在弱化
- ⚠️ 存货5年CAGR 25.74%远超收入5年CAGR 12.84%

**整体判断：财报可信，未发现系统性造假信号。2025年数据"乱"是周期底部的正常表现，不是造假。**

### 3. 历史财务表现如何？

**在可信任的基础上，古井的历史财务表现极其亮眼：**

- 9年营收CAGR 13.52%，净利润CAGR 17.53%——**利润增速持续快于收入增速，是效率提升的明证**
- ROE长期维持在17%-24%——**属于A股最顶级水平的价值创造能力**
- 自由现金流长期正向且充裕（除2019、2025两个异常年份）
- 资产负债率稳定在31%-37%，极其保守稳健

**但2025年标志着"黄金十年"的终结：** 营收-20.1%，净利润-35.7%，ROE从23.89%降至14.28%。这究竟是"周期性的调整"还是"增长天花板的到来"，是当前最核心的判断问题。

### 5. 主要风险点在哪里？

#### 风险一：渠道库存的出清时间与幅度超预期 ⭐⭐⭐

如果终端动销持续低迷，当前"主动出清"可能在半年后变成"被迫出清"，导致报表下滑幅度加大。合同负债是跟踪这个风险的最佳指标。

#### 风险二：省外市场持续萎缩 ⭐⭐

华北市场-46.5%不仅是周期问题，更反映了古井品牌在省外的根基薄弱。如果省外市场在行业回暖后仍无法恢复，则"全国化"这个成长故事将不复存在。

#### 风险三：产能过剩 ⭐⭐

固定资产5年CAGR 34.87%远超收入12.84%，智慧园区建成后的产能利用率将成为远期盈利的重要变量。如果行业容量不能支撑扩产后的产能，折旧将拖累利润。

#### 风险四：财报造假风险（低概率但高影响） ⭐

虽然当前评级为"中高可信"，但经销商白酒企业的"压货空间"始终存在。如果未来发现此前的增长大量依赖渠道囤货而非真实终端动销，股价将面临戴维斯双杀。

### 6. 投资价值的初步判断

#### 正面论据：

- 徽酒龙头低位稳固，安徽大本营近乎垄断
- 财务极端安全：145亿现金，极低负债
- ROIC持续高于WACC，长期创造正向经济价值
- 当前PE约15倍（2026年预测），相对于历史20-30倍估值有安全边际
- 65%分红率对应4%股息率，提供明确的底部支撑
- 机构100%给予买入/增持评级，一致目标价130.82元（上涨空间52%）

#### 负面论据：

- 行业仍处于"下行趋缓"阶段，底部尚未确认
- 全国化进程出现重大回撤
- 投入产出效率持续恶化（WC/收入、固定资产/收入双向上升）
- 产品结构下移压缩利润空间
- 合同负债未见企稳信号

#### 框架性投资评价：

**古井贡酒是一家具"优质基本面、阶段性困境、估值已部分反映悲观预期"特征的公司。** 它不是"买入即躺赚"的标的——行业周期底部的时点和幅度都充满不确定性——但对有耐心的长期投资者而言，当前价格正在提供：①低于历史均值50%的估值水平；②4%的保底股息率；③徽酒龙头在行业出清中大概率受益的竞争格局。

**定性分类：属于"周期底部区域"的投资机会，而非"确定性成长"的投资机会。** 适合对白酒行业周期有深刻理解、愿意等待1-3年的投资者。不适合追求短期确定性的投资者。
