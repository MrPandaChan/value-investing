# 财务报表分析

## 前置步骤：公司理解、财报可信度初判与关键变量搜索

### Step 1：理解公司的生意并初判生意质量

**这家公司靠什么赚钱？**

山西汾酒是中国清香型白酒的绝对龙头，也是"四大名酒"之一。公司核心商业模式极其简单——**采购高粱等原料 → 酿造基酒 → 勾调成品酒 → 通过经销商网络销售给终端消费者**。2025年食品制造业收入占比99.68%，是一门高度聚焦的单一主业生意。

**生意质量三重过滤：**

| 维度               | 评估                                                                                                                                | 结论    |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------------------- | ------- |
| **可理解性**       | 白酒生意模式极其简单易懂——"粮食+水+时间=品牌溢价"，两分钟即可向普通人讲清                                                           | ✅ 通过 |
| **可证实性**       | 下游经销商超3000家，终端消费者亿级，极度分散；现金交易在白酒行业普遍但大商模式为主流，可追踪性强；产品物理形态明确，库存/产能可盘查 | ✅ 通过 |
| **模式不依赖融资** | 自由现金流常年充沛，账上现金97.67亿元（2025年末），有息负债仅1.97亿元（占比0.35%），完全不需要外部融资支撑经营                      | ✅ 通过 |

**生意质量综合判断：优秀。** 白酒是A股商业模式最优的赛道之一，而汾酒具备品牌壁垒、轻资产运营、强现金流的核心特征。

**经营现金流波动分析（重点）：**

2018（63.42%）、2020（65.27%）、2023（69.22%）、2025（73.60%）这四年经营现金流显著低于净利润。结合合同负债（预收经销商款项）变化，可以解释主要波动：

- **2023年**：合同负债从69.08亿元降至70.29亿元（仅微增），而存货从96.50亿增至115.73亿（+19.23亿），存货大幅增加消耗了大量现金。
- **2025年**：合同负债从86.72亿元降至70.07亿元（-16.65亿元）——经销商提取了大量预付款对应的货物，但新增预收款减少，这直接减少了经营现金流入。同时存货继续增加（132.70→143.92，+11.22亿）。

**核心判断**：现金流的波动并非利润造假，而是白酒行业特有的"渠道库存周期"在财务报表上的体现。当行业景气下行、经销商去库存时，合同负债下降+存货上升会暂时压低经营现金流。这属于商业模式固有特征，而非财务操纵。**2025Q4合同负债环比+12.26亿元、2026Q1销售收现+16.18%的信号表明，最困难的去库存阶段可能正在过去。**

**关键发现：**

1. **扣非净利润占比常年＞96%**：净利润几乎全部来自白酒主业，不存在靠卖资产、政府补贴、金融投资粉饰报表的情况。这是A股最纯正的主业驱动型利润结构之一。

2. **经营现金流/净利润的周期性波动（核心看点）**：
   - 高景气期（2019、2021、2022、2026Q1）：经销商积极打款→合同负债增加→经营现金流远超净利润，比率达127%-153%
   - 调整期（2023、2025）：经销商去库存、减少打款→合同负债下降→经营现金流低于净利润，比率降至64%-74%

   **这不是利润质量恶化的信号，而是白酒"DCF前置"商业模式的必然结果**——经销商先打款（现金流入），酒企后发货确认收入。当行业景气下行时，经销商减少预付款，导致当期现金流入减少，但利润表不受直接影响（因为发货确认的是之前的预收款）。这就是为什么2025年净利润持平但经营现金流仅73.60%——本质是"渠道在消耗之前预缴的弹药"。

3. **2026Q1的"异常"强现金流**：经营现金流/净利润=153.34%，收入+Δ合同负债同比+15.74%，销售收现+16.18%——这说明在利润表显示收入下降9.68%的表象之下，真实经营质量在改善。这个指标的解读至关重要。

1. **"毛利率-净利率"剪刀差持续缩小**：从2016年的54.94%压缩到2025年的43.22%，缩小了11.72个百分点。这说明费用端的规模效应极为显著——收入增长了近9倍，而期间费用率从27.24%降至14.74%。

2. **2025年毛利率首次明显下滑（-1.35pct）**：这是本轮分析中最值得警惕的信号之一。
   - **原因**：产品结构下移——高毛利的青花系列增速放缓（+5%+），而相对低毛利的玻汾系列增速较快（+15%+），拉低了整体毛利率。
   - **与行业对比**：茅台2025年毛利率维持92%+，五粮液约75%，汾酒74.85%仍属于行业顶尖水平。

3. **毛利率的"底座"分析**：清香型白酒的酿造成本天然低于酱香型（茅台）和浓香型（五粮液），这是香型特征决定的比较优势。汾酒74.85%的毛利率虽然低于茅台的92%，但在清香型中已是绝对天花板。

### 2. 费用率效率：规模效应的极致演绎

| 年份 | 销售费用率 | 管理研发费用率 | 期间费用率 | 收入(亿) |
| ---- | ---------- | -------------- | ---------- | -------- |

| 2021 | 15.82%     | 5.96%          | 21.61%     | 199.71   |
| 2023 | 10.07%     | 4.04%          | 14.09%     | 319.28   |

**这是一张教科书级别的"规模效应"案例：**

- 收入从44亿增长到387亿（8.8倍），期间费用率反而从27.24%降到了14.74%——**每1元新增收入需要的增量费用在不断降低**。
- 销售费用率在2019年曾达到峰值21.39%（全国化扩张期的大量投入），此后持续下降。这说明早期投入正在进入收获期——品牌认知度建立后，维持市占率所需费用占比自然下降。
- **警惕信号**：2024-2025年销售费用率略有回升（10.07%→10.35%→10.59%），说明在行业调整期，公司可能需要加大费用投入来推动动销。

### 3. 研发投入：白酒不需要"研发驱动"

研发费用率仅0.45%（2025年），这完全正常——白酒行业的核心竞争力是品牌、历史和酿造工艺传承，而非技术创新。研发费用低且全部费用化（不资本化），是财务保守的好信号。

### 2. 增长趋势诊断：从"狂飙"到"换挡"

**增速变化呈清晰的三阶段特征：**

```
2016-2021：高速放量期（营收CAGR ~35%）
  驱动力：全国化渠道铺设 + 玻汾大单品放量 + 消费升级承接
  ↓
2022-2024：结构升级期（营收CAGR ~15%，净利CAGR ~20%）
  驱动力：青花系列占比提升 → 毛利率和净利率双升
  ↓
2025-2026Q1：深度调整期（营收+7.5%→Q1-9.7%，净利+0.03%→Q1-19%）
  驱动力消失：行业需求收缩 + 渠道去库存 + 高端消费疲软
```

**核心判断**：这不是汾酒一家的问题，而是整个白酒行业正在经历的"深度调整期"。对比同行：

| 公司         | 2025年表现                 | 库存状况               |
| ------------ | -------------------------- | ---------------------- |
| 贵州茅台     | 营收首降（上市以来首次）   | 成品酒库存+45.18%      |
| 五粮液       | 利润暴跌72%                | 库存量大幅攀升         |
| 泸州老窖     | 营收净利双降               | 存货5年+227%           |
| 洋河股份     | 利润腰斩                   | 主动控量稳价           |
| 酒鬼酒       | 2014年以来首次年度亏损     | —                      |
| **山西汾酒** | **营收+7.52%，净利+0.03%** | **存货增速与营收匹配** |

汾酒是头部酒企中**最具韧性**的一家——在茅台上市首降、五粮液利润暴跌72%的行业寒冬中，汾酒仍然实现了正增长。

### 3. 增长模式识别：纯内生驱动

- 商誉为**0**——没有外延并购带来的增长水分

**杜邦分析揭示的真相：**

1. **ROE主要由净利率驱动**（2017年16.63%→2025年31.76%），这是最高质量的ROE来源——代表产品定价权和品牌溢价带来的真实盈利能力，而非靠加杠杆的"虚胖"ROE。

2. **权益乘数持续下降**（2.11→1.40）：公司在主动"去杠杆"（减少负债占比）的同时ROE仍高达33.48%，说明盈利能力的提升远超杠杆下降的影响——这是最健康的ROE扩张路径。

3. **资产周转率基本稳定**（0.71-0.84）：作为一家轻资产消费品公司，周转率保持稳定是正常且健康的。

4. **ROE的下降趋势（44.74%→33.48%）**需要正视：
   - 净利率从34.03%→31.63%（-2.4pct）——行业竞争加剧+产品结构下移
   - 周转率从0.79→0.71——收入增速放缓，资产仍在增加
   - 杠杆从1.69→1.40——主动降低负债率

   **ROE从45%降至33%不是危机，而是从"极其优秀"回归到"非常优秀"**。33%的ROE在A股所有上市公司中仍然属于前5%的水平。

## 最终总结：综合投资结论

### 1. 这是一门什么样的生意？

山西汾酒是一门**拥有千年品牌积淀、清香型白酒绝对龙头地位、全价格带覆盖、全国渠道网络的顶级消费品生意**。其商业模式的核心是"品牌×渠道×产能"的正向循环：品牌吸引力和历史积淀（中国四大名酒、清香型鼻祖）→驱动经销商积极打款→资金支持全国化渠道铺设和产能扩建→更广泛的消费者触达进一步强化品牌力。

这门生意的"优雅"之处在于：**每1元新增收入需要的增量投入越来越少**（规模效应），**每1元投入的资本回报极高**（轻资产），**赚到的几乎都是真金白银**（先款后货）。这在A股消费品公司中属于最顶级的商业模式之一。
