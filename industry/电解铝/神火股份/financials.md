## 前置步骤：公司理解、财报可信度初判与关键变量搜索

### Step 1: 理解公司的生意并初判生意质量

**神火股份靠什么赚钱？**

公司是一家"煤电铝一体化"企业，核心盈利来源有三层：

| 业务板块 | 2025年收入（亿元） | 收入占比 | 利润贡献角色               |
| -------- | ------------------ | -------- | -------------------------- |
| 电解铝   | 289.79             | 70.27%   | **绝对核心利润中心**       |
| 煤炭     | 55.96              | 13.57%   | 第二利润来源，周期性波动大 |
| 铝箔     | 28.65              | 6.95%    | 产业链延伸，成长型业务     |
| 其他     | 38.00              | 9.22%    | 贸易、发电、碳素等         |

**商业模式特征：**

1. **一体化降本**：新疆基地（80万吨电解铝）依托自有煤炭+坑口电厂，电力成本约0.236元/度，处于国内电解铝成本曲线最左端；云南基地（90万吨）利用水电，丰水期成本优势显著。这种"煤电铝一体化"是公司最核心的护城河。

2. **双资源品属性**：公司同时暴露于铝价和煤价。2022年煤铝共振上行是业绩巅峰（归母净利润75.78亿），此后两者均下行，2025年归母净利润降至40.05亿。

3. **重资产行业**：煤矿+电解铝+自备电厂，固定资产/收入比约0.59（2025年），属于重资产模式，但近年持续下降。

**生意质量三重过滤：**

| 过滤维度          | 评估    | 说明                                                                                         |
| ----------------- | ------- | -------------------------------------------------------------------------------------------- |
| 业务可理解性      | ✅ 通过 | 挖煤 → 发电 → 电解铝 → 铝箔加工，产业链清晰，可用"妈妈法则"讲清                              |
| 收入/客户可证实性 | ✅ 通过 | 电解铝和煤炭均为大宗商品，有公开市场报价，价格可独立验证；下游客户为冶金、电力等大型工业企业 |
| 模式依赖融资吗？  | ✅ 通过 | 自由现金流近年持续为正，经营现金流充裕，资产负债表快速去杠杆，无需持续融资                   |

### 6. 投资价值的初步判断

**综合评价：周期底部的低成本龙头，下行有底、上行有弹性。**

- **商业模式优秀但具有周期性**：新疆低成本电解铝是真实护城河，但70%收入暴露于铝这一单一商品价格，存在天然的周期波动。
- **财务质量极高**：去杠杆完成、现金流充裕、分红提升，财务风险已降至历史最低。
- **当前处于周期底部区域**：利润较2022年峰值腰斩，但煤炭Q3已触底反弹、氧化铝成本大幅下降、铝价在供给刚性下中枢有望上移。
- **估值合理偏低**：2025年PE约11-14倍（基于当前股价和40亿净利润），低于可比公司均值13.3倍；股息率约3%，属于红利+周期的双重属性标的。
- **关键催化剂**：①2026年铝价中枢上移至21500-22000元/吨（多家券商共识预测）；②氧化铝持续低位运行；③煤炭盈利触底回升；④分红比例继续提高。

**框架性结论**：神火股份是一家在周期底部区域、财务质量蜕变、具备真实成本护城河的优质资源型企业。其最大特征是**下行有底（成本行业最低）与上行有弹性（铝价上涨时吨利弹性极大）的不对称风险收益结构**。当前估值合理偏低，适合作为"周期底部+红利+商品上行期权"配置。主要跟踪变量：铝价-氧化铝价差走势、云南电力供给、煤炭价格反弹幅度。
