# 估值和结论

## 核心结论

小商品城本质是 **"重资产收租+一次性卖楼+贸易服务"** 的混合体。2026年为利润峰值年（合同负债集中释放），2027年断崖，2028年靠内生增长爬出坑。

以下估值**完全剔除选位费和卖楼等一次性收入**，仅针对可持续核心业务。

## 一、核心假设

| 项目              | 假设值        | 依据                  |
| ----------------- | ------------- | --------------------- |
| 老市场租金年增速  | 4%（保守）    | 合同锁定≥5%，保守取4% |
| 贸易服务增速      | 35%→30%→25%   | 高基数下放缓          |
| H股股本稀释       | 10%           | 发行上限10%           |
| 七区折旧+利息拖累 | 0.6→1.2→1.8亿 | 建设转固节奏          |

## 四、一句话结论

当前市值按2028年核心利润44.3亿计算约**12.4倍PE**（未考虑H股稀释），处于10倍（纯REITs）和14倍（含成长溢价）之间，**合理偏贵，安全边际不厚**。H股稀释10%后，对应股价约9.3-11.0元（15-18倍PE）。
