# 非财务信息“八问”

## 靠什么赚钱？核心驱动力是什么？

**生意本质**：安踏赚的是"品牌矩阵运营+全渠道零售"的钱——通过多品牌并购和自有孵化，以不同定位的品牌覆盖从大众到高端、从专业运动到时尚休闲的全场景需求，以DTC直营模式和电商渠道最大化品牌变现效率。

**收入与利润结构**：安踏品牌/FILA/其他品牌三大事业群呈现"1稳2高3快"格局。2025年营收结构为安踏品牌（占比43.3%）和FILA（占比35.5%）构成"双基石"，其他品牌（迪桑特+可隆等，占比21.2%）快速追赶，经营利润占比分别为38%/39%/25%，印证户外品牌群盈利能力已和主品牌并驾齐驱。鞋服业务占比均衡（约40%鞋/55%服），正形成抗周期的"双支柱"。

**核心驱动力**：从量增切换到质增。门店总数已见顶（安踏~9900家、FILA~2000家），增长已从"开店驱动"切换到"店效驱动"。核心引擎有三：① **店效提升**，安踏冠军店效是传统门店的2倍，超级安踏达3倍；② **产品结构升级**，PG7系列年销破400万双，C家族突破120万双，客单价持续上移；③ **全球化拓展**，东南亚"千店计划"、北美进驻Foot Locker等主流渠道。

## 顺风还是逆风？外部大环境好不好？

**宏观定性**：结构分化周期——综合性运动赛道竞争白热化，但细分垂类（户外/跑步/菁英运动）需求高速膨胀，适逢安踏集团多品牌布局深度契合结构性红利方向。

**顺风清单**：

- **户外经济井喷**：2025年户外鞋服细分市场规模已超千亿，预计2028年突破1500亿（CAGR 15%+）。迪桑特、可隆正处放量期，与行业α形成完美共振。
- **运动渗透率持续提升**：户外运动参与人数突破4亿，国民健康意识被疫情彻底重塑，运动鞋服赛道近五年持续增长，2025年同比增长7.38%，韧性显著优于服装大盘。
- **国牌替代窗口期**：耐克大中华区市占率从2021年18.1%降至2024年15.1%，阿迪达斯虽复苏强劲但整体不确定性仍存，安踏集团借多品牌矩阵持续扩大份额。
- **政策红利纵深释放**：全民健身计划、冰雪运动推广、金融支持体育产业等政策层层递进，从基建到消费全面拉动运动需求。

**逆风清单**：

- **综合性市场竞争白热化**：耐克尚处调整期但全球体量巨大，阿迪达斯大中华区连续十二季度增长强势反弹，李宁完成奥运营销锁定，各品牌在专业运动领域鏖战加剧。
- **主品牌增长换挡**：安踏品牌2025年增速降至3.7%，从双位数切换至中单位数。大众运动市场的存量博弈和京东、拼多多等渠道分销的分流，正侵蚀原有基本盘。
- **消费分层与价格战挤压**：运动鞋服行业量价分化明显（鞋类价跌量增、服装量价齐升），中低端因"以价换量"导致毛利率承压，安踏主品牌毛利率2025年下滑0.9pct至53.6%。
- **出海地缘风险**：欧美贸易保护主义抬头、国际地缘政治不确定性，对安踏主品牌海外扩张和PUMA收购整合带来跨境管理复杂性。

## 空间有多大？天花板在哪里？

**第一增长曲线见顶判断**：安踏和FILA线下门店数基本见顶（安踏~9900家，FILA~2000家），未来增长靠店效提升贡献。中国市场运动渗透率仅15%，比肩美欧（30%+）仍有翻倍空间，但渗透率的持续提升需依赖下一代消费者的运动消费习惯养成，是结构渐变而非数字跃迁。

**第二增长曲线储备**：三条主线的接力逻辑清晰——

- **户外品牌群**（迪桑特+可隆）：2025年合计营收达170亿元，同比增长59%。迪桑特年流水已破百亿，可隆突破60亿，目前店效分别为270万/月和200万/月。对标日本迪桑特人均5000元消费水平，中国市场渗透率仍有数倍提升空间。
- **Amer Sports（联营公司）**：2025年为安踏贡献利润12亿元，2026Q1自身营收大增32%，全年指引提升至+20%–22%。始祖鸟、萨洛蒙、威尔胜三大引擎尚未完全释放势能，叠加DTC渠道占比已超44%，是安踏隐藏的"利润加速器"。
- **PUMA收购（拟）**：15亿欧元收购29%股权成为第一大股东，预计2026年底完成，完善全球化大众运动拼图，长期有望赋能其战略重塑。

**天花板量化预估**：中国市场2030年运动鞋服市场规模有望达8963亿元（CAGR ~8%），综合运动品牌CR5约52.5%，安踏集团当前市占率约10.5%，在多品牌矩阵持续渗透下，2030年集团营收有望达到~1300-1500亿元（2025年802亿为基数，CAGR 10%+）。全球视角下，亚玛芬体育+PUMA+迪桑特海外业务有望构成第二成长极。

## 竞争格局好不好？玩法是什么？

**行业梯队地图**：运动行业属典型的"塔尖集中、长尾多元"。安踏集团（2025年802亿营收，按品牌分约10.5%市占率）是综合性大众运动赛道的第一梯队；李宁（营收296亿，毛利率49%）主攻中高端专业时尚；特步（141.5亿，毛利率42.8%）、361度（111.5亿，毛利率41.5%）稳固中低端基本盘。国际方面，耐克大中华区仍在调整，阿迪达斯大中华区2026Q1保持双位数增长。高端/垂类市场则由lululemon、始祖鸟、昂跑等切入防守。

**竞争核心要素**：这个行业拼的是 **"品牌矩阵广度 × 单品运营深度 × DTC渠道控制力"** 。消费分层越极化，单一品牌越难覆盖全客群；只有多品牌矩阵才能实现"降维打击"。

**利润率密码**：行业毛利的"金字塔效应"明显——安踏主品牌毛利率~54%，FILA~66%，其他品牌（迪桑特/可隆）~72%。高毛利品牌占比持续扩大，驱动综合毛利率从2019年55%升至2025年62%。净利率方面，2025年安踏、李宁、特步、361度分别为16.9%、9.9%、9.7%、11.7%，安踏集团显著领先。利润率的决定权在于：品牌溢价能力（决定毛利率中位数）和DTC占比（决定利润的兑现效率），安踏DTC占比约35%，仍有提升空间。

## 有什么优势？护城河在哪？

**对比表格**（安踏体育 vs 李宁 vs 特步 vs 361度，数据为2025年）：

| 对比维度 | 安踏集团                  | 李宁       | 特步          | 361度     |
| -------- | ------------------------- | ---------- | ------------- | --------- |
| 营收规模 | 802亿                     | 296亿      | 141.5亿       | 111.5亿   |
| 毛利率   | 62.0%                     | 49.0%      | 42.8%         | 41.5%     |
| 净利率   | 16.9%（剔除一次性因素后） | 9.9%       | 9.7%          | 11.7%     |
| 品牌矩阵 | 全价位+全场景             | 主品牌单核 | 跑步专业+大众 | 大众综合  |
| DTC占比  | 安踏主品牌约35%           | 约40%-45%  | 约20%-25%     | 约15%-20% |

**独特护城河阐述**：

**① 品牌并购与矩阵运营的"飞轮效应"**——不仅是买品牌，更是构建"品牌运营平台"。从FILA十年运营（年收266亿）、迪桑特儿童破圈，到收购狼爪次日即换帅原亚玛芬操盘手姚剑快速整合，体系化品牌重塑能力是竞对无法复制的稀缺资产。

**② DTC渠道对终端价格与库存的双重控制力**——安踏主品牌DTC+电商占比超过70%，FILA全直营。直营化不仅让毛利率提升显著，更让安踏在消费波动时能敏捷调整终端折扣和库存周期，抗风险能力显著优于批发模式为主的竞争品牌。

**③ 从体育IP到爆品IP的转化效率**——欧文签名鞋、PG7百万销量、C家族爆款矩阵…品牌资源向商品转化的"品效合一"速度，在执行力高度标准化的"铁军"文化下，竞争对手难以追赶。

## 管理层行不行？治理有没有雷？

**管理层画像**：丁世忠继续担任董事局主席，赖世贤、吴永华以联席CEO分掌主品牌/FILA及海外业务。核心团队从金融危机、行业低谷到多品牌扩张一路共事，经历数轮周期考验。股权结构上丁氏家族合计持股约52.7%，中长期利益与公司深度绑定。

**值得关注的红灯预警**：

- 近一年ESG争议频发：始祖鸟生态丑闻、年度反腐风暴等多重负面舆论冲击品牌形象，治理层面存在与"ESG优质企业"宣传的割裂感。
- 家族色彩浓重，二代进入一线管理层——丁少翔掌管MAIA ACTIVE直面lululemon，若管理能力未能跟上，可能带来局部业务的运营风险。
- 2026年5月，执行董事毕明伟减持0.79万股，金额虽小但方向值得持续关注。

**一句话评价**：管理层专业能力强、战略执行坚定，但公司治理的家族色彩和ESG争议持续是中长期必须解决的结构性议题。

## 风险在哪里？薄弱环节是什么？

**风险矩阵**（按严重程度排序★★★★★至★★★）：

| 风险项               | 等级  | 本质原因                                                                                                   |
| -------------------- | ----- | ---------------------------------------------------------------------------------------------------------- |
| 主品牌增长停滞       | ★★★★☆ | 增速降至3.7%，大众市场竞争同质化，DTC改革红利边际递减                                                      |
| PUMA收购整合不顺     | ★★★★☆ | 15亿欧元自有现金收购，短期报表承压；PUMA自身处于业绩阵痛期，若整合时间超预期，将对现金流和盈利产生长期拖累 |
| 狼爪品牌复兴不及预期 | ★★★☆☆ | 从并表至2025年已亏损3.02亿，欧洲核心市场下滑，品牌重塑周期不确定                                           |
| 国际化地缘政治风险   | ★★★☆☆ | 欧美贸易政策收紧、供应链政治化可能干扰东南亚及北美扩张节奏                                                 |
| 管理层集中与家族接班 | ★★★☆☆ | 家族核心决策虽利于战略连贯性，但若出现接班人能力或团队内耗问题，或引发治理风险                             |

**最薄弱一环**：**主品牌增速换挡能否找到新增长极**是最大变量。大货仅3.7%增速，能否靠出海（东南亚千店计划）、差异化店型（冠军店/超级安踏）和专业品类升级拉动回到高单位数甚至双位数，决定了整个集团的"地基"是否稳固。若主品牌长期徘徊在2-4%，即便户外品牌翻倍增长，整体市值扩张逻辑也将面临挑战。

## 未来会怎样？预测与判断

**短中期展望（1-2年）**：预计2026年营收878亿，同比增长约9.5%，归母净利润（考虑Amer上市一次性收益）约140-157亿之间。核心催化剂在于：① 主品牌线下店效能否在奥运年拉动下持续反弹；② FILA专业运动品类转型成效的兑现；③ 迪桑特/可隆能否持续保持30%+增速；④ PUMA收购按预期完成，为全球版图再落一子。

**长期终局判断（3-5年）**：安踏有望从"中国运动品牌龙头"跃迁为**真正的全球多品牌运动集团**——主品牌安踏立足中国+全球化扩张；FILA与户外品牌群（迪桑特/可隆/狼爪/MAIA）构成国内"品质消费"的完整拼图；PUMA作为全球化的大众运动品牌落子，与Amer Sports（始祖鸟/萨洛蒙/威尔胜）在高端和垂类市场形成双核驱动，集团营收有望向1500-1800亿台阶迈进。

**估值锚定**：当前股价约75港元，对应2026年PE约13-14倍。当前市场给予的是"成熟消费龙头"的估值（对标耐克、阿迪15-20倍），而非"高速成长股"定价。若出海步伐加速、户外品牌群的增速持续超出预期，或PUMA整合成效超出预期，不排除估值中枢向18-20倍修复的可能。

**一句话结论**：多品牌矩阵是中国运动领域的终极壁垒，安踏集团处于从本土龙头向全球巨头跃迁的临界点，但主品牌增长的"稳健"与"瓶颈"之间，仍需更多时间检验。
