## 前置步骤：公司理解、财报可信度初判与关键变量搜索

### Step 1：理解公司的生意

**云天化靠什么赚钱？**

云天化是中国最大的磷矿采选和磷化工一体化企业。2025年，其收入结构为：

| 业务板块                       | 收入(亿元) | 收入占比 | 毛利率 | 利润占比(估算) |
| ------------------------------ | ---------- | -------- | ------ | -------------- |
| 化肥（磷肥+复合肥+尿素）       | 270.98     | 55.97%   | 26.18% | ~72.5%         |
| 商贸物流                       | 118.50     | 24.48%   | 1.53%  | ~1.9%          |
| 磷化工                         | 33.83      | 6.99%    | 34.45% | ~11.9%         |
| 其他（工程材料、新能源材料等） | 60.83      | 12.57%   | 混合   | ~13.7%         |

核心盈利来源是**化肥业务**，尤其是磷肥，贡献超过70%的利润。商贸物流虽然收入占比近1/4，但毛利率仅1.53%，本质是流水生意，几乎不创造利润。

**商业模式特征**：资源型纵向一体化。从磷矿石采选→磷肥/磷化工生产→销售，形成"矿化一体"的完整产业链。核心壁垒在于**磷矿资源储量**（近8亿吨）和**采矿权**。

**生意质量三重过滤**：

1. **可理解性** ✅：挖磷矿→生产化肥→卖给农民/贸易商。商业模式清晰，无需复杂术语。
2. **收入可证实性** ✅：下游客户分散（农户、经销商、海外买家），现金交易少，收入确认相对可靠。大宗商品属性使得价格透明，不易操纵。
3. **模式是否依赖融资** ✅：2025年自由现金流75.29亿元，自由现金流/净利润=131.95%，不仅不需要融资，还大量分红。财务上自给自足。

> **生意质量总体评价**：商业模式清晰，护城河来自不可再生的矿产资源，收入真实可验证，现金流充沛。是一门**好生意**。

- **毛利率2025年化肥板块下降1.87pct至36.1%**（来自券商研报），原因是**硫磺价格翻倍**导致原料成本飙升。这恰好验证了硫磺价格作为关键成本变量的重要性。
- **Q1 2026毛利率19.56%**：较2025全年略降0.65pct，但Q1传统上是淡季，属于正常波动。

### 板块二结论

> 云天化毛利率的提升是**业务结构优化+行业景气+成本管控**三重因素共振的结果。费用率整体稳健，财务费用压降是重要利润贡献点。全部研发费用化处理增强了财报可信度。**当前成本费用结构健康，具备可持续性**。

### 二、增长趋势诊断

**收入端的"假象萎缩"**：

- 表面上看营收在持续萎缩（753→691→617→484亿），但这并非业务恶化，而是**主动战略性收缩商贸物流业务**——从2022年的384亿降至2025年的118亿。
- 核心化肥主业收入从2022年的266亿微增至2025年的271亿，基本持平。
- 扣掉商贸业务，**自产产品收入2022-2025年复合增速约为+2%**，属于稳健增长。

**利润端的"真实跃升"**：

- 净利润从2016年的-32.56亿（亏损）→ 2020年的2.72亿（微利）→ 2022年的60.21亿（峰值）→ 2025年的51.56亿。
- 9年年化增速15.24%，5年年化增速80.11%（受益于低基数）。
- 2025年净利润小幅下降3.4%，主要受Q4一次性因素（资源税补缴3.86亿+信用减值2.5亿+预计负债4.29亿）影响。剔除这些，2025年经常性净利润约在60亿左右，与2024年基本持平。

### 三、增长模式识别

**内生增长为主，外延为辅**：

- 利润增长主要来自磷化工行业景气度提升和内部效率改善，非外延并购驱动。
- 商誉仅0.87亿，十年不变——公司历史上几乎没有大规模溢价收购。
- 未来增长引擎在于**镇雄碗厂磷矿注入**（参股35%，控股股东持股55%并承诺3年内注入），这属于关联资产注入，非市场化并购，风险可控。

### 四、增速趋势变化

**三轮驱动 vs 三重压力**：

| 增长驱动力   | 当前状态 | 展望                             |
| ------------ | -------- | -------------------------------- |

| 磷酸铁新能源 | 起步阶段 | 7万吨销量(+56%)，但当前体量小    |

| 增长压力     | 当前状态   | 展望                   |
| ------------ | ---------- | ---------------------- |
| 硫磺成本     | 2025年翻倍 | 短期难以逆转           |
| 尿素价格低迷 | 周期底部   | 下行空间有限           |
| 商贸业务收缩 | 主动行为   | 拖累收入但利好利润结构 |

### 关键变量印证

**Q1 2026数据验证**：营收119.81亿（同比-8.06%），净利润14.25亿（同比+10.39%）。"减收增利"的趋势延续，且净利润增速转正，说明2025年Q4的一次性拖累已消化。

### 板块三结论

> 云天化的"收入萎缩"是假象，本质是主动剥离低毛利商贸业务带来的结构优化。核心化肥主业稳健，利润增长的质量（现金流+扣非占比）高于增速本身。**当前处于结构优化后的稳定期，下一轮增长需等待镇雄磷矿注入及磷酸铁放量**。

## 四、业务构成

### 一、核心利润来源识别

从2025年数据看：

**第一利润中心：化肥（利润占比~72.5%，毛利率26.18%）**

化肥板块是云天化的绝对"现金牛"：

- 磷肥：收入154.79亿（32%），毛利率约36.1%（2025年受硫磺影响），是利润基本盘
- 复合肥：收入65.48亿（13.5%），毛利率高于尿素
- 尿素：收入约50亿（10.3%），毛利率近年承压

这门生意的风险特征：

- **周期性风险**：化肥价格受全球农产品周期和原材料价格影响，但磷矿资源自给提供了成本缓冲
- **政策风险**：出口配额和法检政策直接影响外销利润
- **竞争壁垒**：磷矿采矿权+产能规模构成较高壁垒，新进入者难以短期复制

**第二利润中心：磷化工（利润占比~12%，毛利率34.45%）**

磷化工产品（黄磷、磷酸等）毛利率高，但体量较小（33.83亿收入），是利润的有益补充。

**商贸物流（收入占比24.48%，毛利率仅1.53%）**

这是一个"食之无味、弃之可惜"的业务。从利润角度看几乎可以忽略。其存在的意义可能是维持供应链关系和渠道网络，但从投资视角看，持续收缩是正确的战略选择。

### 三、问题业务诊断

**商贸物流**：毛利率仅1.53%，但2025年仍有118.50亿收入。建议持续观察其压缩进度。如果该业务进一步缩减至50亿以下，公司整体毛利率有望突破22%+。

### 板块四结论

**ROE的"健康度"演变**：

1. **2017-2020年**：ROE极低（3-6%），且由高杠杆驱动（权益乘数6-12倍），属于**伪ROE**。一旦行业下行，高杠杆会迅速吞噬净资产。
2. **2021-2022年**：ROE跃升至43-45%，由利润率提升（磷化工景气）+ 适度杠杆共同驱动，含金量显著提升。
3. **2023-2025年**：ROE回落至22-26%，权益乘数进一步降至1.89。**驱动因素从"杠杆+周期"转向"利润率+周转"**，质量持续提升。

**ROE为何从45%降至22%？**

- 净利润从60.21亿（2022峰值）降至51.56亿（2025），下降14%
- 归母净资产从163.65亿增至245.81亿，增长50%
- 分子缩小、分母扩大 → ROE自然回归。这是**健康的价值回归**，而非经营恶化。

当前ROIC约15%，显著高于融资成本（有息负债利率约3-4%），公司持续创造经济价值。

### 三、资产周转效率

周转率下降的原因同样是商贸业务收缩——分母（总资产）变化不大，但分子（收入）大幅缩减。若只看化肥主业，周转率大约在1.1-1.2次水平。

### 关键变量印证

**ROE未来走势的判断因素**：

1. **利润率**：取决于磷矿石价格和硫磺成本。若硫磺价格回落，磷肥毛利率有望修复至38%+，带动ROE回升。
2. **资产周转**：商贸业务持续压缩将继续拖累周转率，但化肥主业周转稳定。
3. **权益乘数**：去杠杆仍在进行，权益乘数将继续下降，对ROE形成压制。
4. **综合判断**：ROE大概率在当前水平（18-25%）区间波动，不会回到2022年的45%，但质量更高（低杠杆驱动）。

### 板块七结论

> 云天化的ROE经历了"伪高→真高→稳健高"的三阶段演变。当前21.87%的ROE虽然低于2022年峰值，但驱动因素更健康——净利率11.36%（持续提升）+ 权益乘数1.89（极低杠杆）+ 周转率0.95（商贸收缩拖累）。ROIC约15%，持续高于融资成本，真实创造经济价值。

## 最终总结：综合投资结论

### 1. 这是一门什么样的生意？

云天化是一家**以磷矿资源为核心壁垒的纵向一体化化工企业**。它从地下挖出不可再生的磷矿石，加工成化肥卖给农民、加工成磷酸/磷酸铁卖给工业企业。这门生意的本质是**资源变现**——磷矿储量和采矿权是其最深的护城河（近8亿吨储量，1450万吨/年采选能力，国内最大）。商业模式清晰，客户分散（经销商+农户+海外），现金流极好（经销商预付、大宗商品现款结算），是一门**看得懂、算得清**的好生意。

### 2. 财报可信度评级：🟢 高

**两个最核心的支持证据**：

1. **经营现金流/净利润持续5年>170%**：赚的是真金白银，不是应收账款；
2. **资产负债率从92%降至47%，全靠经营现金流偿还**：如果利润是假的，不可能用"假利润"偿还238亿真债务。

### 3. 历史财务表现如何？

**一句话总结**：这是一个"从濒临破产到财务健康"的教科书级转型案例。2020年是分水岭：

- **之前（2016-2020）**：主业持续亏损，靠贸易流水和金融收益勉强维持，资产负债率92%，随时可能暴雷。
- **之后（2021-2025）**：磷化工景气周期+内部改革+去杠杆，盈利质量跃居行业第一梯队。扣非净利润占比>97%，自由现金流/净利润>130%，ROE>20%。

**当前状态**（2025年）：营收484亿（含118亿低毛利商贸），净利润51.56亿，毛利率20.21%，净资产246亿，有息负债116亿。处于转型完成后的稳定期。

### 6. 投资价值的初步判断

**这是一家具备长期投资价值的公司，但在当前价格下需耐心等待更好的入场时机。**

**看好的理由**：

- 商业模式优秀：资源型护城河，现金奶牛，财务极其健康
- 盈利质量顶级：经营现金流/净利润>170%，扣非占比>97%
- 分红慷慨：2025年分红率49.5%，股息率约4%+
- 成长期权：镇雄24亿吨磷矿注入将打开新成长空间
- 估值合理：当前PE约13-14倍，处于化工行业中位数

**需要警惕的**：

- 磷矿石价格处于历史高位，存在均值回归风险
- 硫磺成本高企短期难以逆转
- 营收持续"假性萎缩"可能压制市场情绪
- 磷酸铁等新业务仍在培育期

**定性评级**：商业模式优秀，财务健康度A级，当前估值合理但非显著低估。适合作为**长期持有型资产**，逢低布局。
