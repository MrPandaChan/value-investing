# 东阿阿胶

## 原材料风险

1. **源头资源枯竭**
   国内毛驴存栏量锐减至约200万头；非洲联盟通过历史性禁令，计划全大陆禁止屠宰驴，海外主渠道面临关闭。

2. **质量掺杂风险**
   原料稀缺致马皮、骡皮等掺假泛滥，一旦卷入行业丑闻，品牌信任崩塌；全检成本与可追溯难度极高。

3. **成本与财务爆雷**
   驴皮价暴涨暴跌，公司曾因高位囤货在2019年计提巨额存货减值，业绩“爆雷”；库存管理如走钢丝。
   2016-2018年驴皮供应紧张，公司为防止短缺和涨价，大量采购高价驴皮，2017年末存货高达36亿元。
   2019年活驴及驴皮价格回落，库存成本高于市场售价，触发了会计上的减值处理。

4. **ESG与动物福利**
   国际组织抨击“为皮杀驴”破坏生态与当地民生，可能导致公司被剔除出ESG投资组合，影响资本估值。

5. **应对策略局限**
   自建养殖基地受制于驴繁殖慢，远水难解近渴；快消品多元化未改变对驴皮的根本依赖。

- [这家企业是否值得备选（2025.11.25 终身黑白）](https://mp.weixin.qq.com/s/-q1B070viw86XhqblPP75Q?scene=1)

全文主旨：东阿阿胶品牌积淀深、当下估值较低且股息可观，但需正视原材料和竞争格局的瑕疵，是否投资取决于个人体系，更适合作为分散组合中的高股息配置。

**业绩复苏未回巅峰**：2019年主动清理渠道库存后业绩稳步回升，但营收与净利润尚未突破历史高点。
**分红与现金流扎实**：2021年以来分红率约90%，经营活动现金流自2019年后持续高于净利润，自由现金流仅2019年为负。
**老龄化与保健潮双驱动**：老龄人口攀升和疫后健康意识增强拉动补气补血需求，复方阿胶浆因医保解限和临床证据增多，院内渠道有望增量。
**品牌心智护城河**：“东阿阿胶”几乎成为品类代名词，零售市场份额67%，加上道地原料、高于国标的质控和68年抽检全合格，构筑信任壁垒。
**驴皮原料是长期风险**：驴存栏量急剧下降，多国禁止驴皮出口，驴皮占成本90%，未来供应与成本波动可能制约发展。
**竞争格局被渠道重塑**：直播带货弱化传统渠道优势，竞品如黄芪精等异军突起，行业前十大品牌集中度呈下滑趋势。
**稳健管理尚需观察**：2020年后企业从激进扩张转向稳中求进，但该风格仅维持数年，持续性有待验证。
**是否备选取决于投资体系**：当前约18倍PE、5%股息率，若采用适度分散的高股息策略可作为配置选项；若极度集中持仓，则宜选择护城河更深、增长曲线更明确的公司。

[持有东阿阿胶的人，最近太憋屈了：业绩明明在涨，股价越跌越深（2026.06.23 老叶智道）](https://mp.weixin.qq.com/s/8sLBFDuU-dkjXU8UTA2cWw)

全文主旨：东阿阿胶近期股价持续下跌，并非业绩暴雷，而是市场对其“增长靠赊销、增速持续放缓”的含金量产生怀疑，导致估值逻辑从成长切换为低增长现金奶牛。

**股价与业绩背离**：一季报营收与净利润仍正增长，但股价近一年新低，消费白马整体失血，持有者体感“满仓踏空”。
**科技股抽血非主因**：存量博弈下资金流向科技股能解释“不涨”，但解释不了“跌幅更深”，根子还在自身增长逻辑的边际变化。
**增长质量受质疑**：连续两年一季度放宽信用保增长，应收账款单季飙升，合同负债减少，市场担忧终端动销不足，增长依赖向经销商压货。
**不属危机重演**：当前渠道库存健康、手握超60亿现金、无有息负债，与2019年渠道堰塞湖有本质区别，基本面安全垫厚。
**预期已充分定价**：过去几年的上涨已将“困境反转、修复健康”的利好消化，当下市场转而审视未来增速能否向上，而答案偏悲观。
**增长天花板渐显**：营收增速逐年下台阶，股权激励目标隐含零增长预期，九成收入依赖阿胶单品，驴皮成本挤压利润空间。
**切忌对标茅台**：茅台先款后货、定价权强、全场景刚需；阿胶靠授信拿货、提价影响销量、属可选滋补品，增长含金量与确定性远不及，估值理应不同。

全文主旨：一季报应收账款激增大概率不会重演2019年危机，但它暴露了“不赊销就难增长”的现实，市场正将阿胶从成长股重新定价为收息资产。

**季节性授信非孤例**：连续两年Q1应收账款均大幅攀升、年末顺利回落，本质是配合春节动销的季节性铺货安排，片仔癀、云南白药等企业亦有类似节奏。
**毛利率走向提供佐证**：利润增速高于营收增速，毛利率仍在改善，若公司折价倾销换收入，毛利率应下行而非上行，侧面说明并非渠道积压甩货。
**票据回笼与授信的时间差**：账面货币资金增加8.8亿元，系票据托收已完成变现，而新增约5亿授信尚未到期回款，导致当期经营现金流仅2886万元显得单薄。
**关键验证在年中**：连续两年Q1现金流疲弱，若2026年中报经营性现金流仍未见显著恢复，“增长依赖信用扩张”的判断将获得更强支撑。
**回购信号已现**：公司以45.14至50.30元区间斥资2亿元完成回购，当前股价44.33元已跌破回购最低价，反映管理层对该估值区间的认可。
**估值坐标系正在切换**：市场不再接受成长股逻辑，增速逐年下台阶使16倍PE显得偏高；若按收息资产定位，6%股息率、零有息负债、年现金流超20亿的组合已具备一定吸引力。
**需接受资产真实属性**：不应与科技股比弹性，也不宜对标片仔癀的高增长叙事。将其定位为年化约6%的收息配置，并等待市场将收息逻辑完全定价，比猜测短期涨跌更有意义。

[东阿阿胶第三篇：它有护城河吗？为什么我说它永远成不了茅台（阿胶系列·叁）（2026.06.26 老爷智道）](https://mp.weixin.qq.com/s/TjZnfWXsmo9p85f245COgA)

全文主旨：东阿阿胶具备由品牌、原料、渠道治理和即食化构成的“窄护城河”，但因库存属性、原材料、社交场景、成瘾性和提价逻辑上的根本差异，永远成不了茅台。

**品牌壁垒“有但老化”**：高端市场定价高出福牌约一倍仍占67%份额，但心智优势集中在45岁以上女性，年轻基本盘曾为空，近年靠即食产品才拉回部分份额。
**驴皮是双刃剑**：掌控全球约60%驴皮资源，自给率提升至68%，构成对手难以复制的供应链壁垒；但非单向护城河，历史上驴皮价格曾因反噬暴跌，公司年报亦将驴皮涨价列为长期风险。
**华润治理是核心软实力**：程杰主导渠道归拢、库存清零、产品重塑与研发倍增，使东阿成为老字号中少数完成从“涨价驱动”到“创新驱动”跳跃的企业，这一层比驴皮更值钱。
**即食化正构建新壁垒**：桃花姬、小金条等即食产品将消费场景零食化、日常化，借“赎罪经济”切入年轻群体，即食产品营收占比已达65%，是面向未来的重要增量壁垒。
**库存属性与茅台截然相反**：茅台越陈越香具金融囤积属性，阿胶有5年保质期属消耗品，注定无法形成社会性蓄水池，秦玉峰时代照搬提价囤货模式因而崩塌。
**原材料成本结构悬殊**：茅台原料成本可忽略、毛利率90%以上且稳定；阿胶驴皮占成本60%、全球紧缺、毛利率73%且稳定性差，制约盈利质量。
**社交与成瘾属性单薄**：送礼场景局限于女性滋补礼品，男性商务场景空白，且属非成瘾低频消费，天花板受品类先天限制，无法与茅台全场景刚需高频对比。
**提价逻辑脆弱**：阿胶的稀缺是心理意义上的，可被创造也可被打破；茅台的稀缺是赤水河、窖池等物理意义上的，二者有本质区别，这决定了阿胶无法复制茅台“越提越好卖”的路径。
**老龄化托底与年轻化增量并存**：45岁以上女性刚需基本盘缓慢扩容，即食线已将30岁以下用户拉升至42%，但阿胶系列仍占营收92.5%，即食大单品体量尚小，第二曲线远未成熟。
