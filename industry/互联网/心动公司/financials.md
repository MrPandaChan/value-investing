# 财务报表分析

## 前置步骤一：理解公司的生意

### 这家公司靠什么赚钱？

心动公司是一家**"游戏研发+游戏社区平台"双轮驱动**的互联网公司。2025年营收57.64亿元，分为两大业务板块：

| 业务板块   | 2025年收入 | 收入占比 | 业务本质                        |
| ---------- | ---------- | -------- | ------------------------------- |
| 游戏分部   | 37.96亿    | 65.86%   | 自研+代理手游的研发、发行与运营 |
| TapTap平台 | 19.68亿    | 34.14%   | 游戏社区平台的广告/信息服务变现 |

**核心盈利逻辑**：自研游戏提供利润基本盘，TapTap平台以"零分成"吸引开发者和玩家，形成"平台赋能游戏，游戏反哺平台"的飞轮效应。

### 商业模式特点

- **游戏业务**：自研精品策略（《心动小镇》《出发吧麦芬》《火炬之光：无限》），面向全球市场发行；本质是内容驱动的产品型商业模式，依赖于爆款产品的成功率和生命周期管理。
- **TapTap平台**：国内稀缺的"不联运、不分成"游戏分发渠道+垂直社区，仅通过广告变现，对开发者极具吸引力。当前MAU约4,500万，本质是双边网络效应平台。

### 生意质量三重过滤

1. **可理解性** ✅：用一句话即可讲清——"做游戏和运营一个不抽成的游戏下载社区"。
2. **收入/客户可证实** ✅：游戏流水可通过App Store/Google Play排名交叉验证；TapTap广告收入对应真实广告主需求；上下游分散，无单一客户依赖。
3. **模式依赖漂亮报表** ✅：2019-2023年曾经历大幅亏损（研发激进投入期），但2024年起已实现强劲自由现金流，不再依赖外部融资。

## 最终总结：综合投资结论

### 1. 这是一门什么样的生意？

心动公司是一家**"游戏研发精品化+平台生态零分成"**的互联网公司，核心商业模式是：

> 用心做好游戏 → 优质自研游戏为TapTap平台吸引用户 → TapTap以零分成吸引更多开发者入驻 → 平台内容更丰富 → 用户粘性更强 → 广告商业化变现 → 利润反哺游戏研发 → 循环强化。

这形成了国内游戏行业独一无二的**"内容+渠道"飞轮效应**，竞争壁垒在于：

- TapTap作为稀缺的零分成分发渠道，对游戏开发者的吸引力是结构性优势；
- 自研游戏能力经历2021-2023的"痛苦修炼"后已显著成熟，爆款成功率提升；
- 双业务共享用户、数据和品牌，协同成本低于单独运营任一业务。
