# 财务报表分析

## 前置步骤：公司理解、财报可信度初判与关键变量搜索

### Step 1：理解公司的生意并初判生意质量

**这家公司靠什么赚钱？**

国投电力是中国大型清洁能源发电企业，核心利润来源是**水电**——特别是控股52%的**雅砻江水电**（2025年贡献归母净利润约48亿元，占公司总归母净利润的65%）。此外，公司还拥有火电（1,307万千瓦）、风电（414万千瓦）和光伏（769万千瓦）资产。

从2025年业务构成看：

- **电力收入**：487.70亿元（占91.99%），毛利率约44.73%
- **其他业务**：38.01亿元（占7.17%），毛利率为负（-6.18%），属于亏损拖累项

**生意质量三重过滤：**

| 过滤维度             | 评估        | 说明                                                                                                                      |
| -------------------- | ----------- | ------------------------------------------------------------------------------------------------------------------------- |
| 业务可理解性         | ✅ 通过     | 发电卖电，商业模式简单清晰。雅砻江水电是天然垄断的稀缺资源，来水→发电→上网→收钱，两分钟能讲清楚                           |
| 收入/客户可证实性    | ✅ 通过     | 客户是两大电网（国家电网、南方电网），真实可靠；发电量由国家电网调度数据可验证，上网电价有发改委/市场化交易合同支撑       |
| 模式依赖漂亮报表吗？ | ✅ 基本通过 | 自由现金流近年有所改善（2025年FCF/净利润=137%），但历史上资本开支巨大（常年200亿+），具有重资产行业的天然特征而非刻意做账 |

**生意质量判断**：这是一门**重资产、高壁垒、现金流稳定**的生意。雅砻江水电的垄断性流域开发权是核心护城河。

**关键发现**：

- **2021年是灾难性一年**：毛利率骤降至29.26%（前值44.87%），主因煤炭价格暴涨（当年秦港煤价一度突破2600元/吨的历史极值），火电成本飙升。
- **此后逐年恢复**：2021→2025年毛利率从29%→41%，体现了三个正向驱动：①煤价从极端高位回落；②高毛利水电占比提升；③新能源装机摊薄固定成本。

**护城河判断**：毛利率波动较大（29%-48%），**不具备强定价权带来的稳定高毛利特征**。但水电部分的毛利率事实上是极高的（雅砻江净利润率约37%-40%），整体毛利率受火电拖累。从这个角度说，**国投电力的护城河不在于定价权，而在于雅砻江的天然垄断性和不可复制性**。

### 2. 增长趋势诊断

**营收增速阶梯式下行**：

- 2018年：+29.6%（水电大发+火电高位）
- 2021年：+11.3%
- 2023年：+12.3%
- 2025年：**-8.31%**（首次显著负增长！）

营收负增长的核心原因：①火电发电量同比-17.6%（被清洁能源挤压）；②水电来水偏枯（雅砻江上网电量-6.2%）；③电价整体承压（部分区域火电中长期交易价下降）。

**但利润逆势增长11.30%**，原因有三：

1. 煤价下行→火电燃料成本大幅下降→火电毛利率+7.1pct
2. 财务费用压降21.2%（利息支出减少7.25亿）
3. 水电电价不降反升（雅砻江+2.34%）

**这就是国投电力当前的核心矛盾**：**营收天花板显现（水电来水不可控、火电被挤压），但利润通过成本端改善仍有增长**。

| --------------------- | ----------- | ----------------------------------------- |

| 新能源装机扩张        | ⭐⭐ 成长   | 风电/光伏装机快速增长，但电价下行抵消量增 |

**重要的是**：2023年大举扩张后商誉仅1.06亿（占总资产0.03%），**不存在外延并购带来的商誉减值风险**。

### 🔗 关键变量印证

### 3. ROE未来走势研判

- **利好因素**：财务费用继续压降（LPR下行+还债）→净利率提升；在建水电投产后折旧减少→净利率进一步提升
- **利空因素**：火电利用小时继续被挤压→周转率下降；新能源电价持续下行→净利率承压；来水不确定性
- **中性判断**：ROE预计围绕11%-13%波动，系统性上移至15%+需要雅砻江中游全部投产且来水配合

### 🔗 关键变量印证

- ROE受2021年煤价冲击 → **验证**：2021年ROE仅5.39%，此后逐年恢复，煤价是核心变量
- ROIC仅5.2% → **验证**：重资产公用事业的特征，长江电力的ROIC也仅约7-8%。水电可以跑赢通胀但不能创造暴利
- 2025年净利率创十年新高25.39% → **验证**：煤价低+水电电价涨+财务费用降，三重利好叠加的"黄金窗口"，**可持续性存疑**

## 最终总结：综合投资结论

### 1. 这是一门什么样的生意？

国投电力是一家**以雅砻江流域水电为核心资产、火电和新能源为两翼的清洁能源发电企业**。

**商业模式本质**：借钱→建电站→发电→卖电给电网→收电费→还利息→剩下的就是利润。

**核心竞争壁垒**：

- **雅砻江流域的独家开发权**：这是天然垄断，不可复制。雅砻江是中国水力资源最丰富的河流之一，规划装机3,000万千瓦水电+3,900万千瓦风光。
- **重资产门槛**：已投固定资产2,349亿，新进入者无法复制。
- **现金流确定性**：发电量可测（来水有历史数据）、电价有合同（长协+市场化）、回款有保障（两大电网）。

**劣势**：

- ROE/ROIC偏低（11%/5.2%），不是高回报生意
- 来水不可控（看天吃饭）
- 火电/新能源电价面临市场化下行压力
- 重资产模式下自由现金流波动大

### 2. 财报可信度评级：🟢 高可信

**核心支持证据**：

1. 经营现金流/净利润长期在300-600%，利润是"真金白银"而非纸面数字
2. 商誉仅1.06亿，无并购地雷
3. 审计意见始终为标准无保留，无监管记录

**唯一需要关注的**：2021-2024年应收账款周转天数从30天恶化至93天，虽有"新能源补贴回收周期长"的合理解释，但趋势值得持续监控。

### 6. 投资价值的初步判断

**定性评价**：**价值型公用事业标的——确定性较强但回报率有限**

- **适合的投资者画像**：追求4-5%股息率+5-8%年化资本增值（合计10-13%年化回报）、看重现金流稳定性、不追求短期暴利的长期投资者。
- **不适合的投资者**：追求年化15%+回报的成长股投资者、对宏观经济和来水波动缺乏耐心的短期交易者。

**当前估值水平**：

- TTM PE 14.68倍（处于近5年7.53%分位，**历史低位**）
- PB 1.58倍（处于近5年11.58%分位，**历史低位**）
- TTM股息率3.35%，2025年度分红比例55%（10派5.081元预案，对应股息率约3.73%）
- 券商一致预期2026年归母净利约75-78亿（+2-5%），对应Forward PE约13-14倍

**核心矛盾**：估值处于历史低位→有安全边际；但营收负增长+来水偏枯+煤价可能反弹→短期业绩承压。

**我的初步判断**：国投电力是一家**"可以安心持有但不指望暴富"**的公司。当前13.63元的价格、14.7倍PE、1.58倍PB处于近5年的绝对低位区间，提供了不错的安全边际。如果相信：①雅砻江来水终将回归正常；②新能源装机成长终将转化为利润；③电力市场化改革长期利好优质发电资产——那么当前价位具有中长期配置价值。

**但必须保持警惕的是**：营收-8.3%的负增长 + 新能源电价年降14.5% + 来水连续偏枯这三重压力如果同时恶化，可能导致利润预期下修。**关键观察窗口是2026年汛期（6-10月）雅砻江来水数据。**
