# 非财务信息“八问”

## 靠什么赚钱？

> 搞清楚生意是怎么做的，核心驱动力是什么

**生意本质一句话概括**：赚的是为快消品龙头提供高安全标准、低成本的定制化塑料软包装的钱，具备长期稳健的"卖水人"属性。

**收入与利润结构拆解**：彩印复合包装是绝对核心，薄膜业务正快速崛起。2024年营收结构为：彩印包装70%（21.6亿）、塑料软包装薄膜21%（7.2亿）、油墨4%（1.6亿）、镀铝包装2%（0.6亿）。最赚钱的是彩印包装（毛利率约26-27%）和海外业务（毛利率比国内高约3-5pct）。

**核心驱动力**：业绩增长的真正发动机是——**销量增长，而非提价**。公司下游大客户为雀巢、伊利、宝洁等刚需消费品牌，营收随客户自然增长而稳步扩大。当前核心增长驱动力为：

1. 持续抢占中小落后产能企业的份额（行业CR5仅8.7%）；
2. 薄膜新材料的产能释放（在建2.2万+3万吨功能膜项目预计2026年全部投产）；
3. 海外市场快速扩张（2025年海外收入同比大增24.04%，占比提升至15.05%）。

## 顺风还是逆风？

> 外部大环境境好不好

**宏观定性**：当前行业处于**结构分化期**——整体中低速增长，但环保政策驱动下的优质龙头集中趋势明显。

**顺风清单**（正在发生的有利趋势）：

1. 市场集中度提升逻辑清晰：2023年塑料软包CR5仅8.7%，环保限塑政策持续出清中小落后产能，永新位于行业第二梯队头部，长期受益。
2. 下游必选消费需求稳定：食品饮料/日化/医药为主，粮油食品社零累计同比增长12.3%，抗周期性突出。
3. 公司积极布局BOPE等环保单一材料薄膜产品，精准契合政策导向，有望获得替代增量市场。
4. 海外扩张加速：2025年海外业务收入同比增长24.04%，且海外毛利率高于国内，为公司打开增量空间。

**逆风清单**（制约发展的外部压力）：

1. 原材料价格高企：2026年2月中东战争致原油大幅上涨，聚乙烯/聚丙烯现货价上涨超2000元/吨，公司成本端持续承压。
2. 下游消费需求恢复不及预期：若消费复苏疲软，将直接影响订单放量节奏。
3. 行业竞争激烈，价格内卷压力：包装行业下游大客户议价能力强，在需求疲软期存在年降压力。但薄膜产品调价主动权更大，彩印产品需与下游协商，目前绝大多数客户对价格上调表示接受。
4. 2025年业绩利润端短期承压：2025年营收同比增长5.61%至37.23亿，但归属净利润同比下降6.33%至4.38亿，主要受原材料成本上升影响。

## 空间有多大？

> 行业未来空间有多大，未来发展的天花板

**第一增长曲线见顶判断**：我国塑料包装市场规模2025年达701亿美元，预计2033年增至966亿美元，CAGR约4%。永新市占率仅约1-2%，离天花板仍然很远。行业CR5仅8.7%，市场份额分散，头部企业市占率提升空间极大。

**第二增长曲线储备**：

- **塑料软包装薄膜**：自2017年以来持续贡献增量，2024年营收大增37.9%至7.2亿元，在建2.2万+3万吨新型功能膜项目预计2026年全部投产，投产后有望带动该业务继续高增长。
- **宠物食品包装与精密注塑**：2025年公司宣布推进年产2000吨宠物食品包装和4500吨精密注塑制品扩建项目，顺应新消费需求。
- **环保新型薄膜**：BOPE/BOPP薄膜项目2022年底已投产，聚焦单一材质零碳包装，契合绿色包装行业主流趋势，有望加速抢占千亿级薄膜市场。

**天花板量化预估**：公司当前营收约35-40亿规模，对标国内包装头部企业裕同科技（年营收超170亿）仍有4倍以上的营收差距，在中短期（3-5年）内有望提升至50-70亿级别。

## 竞争格局好不好？

> 认识行业竞争的玩法

**行业梯队地图**：永新股份位于**行业第二梯队头部**。

- **第一梯队**（年营收超100亿）：裕同科技、奥瑞金、合兴包装、紫江企业
- **第二梯队**（30-100亿）：**永新股份**、宝钢包装、昇兴股份、嘉美包装
- **第三梯队**：中小规模企业
- **塑料软包细分龙头**：永新股份（专注度高，70%收入源于塑料软包）、紫江企业（多元化）
- **2023年中国塑料软包CR5仅为8.7%**，极度分散。紫江企业为第一，永新股份位列第二。

**竞争核心要素**：这个行业拼的是**客户关系壁垒 + 综合成本控制能力 + 技术迭代能力**。大品牌对供应商要求极高，认证周期长（通常需5年），因此一旦形成稳固供应关系，客户流失率极低。

**利润率密码**：行业平均毛利率20-25%。永新常年高于同行，年平均ROE达15.27%，远高于紫江企业（11.14%）和双星新材（4.19%）。高利润来源于：纵向一体化自供原材料（油墨、薄膜等）、精细化管理（2022年MES系统上线运营持续降本增效）、以及与品牌大客户长期稳定的合作关系。

## 有什么优势？

> 与同行相比，有什么优势

**横向对比表**（与核心对手2024年数据对比）：

| 维度            | 永新股份          | 紫江企业             | 双星新材 |
| --------------- | ----------------- | -------------------- | -------- |
| 营收规模        | 35.3亿            | 约100亿+             | 约50亿   |
| 主营业务        | 塑料软包为主      | 纸包装+金属包装+塑料 | 塑料薄膜 |
| ROE（近年平均） | **15.27%**        | 11.14%               | 4.19%    |
| 毛利率          | **23.78%**        | ~20-22%              | ~10-15%  |
| 销售+管理费率   | **约5%**          | 较高                 | 较高     |
| 国际业务占比    | 15.05%            | 较低                 | 较低     |
| 分红率          | **连续多年超70%** | 较低                 | 较低     |

**独特的护城河（对手难以复制的壁垒）**：

1. **高安全壁垒的客户粘性**：下游为雀巢、伊利、宝洁等国际一线品牌，品控要求严苛，供应商认证周期长（5年+），一旦进入供应链即形成长期稳固的合作关系。

2. **纵向一体化产业链布局**：以彩印包装为中枢，向上自建油墨（自用率超40%）、塑料软包装薄膜（自用率超74%）和镀铝材料，有效降本增效，保证产品品质稳定。

3. **历史分红记录带来的价值锚定**：自上市以来累计分红19.78亿元，平均分红率高达69.73%，常年稳定高分红在市场中获得"高股息+稳健成长"的独特价值定位，构筑了资金层面的投资壁垒。

## 管理层行不行？

> 特别关注老板和管理层，公司治理有没有问题

**管理层画像**：**坚定自我革新，大胆启用新世代。**

- **董事长**：江蕾（1987年出生），曾任职于乐高、迪士尼等国际知名企业，专注品牌管理与战略规划，积极推动公司拥抱消费新趋势。
- **总经理**：潘健（技术出身、国务院特殊津贴专家），拥有丰富的产品研发与管理经验，确保技术根基稳固。
- **核心高管背景**：专业性强且长期任职，无频繁跨界或背景过度多元的隐患。

**治理红灯预警**：

- 奥瑞金股权质押比例偏高（占其持股的86.31%），存在潜在的股东减持风险。
- 关联交易方面未见明显异常，内部控制较为规范。
- 自上市以来股权激励及员工持股计划与高管深度绑定，管理动力充足。

**一句话评价**：管理层能力强、专业背景扎实，战略视野开阔，对公司整体治理持有**高信任度**。

## 风险在哪里？

> 不利因素有哪些，风险可能出现在什么地方，没达到预期的薄弱环节在哪里

**风险矩阵（按严重程度排序）**：

| 风险项                   | 严重程度 | 说明                                                                                                                             |
| ------------------------ | -------- | -------------------------------------------------------------------------------------------------------------------------------- |
| 原材料价格持续高位       | ★★★★★    | 原材料占成本70%-80%，中东战争油价已暴涨27%，若价格持续维持高位，2026年盈利将持续承压，是最大变量。                               |
| 下游价格竞争超预期       | ★★★★     | 国内需求疲软时，下游大客户可能存在年降压力，压缩公司利润空间。目前薄膜产品价格传导顺畅，彩印产品多数客户已接受涨价，但仍需跟踪。 |
| 第二大股东奥瑞金减持风险 | ★★★★     | 奥瑞金持股比例22.20%，但质押比例高达86.31%，若发生大面积减持会压制股价，但公司正常经营受影响有限。                               |
| 薄膜业务毛利率不及预期   | ★★★      | 产能释放后若毛利率修复不及预期，将拖累整体利润增长。2025年薄膜业务毛利率已修复至14.8%，趋势向好。                                |
| 消费需求复苏不及预期     | ★★★      | 若居民消费持续疲软，公司销量增长将受限，影响产能消化节奏。                                                                       |

**最薄弱一环**：**原材料价格波动（★★★★★）**。公司原材料成本占比极高（70-80%），且其来源是石油衍生品，地缘政治（如中东战争）大幅推高成本时，尽管公司能够通过提价进行传导，但仍会承受阶段性利润压力，成本传导效果存在滞后性，2025年归属净利润同比下滑6.33%便已反映此敏感性。

## 未来会怎样？

> 未来会怎样，对未来做出预测

**短中期展望（1-2年）**：2026年Q1收入实现约10%增长，利润端小幅增长。

- **核心催化剂**：1）新增产能释放（2.2万吨新型功能膜另一半产线、3万吨双向拉伸多功能膜均预计2026年投产）；2）涨价传导落地（彩印产品第一轮价格上调多数客户已接受）；3）海外市场持续高增长。
- **潜在压力**：原油价格大概率维持高位（布伦特/WTI持续走高），上游成本压力将持续压制盈利弹性；需求端若国内消费不能明显好转，增速可能受限。

**长期终局判断（3-5年）**：公司将持续受益于环保限塑政策带来的行业集中度提升，凭借技术积累的护城河不断扩大市场份额。横向一体化向上游薄膜新材料的延伸将打开第二增长曲线。凭借稳健的经营风格与高分红记录，公司有望成为像国际巨头希悦尔（Sealed Air）一样聚焦专业包装解决方案、具有深度客户粘性及穿越周期的"隐形冠军"型企业。机构预测2026-2028年归母净利润分别为5.2、6.0、6.9亿元。

**估值锚定**：当前市盈率（TTM）约14-16倍，市净率约2.7倍，显著低于纯高成长类标的，与估值相呼应的高股息属性明确。市场当前给的是 **"高股息+稳健成长价值股"** 的定价。未来若原材料价格回落、薄膜业务毛利率持续修复并放量，存在估值修复空间。

**一句话结论**：**塑料软包行业隐形冠军，短期成本压力压制弹性，长期行业集中+新材料拓展逻辑清晰，高股息率提供安全垫。**
