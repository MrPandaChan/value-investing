# 财务报表分析

## 前置步骤：公司理解、财报可信度初判与关键变量搜索

### Step 1：理解公司的生意

**这家公司靠什么赚钱？**

老凤祥是中国最古老的黄金珠宝品牌之一（创立于1848年），核心生意是**黄金珠宝首饰的生产与销售**。从业务构成数据看：

| 业务线            | 收入占比(2025) | 毛利率 | 利润占比 |
| ----------------- | :------------: | :----: | :------: |
| **珠宝首饰**      |     80.61%     | 10.63% |  94.22%  |
| 黄金交易          |     18.54%     | 0.96%  |  1.96%   |
| 笔类/工艺品及其他 |     0.85%      | 15-98% |  3.82%   |

**珠宝首饰是绝对核心。** 这门生意的本质是：采购黄金原料 → 设计加工 → 通过加盟店/直营店网络销售给终端消费者。毛利率常年在8-10%区间，这个数字看着低，但对黄金珠宝零售商来说是行业常态——因为金料价格只是"过手"，真正的附加值来自品牌溢价和加工费。

**生意质量三重过滤：**

| 过滤维度            |    评估     | 说明                                                                                                                    |
| ------------------- | :---------: | ----------------------------------------------------------------------------------------------------------------------- |
| ① 可理解性          |   ✅ 通过   | 一句话就能讲清：采购黄金、加工成首饰、通过全国连锁门店卖出，赚品牌和加工的钱                                            |
| ② 收入/客户可证实性 | ⚠️ 中等风险 | 加盟店为主（约90%+门店为加盟），终端销售去向难以完全穿透验证；但客单价低、客户极度分散、C端现金交易为主，收入造假难度大 |
| ③ 是否依赖融资      |   ✅ 通过   | 自由现金流/净利润比率多数年份在50%以上（除个别极端年份），不依赖持续融资                                                |

### Step 2：推断关键经营变量

基于"加盟为主的黄金珠宝零售商"的商业模式，以下非财务经营变量最为关键：

| 类别     | 关键变量                            | 为何重要                                                                   |
| -------- | ----------------------------------- | -------------------------------------------------------------------------- |
| **量**   | 门店数量（加盟/直营）、同店销售增速 | 加盟扩张是收入增长的核心引擎                                               |

| **储备** | 门店储备/签约意向                   | 预判未来扩张节奏                                                           |
| **外部** | 金价走势、消费景气度、行业竞争      | 金价是双向放大器                                                           |

### 第二道防线：财务异常信号扫描

#### 🔴 核心异常信号：经营现金流极端波动

```
经营现金流/净利润 比率历年数据：
2016: -92.54%  2017: +109.86%  2018: -30.77%  2019: -89.06%
2020: +148.03%  2021: +106.05%  2022: +56.70%  2023: +325.67%
2024: +150.72%  2025: +339.75%  2026Q1: -429.43%
```

**这是最值得警惕的信号。** 一家稳定经营的黄金珠宝零售企业，经营现金流/净利润不应如此剧烈波动。波动根源在于存货的急剧变化：

| 年份 | 存货（亿元） | 变动     | OCF/净利 | 解读                     |
| ---- | :----------: | -------- | :------: | ------------------------ |
| 2021 |    125.49    | +6.67亿  |   106%   | 小幅补库                 |
| 2022 |    167.99    | +42.50亿 |   57%    | **疯狂补库**吞噬现金流   |
| 2023 |    123.28    | -44.71亿 |   326%   | **疯狂去库存**释放现金流 |
| 2024 |    118.25    | -5.03亿  |   151%   | 继续去库                 |
| 2025 |    85.72     | -32.53亿 |   340%   | **再度大幅去库存**       |

**判断：** 存货在2021-2023年间"先疯狂堆积、再疯狂去化"的幅度（从125亿→168亿→123亿），已超出正常经营波动的范畴。可能的原因包括：①金价先涨后跌驱动的被动调库（合理）；②管理层通过存货来"管理"现金流表现（可疑）；③加盟商退货/换货机制导致的库存回流（需搜索验证）。

公司给出的解释是"主动瘦身、关闭低效门店"，这与库存大幅下降在方向上一致。但2025年去库存32.5亿的同时营收仅下降7%，意味着去库存速度远超收入降速，需要进一步确认是否有"消化历史包袱"的成分。

### 财报可信度综合定级：**中等可信（有疑点，但非红灯）**

**核心依据：**

- ✅ 审计意见干净、无重大会计差错、无立案调查
- ⚠️ 经营现金流极度波动，反映存货管理存在较大人为操作空间
- ⚠️ 加盟模式下的终端销售真实性难以完全穿透验证
- ⚠️ 2025年跨界奢侈品投资收到监管问询，管理层资本配置能力存疑

**对后续分析的影响：** 财报数字在整体框架上可信，但需对存货相关数据保持警惕，利润率数据比现金流数据更可靠。

**毛利率特征：**

- 毛利率在7.58%-9.09%之间窄幅波动，**2022年是低谷（7.58%），此后连续三年回升**
- 2026Q1毛利率骤升至12.75%，远超历史区间——**这需要高度关注**。可能原因：①金价下跌→终端售价下调滞后于成本下降（短期利好）；②产品结构向高毛利品类倾斜；③季节性因素

**毛利率的护城河含义：**

- 低且稳的毛利率本身不构成护城河，但它反映了**黄金珠宝行业的通行结构**：金料成本占比极高（~90%），真正的差异化空间极窄
- 老凤祥的毛利率在同行中处于中等偏低水平（周大福约28%含高毛利镶嵌类），说明其定价权有限，主要靠规模取胜
- **毛利率的稳定性是好事**——说明公司没有通过激进降价争夺份额，行业竞争尚属理性

- 销售费用率从2022年的1.32%上升至2025年的1.81%，三年上升0.49个百分点——**在收入下滑期费用率反而上升，说明费用存在刚性**，是值得关注的趋势

### 3. 研发投入判断

```
研发费用率：0.03%-0.05%，几乎可以忽略不计

```

老凤祥是**品牌/渠道驱动型企业，而非技术驱动型企业**。研发费用全部费用化（保守处理），绝对值极小。这是商业模式决定的，不是问题。真正值得关注的是**品牌维护支出**（体现在销售费用中）的效率。

### 关键变量印证

- 搜索得知2026年6月金价已从1月高点1,713元/克跌至1,316元/克（-23%）→ **解释2026Q1高毛利率**：终端零售价调整滞后于成本端金价下跌，短期形成利差。但这是不可持续的——当零售价全面跟随下调后，毛利率将回到正常区间
- 毛利率回升与"关闭低效门店"方向一致——淘汰低毛利门店后，单店质量提升会反映在整体毛利率上

### 2. 增长趋势诊断

```
营收增速轨迹：
2019→2020: +4.21%    2020→2021: +13.47%   2021→2022: +7.36%
2022→2023: +13.37%   2023→2024: -20.50%   2024→2025: -6.99%
```

**增长诊断：崩盘式减速。**

- 2021-2023年是高速增长期（增速7-13%），受益于金价持续上涨带动的"追涨"消费和渠道扩张
- **2024年断崖式下跌（-20.50%）**，2025年继续下跌（-6.99%）
- **2026Q1加速下跌（同比-21.57%）**，衰退远未见底

这不是正常的周期性回调。从2023年714亿峰值到2025年528亿，两年蒸发186亿收入（-26%）。对比门店数从约6,000家降至5,170家（-14%），单店收入只跌了不到2%，说明**主要问题是门店数量萎缩而非单店全面恶化**。但如果金价继续下跌，单店收入也可能随之坍塌。

### 3. 增长模式识别

老凤祥的增长历来是**内生加盟扩张驱动**——没有巨额并购，因此也不存在商誉减值的潜在风险（2025年末商誉为0）。

但2025年试图以2,400万美元入股迈巴赫奢侈品亚太公司，标志着管理层开始寻求"第二曲线"。这笔投资金额虽不大（约1.7亿人民币），但**标的公司尚未开始运营即享高溢价**，引发监管问询，折射出管理层在主营业务遭遇瓶颈时的焦虑心态和可能不够审慎的资本配置倾向。

### 关键变量印证

| 变量     | 变革方向                        | 对增速的启示                                           |
| -------- | ------------------------------- | ------------------------------------------------------ |
| 门店数   | 2023~6000→2025 5355→2026Q1 5170 | **主动收缩，收入自然下降**                             |
| 单店收入 | 2025年986万（微增1.4%）         | 存量门店还算稳定                                       |
| 金价趋势 | 2026年从1713跌至1316            | 金价下跌期间，黄金珠宝消费意愿通常下降（"买涨不买跌"） |
| 开店计划 | 2026年计划新开120家             | 远不足以弥补存量关闭，渠道仍在净收缩                   |

**核心矛盾：** 公司正经历一轮主动的渠道出清（淘汰低效加盟店）。出清完成后能否实现单店质量的真正提升，是判断增速能否触底回升的关键。目前的数据显示，单店收入的微弱回升（+1.4%）还远不足以形成趋势。

## 最终总结：综合投资结论

### 1. 这是一门什么样的生意？

**这是一门"加盟网络×黄金流通×品牌变现"的生意。** 老凤祥本质上是一个超级加盟管理平台：通过1,700多个加盟商、5,000多家终端网点，将黄金原料加工成品牌首饰后分销到全国。商业模式极简、可理解性强，核心利润来自极其微薄但稳定的品牌加价率（约10%的毛利率）。护城河在于遍布全国的加盟网络和历史品牌认知——这两者都需要数十年积累，复制成本极高，但不是不可逾越。

### 2. 财报可信度评级：**中等可信（有疑点）**

| 支持可信的证据                   | 削弱可信的疑点                               |
| -------------------------------- | -------------------------------------------- |
| 连续标准无保留审计意见           | 经营现金流极端波动（OCF/净利从-89%到+340%）  |
| 扣非利润占比始终84%以上          | 存货先堆积再去化(125→168→86亿)，幅度过大     |
| 零商誉、极低应收、无在建工程异常 | 加盟模式终端销售难以穿透验证                 |
| 现金充裕、债务低位               | 2025年跨界奢侈品投资收监管问询，管理判断存疑 |

**整体判断：** 没有发现系统性造假的硬证据，但存货管理和渠道库存的透明度不足。财报数字在方向和幅度上可信，但具体年份的利润率/现金流数据需要打折使用。

### 3. 历史财务表现如何？

**在2023年之前是一台精密的盈利机器：** 约20%的ROE、11-12%的ROIC、稳健的净利率、极低的资本开支。但2024年起进入明确的衰退期——收入、利润、ROE三项核心指标同步下行，且2026Q1的衰退在加速。

| 维度       | 2019-2023（扩张期） | 2024-2025（收缩期） |    趋势     |
| ---------- | :-----------------: | :-----------------: | :---------: |
| 营收       |      496→714亿      |      568→528亿      |   🔴 收缩   |
| ROE        |       18-22%        |       14-16%        |   🔴 下滑   |
| 净利率     |      2.8-3.2%       |      3.3-3.4%       |   🟢 改善   |
| 资产负债率 |       43-54%        |       25-35%        | 🟢 大幅改善 |

**核心判断：** 财务质量在改善（更低杠杆、更高净利率），但经营规模在收缩。这是一家正在"做减法"的企业——主动清理渠道、降低杠杆、削减库存。瘦身是否最终能强身，目前尚无定论。

### 4. 当前最关键的经营变量

**① 门店数量何时触底？** 这是判断营收能否企稳的第一先导指标。2026年计划新开120家 vs Q1已关185家，若Q2-Q4净关店幅度收窄，意味着渠道出清接近尾声；反之若继续大幅净关，则下沉周期远未结束。

**② 金价走势。** 金价对老凤祥是双向放大器：①直接影响存货价值（85亿存货的金价敏感度极高）；②通过"买涨不买跌"心理影响终端消费需求；③通过金价与终端价的传导时差影响短期毛利率。当前金价从1,713跌至1,316（-23%），对老凤祥构成明确的逆风。

**③ 单店盈利能力。** 关闭483家门店后单店营收仅微增1.4%、单店净利反降1.9%，说明"瘦身"尚未传导至"强身"。需要持续跟踪单店收入能否回到1,000万以上、单店净利能否回到35万以上。

### 5. 主要风险点

**① 金价持续下行的存货减值风险。** 85亿存货（占总资产41%）是老凤祥的阿喀琉斯之踵。按当前跌价计提比例仅0.26%来看，若金价继续下行10-15%，可能触发远超历史水平的存货减值。审计师已将此项列为关键审计事项，说明专业判断上也存有疑虑。

**② 管理层资本配置能力存疑。** 在主业持续收缩的背景下，管理层选择跨界投资一家"尚未开张"的迈巴赫奢侈品公司，且因此收到监管问询。这不仅消耗了宝贵的现金，更折射出管理层对主业前景的不自信和资本配置纪律的缺失。2,400万美元金额不大，但信号意义负面。

**③ 加盟体系的潜在风险。** 连续两年大规模关闭加盟店（净减683家），是否会引起加盟商群体的连锁反应？加盟商的存货如何处理（由公司回购还是自行消化）？这些在公开信息中缺乏透明度。

### 6. 投资价值的初步判断

**这是一家正在经历主动阵痛的百年老店。** 财务质量在改善（降杠杆、提效率），但经营规模在萎缩（关店、减收）。当前13.64%的ROE和11.18%的ROIC仍然具备超越融资成本的价值创造能力，但增长的缺失使得估值只能向"成熟现金牛"方向收敛。

**定性评价：**

- ✅ 商业模式清晰、资产结构简单、无商誉等暗雷
- ✅ 资产负债表历史最佳（净现金70亿）
- ✅ 品牌历史积淀和渠道网络构成一定的护城河
- ⚠️ 增长引擎熄火，渠道收缩尚未见底
- ⚠️ 金价下行周期中面临存货减值与消费疲软双重压力
- ⚠️ 管理层跨界投资的判断力存疑
- 🔴 经营现金流的极端波动暗示财报可信度存在灰色地带

**适合关注的情景：** ①门店数量确认触底并开始净增长；②金价企稳回升的早期阶段；③管理层放弃奢侈品等非主业投资、专注渠道优化。在此之前，建议保持观察而非贸然介入。
