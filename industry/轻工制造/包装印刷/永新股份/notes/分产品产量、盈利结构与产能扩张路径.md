# 分产品产量、盈利结构与产能扩张路径

**报告范围**：涵盖彩印包装材料、塑料软包装薄膜、镀铝包装材料、油墨四大产品线，覆盖2016—2026H1，包含产量、营收、毛利率、国内外分地区数据、客户与供应商集中度、财务风险维度，并纳入未投产预计产能的营收与利润增量推算及投产时间表。

**重要说明**：部分年份的分产品产量或财务数据在公开年报中未单独披露，报告中以“未披露”明确标注，估算值单独注明估算依据，不做无据推算。

### 5.2 逐年变动说明

**2021→2022（海外）** ：海外收入从2.90亿增至3.53亿，同比+21.6%；毛利率从25.58%降至24.40%，同比-6.4pct，主要系原油价格上涨推高原材料成本。

**2022→2023**：海外收入3.80亿，同比+7.8%；毛利率大幅回升至29.10%，同比+4.7pct，海外毛利率较国内高出约6pct。公司综合毛利率升至24.7%（同比+2.5pct）。

**2023→2024**：国内收入29.63亿（+2.3%），海外收入4.52亿（+18.84%）。海外毛利率从29.10%大幅回落至23.76%（-5.34pct），主要系产品结构变化。公司在泰国设立办事处，持续切入跨国公司供应链。

**2024→2025**：国内收入30.55亿（+3.09%），海外收入5.60亿（+24.04%），海外营收占比跃升至15.05%。海外毛利率23.62%（-0.14pct，基本持平），海外收入增速远快于国内，薄膜业务高附加值产品贡献显著。

**2025→2026H1（半年度口径）** ：国内收入15.27亿（+9.39%），海外收入3.59亿（+18.36%），海外营收占比进一步提升至18.53%。**海外毛利率大幅跃升至33.41%，同比+9.17pct**，而国内毛利率17.47%（-1.55pct），两者差距从2025年全年的约1.4pct急剧扩大至**约16pct**。海外毛利率跳升的核心原因是高毛利的差异化薄膜产品在海外收入中的占比显著提升，同时公司在海外市场的议价能力增强。

## 六、客户与供应商集中度

### 6.1 客户集中度

| 指标                         | 2025年数据     | 数据出处   |
| ---------------------------- | -------------- | ---------- |
| 前五名客户合计销售金额       | 8.10亿元       | 2025年年报 |
| 前五名客户占年度销售总额比例 | **21.74%**     | 2025年年报 |
| 前五名客户中关联方销售占比   | 未披露具体比例 | 2025年年报 |

公司2025年不存在向单个客户的销售占比超过**30%**的情况，亦不存在向前五大客户的销售占比超过**50%**的情况。客户集中度21.74%处于中等水平，但考虑到公司下游为雀巢、伊利、宝洁等规模化快消巨头，**单个大客户在定价谈判中天然占据优势地位**。公司披露的“彩印产品调价需与下游沟通协商”“薄膜产品调价主动性更大”，本质上就是客户结构在定价机制中的映射。

### 6.2 供应商集中度

| 指标                           | 2025年数据     | 数据出处   |
| ------------------------------ | -------------- | ---------- |
| 前五名供应商合计采购金额       | 6.97亿元       | 2025年年报 |
| 前五名供应商占年度采购总额比例 | **29.14%**     | 2025年年报 |
| 前五名供应商中关联方采购占比   | 未披露具体比例 | 2025年年报 |

前五名供应商采购占比29.14%，高于客户集中度，符合公司原材料以石油衍生品为主（占比70%—80%）、供应商相对集中的行业特征。关联方采购方面，2025年向美邦胶业采购材料672.33万元，向三夏机械采购设备及材料357.38万元，金额较小，不构成重大关联依赖。

供应商集中度略高意味着原材料采购价格受少数供应商影响较大，公司通过与核心客户协商调价、拓宽供应渠道、加速国产粒子替代等方式对冲风险。2026H1面对美伊冲突导致的全球石化供应链受阻，公司“多途径拓宽供应渠道、提升安全库存周期，并加速国产粒子替代”。

### 6.3 集中度趋势判断

从2026H1的客户结构数据看，前五名客户销售占比约为19.63%，较2025年全年的21.74%有所下降，表明公司在拓展新客户方面取得了一定进展。结合海外营收占比从15.05%提升至18.53%的趋势，客户结构正在向多元化方向演变，这有助于边际改善公司在定价谈判中的地位，但短期内定价权弱势的格局不会发生根本性改变。

### 7.5 风险综合评估

公司将上述压力归因于产能扩张期的阶段性特征：有息负债快速攀升是为支撑多个项目同步推进的资本开支；应收账款高企源于下游快消巨头客户的账期特征；财务费用大增是利息支出增加与利息收入减少的叠加效应。公司在投资者交流中表示经营现金流回款“有压力，但风险可控”，并已通过远期锁汇对冲汇兑风险。

核心风险逻辑在于：**利润改善的持续性取决于新产能投产后的收入释放节奏，而当前资产负债表上的有息负债和应收账款已提前反映了扩产的代价。** 如果新产能消化慢于预期或下游客户账期进一步拉长，流动性管理将面临实质性压力。报告中第七节的增量营收17亿、增量利润1.58亿的推算，建立在项目顺利达产、资金成本不进一步恶化的前提之上。
