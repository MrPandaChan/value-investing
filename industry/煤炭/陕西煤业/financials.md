# 财务报表分析

## 前置步骤：公司理解与关键经营变量推断

### Step 1: 理解陕西煤业的生意

**这家公司靠什么赚钱？**

陕西煤业是中国西北地区最大的动力煤生产商之一，核心盈利来源是**自产煤的采掘与销售**。2025年煤炭采掘业收入1388亿元，占总营收的87.75%，贡献利润418.93亿元，占利润池的91.14%。2024年底收购陕煤电力集团后，新增电力业务（2025年收入155亿元，占比9.83%），公司正从纯煤炭企业向"煤电一体化"转型。

**商业模式特点：**

| 维度         | 特征                                                                                   |
| ------------ | -------------------------------------------------------------------------------------- |
| **资源属性** | 坐拥渭北、彬黄、陕北三大矿区，保有资源量179.3亿吨，可采储量102.5亿吨，可采年限70年以上 |
| **成本结构** | 重资产采掘业，固定资产和折旧是主要成本；费用端极简（期间费用率仅5%左右）               |
| **客户模式** | 面向大型电力集团、钢铁企业等B端客户，以长协合同为主                                    |
| **周期性**   | 强周期行业，盈利高度依赖煤价，无法通过品牌或差异化规避周期                             |
| **定价权**   | 价格由市场供需决定，个体企业无定价权                                                   |

**生意质量三重过滤：**

1. **业务可理解吗？** ✅ 极其简单：挖煤→卖煤→收钱。可以向任何人讲清楚。
2. **收入/客户可证实吗？** ✅ 客户为大型电力集团和钢铁企业，交易有合同、有票据、有物流记录，难以虚增。下游分散的终端用户极少。
3. **模式依赖漂亮报表吗？** ✅ 不依赖。经营现金流持续远超净利润，自由现金流充沛，无需持续融资。

### 第二道防线：财务异常信号扫描

**利润质量检查：**

- **经营现金流/净利润**：2016-2025年间，此比率在142%-300%区间波动，长期远大于1。2025年为210.38%，说明每1元净利润背后有2.1元的真金白银流入。这是极度健康的信号。
- **扣非净利润/净利润**：除2020年（61.35%）外，均在83%-107%之间。2020年异常是因投资收益波动（持有隆基绿能等股票公允价值变动），属于非经常性。2025年为91.53%，利润质量良好。
- **自由现金流/净利润**：长期在108%-227%之间。2025年为108.62%，自由现金流充沛。

**收入与资产联动检查：**

- 应收账款/收入：从2016年的31.06%大幅降至2025年的4.22%，这是议价能力增强的铁证，而非放宽信用政策。
- 存货/收入：从5.53%降至2.33%，库存管理优秀。
- 不存在收入下滑时存货逆势大增的情况。

**存贷双高检查：**

- 2025年：货币资金317.98亿元，有息债务306.62亿元 → 基本相当，但现金略多。
- 利息费用4.83亿元，对应约1.6%的融资成本，处于合理范围。
- 不存在典型的存贷双高——有息债务/总资产仅12.98%，且现金可覆盖。
- 财务费用为利息收入（2022年财务费用为-4.09亿），说明整体是净利息收入状态。

**投入产出异常检查：**

- 1元收入需要的WC：长期为负值（-0.01至-0.13），说明公司占用上下游资金，这是煤炭企业对下游电力企业有议价权的正常体现。
- 1元收入需要的固定资产：从2016年的1.34元降至2024年的0.61元，资产效率持续提升。2025年回升至0.76元，主要因电力资产并表（电力是更重资产的业务）。
- 人均数据：因用户未提供员工人数，但煤炭央企/国企通常薪酬规范，不存在异常背离。

**可疑会计政策：**

- 研发费用率极低（0.32%-0.44%），无研发资本化问题。
- 煤炭企业会计相对简单，收入确认以交货为依据，不存在完工百分比法等激进手段。

**非经营科目异常：**

- 无重大"其他应收款"挂账的异常信号。

**第二道防线通过，未发现任何重要异常。**

### 第三道防线：业务异常信号扫描

**商业常识符合性：**

- 毛利率（27-55%）在煤炭行业中处于较高水平，但这是**资源禀赋优势**（陕北矿区煤质优、开采成本低）的自然结果，并非反常识。
- 吨煤完全成本~290元 vs 行业平均>450元，差额约160元/吨。这在煤炭行业是合理的——优质露天矿和深井矿的成本差距可达数倍。
- 净利率在景气高峰（2022年）达21.10%，低谷（2016年）仅8.31%，波动与煤价高度吻合，不存在反周期"稳定"的异常。

**交易对象：**

- 下游客户为大型电力集团，交易对手方信用高、可查证。
- 未搜索到隐性关联交易的质疑报道。

**客户性质：**

- 终端用户为发电厂，不存在通过经销商/代理商压货的渠道风险。

**第三道防线通过，未发现任何业务层面异常。**

### 综合定级：🟢 **高可信**

陕西煤业的财报具有以下天然可信基础：

1. 煤炭采掘是极简商业模式，每一吨煤的采掘、运输、销售都有实物对应，造假难度极高

4. 审计意见清洁，无监管记录，无治理丑闻
5. 财务结构保守，低杠杆运营

**关键变量印证：**

### 2. 增长趋势诊断

**三段式增长特征：**

1. **2016-2020（稳步爬升）**：营收从331亿→951亿，净利润从28亿→149亿。煤价温和上涨+产量提升双轮驱动。
2. **2021-2022（超级景气）**：2022年营收1668亿、净利润352亿，创历史巅峰。全球能源危机+供给侧收缩推升煤价至历史高位。
3. **2023-2025（景气回落）**：煤价高位回落，净利润连续三年下滑（352→231→224→168亿）。2025年营收、净利润双双大幅下滑，是煤价同比降18%的直接映射。

**增速特征：量稳价跌**。产量持续小幅增长（2025年+2.58%至1.75亿吨），但煤价下跌完全吞噬了量的增长。这是强周期行业的标准画像：**短期增速由价格决定，长期增长由产量决定。**

### 3. 增长模式识别

陕西煤业的增长主要来自**内生产能扩张**：陕北矿区的小保当、曹家滩等现代化矿井逐步投产放量。2024年底收购陕煤电力集团是首次大规模外延并购，但无商誉（收购价对应净资产，商誉为0.41亿元），不存在商誉减值风险。

**关键变量印证：**

- 2025年产量+2.58%、销量增长约3.5%（含贸易煤），量的增长是健康的内生增长。
- 2026年1-5月产量同比+5.01%，增速进一步提升——产能释放正当时。
- 电力发电量+11.25%，2026Q1再+19.91%，转型方向增长明确。
- ⚠️ 2025年净利润-25.02%的"跳水"完全由煤价下跌解释，**非经营恶化**。

## 最终总结：综合投资结论

### 1. 这是一门什么样的生意？

陕西煤业是中国西北地区最优质的动力煤生产商，凭借陕北矿区世界级的资源禀赋（吨煤成本~290元 vs 行业>450元），构筑了极深的成本护城河。公司正在从纯煤炭企业向"煤电一体化"转型。这是一门**简单、可理解、现金流极度充沛、但强周期性**的生意。周期上行时是印钞机，周期下行时靠成本优势仍能赚取超额利润。

### 2. 财报可信度评级：🟢 高可信

煤炭采掘业的天然特征（每吨煤有实物对应、客户为大型国企、现金交易少）使造假难度极高。三层审查均未发现异常：经营现金流长期远超净利润；应收账款和存货占比持续走低；审计意见始终为标准无保留；无监管问询或立案记录。**财报可以作为投资决策的可靠基础。**

### 3. 历史财务表现如何？

- **盈利质量：卓越。** 经营现金流/净利润长期>150%，自由现金流充沛，利润含金量A股顶级。
- **增长动力：量稳价驱。** 2016-2022年量价齐升带来超级景气，2023-2025年价格回落拉低利润。长期增速（9年化净利润+22.22%）极为亮眼，但短期内增速为负（-25%）。
- **投入产出效率：优秀。** 负营运资本占用上下游资金、极低费用率（5%）、吨煤成本行业领先，是煤炭行业效率标杆。
- **财务稳健度：极高。** 零净债务、低杠杆（资产负债率42%）、巨额现金储备。

### 4. 当前最关键的经营变量

| 优先级 | 变量                   | 当前状态              | 2026-2027年需关注                            |
| ------ | ---------------------- | --------------------- | -------------------------------------------- |
| 1      | 秦港5500大卡动力煤价格 | 835-861元/吨（↑22%）  | 能否维持800+，取决于夏季用电高峰和进口煤政策 |
| 2      | 吨煤完全成本           | ~290元/吨（已至极限） | 能否保持不升，取决于安全和环保投入           |
| 3      | 自产煤产量增速         | +5.01%（2026年1-5月） | 能否突破1.8亿吨，取决于新矿投产和产能核准    |

如果2026全年秦港均价维持800元以上，净利润有望回升至200亿+（券商一致预期）。如果回落至700元以下，净利润可能再次下探至150亿级别。

### 5. 主要风险点在哪里？

1. **煤价超预期下行风险（⭐⭐⭐）**：这是最大风险。若全球经济衰退或新能源加速替代导致煤价跌回500元级别，公司净利润可能腰斩（吨煤利润将从290→210元的成本安全垫被大幅压缩）。
2. **碳中和政策加速风险（⭐⭐）**：长期看，全球碳中和趋势不可逆，煤电终将被逐步替代。虽然过渡期可能长达20-30年，但"夕阳行业"的估值折价会长期存在。
3. **财报造假风险（⭐）**：基于三层审查结论，此风险极低。

### 6. 投资价值的初步判断

**正面因素：**

- 极深的成本护城河（吨煤成本行业最低梯队）
- 极充沛的自由现金流（FCF/净利润>100%）
- 零净债务+高分红承诺（≥60%分红率，当前股息率约3.6%）
- 70年以上可采年限，长期价值底座坚实
- 2026年煤价回暖，业绩大概率触底回升
- 煤电一体化转型，利润稳定性边际改善

**负面因素：**

- 强周期属性，盈利波动剧烈（净利16.8亿→352亿→16.8亿的过山车）
- 煤价不可预测，短期业绩高度不确定
- "双碳"下的估值天花板（煤炭行业PE中枢长期在6-10倍）
- 2025年分红率降至54.81%（低于承诺的60%），股息率仅3.6%，吸引力减弱

**框架性评价：**

陕西煤业是一台**巴菲特式"低迷行业中具有持久竞争优势"的印钞机**。它在强周期行业中以极低的成本基础和极强的现金流质量脱颖而出。当前17.88%的ROE（低谷水平）和3.6%的股息率反映的是周期低谷定价。若煤价维持当前800+水平，2026年ROE有望回升至18-20%，对应内在价值有修复空间。

但需要注意的是，3.6%的股息率在当前无风险利率环境下并不足够诱人。只有当股息率回升至5%以上（对应股价约20元以下），才进入格雷厄姆式的"安全边际充足"区间。**公司质地优秀，但当前价格的安全边际不足。** 更适合在煤价/股价进一步下跌时逐步建仓，而非追高。
