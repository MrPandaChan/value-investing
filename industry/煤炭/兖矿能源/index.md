# 兖矿能源

## 商业模式

**核心结论：** 兖矿能源的商业模式并非简单的“挖煤卖煤”，而是构建了一个以 **“低成本、大规模的煤炭资源”为核心基石，通过“内生外延双轮驱动”实现产能持续增长，并利用“国内大比例市场煤 + 海外完全市场化定价”的结构放大盈利弹性，最终以“稳定高分红”回馈股东与市场的可持续价值交换系统。**

### 1. 价值为先：为谁解决了什么“非解决不可”的问题？

兖矿能源主要服务于三大类客户，解决了他们关于“能源与原料”的根本性需求：

- **客户与任务（Jobs to be Done）：**
  1.  **电力、钢铁、建材行业客户：** 需要 **“稳定、足量、成本可控”** 的基础能源与原材料（动力煤、焦煤/喷吹煤）。它们是国民经济的压舱石，对供应链的安全性与稳定性有极高要求。
  2.  **化工行业客户：** 需要 **“特定规格、高性价比”** 的化工原料（甲醇、醋酸、烯烃等），以维持其生产装置“安稳长满优”运行。
  3.  **股东/投资者：** 在宏观经济波动周期中，寻求 **“具有防御性、现金流充沛、且能提供稳定高股息”** 的价值投资标的。

- **解决方案的价值主张：**
  - **对工业客户：** 提供 **“煤种齐全、分布广泛（国内+澳洲）、供应可靠”** 的煤炭产品，并依托自有物流体系（公铁水+智慧物流平台）保障交付。其煤化工业务则通过“煤化一体”和产业链延伸，提供高附加值的化工新材料。
  - **对股东：** 提供 **“成长与高分红兼备”** 的独特价值。通过清晰可见的产能扩张路径（3亿吨目标）和市场煤为主的弹性结构，在行业上行期能放大收益；同时，通过承诺60%以上的高分红政策，在行业下行期提供安全垫，这种“弹性向上、分红兜底”的组合在周期行业中十分稀缺。

### 2. 交易结构：为什么所有参与者都愿意持续参与？

兖矿能源构建了一个多赢的利益相关者交易结构，确保系统的稳定与可持续。

- **与控股股东（山能集团）：** **“持续的资产注入”** 是核心交易。山能集团通过将鲁西矿业、新疆能化、西北矿业等优质资产注入上市公司，解决了同业竞争问题，获得了数百亿现金对价，并实现了资产的证券化与价值提升。兖矿能源则以此快速扩大了资源储量和产能，实现了外延式增长。双方建立了清晰的“培育-注入-共赢”模式。

- **与国内外客户：** 核心是 **“定价机制与需求匹配”**。
  - 国内：采用“长协煤（约26%）+市场煤（约74%）”结构。长协煤为客户提供了成本稳定的基本盘；市场煤则为公司保留了价格弹性。
  - 海外（兖煤澳洲）：完全市场化定价，与全球煤炭指数挂钩。对日、韩、中国台湾等亚太客户而言，兖煤澳洲是地理位置最近的国际主要供应商之一，运输成本低，是可靠的“现货来源”。对公司而言，则能充分享受全球能源价格周期带来的红利。

- **与核心员工：** 通过 **A股限制性股票激励计划**，将管理层及核心骨干的利益与公司长期业绩（扣非净利润、每股收益）深度绑定，激发了内生增长活力。

### 3. 价值捕获：为什么你能从创造的价值中，稳定地分到一杯羹？

兖矿能源捕获价值的核心壁垒在于 **“资源+成本+结构”** 的独特性。

- **资源壁垒：** 拥有 **JORC标准下超460亿吨的资源量**，且布局于中国内蒙古、新疆、山东和澳大利亚等全球核心产煤区，资源禀赋决定了其经营的长期性与稳定性。
- **成本优势：**
  - **境内：** 陕蒙、新疆基地的千万吨级大型露天或井工矿（如金鸡滩、转龙湾），开采成本极低（吨煤成本200元上下），与东部老矿形成成本互补。
  - **境外：** 兖煤澳洲作为澳大利亚最大的专营煤炭生产商，通过大规模运营和持续的成本管控，现金经营成本长期保持在90-100澳元/吨的竞争力区间。
  - **整体：** 公司通过“十个加强、十个增效”等精益管理措施，实现了对吨煤成本的有效控制，对冲了价格下行风险。

- **独特的盈利结构（弹性捕获）：**
  - **高比例市场煤：** 在国内主要煤企中，其现货销售占比较高。这意味着煤价上涨时，公司业绩增速会显著高于长协占比高的同行。中泰证券测算，其利润弹性系数高达5.0。
  - **海外资产对冲：** 兖煤澳洲的煤炭定价与中国国内形成两个体系，不仅分散了单一市场风险，更提供了跨市场套利和捕捉全球能源价格周期的机会。
  - **煤化工补充：** “煤化一体”将部分煤炭转化为化工品，进一步延伸了产业链，捕获了从燃料到材料的价值增量，减弱了纯煤炭销售的周期性。

### 4. 效率与重构：能否用更低成本、更高效率完成价值交换？

兖矿能源正通过智能化、物流整合和资本运作，持续重构其运营和交易流程。

- **生产端（智能化重构）：** 大力推进“智慧矿山”建设，智能开采产量占比达94%。这不仅大幅提高了开采效率、降低了安全风险和人力成本，本质上是用“数据和机器”替代“传统经验和人海战术”，重构了煤炭生产的成本函数。
- **物流端（平台化重构）：** 通过收购**物泊科技**，将传统的公铁水联运与数字化网络货运平台结合。这打破了传统物流“层层转包”的低效模式，实现了“实体物流+数智平台”的“五流合一”（业务流、货物流、票据流、资金流、信息流），为客户降低综合物流成本3%-4%，同时自身也提升了资产周转效率。
- **产业链（并购式重构）：** 收购德国**沙尔夫公司**，并非简单的财务投资，而是将产业链延伸至“井下单轨吊辅助运输设备”这一细分高端装备领域。这解决了自身矿用设备的部分采购成本和供应链安全问题，同时利用沙尔夫的技术和全球渠道，有望将高端装备制造业务培育成新的增长极。

**总结：** 兖矿能源的商业模式，本质上是 **“用持续扩大的低成本、高品质资源储量，通过更具弹性的定价结构，在保障核心客户需求的同时，最大化地捕获行业周期价值，并借助智能化、一体化和高分红政策，构建起一个穿越周期的、可持续的价值交换闭环。”** 它不追求单一的规模最大，而是追求在“煤”这一传统赛道中，通过资源、成本、结构和效率的组合创新，成为对股东和客户都极具独特吸引力的“价值捕手”。

## 非财务信息“八问”

### 一、靠什么赚钱？核心驱动力是什么？

**生意本质：** 挖煤、卖煤，把煤化成高端化学品卖掉，同时全球布局赚钱。

**收入与利润结构拆解：**

2025年公司营业收入1449亿元，同比-7.49%；归母净利润83.8亿元，同比-43.61%。分业务看：

| 业务                       | 营收占比 | 毛利占比 | 最赚钱与否    |
| -------------------------- | -------- | -------- | ------------- |
| 煤炭业务                   | 约61%    | 约65%    | ✅ 核心利润源 |
| 煤化工业务                 | 约17%    | 约19%    | 利润占比提升  |
| 其他（电力、装备、物流等） | 约22%    | 约16%    | 辅助协同      |

2025年煤化工实现毛利69亿元，同比+17.1%，在煤价下行时逆势增长，验证了"煤化一体"的平滑周期效应；商品煤产量1.82亿吨创历史新高（+6.28%），但受煤价下跌影响，吨煤毛利191元、同比-36%，煤炭业务毛利率35.51%、同比-7.10pct。

**核心驱动力：**

行业β层面是"反内卷"政策驱动供需关系改善、煤价中枢上移；公司α层面是**产能扩张（在建产能近5000万吨+并购资产注入）+ 盈利弹性（市场煤占比超70%、现货价格敏感度极高）+ 第二曲线（煤化工高端化与海外澳洲资产**）三条腿走路。中长期核心是"量"的逻辑——当前在产+在建+规划产能合计已达3.2亿吨/年，陕蒙、新疆、甘肃多地煤矿将陆续投产。公司自身也在关键位置做了风控：鲁西矿业、新疆能化、西北矿业三大并购均附带业绩承诺条款，保护上市公司利益，降低收购风险。

### 二、顺风还是逆风？外部大环境好不好？

**行业定位：结构分化期，底部反转逻辑清晰。**

2025年全年煤炭市场经历"先抑后扬"V型走势：上半年需求疲软、煤价持续下跌，下半年在"反内卷"和安全生产监管强化下供应收紧，价格触底反弹。

**顺风清单：**

1. **"反内卷"政策强化供应约束：** 政策通过抑制无序竞争、查超产等方式推动行业自律，对煤价底部形成较强支撑。
2. **进口煤收缩，国内市场减压：** 2025年中国进口煤炭4.9亿吨、同比-9.6%，进口金额同比降幅高达30.2%。
3. **煤化工逆周期增长：** 2025年公司煤化工产销量同比+8.5%/+5.7%，毛利同比+17.1%，对冲煤价下行压力。
4. **国际化分散风险：** 澳洲资产依托海外市场化定价体系，在国际煤价上行时弹性显著，国内煤价下行时起到"缓冲垫"作用。
5. **股东回报政策锚定：** 2023-2025年公司承诺分红比例约60%、每股不低于0.5元，2025年仍然兑现（10派3.2元），政策可预期性强。

**逆风清单：**

1. **煤价中枢仍处于低位：** 2025年煤价中枢较2024年明显下移，其中炼焦煤全年均价跌幅较大，盈利能力受到压制。
2. **传统用煤需求拖累：** 火电、钢铁和建材均对用煤需求形成拖累，仅化工用煤保持增长。
3. **火电需求面临新能源替代：** 2025年煤炭消费量占能源消费总量比重降至51.4%，同比下降1.8个百分点，长期结构性压力持续。
4. **2025年盈利大幅下滑：** 归母净利润83.8亿元、同比-43.61%，扣非归母净利润73.99亿元、同比-46.73%。
5. **人民币汇率波动：** 海外业务以澳元/美元计价结算，汇率波动影响实际利润折算。

### 三、空间有多大？天花板在哪里？

### 四、竞争格局好不好？玩法是什么？

**行业梯队地图：** 中国煤炭行业呈现"强者恒强"格局，四大龙头占据绝对主导地位。

| 排名 | 公司     | 2025H1归母净利润 | 核心定位                                       |
| ---- | -------- | ---------------- | ---------------------------------------------- |
| 1    | 中国神华 | 246.41亿         | "煤电陆港航"一体化龙头，长协占比85%+，业绩最稳 |
| 2    | 中煤能源 | 77.05亿          | 煤化一体化为主，资源储备丰富                   |
| 3    | 陕西煤业 | 约50-60亿区间    | 优质动力煤龙头，成本优势突出                   |
| 4    | 兖矿能源 | —                | 市场煤占比高+国际化程度最高，业绩弹性最大      |

**竞争核心要素：**

- **资源储备：** 吨煤成本是核心胜负手。兖矿国内基地吨煤成本约200-250元/吨，未来能源金鸡滩煤矿等优质资产毛利丰厚；陕西煤业成本行业最低（约150-180元/吨），中国神华一体化运营平滑周期波动。
- **销售模式：** 决定了煤价下行期的抗风险能力。兖矿市场煤占比约74%，弹性最大，但下行期承压也最重；中国神华长协煤超85%，业绩稳定性最强。
- **国际化能力：** 兖矿拥有境内外六地上市平台，澳煤资产独特，是唯一一家有能力在海外规模化布局的上市煤企。
- **分红能力：** 行业平均分红率40%-70%区间，兖矿2023-2025年承诺约60%，神华长期维持60%-80%，是衡量投资价值的核心维度之一。

**利润率密码：** 行业平均毛利率约30%-45%。成本端吨煤成本在300-500元之间波动，售价端长协煤约500-600元/吨、市场煤弹性更大。煤化工盈利波动更大，2025年公司煤化工毛利率约20%左右，但随着80万吨烯烃等高端项目投产，毛利率有提升空间。

**独特护城河阐述：**

1. **稀缺的国际化资产：** 控股子公司兖煤澳洲资源量43亿吨、可采储量13.9亿吨，是澳大利亚最大专营煤炭生产商，也是唯一一家在澳大规模布局的中资上市煤企。海外高市场化定价机制赋予了在其他煤企不具备的"国际煤价弹性"敞口，叠加澳煤出口至日韩等地的运费优势，在海外能源价格上行周期能实现超额利润。

2. **独一无二的成长性产能储备：** 当大多数煤企面临资源枯竭和新矿审批收紧时，公司清晰规划了近5000万吨在建产能。五彩湾四号（1000万吨已投产/二期1300万吨核增进行中）、霍林河一号（700万吨）、刘三坨旦（1000万吨）、嘎鲁图（800万吨）、西北矿业杨家坪（500万吨）等一系列在建+规划的产能项目，将在未来3-5年内陆续释放，构成"行业β叠加公司α"双击的核心来源。

3. **双重风险对冲机制（国内长协+国际现货）：** 国内约26%的长协煤提供基本盘稳定性；海外澳洲资产对接国际现货市场提供超额弹性；煤化工业务逆周期增长平滑煤价下行压力（2025年毛利同比+17.1%）。三条腿互相支撑，构筑了行业独有的"三重底"防御机制。

### 六、管理层行不行？治理有没有雷？

**管理层画像：** 管理层以工程技术背景和煤企基层出身为主，董事长李伟为工程技术应用研究员、工学博士，近30年行业经验；多名高管从矿长等基层岗位逐步晋升，对行业理解深刻。2021年股权激励覆盖1245人（授予价11.72元/股），将核心管理层和骨干人员利益与公司绑定。目前大部分预留股份已解除限售流通，2024年扣非每股收益1.40元/股未达到第三次解除限售条件（需2.15元/股），第三期股票已由公司回购注销。

**治理红灯预警：**

- ⚠️ **业绩补偿款事项：** 鲁西矿业、新疆能化未完成2023-2025年累计业绩承诺，公司将收到业绩补偿款183.61亿元，说明并购标的盈利能力与预期存在差距。
- ⚠️ **有息负债规模较高：** 截至2025Q3资产负债率约66.9%，有息负债约1378亿元，多次大规模收购后财务杠杆处于相对高位。（研报数据）
- ⚠️ **分红决策的弹性空间：** 2025年每股分红合计5.0元（中期1.8元+末期3.2元），较2024年的7.7元/股有所下降，虽仍保持较高水平但下降趋势需关注。

**一句话评价：** 管理团队专业和经验丰富，但近期并购标的业绩承诺未完成叠加高位财务杠杆，需重点关注后续资产整合成效和现金流改善进度，存在一定执行风险。

### 八、未来会怎样？预测与判断

**短中期展望（1-2年）：**

业绩大概率在2025年筑底，2026-2027年有望实现**量价双升**：①量端——万福煤矿（180万吨焦煤）已进入联合试运转、五彩湾四号（1000万吨）已于2025年投产，2026-2027年贡献增量产能；②价端——"反内卷"政策持续强化供应约束、进口收缩、海外能源价格回暖，煤价中枢有望温和抬升。机构预测2026年归母净利润可达193亿元左右（包含鑫泰煤炭资产处置收益30.5亿元一次性影响）。2026Q1商品煤产量4,155万吨同比-6.28%，需关注产量波动对全年目标的潜在影响。核心催化剂包括：五彩湾四号二期产能核增落地、荣信化工80万吨烯烃项目投产、以及国际煤价与油价联动上行。

**长期终局判断（3-5年）：**

公司2030年前有望实现"原煤产量3亿吨、化工品年产2000万吨以上"的战略目标，届时将成为全球规模最大的多元化清洁能源供应商之一。高成长性+高分红+国际化三重属性，有望推动公司从周期股估值（PE 8-10倍）向"成长+价值"复合型估值（PE 12-15倍）切换。

**估值锚定：**

当前市场给的更多是"价值/红利股"定位（2026年PE约9-10倍），但公司成长性稀缺，实际具备"周期底部的弹性成长股"双重属性。参考可比公司2026年平均PE约10-13倍区间，考虑到公司未来2-3年每年约5-10%的产量增长和约70%的市场煤弹性敞口，2026-2027年PE合理中枢应在10-14倍区间，对应市值约2000-2800亿元。但需密切关注煤价走势和业绩达成情况对估值的动态影响。

**一句话结论：** 产能迈向3亿吨+74%市场煤定价弹性+煤化工逆周期增长，三击共振下，核心变量不是"有没有空间"，而是"煤价什么时候真正企稳回升"。
