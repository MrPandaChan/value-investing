# 财务报表分析

## 前置步骤：公司理解、财报可信度初判与关键变量搜索

### Step 1：这是一门什么样的生意？

中远海控是全球最大的集装箱航运企业之一，其生意本质可以概括为：**用船把集装箱从一个港口运到另一个港口，并管理沿途的码头**。

**核心业务结构（基于2025年报）**：

- **集装箱航运业务**：收入占比95.96%，是绝对的核心。通过自营船队（590艘、约360万标准箱）在全球308条国际航线、62条中国沿海航线、85条支线上提供集装箱海运服务。
- **码头业务**：收入占比4.04%，运营全球40个港口、387个泊位。相对于航运业务，码头业务更为稳定。

**生意质量三重过滤**：

| 过滤维度             | 评估        | 说明                                                                                                                                                                |
| -------------------- | ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 业务可理解吗？       | ✅ 通过     | 用船运箱子，赚运费差价。任何一个普通人都能在两分钟内理解。                                                                                                          |
| 收入/客户可证实吗？  | ⚠️ 部分疑虑 | 客户高度分散（全球货主、货代），现金交易为主，下游真实性较难逐一验证。收入直接受公开运价指数（SCFI/CCFI）锚定，存在外部交叉验证通道，但行业周期性极强、收入波动大。 |
| 模式依赖漂亮报表吗？ | ✅ 通过     | 2021年起自由现金流极其充沛（2021年1614亿、2022年1863亿），现金储备超1500亿，完全不需要靠融资维持运营。                                                              |

- 2017-2019年扣非占比低，主要因行业周期底部，公司依赖非经常性损益维持账面盈利

**判词**：**2021年后利润质量极高，无虚增利润嫌疑。**

### 1.2 利润含金量分析

| 指标              | 2018（谷底） | 2021-2022（巅峰） | 2025（当前） | 评价          |
| ----------------- | ------------ | ----------------- | ------------ | ------------- |
| 扣非净利润/净利润 | 15.48%       | 99.39%-99.81%     | 99.54%       | ⭐ 当前极高   |

**关键解读**：

1. **2021年之后的利润含金量极高**。扣非净利润占比从2018年仅15%跃升至稳定在99%以上，说明公司已摆脱对非经常性损益的依赖。2021年是分水岭——超级周期带来的巨额利润不仅还清了历史包袱，还积累了天量现金。

2. **经营现金流始终大于净利润**（除2023年外），这是最硬的利润质量证据。2023年经营现金流/净利润短暂跌破100%（94.65%），原因清晰：运价回落后，营运资本自然扩张（客户付款节奏放缓），属于正常的周期底部现象。

3. **自由现金流波动大**。2021年高达181%，2023年骤降至30%，2025年66%。核心变量是资本支出：2021年仅95亿（运价暴利期但船未交付），2024-2025年增至250-260亿（新船开始交付）。这是重资产周期行业的天然特征。

**关键解读**：

1. **毛利率的高度周期性**：从2016年的-1%（亏损跑船）到2022年的44%（印钞机），波动幅度惊人。这恰恰说明**集装箱航运属于强周期行业，不具备品牌消费品那样的稳定毛利率护城河**。

2. **底部的抬升**：2016-2018年毛利率在-1%到8%之间挣扎，而2023年运价同样低迷时，毛利率仍有16.35%，远好于上一轮周期底部。这说明：

   - 公司成本控制能力增强

## 最终总结：综合投资结论

### 1. 这是一门什么样的生意？

中远海控是一家**全球第一梯队的集装箱航运央企**，核心收入来源是用船队（598艘、362万TEU）在全球航线上运输集装箱并收取运费。它的商业模式极其简单——**赚运费差价**。附带运营全球40个码头的"收租"业务作为稳定器。

这门生意的本质特征是：**高周期性、重资产、强规模效应、寡头格局下的博弈**。它不是成长股，不是消费股，而是一只典型的周期股。

### 2. 财报可信度评级：✅ 高可信

**核心支持证据**：

- 信永中和连续8年出具"标准无保留意见"，治理结构规范（央企）
- 2021年后扣非净利润占比持续>99%，经营现金流持续>净利润，利润含金量极高
- 财务数据与SCFI/CCFI运价指数的波动高度吻合，不存在"报表业绩与行业背离"的异常

**唯一关注点**：2018年并购东方海外产生的63.59亿商誉，占总资产仅1.31%，且标的持续盈利，风险可控。

### 3. 历史财务表现如何？

**一句话：一顿吃饱三年不饿。**

- 2021-2022年吃到疫情+供应链紊乱+红海危机的超级红利，两年怒赚近2000亿净利润，ROE突破100%
- 暴利之后迅速还债、降杠杆、囤现金、大比例分红+回购，资产质量从高风险蜕变为极稳健
- 2023-2025年回归常态：营收2000-2300亿，净利润240-490亿，ROE 12-23%
- **质的飞跃**：即使运价回到周期底部区域，公司也能保持双位数ROIC和15%+净利率，远好于上一轮周期（2017-2019年净利率仅1-4.5%）

### 4. 当前最关键的经营变量是什么？

| ---- | ------------------------- | --------------------------------------- | -------------------------------------------------------------------------------- |
| ❶    | **SCFI运价指数**          | **2726点，连续六周上涨，两年新高**      | 如果Q3旺季维持2500+，2026年净利润有望重回500亿+                                  |
| ❷    | **红海/霍尔木兹海峡状态** | **持续封锁，绕航常态化**                | 这是消耗运力、支撑运价的"安全气囊"。一旦解除，运力瞬间释放10%+，运价面临崩塌风险 |
| ❸    | **新船交付节奏**          | **2026年预计全球交付165万TEU（+4.3%）** | 运力持续扩张vs需求放缓（+2.4%）→ 中长期供需关系不容乐观                          |

### 5. 主要风险点在哪里？

| 优先级 | 风险                                                            | 概率 | 影响                    |

| **P1** | **全球贸易衰退 + 新船集中交付 → 供需严重失衡 → 恶性价格战**     | 中低 | 重创                    |
