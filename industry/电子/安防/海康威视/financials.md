# 财务报表分析

## 前置步骤：公司理解、财报可信度初判与关键变量搜索

### Step 1: 理解公司的生意并初判生意质量

#### 这家公司靠什么赚钱？

海康威视以**智能物联（AIoT）**为战略定位，核心是通过"物联感知 + 人工智能 + 大数据"三大技术，实现物理世界向数字世界的映射。公司提供超过30,000种智能物联产品，覆盖从前端感知（摄像机、传感器）到后端平台（软件、AI算法）的全链路。

从2026年中报数据看，营收结构为：

- **主业产品及服务**：306.16亿（65.39%），含PBG（公共服务）、EBG（企事业）、SMBG（中小企业）及海外主业
- **创新业务**：151.70亿（32.40%），含机器人（40.28亿）、热成像（29.64亿）、汽车电子（27.64亿）、智能家居/萤石（28.18亿）、存储（19.44亿）等
- **主业建造工程**：10.36亿（2.21%）

核心利润来源仍是**主业产品及服务**，但**创新业务占比已从2019年的不足10%快速攀升至32.40%**，且增速（+28.93%）远超主业。

#### 商业模式特点

| 维度     | 特征                                                                 |
| -------- | -------------------------------------------------------------------- |
| 客户类型 | 以政企大客户为主（PBG+EBG），辅以SMBG渠道分销和海外直销/经销         |
| 收入模式 | 硬件销售 + 解决方案 + 云服务/SaaS（萤石）的混合模式                  |
| 竞争壁垒 | 技术（观澜大模型）、规模（3万+ SKU）、渠道（180+国家）、供应链一体化 |
| 增长驱动 | 从"硬件铺货"转向"AI赋能的场景数字化"，创新业务成为第二曲线           |

#### 生意质量三重过滤

**1. 业务可理解吗？** ✅ 通过。海康的生意本质是"用摄像头+AI帮助客户看见并理解物理世界"。即使向非专业人士解释，核心逻辑清晰：卖设备（硬件）+ 卖算法（AI）+ 卖服务（云/SaaS）。

**2. 收入/客户可证实吗？** ⚠️ 部分存疑。政企大客户（PBG/EBG）占比高，收入可追溯性强；但海外业务（37%）涉及180+国家，且存在代理商/经销商渠道，部分终端客户较难直接验证。此外，项目制收入存在收入确认时点的主观判断空间。

**3. 模式依赖漂亮报表吗？** ✅ 不依赖。公司自由现金流充沛（2025年自由现金流/净利润达152.99%），经营现金流长期为正，无需持续外部融资支撑运营。2025年分红率74.25%，是真金白银的回报。

### 4. 综合定级

**财报可信度评级：高可信**

**核心理由**：

1. **审计意见干净**（标准无保留）+ 研发全部费用化（极保守会计政策），管理层无造假动机（央企控股+74%分红率）
2. **经营现金流/净利润长期大于1**（2025年达178.50%），利润含金量极高，扣非净利润占比持续>95%
3. **没有发现存贷双高、商誉泡沫、激进资本化等典型造假信号**

**需持续关注的信号**：

- 1元收入需固定资产投入持续攀升（从0.10到0.22），可能暗示传统主业投资回报率下降

- 2026年更换审计师（德勤→毕马威），需关注交接是否平稳

**整体结论**：海康威视的财务报表可信度高，可以作为分析的基础。但不排除个别项目（如海外新兴市场代理商收入）存在一定程度的"水分"或"优化"空间，这在大型跨国企业中属常见现象。

   - ③ **AI高毛利产品占比提升**（结构性利好）：观澜大模型产品毛利率显著高于传统硬件

3. **毛利率可持续性评估**：当低价库存耗尽（预计2026Q3-Q4），毛利率可能回落至46-47%区间，但仍显著高于2022-2024年的42-44%水平。

**费用率的"倒V型"特征**：

海康的费用率持续攀升（从2016年的18.39%到2025年的28.72%），但这并非效率恶化，而是**主动的战略选择**：

- **研发费用率**：从0%（2016年费用化数据缺失）到12.70%。这是海康从"安防设备商"向"AIoT科技平台"转型的必然代价，也是构建长期护城河的必要投资。
- **销售费用率**：从9.37%上升到13.35%，反映海外市场开拓、创新业务推广的渠道建设投入。
- **管理费用率**：始终控制在2.6-3.4%的低位，说明管理效率优秀。

**规模效应并未体现为费用率下降**，而是体现在**费用绝对额的增速控制在收入增速以内**。2025年三项费用同比仅增-1.22%，2026Q1+4.86%（远低于收入增速11.78%），这是2025-2026年净利润增速远超收入增速（"增利不增收"）的核心原因。

### 3. 研发投入判断

**全部费用化，零资本化**——这是海康财报最值得信赖的信号之一。

- 当期利润已被充分"压低"（保守处理）
- 不存在通过研发资本化虚增资产/利润的风险
- 未来若减少研发投入增速，利润有较大的"释放"空间

### 2. 增长趋势诊断

**海康正在经历增长模式的根本性切换：**

```
2016-2021  高速增长期：营收CAGR ~20%，靠硬件出货量驱动
2022-2024  调整阵痛期：营收增速骤降至个位数，净利润甚至下滑
2025-2026  质量优先期：营收微增，但利润/现金流大幅改善
```

**"增利不增收"的结构性原因**：

1. **主动退出低端市场**：砍掉薄利甚至亏损的安防订单，不再追求规模
2. **费用管控见效**：2025年员工减少4.17%，薪酬支出减少7.4亿
3. **产品结构升级**：AI产品占比提升，毛利率跃升
4. **应收账款压降**：2025年应收减少77.7亿，坏账计提压力减轻

这种"减脂增肌"的增长模式，在转型期是健康的。但需要警惕：**如果营收持续零增长，仅靠"节流"驱动的利润改善有天花板。**

### 3. 增长模式识别

海康的增长并非依赖外延并购，而是**内生创新驱动**：

- **创新业务来源**：2015年建立内部创新跟投制度，陆续孵化8个创新业务公司，均为内生培育
- **商誉/并购风险**：2025年末商誉仅3.11亿（占总资产0.23%），几乎可以忽略不计
- **外延扩张**：未见大规模溢价并购

这种模式的好处是增长质量高、不存在商誉"暴雷"风险。劣势是增长速度受限于内部孵化节奏，无法通过并购实现跳跃式增长。

- 现在：高ROE更需要依赖高利润率来弥补周转率的下降

如果未来毛利率不能维持在45%+的高位，ROE的下滑压力将显著加大。

### 1. ROE杜邦分解

| 年份   | ROE           | 销售净利率 | 资产周转率     | 权益乘数 |
| ------ | ------------- | ---------- | -------------- | -------- |
| 2016   | 34.58%        | 23.24%     | 89.10%         | 1.69     |

| 2022   | 19.62%        | 16.30%     | 74.56%         | 1.63     |
| 2024   | 15.34%        | 14.21%     | 68.29%         | 1.51     |
| 2025   | 17.30%        | 16.68%     | 68.51%         | 1.51     |
| 2026Q2 | 9.17%（半年） | 19.48%     | 33.96%（半年） | 1.48     |

**杜邦分析揭示的ROE下滑根源**：

ROE从2016年的34.58%下降至2024年的15.34%（腰斩），2025年小幅反弹至17.30%。拆解来看：

```
ROE下滑的因子贡献：
- 销售净利率：23.24% → 16.68%，贡献约 -28%
- 资产周转率：89.10% → 68.51%，贡献约 -23%
- 权益乘数：1.69 → 1.51，贡献约 -11%
```

**双杀**：ROE下滑是"利润率下降 + 周转率下降"的双重打击，且周转率下降（资产变重）的影响不亚于利润率下滑。

好消息是：

- **高杠杆不驱动ROE**：权益乘数仅1.51，ROE的含金量较高（非杠杆驱动）
- **2025年拐点出现**：净利率和ROE双双回升，2026Q2年化ROE约18%+，恢复趋势确立
