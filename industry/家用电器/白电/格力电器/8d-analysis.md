# 非财务信息“八问”

## 靠什么赚钱？

> 搞清楚生意是怎么做的，核心驱动力是什么

**生意本质一句话概括：** 公司赚的是品牌溢价叠加渠道扁平化带来的利润优化，而非纯粹的规模扩张。

**收入与利润结构拆解：** 2024年消费电器（空调为主）营收1485.6亿元，占比**78.54%**，工业制品及绿色能源占比约10%，是典型"一招鲜"结构。但空调业务毛利率34.91%（消费电器整体），而其他业务毛利率仅为个位数，意味着**超过90%的利润仍来自空调**。

**核心驱动力：** 回顾2020-2024年，公司营收CAGR仅+3%，归母净利润CAGR却达+10%，利润弹性远大于收入弹性。核心驱动力是**利润率的持续改善**，而非规模扩张。净利率从2019年的12.3%提升至2024年的16.94%，验证了渠道扁平化的利润释放逻辑。2025年营收同比下滑9.9%至1704亿元，但净利率仍维持在17%左右，利润韧性是当前最值得关注的变量。

## 顺风还是逆风？

> 外部大环境境好不好

**宏观定性：结构分化期——国内存量化加剧，新兴市场出海带来结构性机会。**

**顺风清单：**

1. **以旧换新政策持续发力，龙头最受益。** 格力2026年Q1线下增速+41.97%，排名第一，政策红利主要体现在线下渠道。
2. **国内空调保有量仍有提升空间。** 测算显示远期仍有37%空间，农村市场渗透率仅105.7台/百户，天花板尚远。
3. **新兴市场需求旺盛。** 东南亚/南美市场理论空间分别还有124%、114%，而格力自主品牌出口占比近70%，全球化布局最早。

**逆风清单：**

1. **空调存量周期已然到来。** 2025年全年空调内销同比下滑1.2%，预计2026年市场销额将同比-8.5%，行业增速放缓。
2. **市占率正在流失。** 2025年Q3格力全渠道市占率已降至17.8%，被美的（25.6%）和上升中的小米进一步拉开差距。
3. **营收结构单一风险加大。** 2024年消费电器占比高达78.54%，创近年新高，多元化投入5年仍未形成有效对冲。
4. **大股东减持压力。** 第一大股东珠海明骏披露拟减持不超过总股本2%，增加了股价压制因素。

## 空间有多大？

> 行业未来空间有多大，未来发展的天花板

**第一增长曲线见顶判断：接近天花板但仍有空间。** 2025年空调零售量7604万台，同比仅增4.7%但销售额下滑-0.4%，"量升价跌"的早期信号已经出现。行业进入存量博弈阶段，量难以大幅扩张，价格成为主要竞争战场。对格力而言，国内空调的天花板已经显现在增速放缓，而非绝对渗透率见顶。

**第二增长曲线储备：**

| 业务方向             | 2024年规模    | 未来潜力                                     |
| -------------------- | ------------- | -------------------------------------------- |
| 工业制品及绿色能源   | ~172亿元      | 预计2025-2027年复合增速8%-14%                |
| 盾安环境（制冷配件） | 并入报表      | 全球阀件市占率第一/第二，未来与格力钛协同    |
| 半导体MCU/碳化硅     | 累计超2.6亿颗 | 2026年业务同比+200%，已进入比亚迪/长安供应链 |
| 格力钛（新能源）     | 仍亏损        | 2025年上半年亏损约5.1亿，扭亏尚需时间        |

**天花板量化预估：** 乐观情景下（新兴市场+全屋生态+多元化共振），格力3-5年可实现消费电器中个位数CAGR，加上工业/绿色能源中双位数增长，总营收有望达到2000-2200亿元，对应归母净利润约370-400亿元。但当前实际数据显示短期内未必能达到。

## 竞争格局好不好？

> 认识行业竞争的玩法

**行业梯队地图：** 格力、美的稳居第一梯队，形成"两足鼎立"格局。2025年线下空调市场市占率美的32.27%、格力28.37%、海尔12.27%，三者合计逾70%。小米以线上价格战获得13.7%份额，但技术积累和渠道深度与龙头差距悬殊，尚不足撼动传统格局。

**竞争核心要素：** 空调行业的竞争本质是**品牌信任×渠道覆盖×成本控制**的三元博弈。产品质量的同质化程度越来越高，渠道效率和品牌溢价共同决定最终利润率。格力在这三个维度均有较强积累，但在渠道效率上已明显落后于美的新零售模式。

**利润率密码：** 格力2024年净利率16.94%，在制造业中属于罕见的高利润率水平。这种高利润率的来源是：品牌溢价+渠道扁平化+成本控制合力。但也正是因为这种高利润率，格力几乎不可能在"价格战"中全面降价保份额，任何大幅降价都会直接冲击高利润的基本盘。

## 有什么优势？

> 与同行相比，有什么优势

**对比表格：**

| 维度         | 格力                         | 美的               | 海尔                       |
| ------------ | ---------------------------- | ------------------ | -------------------------- |
| 品牌溢价     | ★★★★★ 显著高于同行           | ★★★★               | ★★★                        |
| 渠道掌控     | ★★★★ 改革中但根基深厚        | ★★★★★ 新零售最成功 | ★★★                        |
| 产品多元化   | ★★ 空调依赖度高              | ★★★★★ 全品类覆盖   | ★★★★★ 卡萨帝高端布局       |
| 海外自主品牌 | ★★★★ 出口近70%自主品牌       | ★★★★★              | ★★★★★ 全球化并购经验最丰富 |
| 技术垂直整合 | ★★★★★ 自研压缩机/电机/半导体 | ★★★★               | ★★                         |

**独特护城河阐述：**

1. **垂直一体化构建的成本护城河**：格力掌握从上游精密模具、压缩机、电机、半导体到下游拆解回收的完整产业链，凌达压缩机、零边界MCU等自研核心部件降低了对外部供应链依赖。这种一体化布局是海尔、海信等竞对难以复制的。
2. **"先款后货"体系塑造的经销商生态**：格力历史上建立起的高度绑定经销商利益的返利体系，虽然经历了阵痛期的经销商出走，但仍是其他品牌难以挑战的"重资产"模式。2025年京海互联的增持说明经销商信心已修复。
3. **董明珠IP积累的品牌认知成本**：格力"好空调格力造"的品牌形象深入人心，形成极高的品牌转换成本壁垒。消费者愿意为格力支付10%-20%的价格溢价，这种品牌认知是其他品牌很难用短期营销复制实现的。

## 管理层行不行？

> 特别关注老板和管理层，公司治理有没有问题

**管理层画像：** 2025年4月完成董事会换届，董明珠继续连任董事长，张伟接任总裁。新管理层呈现**明显的年轻化、工程师化趋势**，新任副总裁刘华（49岁）、李绍斌（49岁）、胡余生（48岁）、王凯（46岁）均是工程师出身，且多为格力内培人才。董明珠此前透露已有三至四名接班人备选，为平滑交接创造了条件。

**治理红灯预警：**

- **大股东减持风险（★★★★★）**：第一大股东珠海明骏2026年2月公告拟减持不超总股本2%，虽然目前尚未大规模实施，但信号意义不容忽视。
- **股权质押风险（★★★★）**：第一大股东珠海明骏所持股份中，质押比例一度高达87.62%，占总股本约14.12%，若股价大幅下跌可能触发补充质押。
- **格力钛持续亏损（★★★★）**：2025年上半年格力钛亏损约5.1亿元，成为拖累报表的主要负面因素，大规模投入尚未见到回报拐点。
- **分红高但经营现金流存在隐忧**：2025年经营现金流仍有463.83亿元，现金储备充裕。但ESG争议和创始人个人IP与公司深度捆绑带来的"接班人焦虑"，构成长期视角下的风险要素。

**一句话评价：** 管理层执行力强、与股东利益绑定度高，但需要警惕格力钛的持续亏损和高瓴减持压力带来的基本面与情绪双重挑战。

## 风险在哪里？

> 不利因素有哪些，风险可能出现在什么地方，没达到预期的薄弱环节在哪里

**风险矩阵：**

| 风险等级 | 风险点                 | 原因/表现                                                    |
| -------- | ---------------------- | ------------------------------------------------------------ |
| ★★★★★    | 大股东减持+股权质押    | 第一大股东披露减持计划，股权质押比例高，股价下行可能触发补仓 |
| ★★★★     | 市占率持续下滑         | 2025年Q3全渠道市占率跌至17.8%，被美的、小米拉开差距          |
| ★★★★     | 格力钛亏损拖累         | 2025上半年仍亏损约5.1亿元，多元化"试验田"成利润出血点        |
| ★★★      | 空调行业进入存量价格战 | 2025年零售量增4.7%但销售额降0.4%，"以价换量"趋势显现         |
| ★★★      | 原材料成本上行         | 铜价仍处高位，持续挤压毛利率，利润弹性可能受限               |

**最薄弱一环：** **空调市占率持续下滑叠加多元化投入尚未见效的双重夹击**。格力若不能在稳住市场份额的同时加速多元化进度，将面临"主业被持续侵蚀、新业务未能接棒"的困境。短期来看，营收与净利润双降（2025年双降约9.9%）最直观地反映了这一压力的现实影响。

## 未来会怎样？

> 未来会怎样，对未来做出预测

**短中期展望（1-2年）：** 2026年Q1公司已实现营收同比+3.46%、归母净利润同比+3.01%，止跌回正信号值得关注，但仅为低基数修复。空调行业进入存量博弈，预计2025-2027年营收增速为低个位数波动（浙商证券预测约+4%~6%）；净利率持续优化是核心看点。核心催化剂有两方面：一是"董明珠健康家"门店改造能否带来生活电器品类的实质性突破；二是碳化硅芯片、盾安协同等多元化业务能否转化为利润增量。

**长期终局判断（3-5年）：** 格力若持续推进全屋生态战略，成功实现从"空调制造商"向"智能家居解决方案商"转型，依托品牌溢价和渠道黏性，有望在消费电器品类上形成更均衡的结构；同时，工业制品与绿色能源有望在营收贡献上逐步提升。但如果格力钛持续亏损、多元化进程停滞且空调市占率进一步下滑，公司将面临成长性被"空调化"所限的困境，最终可能沦为依靠高分红的"价值股"，而非兼具成长的"价值成长股"。

**估值锚定：**

| 券商/来源                        | 2026年目标价    | 备注                             |
| -------------------------------- | --------------- | -------------------------------- |
| 浙商证券（2025年5月）            | 估值锚定7.3X PE | "买入"评级，看治理改善与渠道改革 |
| 财通证券（2026年4月）            | 7.5-7.5X PE     | "买入"评级，看渠道修复+出海逻辑  |
| 行业可比公司平均（2025年预测PE） | 约12-13X        | 当前格力PE仅为可比公司的一半左右 |

格力当前交易在**"价值股"定价逻辑**——高股息（2025年分红比例约57.8%）、低PE（6-7X）、稳定的现金流。如果管理层能打通"第二增长曲线"，或者市占率竞争格局出现有利变化（如竞争趋缓、价格战降温），存在向"价值成长股"估值重塑的机会。但这一重塑逻辑能否兑现，最终还要看业绩数据的持续验证。

**一句话结论：** 高股息、低估值提供安全边际，但成长性不足是核心痛点，近期关注大股东减持风险，长期看多元化何时真正贡献利润增长。
