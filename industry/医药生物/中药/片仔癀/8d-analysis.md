# 非财务信息“八问”

## 维度一：靠什么赚钱？核心驱动力是什么？

**生意本质一句话概括**：片仔癀赚的是**国家级绝密配方带来的独家定价权**——用稀缺名贵药材（天然麝香+天然牛黄）生产不可替代的保肝护肝名贵中成药，通过持续提价实现利润增长。

**收入与利润结构拆解**：

片仔癀的业务分为三大板块：

| 业务板块                         | 2024年营收 | 占比  | 毛利率 | 利润贡献   |
| -------------------------------- | ---------- | ----- | ------ | ---------- |
| 医药工业（自产中成药）           | 56.63亿元  | 52.5% | 64.65% | **~90%**   |
| 其中：肝病用药（片仔癀系列）     | 53.10亿元  | 49.2% | 67.9%  | 核心利润源 |
| 其中：心脑血管用药（安宫牛黄丸） | 2.84亿元   | 2.6%  | 14.2%  | 毛利率极低 |
| 医药商业（药品流通）             | 40.84亿元  | 37.8% | 11.36% | 利润贡献小 |
| 化妆品                           | 7.52亿元   | 7.0%  | 60.80% | 补充利润   |

2024年公司整体营收107.88亿元，同比增长7.25%；归母净利润29.77亿元，同比增长6.42%。**肝病用药（片仔癀系列）是绝对核心**，以不到一半的营收贡献了约90%的利润。医药商业营收规模大但毛利率仅11%左右，是典型的"赚流水不赚钱"业务。

**核心驱动力**：片仔癀的业绩增长发动机是**"提价+销量微增"双轮驱动**。2019-2024年，肝病用药营收从21.8亿元增长到53.1亿元，年复合增速高达19.5%。其中2023年提价贡献了约19.7%的增速，销量贡献约3.8%；2024年价格贡献约16.5%，销量贡献约2.1%【诚通证券测算】。提价是主引擎，销量稳健增长是辅助。2023年5月最近一次提价（出厂+170元/粒，零售至760元/粒）后，2023-2024年连续两年销大于产，2024年末肝病用药库存仅14.1万盒，显示提价并未抑制需求。

## 维度二：顺风还是逆风？外部大环境好不好？

**宏观定性**：**结构分化期——核心产品顺风，但行业整体面临逆风**。

**顺风清单**（3项）：

1. **牛黄进口政策落地（重大利好）** ：2025年4月，国家药监局、海关总署正式允许进口牛黄试点用于中成药生产【诚通证券研报】。天然牛黄价格已从2025年2月165万元/公斤高位回落至2025年12月110万元/公斤。片仔癀已率先完成首单样品进口。这将直接缓解公司最大成本压力。
2. **老龄化趋势推动需求**：中国65岁以上人口持续增长，肝病（尤其是非酒精性脂肪肝）和心脑血管疾病患病率上升，片仔癀（保肝护肝）和安宫牛黄丸（心脑血管急救）的需求天花板较高【万联证券研报】。
3. **品牌壁垒持续加固**：片仔癀是国家绝密级配方（永久保密），品牌价值位列"2023中华老字号品牌榜"第2位【万联证券研报】，这种级别的品牌护城河在消费降级环境中反而凸显稀缺性。

**逆风清单**（4项）：

1. **原材料成本高企（最大逆风）** ：天然牛黄价格从2023年初57万元/公斤飙升至2025年5月170万元/公斤，直接导致公司整体毛利率从2023年46.8%降至2024年42.74%。安宫牛黄丸毛利率从2021年50.7%暴跌至2024年14.2%【诚通证券研报】。
2. **中成药集采深入推进**：集采政策持续深化，倒逼产业转型升级。虽然片仔癀作为独家品种短期受影响较小，但行业整体价格承压。
3. **安宫牛黄丸市场2024年萎缩**：安宫牛黄丸实体药店销售额从2023年51.44亿元降至2024年42.56亿元，同比下降17.24%。行业整体需求出现阶段性下滑。
4. **消费疲软影响高端礼品属性**：片仔癀兼具"药品+高端礼品"属性，经济下行周期中高净值人群消费行为变化可能影响保健用途需求。

## 维度三：空间有多大？天花板在哪里？

**第一增长曲线（片仔癀）见顶判断**：

**远未见顶**。万联证券模型测算显示，片仔癀目前渗透率**远低于2%**【万联证券研报】。在2%渗透率假设下，2016-2019年销量有27-53倍的增长空间。肝病用药市场2022年规模达1364亿元，片仔癀肝病用药2024年收入仅53.1亿元，市占率不足4%【万联证券研报】。考虑到非酒精性脂肪肝病患者占比持续提升（2020年已达56.89%），且片仔癀正在推进肝癌等新适应症的临床研究，市场边界有望进一步扩大【万联证券研报】。

**第二增长曲线（安宫牛黄丸）储备**：

安宫牛黄丸是明确的第二增长曲线。2023年全市场超60亿元，线下实体药店超50亿元。片仔癀牌安宫牛黄丸2021-2024年营收从0.96亿元增长到2.84亿元，CAGR达43.6%。当前市占率仅约1.21%（实体药店口径），而龙头同仁堂市占率超50%【万联证券研报】。若市占率提升至5%，对应营收即可达3亿元以上；提升至10%，则超过6亿元。**空间巨大但挑战同样巨大**。

**化妆品业务**：2024年营收7.52亿元，毛利率60.8%。国妆市场持续增长，但片仔癀化妆品体量尚小，2022年曾经历管理层调整和价格体系梳理【万联证券研报】。若能恢复增长，有望成为第三增长极。

**天花板量化预估（3-5年）** ：

- **肝病用药**：若年均提价9%+销量增长3%，2027年有望达75亿元+【诚通证券预测】
- **心脑血管用药**：若市占率提升至3-5%，2027年有望达5-8亿元
- **整体营收**：诚通证券预测2027年约140.8亿元【诚通证券研报】；招商证券预测2025年约136.8亿元【招商证券研报】

## 维度四：竞争格局好不好？玩法是什么？

**行业梯队地图**：

| 梯队         | 企业               | 核心产品           | 市场地位                         |
| ------------ | ------------------ | ------------------ | -------------------------------- |
| **第一梯队** | **片仔癀**         | 片仔癀锭剂（肝病） | **独家品种，绝密配方，无可替代** |
| 第一梯队     | 同仁堂             | 安宫牛黄丸         | 安宫市场超50%份额，绝对龙头      |
| 第二梯队     | 云南白药           | 云南白药（止血）   | 另一国家级绝密配方，但品类不同   |
| 第二梯队     | 广誉远、南京同仁堂 | 安宫牛黄丸         | 安宫市场各约10%【万联证券研报】  |
| 第三梯队     | 达仁堂、九芝堂等   | 安宫牛黄丸         | 份额较小                         |

**竞争核心要素**：

1. **牌照/配方壁垒（最高壁垒）** ：片仔癀是国家绝密级配方（永久保密），全国仅片仔癀和云南白药两家【万联证券研报】。安宫牛黄丸方面，全国仅6家企业具备双天然生产资格，片仔癀是其中之一【万联证券研报】。
2. **原材料获取能力**：天然麝香实行国家配额制，全国仅16家企业共27款药品获准使用【诚通证券研报】。片仔癀是最早获批的5家企业之一，且自建林麝养殖基地。
3. **品牌力**：中药行业品牌即信任，片仔癀品牌价值409.37亿元【万联证券研报】。

**利润率密码**：片仔癀医药工业毛利率虽从2021年78.4%降至2024年64.65%，但仍远高于行业平均。高毛利的根本原因是**独家品种+定价权**——公司可以随原材料涨价而提价，这是普通中药企业不具备的能力【万联证券研报】。相比之下，安宫牛黄丸竞争激烈，片仔癀该业务毛利率仅14.2%【诚通证券研报】，远低于肝病用药。

## 维度五：有什么优势？护城河在哪？

**对比表格**（片仔癀 vs 同仁堂 vs 云南白药）：

| 维度                     | 片仔癀                          | 同仁堂                      | 云南白药             |
| ------------------------ | ------------------------------- | --------------------------- | -------------------- |
| **配方保护级别**         | **国家绝密（永久）**            | 国家保密（长期）            | **国家绝密（永久）** |
| **核心产品**             | 片仔癀锭剂（肝病）              | 安宫牛黄丸                  | 云南白药（止血）     |
| **2024年医药工业毛利率** | **64.65%**                      | ~50%（估算）                | ~60%+                |
| **原材料壁垒**           | 天然麝香+天然牛黄，自建养殖基地 | 天然麝香+天然牛黄，依赖采购 | 三七为主，壁垒较低   |
| **渠道覆盖**             | 近400家国药堂+10万+终端门店     | 超10万家终端                | 多渠道覆盖           |
| **品牌价值**             | 409.37亿元（2023）              | 高                          | 高                   |

**独特护城河阐述**（3项极难复制的核心壁垒）：

1. **"国家绝密配方+一级中药保护品种"的双重法律护城河**：片仔癀处方和工艺属国家绝密级秘密，保密期限为**永久**【万联证券研报】。全国仅片仔癀和云南白药两家享受此待遇。这意味着不存在仿制药竞争，公司拥有事实上的永久垄断权。

2. **上游原材料的"准入+储备"双重壁垒**：天然麝香实行国家配额制，片仔癀是首批获准使用的5家企业之一【诚通证券研报】。公司还通过自建林麝养殖基地（陕西凤县、四川阿坝）推行"公司+基地+科研+养殖户"模式，从源头掌控供应【诚通证券研报】。2024年末原料库存增至32.1亿元（麝香+牛黄约29.5亿元），同比2022年增长118%。这种"准入资格+战略储备"的组合，新进入者几乎不可能复制。

3. **近500年历史沉淀的品牌溢价**：片仔癀起源于明朝末年，是"海上丝绸之路"上的"中国符号"【万联证券研报】。品牌入选"2022凯度BrandZ最具价值中国品牌百强榜"第33位，居"2022胡润中国最具历史文化底蕴品牌榜"榜首【万联证券研报】。这种历史厚度带来的消费者信任，是任何广告投入都无法短期建立的。

## 维度六：管理层行不行？治理有没有雷？

**管理层画像**：

公司由漳州市国资委实际控制，大股东漳州市九龙江集团持股51.3%。过去十年经历了三任董事长：刘建顺（2014-2021）主导体验馆扩张；潘杰（2021）开拓线上直营渠道；林纬奇（2021-至今）强调"多核驱动"战略【万联证券研报】。管理层风格总体稳健，战略延续性较好。

**治理红灯预警**：

| 风险信号     | 严重程度 | 说明                                           |
| ------------ | -------- | ---------------------------------------------- |
| 高管变动频繁 | ★★★      | 近十年三任董事长，但均在国资体系内轮换，非异常 |
| 关联交易     | ★★       | 国资控股，关联交易风险可控                     |
| 股权质押     | ★        | 大股东质押比例低                               |
| 分红         | ★        | 稳定分红，无异常                               |

**一句话评价**：**信任度评级：中等偏上**。国资绝对控股（累计持股超56%）保证了战略稳定性【诚通证券研报】，但国企体制也意味着决策效率可能不如民企灵活。过去的管理层更迭并未影响核心业务增长，说明公司治理框架较为成熟。

## 维度七：风险在哪里？薄弱环节是什么？

**风险矩阵**（按严重程度排序）：

| 风险                   | 严重程度 | 说明                                                                                                                           |
| ---------------------- | -------- | ------------------------------------------------------------------------------------------------------------------------------ |
| **原材料价格持续高企** | ★★★★★    | 天然牛黄价格从57万→170万/公斤，直接吞噬利润。安宫毛利率已跌至14.2%【诚通证券研报】。若牛黄进口政策效果不及预期，利润将持续承压 |
| **提价导致需求萎缩**   | ★★★★     | 片仔癀零售价已至760元/粒。若经济持续疲软，高价药品的"保健礼品"需求可能下滑。2025年Q1营收已同比下降0.92%                        |
| **安宫牛黄丸竞争失利** | ★★★★     | 同仁堂占据超50%份额且渠道极强（超10万家终端）。片仔癀2024年安宫销量仅82.97万盒，而同仁堂超125万盒。差距悬殊                    |
| **政策风险**           | ★★★      | 中成药集采持续推进，虽独家品种短期豁免，但长期不排除被纳入                                                                     |
| **研发失败风险**       | ★★★      | 公司在研14个新药项目，中药创新药研发周期长、失败率高                                                                           |

**最薄弱一环**：**天然牛黄的供给与价格**。这是当前最关键的变量。片仔癀肝病用药和安宫牛黄丸的直接材料成本均占96%以上【诚通证券研报】，而天然牛黄和麝香在其中占比极高。牛黄进口试点虽已落地，但从政策到实际大规模供给仍有时间和不确定性。若牛黄价格不能有效回落，公司毛利率和净利润将持续承压——2025年Q1归母净利润增速已降至2.59%，增长动能明显放缓。

## 维度八：未来会怎样？预测与判断

**短中期展望（1-2年）** ：

- **业绩趋势**：增速放缓但仍有韧性。2024年营收增速7.25%已是2015年以来最低；2025年Q1营收同比-0.92%，归母净利润同比+2.59%。机构预测2025年归母净利润约31.7-33.3亿元，增速约6-12%【诚通证券研报】。
- **核心催化剂**：①牛黄进口政策落地效果——若价格持续回落，毛利率有望触底回升；②安宫牛黄丸市占率能否继续提升；③化妆品业务能否恢复增长。
- **潜在压力**：①若牛黄价格反弹，利润将进一步承压；②消费疲软可能抑制高端保健需求。

**长期终局判断（3-5年）** ：

片仔癀最终将成为**"精品国药平台型企业"** ——以片仔癀（肝病）为绝对核心，安宫牛黄丸（心脑血管）为第二增长极，化妆品为第三极的多元化大健康企业【万联证券研报】【诚通证券研报】。核心逻辑是：片仔癀的绝密配方护城河在可见未来不会被打破，只要原材料供给有保障、品牌价值不坍塌，公司就能持续享受提价红利。

**估值锚定**：

当前片仔癀PE（TTM）约41倍（2025年4月29日），十年PE估值中枢为64倍，历史分位值仅6.5%【诚通证券研报】。市场当前给的是**"成长股遭遇逆风"的定价**——估值已大幅低于历史中枢，反映市场对原材料成本、增长放缓的担忧。若牛黄价格持续回落、业绩增速回升，存在**估值修复**的可能（向中枢回归）。若原材料压力持续、业绩继续降速，估值可能进一步下杀。

---

**一句话结论**：

> **绝密配方护城河极深，但短期受制于原材料成本高企和增长失速，当前估值处于历史低位，核心观察牛黄进口政策落地效果——若成本压力缓解，估值修复空间显著；若持续恶化，则"药中茅台"的溢价逻辑将面临考验。**
