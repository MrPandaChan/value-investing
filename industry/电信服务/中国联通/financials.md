# 财务报表分析

## 前置步骤：公司理解、财报可信度初判与关键变量搜索

### Step 1: 理解公司的生意

**中国联通是一家什么样的公司？**

中国联通是中国三大电信运营商之一（另两家为中国移动、中国电信），主营业务分为两大板块：

- **联网通信（基本盘）**：移动通信服务（手机话费、流量费）、固网宽带服务。这是公司的"管道"业务，提供信息传输的基础设施，按量或按月收费。
- **算网数智（增长极）**：以联通云为核心的云计算服务、数据中心（IDC/AIDC）托管、智算服务、大数据、物联网、人工智能应用等。这部分正在从"卖管道"向"卖算力"转型。

**生意质量三重过滤：**

| 过滤维度               | 判断    | 说明                                                                                    |
| ---------------------- | ------- | --------------------------------------------------------------------------------------- |
| 可理解性               | ✅ 通过 | 提供通信和算力基础设施服务，商业模式清晰。向个人和企业收"月租"或"服务费"                |
| 收入可证实性           | ✅ 通过 | 作为央企和上市公司，数据受工信部统计、审计机构双重监督。用户数可独立验证                |
| 模式是否依赖"漂亮报表" | ✅ 通过 | 公司产生强大的经营现金流（2025年914亿），折旧占成本大头但非现金支出，自由现金流持续改善 |

**初步结论**：这是一门资本密集型公用事业生意，重资产、高折旧、稳定现金流是核心特征。

**核心发现**：

1. **毛利率呈缓慢下降趋势（26.57%→23.54%）**：这不是竞争力衰退，而是业务结构变化的反映——低毛利的通信产品销售（如手机终端捆绑销售）和云服务（初期投入大、毛利率低）占比提升，拉低了综合毛利率。这是典型的"营收结构调整期"。

2. **毛利率与同行对比**：23.54%低于中国移动（~30%）和中国电信（~28%），反映了联通的行业地位和业务结构差异。联通在移动端份额最小、宽带端也偏弱，规模效应不如对手。

3. **毛利率-净利率差距从22.77%收窄至21.21%**：说明费用管控在持续改善，这是一个积极的效率信号。

**核心发现**：

### 2. 增长趋势诊断

```
营收增长趋势：
  2020-2022：6-8%增速（5G建设期+疫情释放需求）  →  中速增长
  2023-2025：0.7-5%增速                           →  低速增长（趋于饱和）

  2016-2018：爆发式增长（从亏损边缘到盈利，基数效应） → 超高速增长

  2023-2025：10-15%增速                                → 近三年加速

**核心判断**：

   - 折旧拐点（2025年同比下降3.1%）
   - 资本开支缩减释放的现金流

3. **扣非净利润增速加速（14.73%）是一个重要信号**：说明主营盈利能力的改善在2024-2025年间出现了加速，与AI和算力业务的放量时间点吻合。

4. **2026年面临短期逆风**：增值税率从6%→9%的政策变化，一致预期2026年净利润同比下降约10%。但这是一次性冲击，不影响长期投资逻辑。

  周转率贡献：46.21%→58.37%（+12.16pct） ← 次要贡献
  杠杆变动：  1.87→1.78（-0.09）        ← 轻微去杠杆
```

ROE改善的核心是**净利率从接近0提升至5.3%**，这与前述的折旧下降、费用率优化、业务结构改善形成完整的逻辑闭环。

### 1. 这是一门什么样的生意？

中国联通是一门**资本密集型的数字基础设施公用事业生意**，具有以下特征：

- **垄断竞争格局**：三大运营商寡头垄断，联通是第三名，差异化竞争（主打性价比+政企市场）
- **重资产+高折旧**：固定资产3448亿、年折旧808亿，这是理解其"低利润高现金流"财务特征的关键
- **双引擎驱动**：传统连接业务是"压舱石"（稳定但低增长），算网数智业务是"推进器"（高增长+战略转型方向）
- **深度转型中**：从"卖管道"向"卖算力+卖服务+卖安全"转型，2025年战略性新兴产业收入占比已超86%
- **护城河**：频谱牌照（行政壁垒）、全国性网络基础设施（物理壁垒）、数亿用户基础（规模壁垒）

### 2. 财报可信度评级：🟢 高可信

**核心支持证据**：

1. 央企治理结构+标准无保留审计意见，无任何治理红灯
2. 经营现金流远超净利润（1002%）有合理的商业解释（高折旧），且与经营变量完全吻合
3. 会计政策极端保守——研发全部费用化、零商誉、无激进收入确认
4. 无"存贷双高"、无关联交易异常、无渠道压货风险

**唯一需要持续关注的信号**：应收账款/收入从6.37%升至16.83%，随政企业务扩张而增长，需要跟踪坏账风险和回款周期。

### 6. 投资价值的初步判断

**这是一家处于"深蹲起跳"阶段的公司，核心矛盾在"传统业务减速"与"算力转型加速"之间的赛跑。**

**看多逻辑（Bull Case）**：

- 折旧持续下降（2025年已同比-3.1%），未来3-5年将释放数百亿的"隐形利润"
- 资本开支缩量提质（从742→500亿），FCF将持续大幅改善
- 算力业务若成功放量（AI产业大潮+运营商天然优势），ROE有望突破7-8%
- 当前估值（目标价5.97元对应上涨空间36%）提供了安全边际
- 61.3%的派息率+360亿FCF，股息有提升空间

**看空逻辑（Bear Case）**：

- 算力投资可能陷入"内卷"，投入大但回报不确定（董昕本人已预警）
- 传统移动ARPU持续下滑，基本盘收入可能见顶回落
- 应收账款持续攀升，坏账风险隐现
- 增值税一次性冲击后，2027年能否如预期恢复增长？

**投资框架性结论**：

> 中国联通是一家**财务可信、现金流强大、战略转型方向正确但在路上的公司**。它不是一只"高增长性感故事"的股票，而是一只"被低估的现金流机器+转型期权"的组合。核心吸引力在于：折旧释放+FCF改善+算力期权+低位估值。核心风险在于：算力投入能否兑现为可持续的利润。适合**对收益率要求不高（预期年化8-15%）、愿意等待转型兑现、关注现金流质量的长期价值投资者**。需要持续跟踪应收账款质量和算力业务的盈利能力（非收入规模）。
