# 非财务信息“八问”

**投资结论：资产变现的转折之年，价值重估可期**

**一句话结论：** 全球最大通信铁塔运营商，塔类业务筑底、智联与换电双引擎加速，**2026年折旧拐点将带来约100亿税前利润增厚**，当前9-14倍PE处于历史及全球低位，兼具高股息与利润弹性双重属性。

## 【维度一】靠什么赚钱？核心驱动力是什么？

**生意本质一句话概括：**
公司"收租+增值"，以独家拥有的210万+座通信铁塔为底座，向三大运营商出租站址和设备获取稳定租金（塔类业务占比75%），同时利用铁塔的高度、电力、网络"衍生赚钱"——将通信塔改造为"数字塔"向政府/行业提供视频监控和边缘算力（智联业务），利用铁塔直供电和密集点位做电动两轮车换电生意（能源业务）。资产复用一次，边际收益为零，利润往外溢。

**收入与利润结构拆解：**

| 业务板块 | 2025年收入            | 同比增速 | 净利润贡献占比（估）                 |
| -------- | --------------------- | -------- | ------------------------------------ |
| 塔类业务 | 754.98亿元（占75.2%） | -0.3%    | 约60%（毛利率高，共享率持续提升）    |
| 室分业务 | 92.27亿元（占9.2%）   | +9.5%    | 约15%（高速增长中）                  |
| 智联业务 | 101.72亿元（占10.1%） | +14.2%   | 约15%（轻资产，复用属性，净利率高）  |
| 能源业务 | 48.13亿元（占4.8%）   | +7.6%    | 约8%（换电业务固定收费，盈利爬坡期） |

其中**最赚钱的是塔类业务**，站址租户从2018年的1.47户/站提升至2025年的1.72户/站，共享水平提升意味着每一座塔的收入和利润率持续改善。

**核心驱动力：**
业绩真正的发动机正在从"塔类收租"切换到 **"存量资产变现×第二增长曲线"的共振模型**：

1. **短期最大驱动力：折旧拐点释放利润**——2015年从三大运营商收购的约150万座存量铁塔（价值约2035亿元），折旧年限为10年，已于**2025年10月完成全部折旧**，2026年起年折旧费用降为零，直接释放约100亿税前利润（华尔街高盛测算支撑净利润增长46%）。这是最确定的利润爆发点。
2. **中长期核心驱动力：站址复用边际收益≈零**——智联业务只需在已有塔上加装摄像头和边缘计算设备，就能创造增量收入，不需要新建铁塔。2025年智联业务已突破100亿收入，且其核心产品"铁塔视联"已覆盖45余种AI算法、超10万个应用场景，20万座通信塔已完成"数字塔"改造，复用率不足10%，天花板还极高。
3. **换电业务C端锁定效应**——全国超147万付费骑手用户，日均换电超200万次，用户迁移成本极高，粘性如同"电力版的会员制电商"，锁定持续现金流。

## 【维度二】顺风还是逆风？外部大环境好不好？

**宏观定性：结构分化期——运营商基本盘承压，但两翼全面受益于数字化、AI、双碳三大国家级趋势。**

**顺风清单：**

1. **数字经济+AI基础设施建设井喷**——铁塔智联业务即"数字塔"赋能智慧城市、林草防火、耕地保护等国家战略场景，2025年年底已升级23.8万座数字塔，入账101.72亿元（同比增长14.2%），AI中高点位算法已达470余种，服务场景超10万个，处于蓝海爆发期。
2. **"以换代充"政策红利全面释放**——2025年9月电动自行车新国标强制执行防篡改和电池安全要求，直接催化换电行业快速合规化，带动两轮车换电渗透率从当前约24%向2030年52%的方向演进。中国铁塔市占率接近50%，将是最大受益者。
3. **边缘算力全球爆发**——IDC数据显示2025年中国边缘计算市场规模突破800亿元，预计2026年超越1200亿元，年复合增长35%以上；而铁塔拥有近百万机房资源，天然是"挨着用户"的边缘算力节点，正在构建"异网异构边缘算力系统"，已开始布局低空经济、车路协同、应急AI推理等高增长赛道，有望成为第二曲线后的第三增长极。
4. **央企市值管理考核落地+分红刚性提升**——2025年起国务院国资委全面推行央企市值管理考核，公司已连续两年提高派息率且首次派发中期股息，2025年全年派息率预期保持在60%+，股息率达5.15%（按当前市价），投资安全垫深厚。

**逆风清单：**

1. **运营商资本开支持续下行，塔类租金增长天花板已见**——塔类业务2025年同比下滑0.3%，5G大规模建设高峰期已过，客户正在从"新增基站"转向"存量优化"，新一轮商务定价协议的共享折扣相比上一轮提升了2.4个百分点，租金单价承压。
2. **智联业务客户回款周期拉长**——智联业务主要客户为地方政府和行业客户，财政偏紧的背景下应收账款周期有拉长趋势，坏账计提和现金流风险值得警惕。
3. **能源换电赛道竞争加剧、资本回报周期被压缩**——虽然铁塔占据近半市场，但宇谷（这锂换电）、智租换电、小哈换电等竞争对手正加速投建网点，尤其在商户密度高的核心商圈价格战已出现苗头，短期拉低单点盈利。
4. **全球6G技术路线存在潜在冲击**——6G若走向更高频段（毫米波以上），覆盖半径大幅缩小，铁塔部署密度理论上还需提升，但建设节奏与技术成熟度带来的不确定性仍需观察。

## 【维度三】空间有多大？天花板在哪里？

**第一增长曲线见顶判断：**
塔类业务基本见顶。截至2025年年底，国内5G基站总数470.5万个，覆盖行政村超90%，"5G基建"空间主要填充已接近尾声。但铁塔存量214.9万座，运营商租户356.7万户，站均租户仅1.70户，相比海外成熟市场平均2.5-3.0户/站，共享水平仍有提升空间，塔类收入可通过提升共享率缓释单价下行压力。因此判断"温和下滑但绝对不存在崩塌风险"。

**第二增长曲线储备：**
明确的**两大增长极+一个潜在极**：

- **智联业务**：当前仅23.8万座"通信塔升级为数字塔"，占总塔数不足12%，若渗透率提升至30%（约65万座），将带来300-500亿增量营收空间。
- **能源换电**：根据沙利文预测，国内两轮车换电市场规模将从2025年的147亿增长至2030年约1000亿，铁塔市占率保持40%以上将对应200亿以上营收。客户年换电缴费从2025年的147万，到远期渗透率达到骑手换电主流时300-500万付费用户区间，日换电达800-1000万次，规模效应强烈。
- **边缘算力（潜在第三极）** ：IDC预计2026年中国边缘计算市场规模1200亿以上。铁塔"站点密、电力足、光纤通"，天然适合做边缘算力运营者，目前正在6个区域科技创新中心和7个中试平台发力，这一块若打开将开启远超换电的资本空间。

**天花板量化预估：**
**短期（2025-2026年）**：营业收入1050亿左右，归母净利润因折旧减少可望冲击170亿左右（同比增约46%），EPS约0.97-1.0元。
**中长期（3-5年）**：两翼业务占比从14.9%升至25-30%，总营收1200亿以上，归母净利润200-250亿区间。当前市值按1758亿（港股，2026年6月4日）相当于0.78倍市净率、不到10倍2025年EPS（约9-14倍PE，因利润爆发速度市场认知有分歧），若利润如期释放，估值将重估至15-18倍PE，上行空间约60-100%。

## 【维度四】竞争格局好不好？玩法是什么？

**行业梯队地图：**

| 排名 | 公司                     | 全球铁塔数（万座） | 业务地域     | 商业模式                     |
| ---- | ------------------------ | ------------------ | ------------ | ---------------------------- |
| 1    | **中国铁塔**             | 214.9              | 仅中国       | 收租+共享+智联能源，国资控股 |
| 2    | 美国电塔（AMT）          | ~15                | 全球23国     | REITs模式，全球化铁塔出租    |
| 3    | 冠城国际（Crown Castle） | ~14.5              | 美国         | REITs+小基站密集部署         |
| 4    | 印度Indus Towers         | ~24.9（印度铁塔）  | 印度本土为主 | 单一区域运营商服务商         |

中国铁塔以214.9万座铁塔远超第二名美国电塔（约15万座），全球铁塔数占比超50%，行业第一的规模壁垒极强。

**竞争核心要素：**

- **国资护城河+运营商股东深度绑定**：三大运营商合计持股约69%，既是股东又是核心客户，没有第四方竞争者能进入，形成天然的行政与资本壁垒。
- **共享机制决定利润率**：铁塔共享率从14.3%升至86.2%，少建铁塔123万座，节约行业投资2200亿、运营成本1800亿。共享比例越高，单塔利润率越强（单塔三租户ROIC可达24% vs 单租户仅3%）。站均租户仍有向上空间，决定了全行业盈利上限。
- **轻资产拓展的边际效应**：铁塔是"硬件沉淀后做软件和运营"，智联和换电业务复用率达到极致，形成"零资本开支前提下新增100亿营收"的突出优势。行业没人能复制。

**利润率密码：**
美国铁塔净利率约24.69%，远高于中国铁塔的11.6%（2025年），差距根源在于：

1. 美国铁塔采用REITs模式，税率低。
2. 中国铁塔折旧摊销成本占营收的45%+，但2026年后将明显下行。
3. 中国铁塔需承担大量维护维修成本、新能源科研投入。
4. 中国政府定价制度限制租金提价空间。

但随着"智联业务"毛利高、"换电业务"步入规模效应，以及折旧拐点，净利率有望从11.6%向15-18%的长区间推进。

## 【维度五】有什么优势？护城河在哪？

**与核心对手横向对比表：**

| 维度               | 中国铁塔                    | 美国电塔（AMT）            | 冠城国际（Crown Castle）  |
| ------------------ | --------------------------- | -------------------------- | ------------------------- |
| **铁塔规模**       | 214.9万座，全球第一         | ~15万座，覆盖23国          | ~14.5万座，主攻美国小基站 |
| **2025营收**       | 1004亿人民币（约141亿美元） | 106.45亿美元               | ~63亿美元（估）           |
| **净利率**         | 11.6%（向上拐点）           | 24.69%                     | ~22%                      |
| **ROE**            | 5.7%（爬坡中）              | 335%（高杠杆+REITs）       | ~18%                      |
| **股息率**         | 5.15%                       | ~3.4%                      | ~5.8%                     |
| **核心客户**       | 三大运营商（合计持股69%）   | AT&T/T-Mobile/Verizon      | AT&T/T-Mobile/Verizon     |
| **竞争者进入壁垒** | 极高（国资独占+股东锁定）   | 高（全球资本驱动）         | 高（REITs+存量布局）      |
| **增长第二曲线**   | 智联（102亿）+换电（48亿）  | 数据中心（已收购CoreSite） | 小基站铺设覆盖深度        |

**独特护城河阐述：**

1. **站址数量绝对垄断，无有效竞争者**：站址214.9万座，比第二名到第十名的总和还要多，且站址资源受城市规划、土地获取、供电等硬约束极强。新建一个铁塔需要地方政府审批、运营商协调、电力配套，一个新的竞争者无法复刻。"全国所有通信基站的物理地产"都被铁塔公司持有，这本身就构筑不可跨越的壁垒。
2. **"股东即客户"的封闭飞轮**：三大运营商合计持股69%，无法在铁塔租赁上砍价过狠（既损害自身投资收益又会引发国资委问责）。同时，运营商的所有增量站址建设需求必须通过铁塔实现——中国铁塔已成为运营商"5G基础设施建设预算"的唯一出口，这个商业模式极难破局。
3. **数字化+换电的"衍生业务零成本扩张"**：在已搭建好的铁塔上加装摄像头和AI算法提供视频监控（智联业务），在铁塔电力接入点旁建换电柜（能源业务），边际建设成本极低，而竞争对手要从零开始拿地、建柜、拉电网——成本完全不在一个量级。这使铁塔在任何"站址复用型"新业务上都有先天性垄断优势。

## 【维度六】管理层行不行？治理有没有雷？

**管理层画像：**
核心团队全部来自三大运营商，且均有省级分公司或集团高层管理经验：

- **董事长张志勇**（2021年9月上任）：曾任中国电信副总经理、通服董事长，对铁塔的本质业务（运营商基础设施服务）理解极深，主导了从"一体"到"一体两翼"的战略深化转型，并直接推动智联业务的平台化AI体系迭代。
- **总经理陈力**（2024年4月上任）：曾任中国移动湖北/安徽/青海/辽宁/上海多省分公司董事长、总经理，履历横跨运营商区域运营全盘，实战经验极其丰富，2024年上任后迅速推进资产运营效率提升、强化边缘算力和低空经济布局，同时首次推出中期分红，提升股东回报。
- 核心高管如副总经理刘国锋（曾任中国移动省级公司副总经理、铁塔能源董事长）等均在铁塔体系深耕10年以上，管理层稳定性极好。

国有央企股权结构背景下，高管激励以薪酬体系和任期制契约化管理为主，没有股权激励的充分市场化激励，可能影响一些短期激进扩张的动力，但对公司性质而言，"不犯错"大于"冒进"，管理层风格稳健务实。

**治理红灯预警：**

- **未发现严重治理隐患**——公司重大关联交易（与三大运营商的商务定价）都有正式协议公告，公开透明，且需H股投资者及国资委多重监管。
- **应收账款回收风险偏高**——2023年因新商务定价协议切换，应收回款一度明显波动，2024-2025年逐步改善但仍需盯紧地方政府客户账期，但坏账风险可控。
- **资本开支结构性偏高**——2025年资本开支294.86亿元，主要用于站址新建、升级和智联、能源建设，对现金流形成一定压力；但折旧到期同时释放利润后，自由现金流将大幅改善。

**一句话评价：** 管理层高度专业、战略清晰且连贯，正从"基建运营商"向"基础设施+数字服务商"跨越，治理透明度与合规性良好，值得信任。

**最薄弱一环：**
**"存量铁塔租金下降"，是可能彻底改变2026年利润弹性的最大变量。**若三大运营商2027年新一轮定价协议强行要求基准租金下降，恰好对冲了折旧到期带来的利润增量（约100亿元），公司利润增速将从"激增46%"回归"个位数增长"，市场估值重塑（从成长股的15倍PE跌回公用事业股的10倍以内）。所有看多逻辑都建立在不发生租金大幅下调的基础上，这一博弈结果将决定公司终极价值。

## 【维度八：未来会怎样？预测与判断】

**短中期展望（1-2年）：**

2026年将是铁塔的**利润加速释放之年**——折旧到期的确定性将直接贡献约100亿税前利润，归母净利润从2025年的116.3亿拉升至170亿左右的区段，同比增长超45%。塔类业务继续磨底（收入温和下滑0-1%），但站均租户数从1.70向1.80的缓慢提升，足够部分对冲租金单价下降，不至崩塌。智联业务维持15-18%左右的增长，能源业务10%左右稳健增长，两翼业务占收入比重预计突破16%，向"两翼"成为主力引擎更进一步。

核心催化因素：①2026年上半年业绩窗口（折旧到期首次体现在利润中）；②智联业务"铁塔视联平台+AI大模型"在政府预算收紧的大环境下仍保持增速超预期；③换电业务付费用户突破200万，超市场预期。

核心潜在压制：智联业务收款周期延长；运营商新一轮定价协议提前释放不利信号。

**长期终局判断（3-5年）：**

**中国铁塔将从"通信基站垄断运营商"蜕变成为"数字基础设施+能源基础设施的综合服务商"。** 随着智联业务渗透率从12%提升至30%+，边缘算力/低空经济等新场景持续落地，总收入将突破1200亿元，智联+能源占比达30%，净利润率从11.6%提高至15%+，归母净利润可达200-250亿元区间。市场给予的估值将从当前"公用事业股"（7-11倍PE）向"成长基础设施"（15-18倍PE）切换，市值有望攀升至3000-4500亿港元区间。

**估值锚定：**
当前市场（2026年6月4日）股价9.99港元，市值1758亿港元，对应动态PE约9.7-14倍（因对折旧拐点利润释放存在不同预测），市净率约0.78倍，PB低于净资产，处于绝对低估区间；股息率约5.15%，具备债券替代价值。

**交易结论：**
短期看利润弹性，中期看估值修复空间。第一次覆盖给予"买入"或"增持"评级（具体取决于不同券商的2027年定价协议预期分歧）。风险与机会的拐点在折旧释放与租金再定价的博弈结果，但当前位置估值已隐含了大量悲观假设，赔率有利。

**一句话结论：** 全球最大通信铁塔运营商迎来折旧拐点和数字化双引擎共振，**2026年利润将跃迁增长**，当前市净率仅0.78倍、股息率5.15%，是兼具高安全垫与翻倍潜力的央企基础设施估值洼地。
