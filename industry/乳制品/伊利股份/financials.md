# 财务报表分析

## 前置步骤：公司理解、财报可信度初判与关键变量搜索

### Step 1：理解伊利的生意并初判生意质量

#### 这家公司靠什么赚钱？

伊利是全球乳业五强、亚洲第一的综合乳制品企业。2025 年营收 1156 亿元，**液体乳及乳制品制造业占比 97.73%**。进一步细分为三大核心品类：

| 品类             | 2025 年营收 | 占比   | 同比增速 |
| ---------------- | ----------- | ------ | -------- |
| 液体乳           | 704.23 亿   | 60.90% | -6.11%   |
| 奶粉及奶制品     | 327.69 亿   | 28.34% | +10.42%  |
| 冷饮产品         | 98.23 亿    | 8.49%  | +12.63%  |
| 其他（深加工等） | 26.23 亿    | 2.26%  | 翻倍增长 |

**一句话概括**：伊利是一家以液体乳为基本盘（六成营收）、以奶粉和冷饮为增长引擎（增速双位数）、以深加工和国际化为远期战略的综合性乳制品消费品龙头。

#### 商业模式特点

- **消费品品牌商模式**：面向大众消费者，通过品牌溢价和规模效应赚钱。
- **深度分销网络**：经销模式占 95%+，覆盖全国，2025 年直营占比仅 3.66%但增速 27%。
- **上游高度整合**：通过与上游牧场合作/参股整合原奶供应，掌控奶源安全。
- **产品矩阵驱动**：从液奶到奶粉、冷饮、奶酪、深加工的品类延伸。

#### 生意质量三重过滤

| 过滤维度                 | 评估                                                                                                                                                                                   | 结论         |
| ------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------ |
| **业务可理解吗？**       | ✅ 卖牛奶及乳制品，老百姓天天喝，商业模式极其清晰。                                                                                                                                    | **通过**     |
| **收入/客户可证实吗？**  | ✅ 终端消费者数以亿计，经销商网络可核查，但渠道库存管理存在一定调节空间。奶粉品类通过母婴店/商超渠道，上市后需关注渠道压货风险。                                                       | **基本通过** |
| **模式依赖漂亮报表吗？** | ✅ 经营现金流持续为正（除 2019 年），自由现金流整体充沛。2025 年经营现金流 143 亿虽下降 34%，主要受预收款下降及大额捐赠影响，但自由现金流/净利润仍高达 98%。不存在依赖融资的生存模式。 | **通过**     |

**初判结论**：伊利是一门易懂、可证实、现金流充沛的好生意。

### 第二道防线：财务异常信号扫描

#### 2.1 利润质量 — 核心指标扫描

| 年份     | 经营现金流/净利润 | 扣非净利润/净利润 | 经营利润/净利润 |
| -------- | ----------------- | ----------------- | --------------- |
| 2016     | 226.38%           | 79.96%            | 87.70%          |
| 2017     | 116.75%           | 88.79%            | 89.24%          |
| 2020     | 139.18%           | 93.60%            | 84.00%          |
| 2023     | 175.39%           | 96.14%            | 93.59%          |
| **2024** | **257.19%**       | **71.12%**        | **67.17%**      |
| **2025** | **124.03%**       | **95.70%**        | **95.85%**      |
| 2026Q1   | 69.23%            | 98.78%            | 97.17%          |

**关键发现**：

- **2024 年是一个异常年份**：扣非净利润/净利润仅 71.12%（即近 29%净利润来自非经常性损益），经营利润/净利润 67.17%（即近 33%来自金融利润）。这与 2024 年大额商誉减值、资产减值集中释放有关——2024 年计提了大量一次性的资产减值损失（2025 年的减值从 39.45 亿大幅收窄至 7.30 亿），导致账面净利润失真。
- **2025 年恢复正常**：扣非占比回升至 95.70%，经营利润占比 95.85%，利润含金量大幅修复。扣非净利润 84%的暴增，很大程度上是 2024 年基数异常低的结果。
- **经营现金流/净利润**：除 2019 年（-11.36%）和 2026Q1（季节性因素 69%）外，长期保持 100%以上，表明利润有真金白银的现金流支撑。
- **自由现金流/净利润**：2025 年 97.77%，2024 年 210%，长期平均良好。

> **利润质量结论**：整体健康。2024 年是一次性减值释放导致的利润质量恶化，2025 年已显著恢复。经营现金流覆盖净利润的能力强。

**关键发现**：2022 年存在明显异常——营收仅增 11%，但应收暴增 54%、存货暴增 66%，这是一个典型的渠道压货信号。好在 2023-2025 年已通过渠道库存调整消化，截至 2026Q1 渠道库存已处于健康水位（经销商库存天数低于 1 个月）。

> **结论**：2022 年的高存货/高应收已基本消化，当前收入质量改善。

**这是整个分析中最值得警惕的信号！** 伊利在 2021-2025 年间，账上现金一度超过 300 亿，同时有息负债从 225 亿增至 508 亿（2026Q1 更高达 621 亿）。2024-2025 年现金大幅下降（从 434 亿降至 195 亿），但有息债务并未同步下降。

**不过，这并非典型的财务造假存贷双高**。伊利的有息负债主要用于：

1. 收购澳优（2022 年）致商誉大幅增加
2. 上游牧场整合与资本扩张
3. 国际化布局

**但仍需持续监控**：有息债务/总资产从 2021 年的 22%升至 2026Q1 的 39.64%，财务杠杆明显攀升。

### 综合定级：**高可信** ✅

**理由**：

1. 审计意见干净，治理层面无红灯
2. 利润质量整体健康，经营现金流长期覆盖净利润

**但需持续盯住的"黄灯"**：有息债务持续攀升（2026Q1 达 621 亿）、固定资产投入强度上升（轻资产变重资产）、商誉剩余 22 亿的后续减值风险。

### 1.2 利润含金量分析

```
扣非净利润/净利润：
  2016: 79.96%  →  2023: 96.14%  →  2024: 71.12% ⚠️  →  2025: 95.70% ✅

经营现金流/净利润：
  2016: 226%  →  2020: 139%  →  2024: 257% ⚠️ 异常高  →  2025: 124% ✅
```

**核心解读**：

1. **2025 年净利润含金量恢复健康**：扣非占比 95.70%、经营利润占比 95.85%，说明利润几乎全部来自主业经营，金融利润（利息收入等）仅贡献 4.80 亿（2024 年为 27.75 亿，其中包含一次性投资收益）。

2. **2024 年数据失真**：扣非仅 71%、经营利润仅 67%，但经营现金流却是净利润的 257%。这种"利润低、现金流高"的组合，恰好印证了大量计提资产减值（非现金支出）挤压了账面利润。2024 年是"财务洗澡"的一年。

3. **2025 年净利润 36.82%的暴增**，主要由三个因素驱动：
   - **低基数效应**：2024 年净利润基数极低（减值洗澡）
   - **毛利率提升**：原奶价格持续下行，成本端受益
   - **减值收窄**：资产减值从 39 亿缩至 7 亿，释放利润弹性

4. **经营现金流下降 34%**：经营现金流从 217 亿降至 143 亿，主因：
   - 预收经销商货款下降（下游需求偏弱、公司主动减压渠道）
   - 大额捐赠支出（2025 年捐赠 24.17 亿，同比+22.89 亿）

**杜邦分解的核心故事**：

```
伊利ROE ≈ 净利率 × 资产周转率 × 权益乘数

2017年：25.2% = 8.9% × 1.54 × 1.95  （高中低组合，理想状态）
2024年：15.8% = 7.3% × 0.76 × 2.70  （三低组合，最差年份）
2025年：20.9% = 10.0% × 0.76 × 2.60  （净利率修复，但周转仍低）
```

**核心洞察**：

1. **资产周转率是最大隐忧**：从 2017 年的 1.54 次骤降至 2025 年的 0.76 次——几乎腰斩！这直接反映了伊利越来越重资产的趋势。每元资产创造的收入从 1.54 元降至 0.76 元，资产效率在持续恶化。

2. **权益乘数被动上升**：从 1.95 升至 2.60，不是因为伊利在"加杠杆炒股"，而是因为资产扩张速度超过了净资产积累速度（收购澳优导致总资产翻倍，但净资产增长有限）。

3. **2025 年 ROE 回升至 20.87%是好信号**，但主要由净利率驱动（从 7.33%升至 9.96%），而净利率的改善有原奶价格下行的周期性贡献。如果原奶价格触底回升，净利率可能再次承压，届时 ROE 可能重新下滑。

## 最终总结：综合投资结论

### 1. 这是一门什么样的生意？

伊利是中国乳业绝对龙头，拥有**品牌+渠道+规模**三位一体的深厚护城河。营收领先第二名 337 亿（约 41%），净利是第二名的 7 倍多。奶粉、冷饮、液奶三大品类均居行业第一，婴配粉和成人粉的市场份额仍在持续提升。

但伊利的生意本质正在发生变化：从过去依靠液奶单品放量的**高增长品牌消费品**，转变为液奶稳基本盘+奶粉/冷饮多品类驱动的**中低速增长平台型消费品**，同时向重资产的**上游整合型乳业巨头**演进。

这是一门**易懂、可证实、有真实现金流**的好生意，但增长的天花板已经肉眼可见。

- 商誉减值已在 2024 年集中释放，剩余风险可控

**需持续盯住的"黄灯"信号**：
