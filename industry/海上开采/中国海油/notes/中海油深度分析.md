## 概览

这是一期"价值投资者"视角的深度访谈。嘉宾老脸自 2022 年中海油股价 14-15 元、5 倍 PE 时已重仓买入并长期持有至今（节目录制时 A 股股价已超 40 元/股）。整期节目把中海油的投资逻辑拆成了一套相当完整的论证：

1. **为什么是 5 倍 PE 的中海油**——市场失灵的供给与需求；
2. **三桶油商业模式对比**——纯上游 vs 一体化；
3. **完全成本（all-in cost）的护城河**——27 美元/桶 vs 中东 10-12、中石油/中石化 30-50、页岩油 50-80；
4. **页岩油的"反直觉投资逻辑"**——西方石油 30 倍 PE 不一定贵，可能比中海油便宜；
5. **原油的本质**——液态稀土，AI 时代越省油越缺油；
6. **伊朗 / 霍尔木兹局势**——长期性油价中枢上移；
7. **国家意志**——中海油背后的国资意志与战略储备使命；
8. **海上风电的"通点"**——为什么不是 ESG 形象工程而是海洋特色资源公司战略；
9. **AH 折价的合理边界**——25-28% 是合理范围；
10. **抗低油价能力**——低油价时是买油田的最佳窗口。

老脸反复强调的核心：**"价值投资其实非常简单，为什么践行的人很少？因为没有人想慢慢地挣钱。"**

## 一、为什么早早重仓中海油（2022 年 5 倍 PE 的故事）

### 1.1 出发点：从巴菲特/段永平的研究中关注资源类公司

- 巴菲特长期推崇好公司中**有大量资源类企业**；
- 资源类企业产出标品，理论上**没有定价权**；
- 没有定价权的企业为什么仍是好生意？这成了老脸研究的起点。

### 1.2 看到中海油后的硬性指标

- 毛利率/净利率/ROE 都"非常恐怖"；
- 没有定价权的企业能拿到这种经营结果，强烈的护城河信号。

### 1.3 5 倍 PE 极度便宜的原因（2022 年时点）

- 美国对中字头国企的限制性措施；
- 美资基金被迫清掉中字头股票；
- 中海油从美股 ADR 退市，回归港股；
- → 买方力量极度薄弱；
- 静态 PE 一度跌到 **5 倍**——5 年就把自己挣回来；
- 类比：国内大银行才给到 5 倍 PE，但银行没有海油这种增长。

### 1.4 增长还很强但 PE 这么低的反差

- 处于低油价环境（油价上涨有弹性）；
- 海外项目疯狂扩产（圭亚那）；
- 国内勘探不断有好结果；
- 三个增长引擎齐备 → 还给 5 倍 PE → "市场给了极度便宜的机会"；
- → 老脸开始建仓。

## 二、三桶油商业模式对比

### 2.1 业务结构差异

| 维度     | 中石化         | 中石油         | 中海油         |
| -------- | -------------- | -------------- | -------------- |
| 炼化比重 | 最高           | 次之           | **几乎为零**   |
| 业务定位 | 全产业链一体化 | 全产业链一体化 | **纯上游 E&P** |

### 2.2 油价上行时三家都涨停的市场认知

- 伊朗事件后油价飙升时，三桶油**连续两天涨停**；
- 说明市场认知"油价高 → 三桶油都赚钱"——大方向正确；
- 但**弹性不一样**：
  - 一体化公司：油是炼化的成本——油价高 → 上游赚钱多 + 下游亏一些 → 净影响中性；
  - 中海油：油价就是收入端——**纯净弹性**。

### 2.3 抗波动 vs 高弹性

- 一体化公司抗风险能力略强，但**炼化 ROE 只有 ~5%**——底层资产质量低；
- 中石油/中石化的高分红 + 现金流稳定 ≠ 业绩高弹性；
- 中海油牺牲了一些"波动平滑"，换来了**强 β + 强 α**。

## 三、完全成本（All-in Cost）：核心护城河

### 3.1 完全成本的定义

- 把勘探、作业、运输、税务损耗等所有成本都摊到每一桶油上；
- → 衡量一个油企真实的现金成本下限；
- 油价 - 完全成本 = 利润空间（再扣所得税）。

### 3.2 全球完全成本对比

| 玩家                           | 完全成本 ($/桶) |
| ------------------------------ | --------------- |
| **中东国家油企**（沙特阿美等） | 10-12           |
| **中海油**                     | **27**          |
| 中石油/中石化                  | 30-50           |
| 美国页岩油                     | 50-80           |

### 3.3 关键含义

- 中海油是**全球第二便宜**（仅次于中东）；
- 弹性优势：油价每涨 1 块，中海油利润涨幅是其他三桶油的几倍；
- **抗低油价能力**：油价跌到 50 美元，页岩油商嗷嗷叫、中石油/中石化利润很薄，但中海油**仍然挣钱**；
- 即便低油价环境，中海油仍能产出足够现金流去做资本开支 → 反过来勘探更多资源。

### 3.4 储量替代率（Reserve Replacement Ratio）

- 概念：**当年新增证实储量 ÷ 当年实际产量** ≥ 100% 表示储量在增长；
- 中海油 2024 年储量替代率 **>160%**；
- 长期稳定大于 100%；
- → 真实储量"卖完时间"从 12 年延长到 13、14 年——储量越卖越多。

### 3.5 储量盘点

- **真实储量 ~70 亿桶**；
- **已探明未证实储量 ~30 亿桶**；
- → 合计约 **100 亿桶**；
- 中国 95% 海域的勘探权法律框架锁定 → 国外要合作必须中海油作为合作主体且作业方；
- → **法律框架的护城河**。

## 四、圭亚那项目：捡漏的"锦上添花"

### 4.1 收购故事

- 中海油在低油价环境下收购了**加拿大油企**（尼克森）；
- 加拿大油企当时把自己完全卖给了中海油；
- 圭亚那项目 25% 股权**几乎没有谈作价**——等于"捡了个漏"。

### 4.2 圭亚那当前情况

- **作业方**：埃克森美孚；
- 真实储量已 **~100 亿桶**，未来还可能继续上升；
- 由于 capex 限制，开采速度**还没特别快**——还远未到稳态；
- → 储量+产量都还在上升通道；
- 完全成本"非常变态"地低；
- → "**很厚的大肥肉**"。

### 4.3 圭亚那的国家定位

- 圭亚那过去 5 年人均 GDP 增长 4 倍——目前是世界 GDP 增速最快的国家；
- 老脸预判"它会更快"。

### 4.4 但圭亚那不是核心买入理由

- 圭亚那是"锦上添花"，不是核心；
- 核心是中海油的**纯上游商业模式 + 全球第二低的桶油成本 + 中国 95% 海域勘探权**这三重组合。

## 五、页岩油的"反直觉"投资逻辑

### 5.1 页岩油 vs 海上/陆上油田

| 维度         | 海上/陆上油田           | 页岩油                                                      |
| ------------ | ----------------------- | ----------------------------------------------------------- |
| 单井寿命     | 10-70 年                | 3 年（首年采 50-60 桶/百，第二年 10-20 桶，第三年几乎不出） |
| 投资逻辑     | 资本开支陡峭 + 缓慢回收 | 资本开支陡峭 + 快速回收                                     |
| 项目制       | 否                      | **是**——每口井都是单独项目                                  |
| 油价响应速度 | 慢                      | **极快**（1-2 年内反应）                                    |

### 5.2 储量价值的弹性逻辑

- 西方石油完全成本 **50-60**，海油 27-30；
- 油价从 70→80（上涨 ~14%）：
  - 西方石油：利润从 20→30（**+50%**）；
  - 中海油：利润从 40→50（+25%）；
- 页岩油储量价值的**百分比弹性更大**；
- → 西方石油的 32 倍 PE 不一定贵；
- → "**如果价值中枢抬升是真实的，西方石油可能比中海油便宜**"——这是最反共识的判断。

### 5.3 PE 不是绝对的

- PE 是用历史收益框未来；
- 油价中枢上移时，页岩油储量价值的弹性反而更大；
- → 不能简单按 PE 看资源股贵贱。

## 六、原油的本质：液态稀土

### 6.1 反共识立论

- 普遍认知：新能源车崛起 → 油是夕阳产业；
- 反共识：**这是被严重误读的**。

### 6.2 需求侧不会快速消失

- 2025 年世界原油需求 **all time high**；
- 中国原油需求也是历史最高；
- 即便 2030 是峰值，"也不会怎么样"——只是消耗变少不代表不消耗；
- 因为 30 年是峰值的预期 → **资本开支严重不足** → 未来供给不够；
- 类比煤炭：大家一直认为煤炭是夕阳，结果煤炭股越涨越多。

### 6.3 利用效率悖论

- "对煤的利用效率越高 → 大家越需要煤"；
- "对石油的使用效率越高 → 越需要石油"；
- 越省油 → 跑得更多 → 总耗油更多；
- 对个人是省的，对**整个国家工业体系/世界工业体系**是反向加大消耗。

### 6.4 石油正在变成"液态稀土"

- 当前石油的前沿利用价值已经到了**材料价值**层面；
- 高端材料（复杂碳链）的获取：用工业方法 vs 用石油方法 → 石油方法**能源成本更低**；
- 当对高端材料需求越多 → 合成成本和石油成本同步走高；
- → 未采的油**会越来越值钱**；
- → 类比稀土：液态稀土。

### 6.5 AI 时代加速这一过程

- 石油的命运不取决于沙特、美国，"**取决于 AI 的速度长什么样**"；
- AI 提升石油利用/开采效率 → 缺口反而更大 → 价格更高；
- → 老脸的投资框架："AI 紧紧关联的公司 + 不变的公司 + 紧缺的公司"——**原油就是紧缺**。

### 6.6 高能量密度的不可替代性

- 把石油想象成一种能量密度是当前电池 1000 倍的"超级电池"；
- 生产成本极低——这是石油的本质；
- → 在所有需要高密度能量的工业场景中，**石油的可涨空间是开阔的**。

## 七、伊朗局势 + 霍尔木兹海峡：长期价格中枢上移

### 7.1 当前局势

- 美国打伊朗 → 霍尔木兹海峡基本船出不来（半封闭）；
- 伊朗对中国船只"开放"，但保险公司不给保险 → 中国船也不敢出来；
- 该海峡承担全球 **>20%（接近 30%）** 原油运输量；
- 主要运往**亚洲**——中国是最大受影响方；
- 美国受影响 < 3%（自给自足甚至出口国）。

### 7.2 中国对原油的依赖度

- 全球每天消耗 ~1 亿桶；
- 中国每天需要 1500 万桶；
- 中国自产 < 500 万桶 → **75% 依赖进口**；
- 战略储备只有几亿桶 → 90 天储备水平。

### 7.3 沙特"财政平衡油价"逻辑

- 沙特阿美完全成本 ~$10-12；
- 但**国家财政平衡油价 ~$60**（GDP 60-70% 来自原油）；
- 油价 $60 = 国家今年花销刚好够；
- 油价 < $60 → 财政紧张；
- → 沙特并不希望油价太低，也不希望太高（怕页岩油增产）；
- → 历史上维持 $60-80 的"微妙平衡"；
- → **这场战争之后，沙特能接受的财政平衡油价不再是 60，可能是 70**——长期价格中枢系统性上移。

### 7.4 中东产油国的"水龙头"困境

- 中东油田水龙头一旦关闭，恢复成本极高；
- 必须不停往外采；
- 海峡封锁 → 油桶装满 → 科威特已开始关油；
- → 看似油价涨了，但**财政上其实大幅受损**（卖不掉 + 后续恢复成本高）。

### 7.5 国家战略

- "石油如此重要"——美国搞委内瑞拉、搞伊朗都是因为这个；
- 中国 60% 新增勘探量都在中海油这家公司；
- → 中海油**肩负国家重任 + 是能挣钱的公司**——两者正向叠加。

## 八、深海技术与中海油的国家定位

### 8.1 中海油的勘探重心

- **渤海湾**：水浅、不需要深海技术、桶油成本低、靠近用油地；
- **东海/南海**：需要深海技术，目前完全成本稍高但仍远低于页岩油；
- 海油深海一号：**>1500 米**深度采油能力；
- 全自主可控（吸收了部分国外先进技术）；
- → 全球深海能力领先地位。

### 8.2 国资委的国家意志

- 中海油 62% 股份由中国海洋石油集团（母公司）控股；
- 母公司直接由**国资委**控股；
- 上市公司主体只是上游 E&P 部分；
- → 投资中海油就是在持有"国家意志的工具"。

### 8.3 海上风电的"通点"——不是 ESG 形象工程

- 中海油的使命：**做有海洋特色的战略资源公司**；
- 海上风电完全符合这一使命：
  - 远海深层采油 → 必有远海作业平台；
  - 海上作业的技术、维护能力、远海团队 → 维护海上风电只是顺便；
- ROE ~10%——**不亏钱**；
- 海上风电的副产品：自给电、外送电（电力运输比油运输简单）；
- 海洋作业平台 + 风电场 + 海底工厂 → 长期愿景非常大。

### 8.4 与中石化的对比

- 中石化大力发展**氢能**——也是基于其炼化能力（氢气是炼化重要产出品）；
- → 三桶油的"二次能源"布局都是基于自身核心能力的延伸，不是凭空乱布局。

## 九、估值与 AH 折价

### 9.1 当前估值

- 港股市值 **~1.1 万亿**；
- 港股 PE ~10 倍；
- 2025 年预测净利润 **1200-1300 亿**（油价较低环境）；
- 2026 年若油价维持 $80，预测利润 **~1600 亿**；
- → 仍然是非常低的 PE。

### 9.2 分红承诺

- 写进决议：**每年分红率不低于 45%**；
- 2025 年若挣 1200 亿 → 分红 ~540 亿；
- → 长期股息率仍非常诱人。

### 9.3 AH 折价的合理边界

- 历史上港股相比 A 股最便宜时折价达 **44%**；
- 当前折价约 **40%**；
- 老脸的合理性公式：
  - A 股不交税；
  - 港股要交税才到账户；
  - → **港股 28% 折价是合理的**；
- → 当前 40% > 28% → 港股仍有 ~12% 的"折价空间"；
- → 港股仍具性价比。

### 9.4 为什么 A 股短期涨得更猛

- 港股通有门槛 + 外资可买页岩油等其他选择；
- A 股热钱集中冲入 → 几个涨停瞬间打满预期；
- → 港股是更慢但更稳的"长期钱"。

## 十、抗低油价能力：低油价是买油田的窗口

### 10.1 老脸的反共识判断

- 中海油不仅在高油价时挣钱；
- **低油价时反而能"扩张储量袋子"**——这是被忽视的能力。

### 10.2 现金储备分析

- 中海油资本开支需求约 **1100-1300 亿/年**——勘探、开发、维持运营；
- 截至 Q3 报表，**手握 2400+ 亿现金**；
- 一年分红只分几百亿；
- → "**剩下的一千多亿现金长期握着等机会买油田**"。

### 10.3 低油价的战略价值

- 只有低油价时油田才便宜；
- 只有低油价时油田才**愿意卖**；
- → 圭亚那就是低油价时捡的漏；
- → 短期低油价对中海油是好事——快速扩大储量袋子；
- → 高油价时则只能靠自己慢慢做"辛苦活累活"。

### 10.4 复权回报

- 中海油从港股上市至今——按复权计算**成本已经为负**；
- 长期股东已通过分红收回了所有本金；
- → 这家公司**具备"把自己买好几遍"的能力**。

## 十一、实现价格 (Realization Price)：被忽视的优势

### 11.1 实现价格的定义

- 你能以多少钱把油卖给客户；
- 跟运输成本紧密相关。

### 11.2 实例

假设客户在天津港，标价 $85/桶：

- **从中东运过来**：扣运输 10+ → 实现价 70；
- **从美国运过来**：类似；
- **从渤海湾运过来**：运费几个美元 → 实现价 ~$80；
- → 中海油对中国市场的实现价**比国际同行高一截**。

### 11.3 中国是最大消费市场之一

- 全球 15%+ 原油消耗在中国发生；
- 中海油的产油地与最大消耗地高度近邻；
- → 这是"地缘亲近"带来的相对竞争优势。

### 11.4 国际公允定价

- 中海油是纯上游 → 可以按 **Brent oil** 国际公允价销售；
- 不像中石化中石油在国内分销受价格管制；
- → **国际定价 + 国内运输成本优势** = 双重红利。

## 十二、价值投资者的心法

### 12.1 为什么这家公司这么便宜？

- 老脸的回答："价值投资其实非常简单，为什么践行的人很少？**因为没有人想慢慢地挣钱**"；
- AI、新概念两天翻倍 → 没人感兴趣股息率；
- → 这种慢挣钱的公司就是**反共识的入场机会**。

### 12.2 决定加仓的方法论

- 不揣测市场为什么给你这个价格；
- 只从公司经营层面思考：今年挣多少、明年挣多少、十年挣多少、何时把公司挣回来；
- 跟其他持仓的相关性如何；
- → "**给的时候你就重仓干就完了**"。

### 12.3 反共识决策的前提

- 一定要确信自己懂这个事情；
- 才敢下大仓位；
- 才敢做跟大家不一样的决定；
- → 这才是挣钱的基础。

## 十三、隐含结论与未点明的推理

1. **老脸的整套投资框架是"AI 时代的资源股估值范式"**：他把投资组合分成"AI 紧关联 + 不变的 + 紧缺的"三类——中海油属于"紧缺的"。这个框架其实非常深刻：在 AI 高估值席卷一切的时代，**真正稀缺的不是算力，是能源**。AI 越发展越需要电，而电的边际成本越来越依赖石油（材料）。这个隐含命题让中海油从"夕阳能源股"重定性为"AI 时代的隐性算力股"。

2. **"石油作为液态稀土"是本期最深刻的命题**：当石油的边际用途从燃料变成材料，它的需求曲线就**与新能源车的渗透率脱钩**了。这意味着市场普遍用"新能源渗透率"来预测原油需求增速的方法论是**根本性错误**——电动车再多，材料级石油需求依然在增长。这是嘉宾用最少篇幅说出的最重要观点，但听众如果不懂材料行业可能会忽略。

3. **"低油价是中海油扩张储量的最佳时机"是节目独有的反共识判断**：所有人都在押注油价上涨，但老脸告诉你——**低油价反而可能让中海油更受益**（因为可以低价收购海外油田、扩大储量）。这意味着中海油的投资逻辑**对油价方向并不敏感**——这是真正的全周期资产。这才是 2400 亿现金长期闲置的真正用途。

4. **西方石油可能比中海油"更便宜"——这是嘉宾的最大反共识**：32 倍 PE 的西方石油和 10 倍 PE 的中海油，谁更贵？嘉宾的回答是"如果油价中枢长期抬升，西方石油更便宜"。这背后是**储量价值的非线性弹性**——页岩油因为成本接近油价，每涨 $10 油价 = +50% 利润；中海油因为成本远低于油价，弹性百分比反而较小。这意味着**赌油价上涨的最佳标的可能是页岩油，赌长期稳定的最佳标的才是中海油**。这是非常专业的资源股估值洞察。

5. **AH 28% 折价 = 数学上的合理边界**：这个数字解释了为什么港股海油长期"看起来便宜"但其实只是公允——A 股不交税分红，港股要交税。这一发现把"AH 折价 = 套利机会"的朴素认知改为"折价 < 28% 时港股反而贵"——只有当折价 > 28%（如当前的 40%）时才是真正套利机会。这是一个被很多投资者忽略的细节。

6. **"沙特财政平衡油价从 60→70"是嘉宾给出的非常具体的择时锚点**：这意味着如果你认为沙特战后财政压力上升，那么长期油价下限会从 60 抬升到 70——这给了未来 5 年的"投资油价"一个非常具体的中枢。结合 HC 商业观察 E1+E2 的"$70 是新底部"判断，**两组完全独立的研究居然得出了同一个数值**——这构成了非常强的证据交叉验证。

7. **海上风电的"战略一致性"暗示中海油正在构建"海洋特色综合资源公司"**：嘉宾从对中海油的"为什么做海上风电"困惑到突然顿悟——这家公司的边界不是"油气公司"，而是"海洋资源综合公司"。意味着未来海上风电、潮汐能、深海矿产、海底数据中心 ALL POSSIBLE。这个隐含愿景如果实现，**中海油的市值将远超当前估值锚定的"油气公司"框架**。

8. **2400 亿现金 + 1100-1300 亿 capex = 1100+ 亿净现金等待时机**：这个数字揭示了中海油的"实物期权"价值——这家公司每年都有 1000+ 亿现金等着低油价时去抄底油田。如果未来 5 年内出现 OPEC+ 价格战（HC 商业观察 E2 的尾部风险情景），中海油是**全球少数几个有钱在低油价时大举并购的玩家**。这是一种没有标在 PE/PB 上的隐性估值——但对老脸这种 10+ 年从业的价值投资者来说，是核心买入逻辑。

9. **节目的双重叙事**：表面上是"重仓持有的中海油深度分析"，实际上是**老脸在借中海油讲他的整套价值投资方法论**——从巴菲特/段永平的资源股偏好、到完全成本/储量替代率/实现价格的精细财务指标、到"AI 时代紧缺资源"的宏观框架，再到"慢慢挣钱"的心法——这是一节给二级市场散户的**完整价值投资公开课**。

10. **"为什么这么便宜，难道全市场都是傻子吗"是反复出现的灵魂叩问**：嘉宾不去揣测，而是回归本质——市场偶尔会犯错，价值投资者的工作就是在市场犯错时下重注。这种心智模式的稳定性比任何具体分析都重要——因为**懂这家公司**和**敢重仓**是两回事，而真正稀缺的是后者。这也呼应了节目结尾"非共识判断需要真正深入商业本身"的告诫。
