# 宇通客车

## 商业模式

宇通客车的商业模式，本质上是构建了一个跨越国内与海外、连接政策与市场、兼顾制造与服务的价值交换系统。其成功的关键在于，不仅解决了客户“如何更高效、更绿色地完成公共出行任务”的核心问题，还为供应商、合作伙伴及股东设计了共赢的交易结构。通过技术壁垒、渠道壁垒和服务壁垒，宇通确保了从创造的价值中持续捕获利润的能力，并最终以高分红形式回馈股东，形成了商业闭环。

### 一、 价值为先：解决了谁的什么“非解决不可”的任务？

宇通的价值主张并非提供“一辆客车”，而是为不同客户在特定约束下的“出行任务”提供最优解。

- **国内客户（政府公交、旅游公司等）：解决“财政压力下的绿色转型与运营效率”问题。**
  - **任务：** 地方政府需完成新能源公交推广的政治任务与碳排放目标，但面临财政紧张；旅游公司需应对疫后复苏的爆发性需求，同时控制运营成本。
  - **解决方案：** 提供全系列、高可靠性的新能源客车，并通过整车节能技术、低故障率降低全生命周期成本（TCO）。在公交领域，提供从车辆到电池更换的全套解决方案，以匹配“以旧换新”政策；在旅游市场，推出高端化、定制化车型（如T7、全景观光巴士），满足消费升级需求。

- **海外客户（欧洲、拉美、独联体等运营商）：解决“本地供应链缺失下的快速电动化”问题。**
  - **任务：** 欧洲需在2030/2040年前实现公交车零排放，但本土传统车企电动化转型慢、产品价格高、交付周期长；亚非拉市场则面临客车产能不足和城市化带来的运力缺口。
  - **解决方案：** 提供高性价比、短交付周期的电动客车产品。在欧洲，以技术领先的新能源产品切入高端市场；在“一带一路”国家，不仅输出产品，更通过KD（散件组装）工厂输出技术和产能，解决当地制造能力不足的问题。

### 二、 交易结构：为什么所有参与者都愿意持续参与？

宇通构建了一个多边共赢的交易结构，确保系统稳定运行。

- **与客户：** 提供高残值、低故障、长寿命的产品，降低客户的后顾之忧。特别是“直销+直服”模式，派驻服务经理深入客户运营，提供从车辆采购、金融方案到售后维修的全流程服务，显著提高了客户切换成本。
- **与供应商：** 与康明斯、采埃孚等全球顶级零部件商深度合作，并通过联合服务保障重点订单。同时，积极培育精益达、科林等核心零部件企业，发挥国内产业链集群优势，确保供应链的稳定与成本可控。
- **与合作伙伴（海外）：** 在十余个国家推行KD本土化合作，将单纯的买卖关系升级为技术输出和品牌授权。当地合作伙伴获得了就业、技术和税收，宇通则绕开了部分贸易壁垒，深化了市场扎根。
- **与股东：** 在行业进入成熟期、资本开支减少后，将经营产生的充沛现金流以高分红（近年分红率常超100%）的形式回馈股东。这一定期“价值返还”机制，吸引了追求高股息的红利型投资者，形成了稳定的股权结构。

### 三、 价值捕获：为什么宇通能稳定地分到一杯羹？

宇通捕获价值的核心，在于其构建了难以复制的竞争壁垒，使其在价值分配中占据主导地位。

- **稀缺的规模与品牌护城河：** 国内大中型客车市场已形成宇通+金龙（CR2约60%）的稳定双寡头格局。宇通连续二十余年销量第一，市占率高达30%-40%。这种市场地位使其拥有定价权，能够拒绝低端价格战，坚持“高端化”战略。
- **不可替代的服务与渠道壁垒：** 海外市场有400余家服务站、近800名驻外服务人员、40余个海外配件库。这套“保姆式”服务体系是竞争对手在短期内无法复制的软实力，是赢得海外客户信任、维持高毛利率的核心支撑。
- **难以复制的技术与成本优势：**
  - **技术领先：** 自主研发的“睿控E平台”等核心技术，带来真实的产品差异化（如能耗更低、可靠性更高）。
  - **成本控制：** 采用双倍余额递减法加速折旧，已在前期产能建设高峰计提完毕。当前资本开支极低，折旧压力逐年减小，使得利润含金量高。同时，对上游原材料的议价能力强，能有效对冲价格波动。
- **周期红利捕获能力：** 精准把握两轮大周期。上一轮（2012-2016）抓住国内新能源公交红利，奠定龙头地位；本轮（2020-至今）抓住海外新能源普及红利，开启第二增长曲线。高盈利的出口业务（毛利率比国内高约8-10个百分点）驱动了本轮利润的超额增长。

### 四、 效率与重构：如何以更优方式完成价值交换？

宇通用第一性原理打破了客车行业的传统经营假设。

- **打破“高增长必须高投入”的假设：** 传统制造业增长需伴随资本开支。宇通在周期顶峰（2016年）前完成主要产能建设，在本轮业绩爆发期，资本开支却降至历史低位（收入占比仅2%）。这意味着销量的增长几乎能完全转化为自由现金流和利润，效率极高。
- **重构“制造与服务”的关系：** 宇通已不是单纯的制造商，而是“出行解决方案提供商”。通过“直销+直服”模式，将服务从成本中心转变为利润中心和壁垒中心。在海外，这种深度服务甚至成为比产品更重要的竞争优势。
- **重构成本结构：** 通过采用加速折旧法，将成本压力前置。在行业下行期（2017-2022）承受了更高的折旧，但在行业上行期（2023年起），折旧压力骤降，业绩弹性被充分放大。这是一种前瞻性的、反周期的财务成本管理策略。

**结论**

宇通客车的商业模式，是一个基于“可持续价值交换”的理想范式。它**为内外客户创造了不可替代的出行解决方案**，**为所有参与者设计了共赢的交易结构**，**凭借稀缺的规模、服务和品牌捕获了超额利润**，最后**通过前瞻性的战略和财务安排，以极高的效率实现价值转化，并将成果（高分红）返还给价值贡献者（股东）**。这一闭环系统，是其穿越周期、从中国龙头迈向世界龙头的根本动力。

## 非财务信息“八问”

## 【维度一】靠什么赚钱？核心驱动力是什么？

**生意本质：赚"全球客车出海的价差红利"——国内卖车赚规模，海外卖高端新能源赚超额利润。**

**收入与利润结构拆解：**

2025年，宇通实现营业收入414亿元，同比增长11%，归母净利润55.5亿元，同比大增35%。海外收入首次超越国内：全年海外营收211亿元，同比增长39%，占总营收比例攀升至58%，成为第一大收入来源。

**最赚钱的业务是出口高端新能源客车。** 2025年公司毛利率24.14%，同比提升1.2个百分点，但海外业务毛利率高达29.6%，较国内高出10.5个百分点，且2025年还在继续提升。出口单车ASP高达123万元，是国内市场（48万元）的2.5倍以上，出口单车毛利是国内的三倍。

2025年公司新能源出口占比已提升至23%（19年仅13%），且出口新能源车单价远高于燃油车。国内市场上，公司已从"要规模"转向"要利润"：2025年内销销量同比下降，但通过产品结构优化，盈利能力反而提升，2025年归母净利润增速（35%）是收入增速（11%）的三倍以上。

**核心驱动力：出口的"量价利"三箭齐发。**

第一，**出口销量持续高增**——2025年出口1.71万辆，同比+22%，2026Q1继续增长31%。第二，**新能源出口结构升级**——2025年新能源出口占比达23%（同比+4pct），ASP更高。第三，**盈利剪刀差不断扩大**——出口业务占比提升→利润率结构性上升→利润增速远超收入增速。这一"海外高端化→利润弹性释放"的正向循环，是宇通当前最核心的增长引擎。

## 【维度二】顺风还是逆风？外部大环境好不好？

**宏观定性：结构化分化期——海外顺风强劲，国内托底企稳，总体偏暖。**

**顺风清单：**

1. **海外电动化大势不可逆**：欧洲新能源客车渗透率已超40%，进入爆发期。欧盟新法规要求城市公交2030年零排放销售占比达90%，长途和城际客车2030年减排43%，带来明确需求。
2. **"以旧换新"政策持续加码**：2026年政策继续执行，新能源公交单车平均补贴8万元（动力电池更换补贴4.2万元），2025年该政策已拉动新能源公交销量大幅增长，多地大规模置换已落地执行。
3. **中国客车海外市占率仍处低位**：全球客车市场（除中国）约26万辆大中客需求，中国出口占比仅11%，有近10倍理论天花板。宇通2024年已超越戴姆勒成为全球大中客市占率第一（12.4%），但仍有巨大提升空间。
4. **旅游市场强势复苏支撑内销**：2024年国内旅游收入达5.75万亿元，同比增长17.1%，旅游客车需求持续旺盛，支撑公司国内公路客车销量企稳。

**逆风清单：**

1. **国内公交市场复苏低于预期（★★★☆）** ：2025年国内销量同比-1.7%，国内收入同比-12%，公司内需尚未恢复到疫情前水平。虽政策托底，但地方财政仍承压。
2. **原材料价格持续上涨（★★★★）** ：自2025年6月起，磷酸铁锂价格从约3万元/吨上涨至当前约6万元/吨，近一年涨幅接近一倍。电池成本占客车成本40-45%，成本传导已开始侵蚀利润，2026Q1毛利率环比下滑3.7个百分点已部分反映。
3. **贸易摩擦及地缘政治不确定性（★★★☆）** ：中国电动车在欧洲已成"敏感话题"，2024年中国电动客车欧洲市占率约28%，2025年宇通欧洲市占率约15%。海外关税、碳边境调节机制（CBAM）等政策风险始终高悬。华为及乘用车企业的教训提醒出海企业面临的地缘政治挑战。
4. **汇率波动扰动利润**：2025年公司汇兑损益0.54亿元，同比恶化125%，汇率波动对海外收入利润转化形成扰动。

## 【维度三】空间有多大？天花板在哪里？

**第一增长曲线见顶判断：国内客车市场已进入成熟期，天花板明确。**

国内大中客市场年销量峰值17万辆（2016年），近年回落至8-10万辆水平。2025年大中客内销量约6.5万辆，较2016年峰值下降了62%。政策驱动的新能源公交置换虽有增量，但总体"存量替换"特征明显，增长空间有限。旅游市场为座位客车提供韧性，但整体天花板难以突破。

**第二增长曲线：海外新能源客车，空间广阔且壁垒已形成。**

**中国客车出海的理论天花板≈20万+辆/年（出口全口径）。** 根据Marklines数据，除中国外全球大中客年销量约25-30万辆，其中超过20万辆的市场中国客车尚未充分渗透（排除美国/加拿大/日本/印度等高壁垒市场）。2025年中国大中客出口约5.9万辆，渗透率约22%，仍有一倍以上的规模扩张空间。

**新能源的空间更大**：全球客车电动化渗透率仅约3%（不含中国），欧洲约40%仍处于中低水平，亚非拉新能源起步更晚。印尼、印度、巴西等人口大国正陆续推出电动公交规划。宇通凭借领先的新能源三电技术和成熟的出海经验，有望占据更高的海外新能源份额。

**中长期量化天花板预估：** 行业层面，机构预计2027年中国大中客出口超7万台（较2025年的5.9万台提升约19%），新能源出口占比有望从25%提升至40%以上。宇通层面，当前海外市占率（按全球大中客口径计）约12%，海外业务目标市占率15%→在全球客车电动化浪潮中，公司出口总量有望突破3万+辆/年。对应2026年，主流机构预测归母净利润约61-63亿，2027年约69-70亿元。在100%分红假设下，6%股息率对应2026年目标市值1000亿。

## 【维度四】竞争格局好不好？玩法是什么？

**行业梯队地图：**

宇通处于客车行业绝对龙头地位。2025年大中客市场宇通市占率高达43%（2024年36%，集中度加速提升），金龙约30%，中通约12%，三强合计超85%。全球视野上，宇通2024年超越戴姆勒成为全球大中客销量第一（市占率12.4%），金龙位居第三（9.4%）。

**竞争核心要素：客车作为ToB/G的公用事业设备，竞争要素排序为：渠道/品牌力＞产品力＞成本＞技术。**

1. **渠道网络**是决定客车能否持续渗透的关键。宇通国内外渠道体系最完备：海外在6大区域拥有320余家服务站、410余个授权服务网点，全球布局40余个海外配件库，直服模式极难复制。
2. **品牌力与安全背书**在政府采购和海外高端市场至关重要。宇通国内销量"23连冠"的积累和国际赛事（如卡塔尔世界杯）的品牌背书，是中小厂商难以追赶的软壁垒。
3. **产品力与定制化能力**：宇通实现"一车一策"定制化，从"卖产品"升级为"出行解决方案提供商"，海外客单价远高于同行。
4. **技术壁垒在加深**：睿控E平台（第三代"睿控E+智电平台"）控制效能大幅提升，L4级自动驾驶已在北京、广州、郑州等26个城市常态化运营，并进入卡塔尔、法国等海外市场，长期维度形成护城河。

**利润率密码：客车行业平均净利率极低（中通约6.5%、金龙约4-5%、安凯亏损）。** 但宇通净利率高达13.58%（2025年），4Q25达13.41%的年度新高。"高利润密码"就是出口高端化：出口毛利率近30%，国内毛利率不足20%，且出口毛利率还在提升（2025年同比+1.2pct），国内受成本拖累持平甚至下滑。宇通的利润模式即是"海外越挣钱→整体利润率越高→估值越提升→进一步加码高端出海"的正向循环。

宇通在出口环节的"量价利"远优于国内所有竞争对手，尤其在毛利率和ASP上的优势是数量级的差距。

**独特护城河的三重壁垒：**

1. **高端出海的先发与积累壁垒（极难突破）** ：宇通在海外市场的布局始于2005年（古巴市场），近20年时间积累了从市场准入、渠道网络到品牌声誉的巨大壁垒。海外"直销+直服+直融"模式，需要当地持续投入才能维持，而服务网络的搭建需要数年甚至十年以上时间。竞争对手短期内难以复制这一"服务先发权"。
2. **技术平台代际差距（不易短期追赶）** ：睿控E平台实现算力提升200%、控制效能提升100%，第三代"睿控E+智电平台"进一步深化技术优势，"车电同寿"15年150万公里电池质保在中国车企中是唯一一家，技术代差难在1-2年内抹平。
3. **高分红文化形成的"资本共识"（长期复利）** ：已连续5年超100%分红，分红率从未低于81%，2025年分红总额高达55.35亿元，股息率约7.7%，超过多数银行股。管理层MBO后与股东利益深度绑定，形成了"稳健经营→高ROE→高分红→提升估值→再投资研发"的正向飞轮，这种长期复利机制构成了极高的资本配置效率壁垒。

## 【维度六】管理层行不行？治理有没有雷？

**管理层画像：以创始人/老将为核心、股权深度绑定的稳定团队。**

董事长汤玉祥担任公司领导人31年，带领宇通从地方小厂走向全球第一。核心管理层均为公司长期培养，具备深厚的行业洞察力。2003年MBO（管理层收购）完成后，管理层通过宇通集团（持股41.65%）实现与公司利益的高度绑定，多年来无大额减持。公司形成"大股东即管理层"的高度稳定结构，决策链条短、执行力强。

**分红文化独特：已连续5年派息率超100%，2025年合计派发现金55.35亿元（每股2元），股利支付率接近100%。** 2026年半年度利润分配每10股派5元已落实。2021-2024年股利支付率分别达180%、292%、183%、81%，平均超180%。这种高分红幅度在A股制造业极为罕见。

**治理红灯：未见明显硬伤。**

- **无有息负债**：短期借款、长期借款均为零，一年内到期非流动负债仅4000余万元。超低杠杆运营。
- **股权质押、关联交易等无明显异常。**
- **高管团队稳定**：董事长汤玉祥等核心高管任职超过20年，没有频繁更换的隐患。

**一句话评价：A股少有的"利益绑定彻底、战略执行力强、资本配置效率高"的治理样板，可给予五星级信任度。**

## 【维度八】未来会怎样？预测与判断

**短中期展望（1-2年）：业绩仍有韧性，但增速趋缓。**

**乐观面**——国内以旧换新政策延续至2026年，"置换放量"仍有空间；海外欧洲新能源客车渗透率仍在加速，2026年欧洲新能源客车出口有望保持30%以上增速。2026Q1出口销量同比增31%，新能源出口增57%，表明出口逻辑仍在强化。

**压力面**——2026Q1营收同比-8%、归母净利润同比-13%开局不佳，增速较2025年明显收窄。国内座位客车需求回落已拖累国内销量。机构已下调2026年营收预测至455亿元（原499亿），但上调了净利润预期（归因于海外高盈利业务占比提升）。

**2026年全年预测：** 主流机构预计归母净利润约61-63亿元，同比+10-13%。

**核心催化剂**：1）欧洲新能源客车渗透率超预期（目前超40%，可能更快接近50%）；2）亚非拉地区出口大单持续落地；3）国内以旧换新政策实际执行力度超预期。

**长期终局判断（3-5年）：全球客车电动化龙头的"价值收束"。**

理想状态：宇通从"国内客车制造商"演化为"全球新能源出行解决方案领导者"。支撑这一终局的核心链条是：

**国内（现金牛）** → **海外高端新能源（高成长引擎）** → **睿控平台持续迭代** → **L4级自动驾驶未来商业模式变革**。

**关键观测节点：**

- 欧洲出口占比能否从当前约25%（估算）提升至35%以上；
- 新能源出口渗透率能否突破40%（目前23%）；
- 海外单车ASP能否站上150万元平台；
- 海外直服带来的售后利润占比能否从零成长至5-10%。

如果以上四要素均兑现，**2028年归母净利润有望达80亿元水平，对应PE 10-11倍，市值约880-900亿，较当前尚有30%+空间。**

**估值锚定：市场当前给的是"价值重估期的价值成长股"定价，兼具防守与成长的双属性。**

当前TTM PE约12倍，Forward PE（2026E）约11-12倍，股息率约7.5-8.3%，ROE约30%。这是一个既包含"制造业龙头"的估值底（约10-12倍）+ "成长溢价"（出口高增，每年利润增速15-20%）+ "红利溢价"（7%+股息率提供安全垫）的复合定价。

对标全球客车龙头：宇通已超越戴姆勒（约12%），从纯制造业PE来看，戴姆勒约10-11倍，宇通略贵但成长性显著优于对手。PEG约0.8，估值具备吸引力。

存在**估值重塑潜力**——若市场将宇通从"周期性制造业"重塑为"稳定高分红+出海高增长"的复合定价模型，合理PE可升至15-17倍。这恰好是2026E利润水平下市值约950-1100亿的空间（当前约664亿），目标价对应42-49元区间。

## 一句话结论：

**基于海外高端新能源业务驱动的"量价利"三重共振与近100%分红率的极致股东回报，宇通客车当前兼具防御与成长属性，A股制造业中稀缺的价值成长双优标的，但需警惕原材料成本上升与出口政策变动的短期扰动。**
