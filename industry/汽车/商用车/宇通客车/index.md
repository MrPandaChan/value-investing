# 宇通客车

## 和AI反复讨论后汇总的分析报告

**报告日期：2026年8月7日**

### 一、投资要点

1. **国内龙头地位稳固但总量见顶**：宇通在国内6米以上客车市场份额28.09%，稳居行业第一，但国内客车市场已从"增量扩张"完全转入"存量替换"阶段，总量零增长已成常态。

2. **海外是核心增长引擎，空间明确但竞争激烈**：全球客车市场到2030年仍有近千亿美元增量空间，中国客车出口CAGR约15-20%。但宇通面临比亚迪（新能源技术）和金龙（出口规模）的双重夹击，竞争格局远未稳定。

3. **盈利质量是宇通最深的护城河**：2025年归母净利润55.54亿元，同比增长34.94%；净利率13.58%，ROE 38.03%；出口均价109万元，毛利率29%，显著优于同行。

4. **护城河在加宽，也在被冲击**：宇通在盈利能力、品牌溢价、服务生态上的壁垒持续加厚；但在新能源技术和出口规模两个维度上面临强有力的挑战。

---

### 二、国内市场：存量博弈，龙头稳固但无增量

#### 2.1 市场总量：零增长已成常态

2026年上半年，国内6米以上客车累计销量**56,172辆**，同比微增0.56%。国内客车总销量19.5万辆，基本持平。市场已从"增量扩张"完全转入"存量替换"阶段。

**核心特征**：客车市场存量规模已经接近饱和，**新增需求占比不足三成，七成以上需求来自老旧营运车辆的更新替换**。总量天花板清晰可见。

#### 2.2 竞争格局：宇通"一超多强"

| 指标              | 数据       | 含义                           |
| ----------------- | ---------- | ------------------------------ |
| 宇通6米以上市占率 | **28.09%** | 行业唯一销量破万，龙头优势稳固 |
| 前十企业集中度    | **91.7%**  | 行业高度集中，中小品牌持续出清 |
| 宇通1-6月销量     | 15,779辆   | 同比下滑8.3%，受国内总量拖累   |

在大型客车细分市场，宇通市占率高达**44.9%**，无可撼动。

#### 2.3 新能源渗透率：结构分化明显

| 细分市场 | 新能源渗透率（2026年5月） | 状态判断     |
| -------- | ------------------------- | ------------ |
| 轻型客车 | **75.8%**                 | 接近饱和     |
| 中型客车 | **49.7%**                 | 仍有空间     |
| 大型客车 | **39.6%**                 | 空间较大     |
| 整体客车 | **39.9%**（2026H1）       | 仍有提升空间 |

公交领域新能源渗透率已超99%，基本触顶。公路客车新能源渗透率2026年预计达30%，未来五年有望升至50%，是结构性的增量来源。

#### 2.4 国内市场核心判断

国内客车市场总量已触顶，未来增量主要来自：

1. **存量替换**：公交置换周期的政策托底（以旧换新补贴）
2. **结构升级**：新能源对燃油的持续替代（公路客车是主力战场）
3. **产品升级**：高端化趋势（高端座椅车型占比从8.4%升至27.1%）

**但总量层面，零增长是常态，无法提供增长弹性。**

### 三、海外市场：增长的主战场，空间明确

#### 3.1 全球客车市场：稳步扩容，天花板尚远

多家机构对全球客车市场的预测较为一致：

| 机构/报告            | 基期规模          | 远期规模          | CAGR      |
| -------------------- | ----------------- | ----------------- | --------- |
| GII（巴士市场）      | 2025年772亿美元   | 2030年1,133亿美元 | **8.0%**  |
| GII（客车市场）      | 2024年1,245亿美元 | 2030年1,993亿美元 | **8.17%** |
| Research and Markets | 2025年914亿美元   | 2031年1,458亿美元 | **8.09%** |
| 中金普华产业研究院   | 2024年680亿美元   | 2030年1,150亿美元 | **10.2%** |

全球客车市场2024年规模约680-1,245亿美元，到2030年预计达到1,100-2,000亿美元，CAGR约**8%-10%**。

**核心驱动力**：电动化和零排放转型加速、智慧交通普及、旅游和长途出行需求增长、智慧城市基础设施扩张。

**天花板判断**：海外大中客新能源渗透率刚突破10%，电动化替代才刚刚进入加速期。以欧洲为例，2025年新售电动公交占比已超50%，2030年有望实现100%零排放公交。仅存量燃油客车的电动化替换就能提供巨大的市场增量。

#### 3.2 中国客车出口：核心引擎，CAGR约15-20%

**短期（2026年）** ：

| 指标           | 预测值      | 同比增速 |
| -------------- | ----------- | -------- |
| 客车出口总量   | **7.8万辆** | **+32%** |
| 新能源客车出口 | **2.0万辆** | **+34%** |

2026年上半年大中客出口已达2.8万辆，同比增长20%。

**中长期（2030年）** ：

> **预计到2030年，国产大中客出口销量有望达13.5万辆，5年CAGR接近20%，占据海外约33.9%的市场份额。**

从7.8万辆（2026年）→13.5万辆（2030年），增量空间约5.7万辆，增幅73%，年化增速约15-20%。

**分区域空间**：

| 区域      | 当前国产份额 | 2030年目标份额 | 2030年出口销量 |
| --------- | ------------ | -------------- | -------------- |
| 中东&亚洲 | 21%          | **35%**        | **6.2万辆**    |
| 拉美      | 15.2%        | **25%**        | —              |
| 欧洲      | 15.4%        | **30%**        | —              |

中东&亚洲是最大的增量来源。欧洲市场伴随动力结构变革，国产份额有望从15.4%跃升至30%。

#### 3.3 新能源客车：结构性超额增速

| 市场               | 2024年规模    | 2030年预测    | CAGR       |
| ------------------ | ------------- | ------------- | ---------- |
| 全球电动客车市场   | 141-170亿美元 | 264-375亿美元 | **13-14%** |
| 中国新能源客车出口 | 2026年2万辆   | 持续高增      | **>30%**   |

全球电动客车市场增速（13-14%）显著高于整体客车市场（8%），新能源是结构性超额增速的来源。

### 四、海外竞争格局：宇通被两面夹击

#### 4.1 整体出口：金龙总量领先

2026年上半年，中国3.5米以上客车出口41,156辆，同比增长15.64%。

| 排名  | 企业         | 出口量      | 同比    | 市占率 |
| ----- | ------------ | ----------- | ------- | ------ |
| 1     | 金龙客车     | 8,075辆     | +37.99% | 19.62% |
| **2** | **宇通客车** | **6,850辆** | +13.79% | 16.64% |
| 3     | 苏州金龙     | 5,110辆     | +56.75% | 12.42% |

**关键观察**：金龙以全系列车型布局在总量上领先，增速37.99%远超宇通的13.79%。

#### 4.2 大中客出口：宇通的核心堡垒

在7米以上大中客这一核心赛道：

| 排名  | 企业         | 出口量      | 同比    | 市占率     |
| ----- | ------------ | ----------- | ------- | ---------- |
| **1** | **宇通客车** | **6,642辆** | +13.07% | **22.08%** |
| 2     | 苏州金龙     | 4,429辆     | +94.25% | 14.72%     |
| 3     | 中通客车     | 4,318辆     | +23.65% | 14.35%     |

宇通是大中客出口唯一超6,000辆的企业，领先优势显著。宇通的"弱势"在于轻型客车出口，导致全口径排名被金龙反超。

#### 4.3 新能源客车出口：比亚迪的技术壁垒

2026年上半年，中国新能源客车出口10,081辆，同比增长32.14%。

| 排名  | 企业         | 出口量      | 同比        | 市占率     |
| ----- | ------------ | ----------- | ----------- | ---------- |
| **1** | **比亚迪**   | **2,233辆** | +7.25%      | **22.15%** |
| **2** | **宇通客车** | **1,676辆** | **+55.47%** | 16.63%     |

**关键观察**：

- 比亚迪连续三年夺冠，是上半年唯一出口突破2,200辆的企业
- **宇通增速高达55.47%**，远超比亚迪的7.25%，差距正在快速缩小
- 6月单月，宇通以621辆夺冠，市场份额24.92%

### 五、竞争对手的攻势分析

#### 5.1 比亚迪：新能源领域的技术定义者

**核心优势**：全栈自研的三电技术（e-BUS平台3.0、刀片电池等），实现"技术出海、产品出海与标准出海"三位一体。

**市场渗透**：

- 欧洲市场累计交付超7,000台纯电大巴
- 英国零排放大巴45%市场份额
- 日本电动巴士市占率超50%
- 巴西一次性交付265台电动大巴

**战略路径**：凭借三电核心技术，在各国复制"英国模式"（占据零排放大巴近半份额），在新能源细分市场建立技术标准的定义权。

#### 5.2 金龙汽车：规模与网络的压制

**核心优势**：多品牌协同（"三龙"整合）、全球销售网络覆盖170多个国家和地区。

**市场表现**：

- 上半年全口径出口8,075辆，同比+37.99%，总量第一
- 苏州金龙上半年增速56.75%，是主流企业中最高
- 2026年初获阿尔及利亚3,000台大单，创中国客车出口最大单纪录

**战略路径**："三龙整合"成功后，将在采购、研发、销售上形成统一高效的巨头，凭借更广的渠道和成本优势在总量上长期保持第一。

#### 5.3 竞争格局总结

| 维度       | 宇通               | 比亚迪             | 金龙               |
| ---------- | ------------------ | ------------------ | ------------------ |
| 国内市占率 | **28.09%（第一）** | 较小               | 较小               |
| 大中客出口 | **22.08%（第一）** | 7.39%              | 合计约23%          |
| 全口径出口 | 16.64%（第二）     | 5.43%              | **19.62%（第一）** |
| 新能源出口 | 16.63%（第二）     | **22.15%（第一）** | 合计约27.55%       |
| 盈利质量   | **最高**           | 中等               | 较低               |
| 技术壁垒   | 强                 | **最强**           | 中等               |

**核心结论**：宇通在大中客和盈利质量上领先，但在新能源技术上落后于比亚迪，在出口规模上落后于金龙。三强各有所长，竞争格局远未稳定。

### 六、宇通的护城河评估

#### 6.1 盈利能力：最深的护城河

| 指标       | 2025年数据                     | 意义               |
| ---------- | ------------------------------ | ------------------ |
| 营业收入   | 414.26亿元，同比+11.31%        | 稳健增长           |
| 归母净利润 | **55.54亿元**，同比**+34.94%** | 利润增速远超营收   |
| 净利率     | **13.58%**                     | 行业最高           |
| ROE        | **38.03%**                     | 远超同行           |
| 分红率     | **99.65%**                     | 2025年派发55.3亿元 |

宇通的出口均价（109万元）和毛利率（29%）显著优于金龙（44万元，14%），体现高端化战略的成功。

#### 6.2 技术护城河：持续加厚

- 2026年3月发布**睿控E+平台**，以"1个智电底盘+1个智慧大脑+1个智能服务"为核心架构
- 截至2025年底，新能源客车全球累计销量突破**21万辆**
- 产品从挪威北极圈（-38℃）到卡塔尔沙漠均能稳定运行
- 年研发投入18亿元，行业最高

#### 6.3 全球化布局：从"产品出海"到"产能出海"

- 已在**16个国家和地区**布局KD工厂
- **卡塔尔**：首个海外新能源商用车工厂已动工，设计年产能300辆，可扩展至1,000辆——是中国企业在中东建设的首个新能源商用车工厂，获卡塔尔国家级战略支持
- **哈萨克斯坦**：QazTehna工厂已投产

宇通的出海模式已从"产品输出"升级为"**技术、品牌、产能、服务的全方位输出**"，这是护城河加宽的最核心标志。

#### 6.4 财务护城河：零有息负债+高分红

- 连续多年保持**零有息负债**
- 2025年每股分红2.5元，股息率8.7%
- 健康的财务状况使其能承受价格战、进行长期投入

#### 6.5 护城河判断：加宽中，但受到冲击

| 维度     | 变化方向   | 判断                                 |
| -------- | ---------- | ------------------------------------ |
| 盈利能力 | **加宽**   | 净利率13.58%，ROE 38%，行业无可匹敌  |
| 品牌溢价 | **加宽**   | 出口均价109万，毛利率29%             |
| 服务生态 | **加宽**   | 16国KD工厂，400+海外服务网点         |
| 技术壁垒 | **受冲击** | 比亚迪全栈自研三电技术形成定义者优势 |
| 出口规模 | **受冲击** | 金龙总量反超，增速更快               |

### 七、海外市场空间与宇通的增长路径

#### 7.1 空间足够大

- 全球客车市场到2030年CAGR约**8%-10%**，增量空间近千亿美元
- 中国客车出口从7.8万辆（2026年）→13.5万辆（2030年），**增量空间73%**
- 新能源客车增速（13-14%）高于行业平均，是结构性超额增速来源

#### 7.2 但竞争是核心变量

**市场空间清晰，不确定性在于"宇通能吃到多少"**。

宇通的增长路径取决于三个关键变量：

1. **能否在新能源技术上缩小与比亚迪的差距**：睿控E+平台的落地效果、下一代技术（氢燃料、智能驾驶）的布局速度
2. **能否在出口规模上守住大中客第一并缩小全口径差距**：KD工厂的产能释放、新市场的开拓节奏
3. **能否在保持高盈利的同时扩大份额**：盈利质量是宇通最深的护城河，但若因竞争被迫降价，将侵蚀这一优势

#### 7.3 三种情景推演

| 情景     | 假设                                       | 宇通2030年状态                               |
| -------- | ------------------------------------------ | -------------------------------------------- |
| **乐观** | 睿控E+成功，欧洲市场突破，KD产能释放       | 保持大中客第一，新能源差距缩小，盈利质量维持 |
| **基准** | 技术追赶缓慢，份额略有下滑，但盈利维持     | 大中客第二（被金龙或比亚迪超越），盈利仍领先 |
| **悲观** | 技术落后扩大，价格战被迫跟进，份额利润双失 | 三强中掉队，沦为区域性企业                   |

### 八、风险提示

1. **国内总量持续萎缩风险**：公交领域新能源渗透率已超99%，更新周期从8年拉长至10-12年，若"以旧换新"政策退坡，国内销量可能进一步下滑。

2. **海外竞争加剧风险**：比亚迪在新能源领域的技术优势、金龙在规模上的压制，可能持续侵蚀宇通的海外市场份额和利润率。

3. **地缘政治与贸易壁垒风险**：欧盟潜在的本地化要求、碳关税等贸易壁垒可能影响出口节奏。

4. **汇率波动风险**：海外收入占比持续提升（2025年已超50%），人民币升值将直接影响利润。

5. **技术迭代风险**：若宇通在下一代技术（氢燃料、智能驾驶）上不能保持领先，可能被比亚迪进一步拉开差距。

---

### 九、总结

#### 核心结论

**宇通客车的护城河在"盈利能力"和"大中客市场地位"上持续加宽加深，但在"新能源技术"和"出口规模"两个维度上面临比亚迪和金龙的有力挑战。**

#### 关键数据一览

| 维度         | 核心数据                                 | 判断                                  |
| ------------ | ---------------------------------------- | ------------------------------------- |
| 国内市占率   | 28.09%（6米以上）                        | 龙头稳固，但无增量                    |
| 大中客出口   | 22.08%（行业第一）                       | 核心堡垒，但苏州金龙追赶凶猛（+94%）  |
| 新能源出口   | 16.63%（行业第二）                       | 增速55%领先行业，但比亚迪连续三年第一 |
| 盈利质量     | 净利率13.58%，ROE 38%                    | 行业无可匹敌                          |
| 全球市场空间 | 2030年1,100-2,000亿美元，CAGR 8-10%      | 空间明确                              |
| 中国出口空间 | 7.8万→13.5万辆（2026-2030），CAGR 15-20% | 增量清晰                              |
| 竞争格局     | 三强鼎立，各有所长                       | **远未稳定**                          |

#### 一句话总结

> **全球客车市场到2030年CAGR约8-10%，中国客车出口CAGR约15-20%，海外空间远未触顶。但"市场有空间"和"宇通能吃到"是两回事——真正的悬念不在于市场天花板的高低，而在于宇通能否在比亚迪的技术攻势和金龙规模压制之间，守住并扩大自己的阵地。**
