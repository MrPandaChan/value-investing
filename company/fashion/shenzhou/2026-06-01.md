申洲国际是全球最大的纵向一体化针织服装制造商。在中国、越南、柬埔寨设有生产基地，员工约10.87万人，年产面料约28万吨、服装约6亿件。

| 休闲类 |      93.1      | 27.14% |  +27.1%  |
| 内衣类 |      15.5      | 4.53%  |  +4.1%   |
| 其他   |      2.4       | 0.69%  |    —     |

**四大核心客户（占比约80%）**：Uniqlo、Nike、Adidas、Puma

**区域分布（高度全球化）**：中国内地23.8%、欧盟20.2%、其他地区21.4%、美国18.0%、日本16.6%

## 二、八维度深度分析

### 维度一：靠什么赚钱？（商业模式）

**纵向一体化ODM代工**——从面料研发到成衣制造全链条自己做。

与普通代工厂的核心差异：

- 普通代工厂：客户给面料→加工成衣→赚加工费（毛利率10-15%）
- 申洲国际：自己研发面料→自己织布→自己做成衣→交付品牌（毛利率26%+）

这种模式的价值链更长、附加值更高、客户黏性更强。品牌客户将核心面料研发交给申洲，转换成本极高。

### 维度二：顺风还是逆风？（宏观环境）

**中性偏顺风**：

| 因素               | 方向 | 影响                     |
| ------------------ | :--: | ------------------------ |
| 全球运动休闲趋势   | 顺风 | 运动品类增长持续         |
| 品牌商供应链集中化 | 顺风 | 头部供应商份额持续提升   |
| 美国关税政策       | 逆风 | 但越南/柬埔寨产能已规避  |
| 中国劳动力成本上升 | 逆风 | 海外产能持续扩张对冲     |
| 人民币汇率         | 中性 | 收入多外币结算，自然对冲 |

### 维度三：空间有多大？

**代工行业的天花板在于品牌客户的增长 + 份额提升**：

- 全球运动服装市场约3,500亿美元，CAGR 5-7%
- 申洲四大客户（Nike/Adidas/Uniqlo/Puma）合计年营收超1,500亿美元
- 申洲目前占四大客户采购份额约5-10%，仍有提升空间
- 中国运动服装市场渗透率仍远低于发达国家
- **新增量**：Lululemon等新客户拓展

**保守估计**：若品牌客户年均增长5-8%，申洲份额每年提升0.5-1%，则申洲收入CAGR可达8-12%。

### 维度四：竞争格局

全球服装代工极度分散，但头部集中趋势明确：

| 竞争对手 | 定位           | 规模对比 | 核心差异           |
| -------- | -------------- | :------: | ------------------ |
| 晶苑国际 | 多品类代工     | 申洲1/3  | 非一体化，毛利率低 |
| 儒鸿企业 | 中国台湾面料厂 | 申洲1/4  | 面料为主，非一体化 |
| 维珍妮   | 内衣代工       | 申洲1/5  | 品类单一           |

**申洲在四个维度上均领先**：规模最大、客户最优质、纵向一体化最深、全球化布局最广。

### 维度五：核心优势与护城河（芒格五重共振分析）

申洲的护城河是典型的**鲁拉帕路萨效应**——五种力量同时支撑、相互强化：

| 力量                     | 本质                                     | 强度  |
| ------------------------ | ---------------------------------------- | :---: |
| **规模经济**             | 年产6亿件、28万吨面料，单位成本行业最低  | ★★★★★ |
| **纵向一体化**           | 面料→成衣全链条，交期缩短50%，附加值翻倍 | ★★★★★ |
| **客户黏性（转换成本）** | 深度参与品牌商产品研发，面料独家开发     | ★★★★★ |
| **全球化产能布局**       | 中国+越南+柬埔寨，关税风险分散           | ★★★★  |
| **创始人管理**           | 马建荣持股42.6%，"切身利害"              | ★★★★  |

**这五种力量不是加法关系，是乘法关系。** 规模越大→一体化越深→客户黏性越强→订单越多→规模更大。单点被突破不会导致连锁崩塌。

### 维度六：管理层与治理

- **马建荣**：创始人，持股42.6%，身家与公司深度绑定
- 管理风格低调务实，极少公开露面，专注主业
- 资本配置纪律良好：过去10年无大额并购失败记录
- 分红持续增长：FY2024股息2.53港元/股，FY2025中期1.38港元
- 全球顶级机构持股：施罗德、挪威主权基金、普信、贝莱德、富达等

### 维度七：风险识别

| 风险                         | 严重度 | 说明                                              |
| ---------------------------- | :----: | ------------------------------------------------- |
| 客户集中度高（四大客户~80%） |  ★★★★  | 任一客户流失影响巨大，但转换成本极高              |
| 美国关税/贸易政策            |  ★★★★  | 越南/柬埔寨产能已部分规避，但仍需关注             |
| 毛利率持续下行               |  ★★★   | FY2024 28.1%→FY2025 26.35%，人工成本+客户结构变化 |
| 劳动力成本上升               |  ★★★   | 海外扩张部分对冲，但中国基地成本压力持续          |
| 品牌客户自建产能             |   ★★   | Nike/Adidas趋势是外包增加而非减少                 |
| 越南税收优惠到期             |   ★★   | 已部分反映在FY2025税率中                          |

### 维度八：未来展望与结论

**关键假设**：

- 产能持续扩张：越南新面料厂（200吨/天）+ 柬埔寨新工厂（6,000人）
- 订单增长：四大客户份额提升 + 新客户（Lululemon等）拓展
- 毛利率修复：一次性加薪影响消退 + 产能利用率提升

**核心判断**：申洲不是简单的代工厂，而是品牌供应链的核心基础设施。全球运动品牌越竞争，越需要申洲这样的顶级供应商。护城河不仅宽，而且在加深。

## 三、BG十问尽调

### Q1 成长性判定：**是**

关键引擎：

1. **现有客户份额提升**：四大客户中份额仅5-10%，远未见顶
2. **新客户拓展**：Lululemon等新品牌持续导入
3. **产能扩张**：越南/柬埔寨新基地支撑量增

### Q2 十年后图景

**情景描述**：申洲将成为全球运动品牌不可或缺的"制造操作系统"，年产量突破10亿件，客户覆盖全球前十大运动品牌，海外产能占比超60%。

**关键不确定参数**：

1. 全球贸易壁垒是否会阻断供应链全球化
2. 自动化/AI能否解决劳动力成本持续上升问题

### Q3 竞争优势（已在上文五重共振中详述）

核心护城河：**纵向一体化×规模经济×客户黏性×全球化布局×创始人治理**——五重共振

### Q4 文化适应性

标志文化特征：**极致务实、长期主义、低调深耕**

- 不追逐短期热点，不跨界多元化
- 持续投入面料研发（全球领先的针织面料技术）
- 与客户关系超越简单代工，更像是"制造合伙人"

### Q5 用户喜爱与社会价值

- 终端消费者不知道申洲，但穿的衣服大概率是它做的
- 社会贡献：#全球最大纵向一体化服装制造商 #中国制造业标杆 #10万+就业
- ESG：越南/柬埔寨工厂提供当地优质就业，获恒生可持续发展指数纳入

### Q6-Q7 盈利趋势

**当前评级**：健康（短期承压）
**未来利润率方向**：↓→↑（先修复后稳定）

核心驱动：

- 毛利率从FY2024 28.1%降至FY2025 26.35%，主因一次性大幅加薪
- FY2025H2毛利率已环比修复，预计FY2026回升至27-28%
- ROE维持16-18%，符合优秀标准

### Q8 资本配置

**风格**：平衡型（再投资为主+稳定分红）

- FY2025 Capex约27亿港元，主要用于越南/柬埔寨产能
- 分红率约55-60%，股息率5.6%
- 无大额并购失败记录，资本纪律良好

### Q9 市值五倍潜力

**必要条件**：

- 营收达到1,500亿港元（当前343亿，CAGR 15%需约11年）
- 净利率维持18%+（当前18.8%）
- PE维持12-15x

**最大挑战**：代工行业天然有增速上限，靠的是品牌客户的增长，而非自身的指数级扩张。

**更现实的路径**：5年内营收500-600亿港元，净利100-120亿港元，对应市值1,200-1,500亿港元（当前714亿，翻倍）。

### Q10 市场低估点

**认知误区1**："代工厂就是低端制造，没有护城河"
→ **修正**：顶级代工是品牌的核心基础设施。Nike更换申洲的成本远超市场想象——需要数年时间重建面料研发+品控+交期体系。

**认知误区2**："客户集中度过高=高风险"
→ **修正**：集中度高是因为品牌商也集中。且申洲与客户是相互依赖关系——品牌需要顶级供应商保证品质和交期，不是单方面依附。

## 四、魔鬼代言人反偏差分析

### 识别到的认知偏差

| 偏差类型     | 具体表现                                                                        |
| :----------- | :------------------------------------------------------------------------------ |
| **确认偏差** | 市场过度关注申洲"好"的一面（大客户、高ROE），忽视了毛利率下行趋势可能不是短期的 |
| **锚定效应** | 投资者习惯了申洲20%+ ROE和28%+毛利率，但行业结构性成本上升可能改变历史中枢      |

### 核心反驳论证

**反驳一**："毛利率下滑只是暂时的"
→ **反向观点**：中国劳动力成本长期上行是结构性的，越南/柬埔寨成本也在上升。品牌客户压价能力极强，申洲能否完全转嫁成本存疑。如果毛利率中枢从28%降至25%，净利将缩水10-15%。

**反驳二**："大客户不会离开"
→ **反向观点**：Nike 2024年已开始部分订单回流自建工厂（墨西哥），虽然规模不大，但趋势值得警惕。品牌商"近岸外包"（nearshoring）趋势可能侵蚀亚洲代工份额。

**反驳三**："估值低就是安全边际"
→ **反向观点**：PE 11x看似便宜，但如果盈利继续下滑（FY2025净利润-4.3%），低PE可能变成"价值陷阱"。需确认盈利底在哪里。

### 缺失的尽调建议

- 实地调研越南/柬埔寨工厂的产能利用率和劳动力供给情况
- 与四大客户的采购负责人访谈，确认份额变化趋势
- 分析美国"近岸外包"对亚洲代工份额的量化影响

### 归零假设审查

| 问题                                | 评估                                               |
| ----------------------------------- | -------------------------------------------------- |
| 如果今天不持有，我会买入吗？        | **会**，当前价位有吸引力                           |
| 有没有更好的替代标的？              | 晶苑国际（更便宜但质地差）、儒鸿（更小但专注面料） |
| 当初买入逻辑是否仍然成立？          | 核心逻辑（一体化护城河+大客户黏性）未变            |
| 仓位是否超过了我能承受的波动？      | YTD跌22%，需评估个人风险承受力                     |
| 如果股价再跌20%，我会加仓还是恐慌？ | 应加仓（47.48→38港元对应PE 8.8x）                  |

**结论**：当前投资决策存在**中等**级别的认知盲区风险。毛利率走势是核心变量，需密切跟踪。

## 七、周期压力测试（四层穿透法）

### 第一层：宏观债务周期定位

**定性判断**：全球处于"被动去杠杆"后期向"主动加杠杆"过渡阶段。运动消费具有一定韧性（刚需+健康趋势），但关税和贸易壁垒是最主要的外部冲击源。

### 第二层：行业放大器识别

**放大器类型**：渠道蓄水池型 + 关税冲击型

服装代工行业不直接面对终端消费者，压力传导路径为：
品牌商终端销售放缓 → 品牌商削减订单 → 代工厂产能利用率下降 → 毛利率承压

**当前状态**：四大品牌客户FY2025订单稳中有升，暂未见削减信号。

### 第三层：商业模式脆弱性体检

| 检查项           | 评分  | 说明                                   |
| ---------------- | :---: | -------------------------------------- |
| 定价权           |  ★★★  | 成本转嫁能力中等，需6-12个月传导       |
| 现金流韧性       | ★★★★★ | FY2025经营现金流61.4亿，FCF 34.4亿，强 |
| 资产负债表       | ★★★★★ | 现金171亿，有息负债低，净现金状态      |
| 利益攸关方牢固度 | ★★★★  | 客户长期合作关系，员工流失风险可控     |

**模拟压力测试**：

| 情境     | 营收变化 | FCF（亿港元） |   能否生存    |
| -------- | :------: | :-----------: | :-----------: |
| 温和衰退 |   -10%   |      ~30      |    ✅ 充裕    |
| 严重衰退 |   -20%   |      ~15      | ✅ 可维持分红 |
| 极端情境 |   -30%   |      ~5       | ✅ 净现金缓冲 |

### 第四层：微观信号验证
