# 中煤能源

## 商业模式

**核心判断：**

中煤能源的商业模式，本质上是一个以不可替代的**低成本、大规模煤炭资源**为根基，通过“**高稳定性价值交付**”换取“**可持续现金回报**”，并以“**煤化电新一体化**”对冲周期波动、构筑长期护城河的**可持续价值交换系统**。其成功的关键不在于技术颠覆，而在于对“确定性”和“协同性”的极致追求。

### 一、 价值为先：为谁解决了什么“非解决不可”的问题？

中煤能源的核心价值主张，是为**国家能源安全**与**下游工业客户（电厂、化工厂）** 解决一个“非解决不可”的问题：**获得长期、稳定、可预期成本的大宗能源及化工原料供给**。

- **客户任务（Jobs to be Done）：** 对中国国电投、华能等电力巨头而言，其最核心任务是“**确保发电机组持续、稳定运行**”，而非在燃料价格上博弈。对煤化工企业而言，是“**保障化工装置满负荷运转的原料来源**”。这些任务的成功标准是“**供应安全**”和“**成本可预测**”，而非绝对最低价。
- **价值主张：**
  1.  **供应确定性：** 作为国资委直属的央企煤炭龙头，中煤能源是国家能源保供的核心力量。其庞大的资源储量和生产能力（可采储量行业第一）天然提供了“**绝不会断供**”的心理与现实保障。
  2.  **价格稳定性：** 公司坚持**80%左右的高比例长协销售模式**，主动放弃现货市场的短期暴利，换来的是客户最渴望的“**成本可预测性**”。这直接解决了客户在煤价剧烈波动时的经营焦虑。
  3.  **产品可靠性：** 煤种优质（以动力煤为主，兼有稀缺炼焦煤），热值高、杂质低，并可通过洗选精确匹配客户锅炉需求，降低了客户的适配成本。

**结论：** 中煤能源出售的不仅是煤炭，更是 **“稳定”与“安全感”** 。这一定位使其与客户结成长期利益共同体，而非单纯的买卖博弈关系。

### 二、 交易结构：为什么所有参与者都愿意持续参与？

其商业模式的稳定性，源于构建了一个多方共赢、难以退出的交易结构。

- **与客户（电厂、钢厂）：** 通过高比例长协锁定销量和价格区间，客户获得供应保障和成本稳定，公司获得确定性收入和市场占有率。这是一个典型的 **“稳定性换确定性”** 的双赢结构，尤其在能源安全成为国家战略的背景下，粘性极强。
- **与控股股东（中煤集团）：** 公司作为集团最核心的煤炭上市平台，持续获得集团在**资源获取、资产注入**（承诺2028年前注入部分同业竞争资产）、**政策支持**等方面的强大赋能。集团则通过公司获得稳定的分红现金流和资本运作平台，用于支持自身庞大的煤电、新能源转型投资，形成内部“造血-输血”循环。
- **与产业链下游（内部）：** 公司依托自有煤炭，大力发展**煤化工（聚烯烃、尿素）和煤电业务**。内部煤炭以成本价供应下游环节，使得化工、电力业务获得无与伦比的成本优势，同时为主业煤炭提供了一个“内部消费市场”，平抑了外部需求周期波动的冲击。这是 **“一体化协同”** 创造超额价值的核心。
- **与资本市场：** 作为“中特估”核心标的，公司积极响应政策，通过**提高分红比例（2024年达40.6%）、实施中期分红、推动市值管理**等方式，持续回报投资者，吸引了追求稳定股息的红利型资金。其低负债率（46.3%）、充沛现金流也为高分红的可持续性提供了坚实背书。

**结论：** 交易结构的核心是 **“锁定”** 。通过长协锁定客户，通过集团锁定资源，通过一体化锁定利润，通过高分红锁定资本。所有参与者都在这个闭环中获得了比外部交易更优的稳定回报。

### 三、 价值捕获：为什么你能从创造的价值中，稳定地分到一杯羹？

中煤能源能稳定捕获价值，源于其构筑了难以复制的多重壁垒。

- **稀缺资源壁垒：** 拥有**可采储量138.7亿吨（行业第一）**，主要集中于晋陕蒙核心产区，资源禀赋优渥，低成本露天矿占比较高。这是物理层面的绝对门槛，后来者无法通过资本投入轻易复制。
- **成本优势护城河：** 2024年自产商品煤成本降至**282元/吨**，处于行业第一梯队。这得益于优质资源、露天开采、智能化矿井（如大海则煤矿）以及持续的降本增效管理。低成本是其“高长协低价格”策略下仍能保持可观盈利的根本。
- **一体化运营效率：** “煤-化-电”一体化使其能将煤炭价值的实现环节从“坑口”延伸至“化工厂”和“电厂”。这种模式将产业链利润“内部化”，同时通过内部结算平抑了单一环节的价格波动，实现了`1+1>2`的协同效应。这是单纯的煤炭开采企业难以企及的。
- **政策与体制壁垒：** 作为央企，其在获取新增煤矿审批、参与央企煤炭资源整合、获得银行贷款等方面享有天然优势。国资委推行的“一利五率”考核（特别是ROE和营业现金比率），进一步驱动其提升资产质量和分红回报，强化了其作为“红利资产”的定位。

**结论：** 中煤能源捕获价值的根本，在于其**物理资源（煤）与组织能力（低成本、一体化、强治理）的深度耦合**。它创造的价值中，相当一部分来自“结构效率”（一体化和长协模式），而非单纯的“运营效率”。

### 四、 效率与重构：能否用更低成本、更高效率完成价值交换？

中煤能源并非颠覆式创新者，但其持续通过效率改进和模式重构巩固护城河。

- **成本效率重构：** 通过**大规模计提资产减值（2021-2022年超120亿）**，彻底甩掉北岭煤矿、沙拉吉达井田等历史包袱，优化了资产组合，轻装上阵。这是对自身资产结构的“断臂式重构”，显著提升了未来整体资产的回报效率。
- **运营效率提升：** 大力推动**智能化矿山建设**（如大海则煤矿实现5G+智能开采），减少人员、提高安全性的同时，有效降低了吨煤开采成本和维修支出。在建的榆林煤化工二期项目，通过采用最新技术，单吨投资和单吨煤耗较一期项目大幅下降24.8%和46.8%，预计投产后毛利率将大幅提升。
- **业务结构重构：** 公司正积极从“纯煤炭生产商”向 **“综合能源服务商”** 转型。通过集团“两个联营”战略，大力布局坑口煤电和新能源（风电、光伏、绿氢），旨在打造“煤-电-化-新”致密产业链。这不仅能内部消纳煤炭，还能在未来碳约束时代获得新的增长空间和绿色溢价，是对传统煤炭商业模式的战略性升维。

**结论：** 中煤能源的效率提升路径清晰：**淘汰落后资产、以智能化改造存量、以高标准建设增量**。其未来的核心竞争力，将不仅体现在更低的煤炭成本，更体现在整个“煤-电-化-新”系统的综合能源供给效率。

### 最终总结：商业模式的本质画像

**一句话概括：** 中煤能源是一个以“物理资源+体制信用”为根基，通过“长协锁定+一体化运营”构建稳定价值网络，并持续通过“降本增效+资产优化”来巩固护城河的**超大型、低风险、可持续能源价值交换平台**。

**可持续性评价：** 其价值交换逻辑**高度自洽且可持续**。

- **供给侧：** 资源壁垒稳固，成本优势长期存在。
- **需求侧：** 客户对“稳定供应”的需求刚性，长协模式粘性极强。
- **利润侧：** 高分红政策锁定了一批稳定的长期投资者，降低了股价的投机性波动。
- **风险点：** 远期主要风险在于“双碳”目标下煤炭需求的终极萎缩。但公司已通过布局煤化工和新能源进行对冲，其100多年的可采储量提供了充足的转型缓冲期。因此，这是一个**稳健有余、成长可期**的“压舱石”型商业模式。

## 非财务信息“八问”

基于研报信息和最新数据，中煤能源当前处于**煤价下行周期中的盈利韧性验证期**，核心投资逻辑在于"**稳定的煤炭主业基本盘 + 显著的煤化一体协同优势 + 逐步释放的分红潜力**"。

### 【维度一】靠什么赚钱？核心驱动力是什么？

**生意本质**：赚取"低成本开采的煤炭资源价值 + 清洁转化的化工产品附加值"。

**收入与利润结构**：

2025年，公司营收1480.57亿元，其中煤炭业务营收1204亿元、占比81.3%，煤化工业务营收186.6亿元、占比12.6%，其他业务（装备制造、金融等）合计占比约6%。

毛利结构方面，煤炭业务贡献毛利约325.7亿元（占比约92%）、毛利率27.1%，其中自产煤毛利率高达**48.1%**；煤化工业务毛利约26.9亿元（占比约7.6%）、毛利率14.4%；金融业务毛利率高达**65.92%**，但规模较小。

**核心驱动力**：

（1）**自产煤炭业务**——公司的绝对"利润发动机"。2025年自产煤销量13636万吨、贡献毛利317.85亿元，单吨毛利约233元。自产煤高长协比例（约80%）使售价波动远小于市场煤价，业绩稳定性领跑行业。

（2）**煤化工一体化**——既是"利润稳定器"也是"增长第二极"。煤化工业务一体化成本优势显著，将自产煤转化为烯烃、尿素等高附加值产品，在煤价下行期可对冲部分煤炭利润波动。

### 【维度二】顺风还是逆风？外部大环境好不好？

**宏观定性**：行业处于**结构分化期**，煤价下行压力仍存但底部有支撑。

**顺风清单**：

1. ✅ **供给端"反内卷"政策持续发力**。2025年7月国家能源局发布煤矿超产核查通知，对超核定产能生产行为实施整改，煤炭月度产量同比由正转负，有效遏制了无序竞争，成为下半年煤价修复的重要推动力。

2. ✅ **央企市值管理和分红考核持续推进**。国务院国资委全面推行"一企一策"考核，将分红和市值表现纳入央企负责人考核体系，为公司提升分红率和市场沟通提供了制度动力。

3. ✅ **煤化工景气度维持**。2025年煤化工行业高景气度延续，原油价格高位使煤制烯烃具有显著的成本竞争力，为煤化工业务毛利提供了支撑。

**逆风清单**：

1. ❌ **煤炭价格下行压力尚未完全解除**。2025年全年秦皇岛港5500大卡动力煤均价约685元/吨，同比下降约22.2%，长协价也出现小幅松动。

2. ❌ **下游电力需求增长放缓**。受新能源（风电、光伏）高增及水电丰年影响，火电发电量增速趋缓，对电煤需求形成压制。进口煤虽然同比下降但仍处高位，进一步加剧了供给宽松格局。

3. ❌ **煤化工部分产品价格承压**。2025年聚乙烯、聚丙烯销售均价同比分别下降10.8%和7.7%，尿素价格同比下降14.4%，压缩了煤化工业务的盈利空间。

### 【维度三】空间有多大？天花板在哪里？

**第一增长曲线见顶判断**：**未达天花板，仍有增长空间**。

公司煤炭可采储量138.71亿吨，按2025年产销量1.35亿吨计算，可采年限约**103年**，资源保障度极高。在产主力矿井产能利用率已达到较高水平，但通过新建矿井投产和存量核增，仍可实现稳步增长。【研报中披露了可采年限103年，数据来源指向研报页面12】

**第二增长曲线储备**：多元且空间可观。

- **煤矿产能增量**：在建矿井里必煤矿（400万吨/年）预计2027年投产，苇子沟煤矿（240万吨/年）预计2026年底投产；远期规划大海则二期（2000万吨/年），产能成长路径清晰。

- **煤化工增量**：榆林二期煤化工项目（90万吨聚烯烃/年）计划于2026年底投产，预计投产后新项目吨毛利较现有水平提升248.5%，达1854元/吨。【研报（民生证券2024-08-21）第20-22页估算数据】

- **集团资产注入**：中煤集团承诺2028年5月前注入存在同业竞争的资源发展公司（含7座煤矿，权益产能742万吨）和华昱公司（中煤集团持股60%，含7座煤矿，权益约1089.6万吨）。【研报页6-11】

### 【维度四】竞争格局好不好？玩法是什么？

**行业梯队地图**：中煤能源与**中国神华、陕西煤业、兖矿能源**并称煤炭"四大金刚"，自产煤产量约**1.35亿吨**，稳居行业前四。

| 对比维度              | 中煤能源 | 中国神华 | 陕西煤业 | 兖矿能源           |
| --------------------- | -------- | -------- | -------- | ------------------ |
| **自产煤售价(元/吨)** | ~485     | ~472     | ~444     | ~513               |
| **自产煤成本(元/吨)** | ~252     | ~172     | ~289     | ~344               |
| **吨煤毛利(元/吨)**   | ~233     | ~300     | ~155     | ~169               |
| **2025年净利同比**    | -7.3%    | -5.3%    | -25.0%   | -43.6%             |
| **长协比例**          | ~80%     | ~92.6%   | ~60%     | 较低（市场煤为主） |
| **2025年分红率**      | ~35%     | ~79%     | ~60%     | ~60%               |

其中，中国神华成本最低（约172元/吨），但中煤能源**成本下降幅度最大**（2025年同比下降10.7%至252元/吨），且**2025年净利降幅小于陕西煤业和兖矿能源**，展现出较好的抗风险能力。

**竞争核心要素**：成本（拼吨煤开采成本）+产能（拼在产/在建规模）+长协（拼比例锁定价格）+分红（拼股息率吸引长期资金）。中煤在成本和产能上具有比较优势，长协比例高带来稳定性。

**利润率密码**：煤炭行业利润率中枢约15%-25%。中煤自产煤毛利率48%，处于同业较好水平；煤化工毛利率14.4%，处于行业中游，但一体化供应链带来的稳定性优于独立化工企业。

### 【维度五】有什么优势？护城河在哪？

**独特护城河**（对手极难复制的核心壁垒）：

1. **"央企唯一的煤炭+煤化一体化"平台优势**。公司是唯二煤炭央企之一，在资源获取、政策支持、资产注入等方面具有绝对优势。中煤集团明确承诺2028年前注入优质煤炭资产，外延成长路径独特。

2. **资源禀赋与成本优势的叠加**。公司可采储量138.71亿吨，位居行业第一，且煤炭赋存条件好，平朔矿区露天矿占比超40%，吨煤综合成本远低于行业均值。2025年自产煤单位成本仅251.51元/吨，同比下降10.7%，降幅居行业之首。

3. **产业链深度协同的"利润率稳定器"**。自产煤高比例内部供应煤化工，煤炭-化工一体化降低了化工业务的原材料成本波动；同时2025年在尿素等产品价格下降的情况下，通过降本增效，甲醇外销量同比大增10倍以上，展现出了极强灵活性。

### 【维度六】管理层行不行？治理有没有雷？

**管理层画像**：中煤集团控股，国资委实际控制，管理层风格稳健务实。公司主动推进市值管理，在投资者回报方面态度积极，2023年新增特别分红，2024年、2025年连续实施中期分红，分红频次和比例明显提升。

**治理红灯预警**：暂无重大风险信号。大股东持股稳定，资产负债率持续下降（2025年预计约40%左右），货币资金充沛，未出现关联交易异常或股权质押风险。

**分红政策持续兑现**：董事会已通过2025年中期分红方案（每股0.166元），并获股东大会授权，预计全年股利支付率约**35%**，较2023年的30%进一步提升。随着国资委市值管理考核深化，分红比例仍有进一步提升空间。

**一句话评价**：管理层稳健、分红意愿持续增强，可给予较高信任度。

### 【维度八】未来会怎样？预测与判断

**短中期展望（1-2年）**：

业绩大概率于2025-2026年筑底。2025年归母净利润178.84亿元，同比下降7.3%，降幅已显著收窄。2026年受益于煤价中枢上移（华福证券预测至770元/吨）及榆林二期等新项目投产，业绩有望实现10%左右的同比增长。当前PE约10-11倍，高于历史底部但低于成长估值中枢。

**催化剂**：①煤价超预期回暖；②里必/苇子沟煤矿提前投产；③集团资产注入进度超预期；④分红率意外提升至40%以上。

**长期终局判断（3-5年）**：

公司将从"纯煤炭央企"向"煤电化新综合能源服务商"转型。煤炭主业维持1.35-1.45亿吨稳定产出，煤化工业务通过榆林二期等项目实现总产能大幅提升，煤电+新能源业务形成新的利润增长点，集团资产注入完成后外延成长空间进一步打开。

**估值锚定**：当前市场给予**价值股+周期股双重属性**定价（PE 10-11倍，PB约1.0倍，低于中国神华、陕西煤业的PE和PB水平）。若公司持续兑现高分红（分红率提升至40%以上），估值中枢有望向13-15倍PE的重估空间迈进；若煤价进入新一轮上升周期叠加成长性兑现，有望迎来"周期向上+成长兑现"的双击行情。

**一句话结论**：**煤电化一体央企龙头，2026年起多重成长极逐步放量，高分红政策渐入佳境，兼具稳健底仓与弹性期权属性。**
