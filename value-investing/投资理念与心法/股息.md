# 股息

## 高股息率的好处

——《不焦虑的投资》

在价值投资中，股息率（股息和股价的比）是被不少优秀价值投资者所重视的指标。比如，在沃伦·巴菲特的许多投资中，我们都可以看到高股息率的影子。

在价值投资领域著名的经典著作—杰里米·西格尔所著的《股市长线法宝》一书中，也有专门的章节，统计高股息率对长期投资带来的超额收益。

在“如何打败市场”一章中，西格尔用专门的一节“高股息率”讲述了一个模型。这个模型非常简单：在每年年底，把标普500指数的成分股，按股息率由高到低，分成5档，统计它们在下一年的股价表现。最后，将这些股价表现加总，就得到股息率从高到低的5档股票长期的股价表现。

如此简单的一个模型，就得到了惊人的结果。

从1957年到2006年，从1000美元开始，股息率从高到低的5档，最后分别会变成675211美元、419071美元、136482美元、97301美元、93106美元。而标普500指数的对应指数基金（和股票复权价格一样包含了股息）​，则会把1000美元变成176134美元。

可以看到，在西格尔的模型中，标普500指数中股息率最高一档的股票，在1957年到2006年的50年间，回报率是674倍。相比之下，最低档股票只有92倍，标普500指数（包含股息再投资）也只有175倍。高股息率的威力，由此可见一斑。

以上规律，在中国资本市场中，也屡屡被聪明的价值投资者发现。其实，验证以上的规律并不难，在电脑技术普及的今天甚至是一件非常简单的事。只要一个金融数据库，加上一些Excel的编程计算，花上几十分钟我们就可以复制以上模型，并且发现极其相似的结果。有兴趣的投资者，可以自己动手算一算。

统计数据简单明了，但是聪明的投资者必然是要“知其然，又知其所以然”​，才算真正搞懂。那么，为什么高股息率会在长期给投资者带来巨大的好处呢？这里，就让我们来看看高股息率带来的各个投资优势。

### 高股息率往往意味着股票便宜

高股息率最重要的好处是，它往往意味着低廉的估值。一般来说，上市公司的分红不会是一个很夸张的数字，唯二的例外是一些周期性行业在周期景气度顶点的高额分红，以及有时候上市公司放弃发展业务，进入“准清算模式”后进行的大额分红。

因此，当一家上市公司的股息率很高时，极大概率意味着上市公司的估值很低。虽然也会有例外，但是当西格尔在他的模型中，把每组股票的数量设置为100只时（整个标普500指数被分成5组）​，这种小概率的例外也就被大样本稀释了。

所以，当投资者构建了一个拥有几十只高股息率股票的投资组合时，他极大概率会买到很多便宜的股票。而低廉的买入价格，从来都是优秀投资结果的保障。

### 高股息率往往意味着财务情况较佳

由于股息率=股息/股价，因此高股息率在对应着较小的分母（较低的估值）的同时，往往也对应着较大的分子（慷慨的分红）​。而能够给出慷慨分红的公司，一般来说财务状况不会太差。

这种“财务状况不会太差”​，至少包含两层意思。第一，从企业报表的数据来说，盈利情况不会太糟糕，否则分红无从谈起。第二，从报表的质量来说，企业的盈利往往是比较扎实可信的，因为在赚到账面的利润以后，企业真的有现金回馈股东。

但是，这种“股息率高所以企业财务情况较佳”的规律，并不是100%可靠。

比如说，在一些财务造假案件中，我们也可以看到，企业在暴雷之前，进行了大量分红。这种分红的目的，并不是回馈所有股东，而是控股股东知道上市公司的骗局难以支撑，因此早点儿拿分红套现走人。控股股东占股较多，大部分的分红自然也就落入他们的口袋，小股东得到的分红只是“不得区别对待股东”的上市规则下的好运气而已。

不过，高分红的企业大概率财务情况的确不错。既然有了优秀的估值，又有了不错的基本面，高股息率在长期给投资者带来好处就是水到渠成的事情了。

### 股息再投资带来持仓基本面的增加

由于高股息率往往对应着较低的估值，因此，当投资者拿到股息，再把这笔股息投入上市公司时，也就意味着以很低的价格追加了一笔投资。长此以往，这种低估值下的股息再投资会带来巨量的基本面增加。

比如，当上市公司的市净率为0.5倍时，公司进行高分红，投资者持有的净资产减少：100元的净资产分红10元，会变成90元。但是，当投资者拿到10元分红以后，以0.5倍市净率的现价买入股票，会得到20元净资产。

如此一来一去，投资者持有的净资产变成了110元。企业的经营在此期间没有发生任何变化，10元净资产增加的魔法就来自低估值与高分红。

硬币的另一面，则是当上市公司估值很高时，分红再投资则会让投资者持有的净资产变少。

比如，当上市公司的市净率是5倍时（而不是上个例子中的0.5倍）​，100元的净资产在进行10元分红以后，会剩下90元。投资者拿着10元分红按5倍市净率进行再投资，则只能买到2元的净资产。现在，加上股息再投资以后，投资者持有的公司净资产，从100元变成了92元。

### 高股息率可以改善投资者的现金流

高股息率还有一个好处，它可以改善投资者的现金流。在价值投资中，我们都知道，市值是虚幻的存在，它只不过是用一小部分市场交易者给出的交易价格，乘以公司的总股本，得到的所谓“总价

但是，凭什么大量不交易的股东，他们所持有股票的价值，就一定要被小部分交易的股东所代表呢？市值这个概念并没有给出合理的答案，也不可能给出合理的答案。

举例来说，农业银行（601288）的A股，2022年的日均交易金额是10亿元左右，而农业银行当时的总市值大约是9000亿元。每天10亿元的交易，就决定了相当于交易金额900倍的全体股东持有的“价值”​，这怎么想都是一件不合理的事情。​（站在2025年，回头看当时这家公司的股票价格，2022年是一个多么美妙的买入时点！）

所以，对于价值投资者来说，企业的市值远没有企业的基本面来得重要。从财务上说，企业的基本面至少包括了收入、利润、净资产、现金流等诸多指标。而从商业来说，基本面还包含了诸如竞争格局、管理层、企业文化等更为“虚无缥缈”的东西。

市值这个概念虽然有千般不是，却有一个好处：它是可以随时变现的价值。这也是许多投资者非常看重市值的主要原因，毕竟财务报表上的数字再好看，也拿不到手上，虚无缥缈的企业文化和竞争格局就更不用谈了：君不见，人力资源部让员工拿企业文化当饭吃，从来都不会得到好结果。

于是，对于价值投资者来说，高股息率就在一定程度上弥补了企业基本面无法变现带来的不足。

当一个投资组合的股息率为8%时（在2022年秋天的港股市场，在国企中，这是一个很容易得到的数字。后来2023～2025年的行情走势，也证明了2022年的价格非常低廉）​，投资者每年都会获得相当大的一部分现金。一般来说，高股息率的股票组合至少会有4%的股息率。

更重要的是，这笔现金流与企业的市值毫无关系。市值的涨跌会通过改变股息率的分母，影响股息率的高低，但是不会改变分子，也就是投资者得到的分红金额。这笔现金流的大小，只和企业的真实经营情况有关。

对于高净值个人投资者、以自有资金投资的企业财务投资部门、家族办公室等投资者来说，这种现金流显得尤其重要。一般来说，专业投资者很少需要突然动用总市值几分之一的金额，相当于总市值几个百分点的现金流就足以应付一年的大部分财务需求。

以上，就是对高股息率的好处和产生这些好处的具体原因的分析。看完之后，你是否对高股息率的好处，有了更清楚的认识呢？

当然，在应用高股息率选择股票时，投资者也需要注意其中可能存在的一些陷阱。同时，对于没有高股息率的股票，我们也不可以一概否定。

要知道，在投资的世界里，对于取得超额投资收益，没有任何一条简单定律是100%有效的。否则，所有投资者就可以抱着这条简单定律，慢慢赚走世界上所有的钱。虽然价值投资的核心哲学亘古不变，但在实际投资中却永无成法可依，这是投资这份工作最艰难之处。
