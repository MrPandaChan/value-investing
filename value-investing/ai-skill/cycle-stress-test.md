# 四层穿透法

## Skill: 四层穿透法 — 周期下的商业模式压力测试

**适用场景：** 当一个行业或头部公司遭遇宏观经济波动、政策冲击或自身周期拐点时，用于评估其当前困境的本质原因、可能持续的时间，以及其商业模式的真实韧性。

**核心思想：** 穿透现象看本质。不满足于“好公司遇到暂时困难”的笼统说法，而是通过四个递进的层次，结构化地拆解压力传导路径，区分是周期性的“皮外伤”还是结构性的“致命伤”。

### 触发词

用户可使用以下关键词触发此技能：

- “用四层穿透法分析 [行业/公司名]”
- “对 [行业/公司名] 的困境进行周期压力测试”
- “从债务周期的角度看，[行业/公司名] 还行不行”

---

## 分析执行步骤

### 第一层：宏观债务周期定位（定方位）

**目标：** 第一步不分析公司，先分析整体经济环境的性质。这决定了后续所有分析的基调。

**需要收集的信息：**

- 居民、企业、政府三个部门的当前杠杆率水平及近年来的趋势。
- 社会融资规模数据中，代表真实需求的信贷增速与结构。
- 具有宏观风险偏好风向标意义的资产（如房地产、股票指数）的价格走势。

**关键分析与输出：**
生成一个宏观定性判断，回答下面这个问题：

> 当前经济是处于“主动加杠杆”的扩张期，还是处于“被动去杠杆”的收缩期？

并明确这种宏观状态对消费和投资行为的根本影响：

- **如果是扩张期：** 源于现金流充裕的信心问题，恢复可能较快。
- **如果是收缩期：** 源于资产负债表受损的偿付问题，去杠杆过程漫长且痛苦，消费和投资行为会发生结构性改变（如消费降级、追求性价比）。

---

### 第二层：行业的“周期放大器”识别（找痛点）

**目标：** 找出宏观压力传导至该行业时，会被哪个关键环节成倍放大，而不是被吸收。

**需要收集的信息：**

- 行业价值链结构图（从原料到终端用户的所有环节）。
- 各个环节的库存模式（是否有多级渠道压货的惯例）。
- 行业产品是否具备投机/金融属性（买涨不买跌）。
- 行业典型的资本开支周期（产能建设耗时多久，投产高峰在何时）。

**关键分析与输出：**
为标的行业识别出其特定的“放大器”，并绘制宏观压力的传导路径图。常见的放大器包括：

- **渠道蓄水池型：** 如白酒、服装；传导链为：需求降温 -> 终端动销变慢 -> 渠道库存高企 -> 价格倒挂 -> 品牌方压货失败、报表恶化。
- **资本开支型：** 如养猪、面板；传导链为：盈利高峰 -> 全行业疯狂扩产 -> 产能集中释放 -> 供需瞬间逆转 -> 价格暴跌 -> 全行业亏损。
- **金融属性型：** 如部分高端消费、投机性电子元器件；传导链为：涨价预期 -> 囤货需求增加 -> 价格上涨强化预期 -> 预期逆转 -> 金融需求瞬间消失 -> 社会库存抛售 -> 价格崩塌。

**明确输出该行业的“压力传导图”。**

---

### 第三层：商业模式的“脆弱性体检”（检内核）

**目标：** 在宏观压力和行业放大器的作用下，重新审查公司的商业模式，哪些曾经的“优势”现在变成了“脆弱点”。

**需要收集的信息：**

- 企业的定价机制：历史上如何提价，提价后销量变化。
- 现金流量表与利润表的匹配度：利润有没有变成真金白银。
- 与核心利益相关方（经销商、供应商、员工）的利益分配格局：是共赢还是压榨。
- 品牌忠诚度/转换成本的检验：用户放弃你的产品/服务，需要付出什么代价？

**关键分析与输出：**
对照检查清单，输出一份该企业商业模式的“体检报告”。

- **定价权真伪检查：** 提价是来自终端消费者愿意付更多钱（真定价权），还是来自经销商认为囤货能赚钱（假定价权/泡沫）？后者会在周期逆转时反噬。
- **护城河方向检查：** 你的护城河（品牌、专利、规模、网络效应）能保护你免受竞争，但在“需求总量消失”面前，它还有用吗？高端白酒品牌很强，但在全民资产负债表收缩时，消费者想的是“我为什么不少喝点，或者喝便宜点的”，转换成本为零。
- **现金流压力测试：** 模拟在营收下降15%、30%两种情况下，企业是否还能产生正向自由现金流？是否高度依赖外部融资或压榨供应商（如拉长账期）来续命？
- **利益攸关方牢固度：** 你的经销商/供应商/加盟商在顺境中赚钱，在逆境中是会选择与你共渡难关，还是会成为优先抛售你产品、破坏你价格体系的“叛军”？

---

### 第四层：微观信号的跨期验证（等信号）

**目标：** 将前三层推导出的逻辑，与现实世界中发生的事实进行“时间序列”上的验证，避免陷入纯粹和主观的逻辑自洽。

**需要收集的信息：**

- 终端销售数据（一批价、零售价、终端动销率）。
- 渠道反馈（经销商进货意愿、库存天数、利润空间、退出情况）。
- 公司行为变化（是否祭出过去不用的非常规手段：控量保价、放松打款条件、给经销商补贴、会计手段调节利润）。
- 竞争对手的应对行为（扩张还是收缩）。

**关键分析与输出：**
输出一份“压力传导顺序检查清单”，回答：

> 我们所推断的逻辑链条，在现实中是否一项一项，按照正确的时间顺序依次发生了？

以白酒为例，正确的验证顺序是：

1.  **终端动销首先放缓**（可以被草根调研、电商数据验证）。
2.  **然后，经销商库存水位上升**（需要经销商调研验证）。
3.  **再然后，酒厂开始放宽打款要求、控量保价**（可以通过公司政策、渠道反馈验证）。
4.  **最后，酒企财报才会在1-2个季度后体现恶化**（在此之前都是经销商在当蓄水池）。

**判断规则：**

- **顺序正确、信号清晰：** 压力传导逻辑成立，困境可能才刚开始，需警惕财报滞后性。
- **顺序错误或信号模糊：** 逻辑可能有问题，需要重新审视。比如，如果零售价还在涨但报表已经恶化，那问题出在公司自身经营上，不是周期问题。
- **厂商非常规手段频繁出现：** 这是动销出问题的铁证，是压力即将从渠道传导至报表的最后预警信号。

## 最终输出模板

完成以上四层分析后，如果用户要求给出综合结论，可按照此结构呈现：

**1. 底层定性**

- 当前困境是周期性的，还是结构性的？
- 是皮外伤，还是致命伤？

**2. 压力路径**

- 宏观压力是如何一步步传导到公司的？（附传导图）

**3. 商业模式韧性评分**

- 在周期底部，它是会产生自由现金流的强者，还是会持续失血的弱者？

**4. 核心追踪指标**

- 在未来的财报和行业动态中，最应该盯住的1-3个先行指标是什么？
