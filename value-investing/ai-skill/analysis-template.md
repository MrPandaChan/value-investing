# 分析模板

请严格按照以下【投资分析模板】的结构和深度，对【公司名称】进行全面分析。

## 模板要求：

1. 必须覆盖模板中所有一级和二级标题。
2. 财务数据分析需覆盖**最近五个完整财年**，年份标签由你根据可获取的最新数据自动确定（例如当前是2026年，则覆盖2021-2025；若数据仅到2024年，则覆盖2020-2024，并注明原因）。所有数据以表格呈现，首行为年份。
3. 估值部分必须包含DCF三阶段模型、相对估值法（PE/PB/股息率历史分位）、SOTP分部估值法，并给出综合目标价。
4. 所有观点必须附上数据依据或逻辑推演过程。
5. 最终结论需包含：一句话核心观点、与至少一家同行业可比公司的正面对决、以及具体的操作建议与价格区间。
