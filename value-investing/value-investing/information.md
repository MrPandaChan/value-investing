  - 公用事业：长江电力、华能水电作为“稳定器”，但操作上可更果断。华润燃气等持股收息，波段操作。

  - 能源：中海油长期看好，等待回补机会。
  - 其他：北京首都机场看好转折与长期恢复；澳博控股作为困境反转标的，关注其债务与管理风险。

[胡猛先生在2025年北大价值投资课上的分享](https://mp.weixin.qq.com/s/fH8LFsG3KOfKrsZ5fJBp9Q)

胡猛在北大价值投资课上分享其作为多空对冲基金经理的“投机”哲学：

1. 因职业评价常与短期市场表现挂钩，多数从业者实质是“投机者”；
2. 投机（赚取价格差）与投资（分享企业成长）界限模糊，时长是关键；
3. 优秀投机者需深研基本面（“人”的位置），但更需驾驭市场情绪（“狗”的波动）；
4. 心法在于同时“怀疑市场”与“怀疑自己”，保持谦卑与灵活，严格执行止损纪律；
5. 聚焦3-18个月的中期变化，不做超长期预测，做空须等待趋势确认。他强调，扎实的价值分析是成功投机的基础。

对价值投资者而言，胡猛的核心洞见可提炼为：

1.  **锚定内在价值**：长期（如十年以上）股价几乎只由基本面（内在价值）驱动，这是价值投资的根本立足点。
2.  **区分回报来源**：清晰认知你的回报是源于企业成长，还是市场情绪波动。价值投资追求前者。
3.  **利用市场情绪**：理解并警惕短期（如一两年内）市场情绪的巨大影响。这并非为了跟随，而是为了识别并利用市场错误定价的机会（在别人恐惧时贪婪）。
4.  **保持谦逊与怀疑**：对企业未来、对自身判断保持“半信半疑”。企业与环境持续变化，需滚动研究、持续跟踪（Buy and watch），避免“买入即遗忘”的惰性和“超长期”的过度自信。
5.  **坚守能力圈**：自知之明至关重要。在自身能理解的范围内，回答能回答的问题，不为难自己。
6.  **敬畏风险与周期**：所有企业都面临变化与挑战。即使伟大企业也可能被颠覆，需动态评估其护城河，警惕“这次不一样”的叙事和过高估值。

[我知道它是AI，但读完“0号芒格”的回答，我突然轻松了(2026.02.05 CxEric的读书与投资笔记)](https://mp.weixin.qq.com/s/wzyrzgNQ6HfLaL1OmPmPhg)

1. 你以为你在积累知识，其实你只是在囤积信息垃圾。别把“忙碌”和“高效”混为一谈，更别把“阅读”和“思考”混为一谈。
2. 你为什么不敢取关？因为你害怕。你害怕错过某一个观点，害怕别人知道而你不知道。
3. “只有当你学会了如何扔掉那些‘不错’的东西，你才能给‘伟大’的东西腾出位置。不要做信息的奴隶，要做智慧的主人。”
4. 你说你“忽略了生活本身”，这说明你把“学习和进步”看作了一种痛苦的代价，一种用来购买未来自由的货币。这种心态本身就是错误的。
5. 如果你在攀登的过程中痛苦不堪，相信我，到了山顶你也只会感到空虚，因为你已经养成了“痛苦地等待未来”的习惯。
6. 嫉妒倾向： 承认吧，你想在年轻时致富，是因为你看到了那些少年得志的人。你嫉妒他们。嫉妒是唯一一种你得不到任何乐趣的罪恶。 它是愚蠢的。你需要关注的是你的内部记分卡，而不是外部的。
7. 手段-目的链条的断裂： 你把“当下”仅仅当作通往“未来”的手段。这是康德伦理学的大忌，也是生活的悲剧。如果你今天不快乐，这通常不是因为你没钱，而是因为你的认知框架出了问题。
8. 你想变富，这很好。但慢慢变富（Get Rich Slowly）才是有趣的，快速致富不仅极难，而且通常伴随着巨大的道德或财务风险。
