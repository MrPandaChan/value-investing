# 卖出策略

1. 股票涨到**目标价位**，就会选择卖出，比如，原来四五倍的市盈率涨到了 10 倍
2. 股票**基本面有本质的恶化**
3. 发现了**性价比更好的股票**

人们常把价值投资简单等同于长期持有，这种认识是有偏差的。长期持有往往是因为我们的**研究领先于市场**，而中国市场的**效率偏低**，股价反映基本面的变化可能需要相当长的时间，导致我们持有时间长。**长期投资、价值投资不是持股不动**，而是需要**不断客观分析行业和公司的发展，并与当时的股价相结合**，判断股价是否高估，风险收益是否合适，如果**已经透支了未来，就要调整**。——《投资中不简单的事》23 邓晓峰：投资的赛场比拼的是学习能力

1. 如果发现**最初对公司的判断和前景假设出现了错误**，或**企业发展的大环境变了**，会卖出。
2. 如果股价的涨幅达到**预期价位**，公司的**风险收益比也达到预期**，会卖出。
3. 在类似属性的资产里发现了**更好的选择**，会卖出。

卖早了很正常，从**组合的角度**，我们会根据个股的表现不断调整，**低估的时候超配**，随着公司价值不断被发现，估值提高了，会**逐渐降低配置**，如果公司股价**已透支了未来，可能会全部卖出**。一只基金的持仓是多个行业的组合多个策略的组合，行业之内的比例处在**动态调整**的过程中，一城一地的得失不重要，主要是看**整体配置长期获取超额收益的情况**，**长期是不是有超额收益更重要**。——《投资中不简单的事》23 邓晓峰：投资的赛场比拼的是学习能力

## 四个标准

#### 1. **第一个卖出标准是，发现当初对企业看错了**

- 任何人对企业的理解都是具有历史性的，都可能发生错误和偏差。我们理解任何问题，难以避免会有事先的成见
- 发现后当然应该**第一时间卖出**。这个时候**不论股价是跌了很多，还是上涨了很多，都应该坚决卖出**

#### 2. **第二个卖出标准是，企业后来的基本面发生了长期的恶化**

- 卖出的标准是企业**基本面发生了长期的恶化，不是短期的恶化**
- 遇到短期负面消息时对公司信心不足，是很多投资者卖出的原因。即使经营再好的公司，也会一路上时不时冒出负面消息。这时候是考验我们的**信息处理能力和商业洞察力**的时候。

#### 3. **第三个卖出标准是，企业价值被“极度高估”**

- 卖出标准是“**极度高估**”，而不是“**一般的高估**”。
- 已经持有的优质股权被市场一时高估（但不是极度高估），是很难被价值投资者“利用”的，所以这种“一般的高估”也没什么用。
- 第一，优秀公司如果暂时被高估，**收益迟早会增长到让估值变得合理**，并且也许能上涨得更高，**增长是能够很快抹平一时的高估的**。
- 第二，**真正有吸引力的好公司数量特别少**，卖掉高估的优秀公司还是需要寻找新的投资机会。如果**降低了公司品质，产生的风险要大于当前持有价格高估的优质公司的临时性风险**。
- 第三，由于**股价的不可预测性**，卖出后如果股价短期内继续大幅上涨，很难再以合适价格接回来了，只能**错失后面的所有涨幅**，并且还可能因此买入了其他质地很差的股票。
- 如果持有的股票被极度高估，也就是说**市场先生的出价远远高于内在价值**。哪怕我们对未来长达 10 年的增长率做出极其乐观的假设，折现率做出最低的假设，股价也远远高于内在价值。
- **卖出优质股权，并且再也无法接回，是“一般的高估”之时卖出的最大风险**。
- **不躲避高估只是给优秀公司的特殊待遇，并不适用于普通公司或者烟蒂股**。质地较差的公司依靠未来业绩增长抹平高估可能需要极长的时间，甚至永远回不来。**烟蒂式投资一定是不能长期持有的，价值回归即要卖出**。

#### 4. **第四个卖出标准是，发现了“明显更好”的投资机会**

- 巴菲特自己几乎很少有**永恒的持股**（除了购买的未上市公司），一方面是**潜力永远不耗尽的企业极少**，另一方面真要是出现了太过疯狂的价格，卖出也许是**机会成本更小的决策**。
- **将价格疯狂的股权转换成现金资产，也是一种投资**。
- ​**“永恒持股”只适用于少数非常优秀的企业**，它们**商业模式极其优秀、发展潜力巨大、有坚不可摧的护城河、优秀的管理和企业文化**。

—— 《投资至简：从原点出发构建价值投资体系》第一章 第三节 构建价值投资体系

## 持有与卖出的方法论

### 持有的核心：逻辑有没有被证伪

- 只要买入时的逻辑没有被证伪，不需要动
- 短期股价波动不影响持有决策
- 关注的变量：海外趋势有没有变？增速有没有变化？
- 当出现大幅波动时，通过投资圈子多维度验证——是真的基本面变化还是市场情绪/大盘波动

### 持有的最重要前提

**必须是暂时用不到的钱 + 不加杠杆**

- 这是"最最最最最重要的因素"
- 如果是短期要用的钱，一定会慌
- 如果加杠杆，面临爆仓压力会导致手势变形

**个人经验**：持有教育股期间经历过两次单日跌25%以上（港股）：

- 当天心情很差，跟圈子里朋友聊聊
- 第二天第三天就恢复了——因为要上班（有其他事情转移注意力）
- 有工资收入兜底——最差情况亏一半也不影响日常生活
- 不能把日常生活搭进去，不能把下个月还房贷的钱或明年买房的钱投入

### 三种卖出信号

**信号一：逻辑证伪**

- 例如：美国、日本、东南亚、法国等所有海外市场全都熄火了
- 某个IP之后全都平庸了
- 证明出海路线/这种形式在海外吃不开，或只是一时新鲜劲
- → 立即卖出

**信号二：估值过高/过于狂热**

- 把各种良性条件都输入进去，估值仍然无法justify
- 例如2021年时，海外还没跑通，增速不高，但股价冲到100多——怎么算都算不过账
- 如果在当前价格基础上再涨50%或翻倍，业务没有太大变化——肉眼可见的高估
- → 卖出

**信号三：增速放缓/业务空间见顶**

- 即使数据很好看，如果变成持续稳定高利润但不再增长
- 那就变成了高股息股票的逻辑（茅台、高速公路）
- 对追求涨幅的投资者来说，没有第三第四曲线时就该离场
- → 卖出，去寻找新的高速增长期
