# 价值投资者AI融合增强系统

## 从“超级个体”到“决策架构师”的落地指南

### 一、核心理念：构建“人机共生”的增强智能体

AI是认知的延伸与倍增器。本方案旨在通过AI将我们的**深度思考、提问能力、决断勇气**三大不可替代的核心能力，与机器的**全知记忆、无限算力、不知疲倦**的特性深度融合，实现投资范式升级。

### 二、核心原则

1. **人主AI辅**：AI负责“可能性的扩展”与“效率的极致”，人负责“问题的定义”与“最终的责任”。
2. **闭环进化**：建立“提问→AI辅助→深度思考→决断→复盘→优化提问”的增强回路，使系统与你共同成长。
3. **聚焦本质**：一切应用以“提升对商业本质的理解”为标尺，过滤技术炫技。

### 三、工具选择

豆包 + iFind/Choice + 有道云笔记

## 第一部分：学习体系——从知识构建到思维锻造

**目标**：突破认知边界，构建“广深高远”型知识结构，并训练跨学科思维迁移能力。

## 第二部分：工作流——赋能研究投资全流程

**目标**：将AI深度嵌入“发现-分析-决断-复盘”的完整链条，打造一个24小时在线的“超级研究员团队”，让你聚焦于最核心的思考与判断。

| 阶段                  | 具体落地动作（“人机协同”闭环）                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                | 人的核心任务与原则                                                                                                                                    |
| :-------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------- |
| **1. 机会发现与筛查** | **1. 宏观线索**：指令：“监控并摘要近一年可能影响[物流/消费]行业的宏观政策、技术突破、社会趋势，并按影响概率与程度排序。”<br>**2. 量化初筛**：在金融终端（Wind/同花顺）设置自定义AI选股条件（如“连续五年ROE>15%、近季度营收增速加速、毛利率环比改善”），生成初步观察池。                                                                                                                                                                                                                                                                                                                       | **原则**：AI是“雷达”和“筛子”，你是“指挥官”。                                                                                                          |
| **2. 深度研究与分析** | **1. 财报智能阅读**：上传PDF年报，指令：“对比公司近五年三张核心财务表格，计算关键比率趋势。**重点关注：** a) 资本开支与自由现金流的背离；b) 营收增长与应收账款增长的匹配度。并用一句话总结每年的核心财务故事；c) 财务数据真实性分析。<br>**2. 商业逻辑推演**：指令：“基于以上财务数据，推测公司管理层过去三年的战略重点是什么？其执行效率如何？（请用数据支持）”<br>**3. 模拟压力测试**：指令：“请对我的核心投资假设（如‘中谷物流将受益于外贸复苏’）进行压力测试。分别推演在外贸**持平、温和衰退、剧烈衰退**三种情景下，对公司未来三年净利润、现金流和资产负债表的具体影响（给出量级估算）。” | **原则**：AI是“数据分析师”和“情景模拟器”。你必须超越数据，追问“为什么”，将数字转化为对**商业模式优劣和管理层能力**的洞见。                            |
| **3. 决策与验证**     | **1. 强制性反方扮演**：形成初步观点后，**必须**指令AI：“请扮演最苛刻的悲观派投资者，从商业模式、财务、竞争、管理层、估值五个维度，提出10个最尖锐的问题来挑战这个投资逻辑。”<br>**2. 董事会模拟**：指令：“你现在是公司董事会成员，我是潜在投资人。请基于我们所有的分析，向我提出5个关于这次投资你认为我必须回答的关键问题。”                                                                                                                                                                                                                                                                   | **原则**：这是**最重要的环节**。AI是你内心的“恶魔代言人”。你的工作不是说服AI，而是确保自己的逻辑能经受住最残酷的自我质疑。                            |
| **4. 持有期动态监控** | **1. 构建核心变量跟踪清单：**<br>• 指令AI：“基于[某公司]的商业模式，列出5-8个决定其长期价值的**核心变量**（如：单箱成本、客户续约率）、每个变量的**预警阈值**（如成本同比上涨>10%）、**数据来源**（公告、行业数据）及**跟踪频率**（月/季）。”<br>**2. 设置再评估触发机制：**<br>• 触发条件：核心变量突破阈值、行业政策巨变、估值波动超30%。<br>• 触发后动作：指令AI：“基于最新数据，重新推演公司盈利模型，对比当前估值，提出3个最关键的**再验证问题**（如：成本上涨能否顺利传导至定价？）。”                                                                                                  | **原则：** 从“买入并遗忘”转向“买入并管理”。人的核心任务是解读变量变化的**商业意义**，并对AI提出的关键问题通过深度研究进行验证，决定“加仓/减仓/持有”。 |

## 第三部分：保障机制——构建系统的“免疫体系”

1.  **事实核查机制**：对AI输出的任何具体数据、案例、引文，**必须**通过权威信源（公司公告、统计局、学术期刊）进行二次验证。指令AI：“请为你刚才的结论提供引用来源或推理步骤。”
2.  **“第一性原理日”**：每周或每两周，选择一个核心标的，完全脱离AI，仅用白纸、笔和原始公告，进行最基础的、从零开始的推理。完成后，再与AI的分析对比，**校准自己的思维基准**。
3.  **决策冷却与肉身验证**：对AI辅助生成的、令你极度兴奋的投资逻辑，强制设置**48小时冷却期**。期间，去线下门店观察，与行业普通人交谈，获取“湿件”（人类感知）信息，挑战冰冷的逻辑。
4.  **工具边界清单**：
    - **绝对禁止**：让AI做任何最终的投资决策（买/卖/仓位）。
    - **绝对禁止**：直接用AI生成的文本作为你的研究结论（必须重写内化）。
    - **绝对禁止**：在未经验证的情况下，将AI输出的事实作为论据。
