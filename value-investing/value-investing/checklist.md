# 检查清单

## 投资的检查清单思维

### 一、入市之前的自我检查清单

1. 是否具备了**完善的投资体系**
2. 是否具备**必要的知识结构**
3. 是否具备**合适的世界观、价值观、人生观和性格**
4. 是否做好了**财务准备**

### 二、公司研究阶段的检查清单

1. 公司过去多年的**财务数据**如何，有无重大疑问，财务表现是否优秀

- 盈利能力指标：历年的**ROE**情况、毛利率、费用率和净利润率
- 成长能力指标：历年的营收和扣非净利润的**增长率**
- 现金流状况指标：经营活动现金流量净额与净利润的比值、应收账款占营业收入的比重、预收账款占营业收入的比重、**自由现金流**等
- 运营能力指标：总资产周转率、应收账款周转天数、存货周转天数
- 财务安全性指标：资产负债率、流动比率、速动比率、股票质押比例等
- 财务数据的**稳定性**：企业经营是大起大落还是平稳增长
- 回报股东的**能力和意愿**：历年融资和分红情况
- 各种财务数据的**同行业比较**
- **ROE**是财务指标中**最重要**的指标，可利用**杜邦分析**工具将企业财务数据统一起来，理解ROE的来源和变化的原因

2. 公司的**商业模式**是什么样的

- 公司的**客户**是谁
- 公司提供什么样的**产品和服务**
- 公司的**价值主张**是什么
- 解决了客户什么样的**需求和痛点**，公司内外部**价值链**是怎样的
- 公司的**盈利模式**是怎样的
- 公司所从事业务的**生意特性**是怎样的
- 公司的**自由现金流**状况如何

3. 公司未来的**成长空间**大小，**成长动力**是什么

- 成长动力包括：行业增长带来销量增加、占领更多**市场份额**、扩展更多地域、产品提价、产品结构升级、开发新产品、进入新业务领域、收购兼并等

4. 公司有没有**宽阔的护城河**，体现在哪些方面

- 可通过**波特五力分析**、护城河分析判断

5. 公司的**管理层**是否**德才兼备**

6. 公司的**治理结构**如何

- 关注要点：主要股东、实际控制人、企业属性（国企/民企）、管理层及核心骨干持股情况、股权质押情况、公司运作模式（制度化/依赖企业家个人）

7. 公司的**企业文化**如何

8. 公司存在哪些**劣势**，未来可能存在哪些**风险**，有哪些**负面因素**

- 思考方向：公司的劣势/软肋、相关负面观点/消息对**投资价值**的影响、公司发展潜在风险、导致公司衰落/倒闭的可能原因、极端情况下公司的生存发展能力

9. 对公司的**定性分析**能否解释公司过往的**经营业绩**

- 核心要点：对于财务数据优秀的公司，需理解其过往**为何而优秀**，才能判断未来能否持续优秀或变得更优秀

### 三、买入阶段的检查清单

交易阶段的检查清单的任务是**拒绝买入**，拒绝不够安全的买入机会。① 尽可能以**较低的成本**获得更多的**股权份额**；② 为复杂多变的未来**预留准备**。

1. 当前**市场估值**情况如何

- 市场估值仅作参考，**萧条时机会更多**，但多数公司估值下跌不代表具体公司具备投资价值

2. 当前**公司估值**情况如何

- 公司历史估值与当前估值仅作参考，估值高低不能简单看市盈率、市净率、市销率等指标，要回归到**现金流折现**这一原点

3. 当前公司**基本面再分析**

- 当前公司基本面与研究阶段相比是否发生**重大变化**
- 正面因素是否仍然存在但被**忽视**
- 负面信息是否已被股价**体现甚至过度体现**

4. 当前价位下买入多少**仓位**

- 仓位大小取决于对公司的**确定性**把握，以及当前估值下预期收益率的**弹性**
- 在**能力圈**范围内，结合个人**机会成本**，为确定性高、弹性大的标的建立更大仓位
- **仓位管理**需有**容错机制**，保证完全看错时也能**损失可控**，不伤及根本

5. 当前价位买入后的**加仓/持有预案**

- 需制定股价短期内下跌/上涨10%、20%、30%、50%等情况的**应对方案**

6. 买入前**再次检查**

- 对公司的研究是否**足够彻底**，是否存在被忽视的**重大信息**
- 可持仓的期限，是否愿意持有这家公司**十年**
- 仓位是否合理，若该笔买入本金**完全损失**，是否可以承受

7. 检查买入动作是否受到**心理偏误**的影响

- 是否仅因股价**正在**上涨/**已经**下跌而买入
- 是否仅因股价**已经**上涨/**正在**下跌而拒绝买入
- 买入动作是否受到价格/PE/PB**锚定效应**的心理影响

### 四、持有阶段的检查清单

持有阶段的检查清单，任务是**拒绝卖出**。解决卖出的标准问题，**不触发卖出即为持有**。牢记**股权是目的，现金是手段**；**卖出是被动行为—不得不卖出（股权思维）**，而非主动行为—“落袋为安”或者“截断亏损”（现金思维）。

1. 持续关注公司的**经营状况**，判断其是否按预期进展，或变得更好/更坏

- 对持仓公司需**定期体检**，平日关注公司新闻，季报、半年报、年报发布后**持续跟踪**经营状况
- 同步关注行业信息、竞争对手信息及其他投资者的思考
- 核心原则：不在意**短期业绩**，只关注对公司有**长期影响**的因素

2. 是否**触发了卖出标准**

- 核心原则：仅基于现价与买入成本价的差距做出卖出决策，属于**逻辑错误**
- 卖出的标准有且仅有**四个**：
  ① **看错了**：若买入逻辑不成立，无论浮亏/浮盈，都要**果断卖出**
  ② **股价被极度高估**：单纯高估非卖出标准，仅极度高估甚至疯狂时值得卖出；超优秀公司可作为**“永恒的持股”**，潜力未释放则永不卖出
  ③ **公司基本面恶化**：因不可逆转的经营失误/外部环境变化，导致商业模式失效、成长空间/护城河受损时卖出；需**区分短期业绩回落与长期业绩下滑**
  ④ **发现了更有确定性、更好的标的**：该标准一般极少使用，除非遇到明显更优标的

3. 卖出动作是否受到**心理偏误**的影响

- 警惕错误卖出动因：是否因股价**涨太多**卖出、是否因无法承受股价**下跌**卖出、是否受**买入成本价**影响而卖出
- 核心原则：买入价、浮盈、浮亏程度，与是否应该卖出**没有任何关联**

4. 是否**触发了新的买入标准**

- 少数优秀公司股价大幅上涨后，反而具备**更大的投资价值**，即**“好公司的股价可能越涨越便宜”**
- 当公司遇熊市或暂时性**“黑天鹅”事件**导致估值大幅下滑时，重新执行研究阶段和交易阶段的检查清单
- 核心原则：若触发新买入标准，切勿受最初买入价格**锚定效应**的影响

从以上的检查清单，我们可以看出，检查清单的主要任务是各种**排除和拒绝**：**拒绝买，除非不得不买**；**拒绝卖，直到不得不卖**。检查清单从来都不是大而全的操作手册，而是**理性选择后的思维方式**，帮助我们**程序化地识别并避免各种严重风险**。

史学泰斗吕思勉先生提出史学研究有四大任务：搜寻过往的事实；加以解释；用以理解当下；因以推测未来。

研究企业的任务与之类似：一是搜寻以往的**经营行为和经营绩效**；二是对过去的经营绩效**加以解释**；三是理解企业**当下的环境、优势和问题**；四是**预测企业未来的经营绩效**（判断其不变、更差或更佳，或分析企业未来哪些经营行为会导致绩效变化）。这四个环节中，**重点和难点**在于**解释公司过去为何优秀**，以及**预测未来三五年或更长时间公司的情况**。理解过去是预测未

## 长期持有

其实A股里很多的**白马股、长牛股**，多少年前就众人皆知。很多人也多多少少买过，但真正从这些标的上赚取大量**绝对回报**的人却很少。原因无非是：怕继续跌不敢下手买，看见已经涨了怕回调不敢买，涨了心慌天天想卖，涨了跌下来要卖，跌了涨回去也要卖，嫌涨得慢等不了要卖，躲回调做波段被洗出，遇到利空消息被吓出来……

这几条原因，归根结底可归结为两点：一是对公司价值**没有建立足够的信心**；二是对市场波动**没有形成正确的认识**。

### 长期持有一家公司股票的核心要点

1. **买入的时候，要有充分的安全边际**
   买入位置需建立在风险**完全释放甚至过度释放**的基础上，即便估值短期进一步下滑，也不会遭受**毁灭性的打击**；若判断正确，未来可获得可观盈利。

2. **忘掉买入价**
   买入完成后，买入价便失去参考意义，股价相对买入价的涨幅绝非卖出理由；部分标的涨一倍后，当下位置可能比最初买入点**更好的一个买入点**。

3. **不要有预期收益**
   完全不预判股票未来的上涨时间和涨幅，买入的逻辑需随着企业经营的推进逐步得到**印证**；只要经营和财报持续印证买入逻辑，便可**安坐下来**，继续观察后续发展。

4. **动态检视对企业价值的评估，非一劳永逸**
   企业的**市场环境、内部的经营管理**会持续变化，需**不断衡量**企业的**内在价值**，并对比**当前股价与企业当前内在价值的关系**，而非与买入价的关系。如**“三聚氰胺事件”**后，牛奶行业格局和企业发展态势、命运均发生了重大变化。

5. **没有确定性的东西，不必提前忧虑和事后后悔**
   持股期间可能遭遇黑天鹅事件、无理由的市场大幅波动，这类情况通常**没有可能**提前预测；既然无法预测，便要**坦然接受**，将其视为投资的一部分；核心是**分清这是市场波动还是公司出了问题**，并判断公司问题是否带来**实质性的影响**。

6. **正确面对长期盘整甚至回撤**
   不愿参与盘整、因预判/已发生回撤而卖出，都**不是明智的选择**；盘整和回撤往往是股价上涨**不可或缺的组成部分**，优秀公司股价的**主要升幅都在较短时间内完成**；要百分百抓住主升浪，最靠谱的办法是**全程在场等待**，虽看似笨拙但足够有效。如持有伊利期间曾遇两次股价近腰斩的回撤，并未影响长期收益。

长期持有一家公司的股票其实一点儿都不波澜壮阔，一点儿也不心惊肉跳。它只是**持续地做正确的决策**之后，一个**慢慢呈现的、自然的结果**。
