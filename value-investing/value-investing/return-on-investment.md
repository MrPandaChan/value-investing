# 投资回报率

## 回报率

傲雪：

巴菲特的浮存金杠杆：
巴菲特有 1700 多亿的浮存金。
这些资金的成本几乎是 0，甚至是负的（保险本身还能赚不少钱）。
这是巴菲特用全资的保险子公司搭建的特殊结构，普通人参照不了。

实际上，发现巴菲特基本在有 8%收益率的时候，就开始行动了。
机会好的时候能买到 10%左右的收益率，再高的其实貌似就极少了。

所以重新理解把成本 3%的资金持续投入到收益率有 13%回报率的资产上。
本质上，还是老巴有浮存金作为杠杆资金才能达到的的结果。
有一个研究团队分析了伯克希尔 1976-2017 的年数据，计算出巴菲特使用的平均杠杆大约是 1.6-1.7：1。
也就是 65%左右的杠杆。
100 亿投资款，回报率 8%，回报金额 8 亿；
加上 65 亿浮存金杠杆，回报率也是 8%，汇报金额 5.2 亿；
8 亿+5.2 亿=13.2 亿；
相对于 100 亿的自有本金投资款，在 8%的回报率下，确实会有 13.2%的回报率，在 13%以上了。
何况浮存金也在越滚越大。

我们对标的目标，非折现情况下的 10%投资收益率，也就是通俗意义上的“十年回本”。
在折现率设为 4%之后，基本上的情况下，都对应 8.3%左右的复利收益率。

其实这个要求已经比较高了。8%的收益率，差不多也就在击球区边缘的位置。
要重新考虑下特价区的设置，可能对于不能上杠杆的我们来说，这个要求有点太高了。

## 机会成本

**对机会成本的衡量，要考虑“未来的机会成本”​，保留一定的前瞻性，而不是仅仅考虑眼前的机会成本**。巴菲特在 2003 年股东会上说：​“我们有 160 亿美元资产税前收益率只有 1.25%，每年利息为 2 亿美元。我们很容易就能买到 20 年到期的政府债券，并获得大约 5%的收益，我们可以获得每年 8 亿美元的收入。我们现在决定持有 2 亿美元收益的流动性资产，是因为相信不久的将来能找到 10%或回报更高的资产。如果我们选择投资 8 亿美元收益的债券，一年后要是出现大机会，我们损失就大了。​”巴菲特猜测他在未来适当时候会有机会以有吸引力的回报率投放资金，因此他不会浪费太多的“火力”现在就去购买较低回报、流动性差的资产，但这依然是基于机会成本的计算，因为这种暂时保留“火力”的做法大概率地在整体上最小化了机会成本。

## 估值的逻辑

[估值的逻辑（2026.01.26 微疯侠与暴食君）](https://mp.weixin.qq.com/s/48KjJHCgZRWiDg7x5cY1sg)

**金钱是有时间价值的（Time value）——今天的一块钱，一年以后的一块钱，十年以后的一块钱，价值是不同的。这也许是金融学里最重要的一个概念。**

因为金钱是有时间价值的，当我们在比较两串涉及多期现金流（cash flow stream）的大小的时候，一个理想的方法是用一个相同的利率计算这些现金流的**现值（present value）**，这个过程就叫**折现（discounted cash flow, DCF）**，这个利率就叫**折现率（discount rate）**。

在数量上，折现率的取值具有一定的主观性。也就是说，取5%，8%，10%，15%，都可以。

**在概念上，折现率和报酬率（rate of return）是一个硬币的两面。** 折现率是一个“时间机器”的费率。它回答的是：“为了在未来拿到这1块钱，考虑到风险和等待的时间，它现在值多少钱？” 它是用来缩减未来价值的。报酬率是一个“增值”的速率。它回答的是：“我投进去1块钱，将来能变成多少钱？” 它是用来扩张现在价值的。

OK，理清了这些概念，我们可以来“玩弄”这些现金流了。

假设有这样一组现金流，它在T0的时候是1，T1到T10这十年间，每年增长5%。T11~永远，每年增长2%。如果折现率是8%，那么这串现金流的现值是**21.17**。**基于我们上面陈述的各种概念，这个现值的另外一重含义是，如果我在T0付出21.17，并在未来获得了这样的一串现金流，那么我这笔投资的年化报酬率是8%。**

**理所当然，在折现率（报酬率）不变的情况下，一串增长更快的现金流具有更高的现值**——假设在T0的时候是1，T1到T10这十年间，每年增长10%。T11~永远，每年增长2%。如果折现率是8%，那么这串现金流的现值是**31.1**。

**那么，可不可以，在现金流不变的情况下，提升报酬率呢？答案是可以的。**假设在T0的时候是1，T1到T10这十年间，每年增长5%。T11~永远，每年增长2%。如果折现率是15%，那么这串现金流的现值是**9.37**。**也就是说，哪怕现金流不变，付出的更少（买的更便宜），也能明显提升报酬率。**

到这里，这个简易的模型，能玩的两种方式，已经都展示过了——**改变折现率（报酬率），改变现金流**。那我们不妨把不同现金流和折现率组合计算出来的现值，以表格的形式陈列出来。

接下来，是一些自问自答时间（Q&A）。

**Q：现金流为什么要设计两段，头十年和之后的永续阶段？**

**A：为了让折现后的现金流收敛以得到一个有限的现值**，而不是远期的折现后的现金流一直增长下去，从而使现值趋向于无穷大，**现金流的增长率必须小于折现率**。因此，在数学上，现金流需要至少分成两段，并确保后面的那段的增长率小于折现率。在现实中，一个公司永远保持一个5%甚至更高的增长率是不现实的，因为那样它终将超过宇宙的承载。毕竟几百年的公司是罕见的。那些曾经不可一世的公司都曾因为这样那样的原因在历史中轰然倒塌。那在保证最后一段的增长率低于折现率的情况下，前面的现金流可不可以设计成多段呢？当然可以。只不过，我们在这里追求的是，极致的简化。设计成多段，有违这个偷懒的初衷。

**Q：现金流为什么要选这七种？**

**A：（25%，2%）（头十年CAGR，之后的永续阶段CAGR，下同）和（15%，2%）算是我心中的高增长组。** 今天现金流是1，十年后，前者的现金流会变成9.3，后者的现金流会变成4.1。类似的案例，比如，腾讯2015年的利润247亿，2025年的利润约2255亿，（1变9.1）。

**（10%，2%）和（5%，2%）算是我心中的稳健增长组。** 今天现金流是1，十年后，前者变成2.6，后者变成1.6。类似的案例比如，比如，招行2015年的利润571亿，2025年的利润约1500亿，（1变2.6）。

**（2%，2%）和（0%，0%）算是我心中的稳定组。** 今天现金流是1，十年后，前者变成1.2，后者变成1。类似的案例比如，比如，中石油2013年的利润1296亿，2025年的利润约1608亿，（1变1.2）。

**（-5%，-2%）算是我心中的衰退组。** 今天现金流是1，十年后，变成0.6。比如保利发展2014年的利润122亿，2024年利润50亿。

**特别说明，过去的高增长往往意味着未来的增长空间缩小。** 腾讯过去十年利润1变9，未来十年肯定没有办法1变9了。未来十年，腾讯大概率是稳健增长组的一员。同样，过去十年是稳健增长组的，未来十年大概率是稳定组。

**Q：如何看待这种极其简化的现金流和现实中变化很大，高度不确定的现金流？**

**A：稳如腾讯，哪怕真的实现了1变9，过程中也不是每年都稳稳地增长25%，而是有增长50%的年份，也有连续负增长的年份，** 期间股价也出现了巨震，相信大家对2021-2022年还记忆犹新。腾讯尚且如此，那些利润腰斩，脚踝斩，甚至亏损的行业和企业就更不消说了。**投资最难的，永远是判断企业的现金流趋势。** 虽然这个极难判断，但我们毕竟要估值，要出价，极其简化的现金流是起点，也只是起点。

**Q：折现率（报酬率）为什么要选这四种？**

**A：长期来讲，2%是通胀率，+1%到3%是长期国债利率，+5%股权风险溢价到8%，是比较合适的风险资产的长期回报率。15%~20%是我心中能够接近的优秀的回报率。5%是我觉得过低的回报率。**

**相应的，一个资产的价格持续下跌，以使得它当前价格结合未来现金流所对应的隐含报酬率升至15~20%时，对于我来讲，值得建仓，加仓。**

**一个资产的价格持续上涨，以使得它当前价格结合未来现金流所对应的隐含报酬率降至8~5%时，对于我来讲，值得减仓，清仓。**

**Q：同一个市场中，不同增长前景的资产，它的估值中枢和波动范围为何差异如此巨大？**

**A：估值中枢为什么会有巨大差异**：假设市场是有效的（真实的情况，市场是半有效的，但我们分析一个问题，总要先从一个简单的起点出发，不是吗？），那么**所有股票价格隐含的报酬率应该是一样的，至少是相近的**，否则报酬率高的股票股价应该上涨，报酬率低的股票股价应该下跌，直到两者接近，资金的流动才会停止。**报酬率相同，但增长前景不同，就会导致现值相对当前现金流的倍数，有巨大差异。**

**估值波动范围为什么也会有巨大差异**：**成长股，久期长，利率敏感。** 当折现率/报酬率变化比较大的时候，它的现值也就是估值就会波动很大。**价值股，久期短，相对利率不敏感。** 哪怕折现率/报酬率变化比较大，它的现值也就是估值波动也相对较小。

## 分红回本函数

```js
function calculateYearsToBreakEven(initialDividendYield, growthRate) {
  // 将百分比转换为小数
  const r = initialDividendYield / 100;
  const g = growthRate / 100;

  // 特殊情况处理
  if (r === 0) {
    return Infinity; // 无股息，永远无法回本
  }

  if (g === 0) {
    // 股息不增长的情况
    return 1 / r;
  }

  // 计算公式: 1.0 = r * ((1+g)^n - 1) / g
  // 推导得: (1+g)^n = 1 + g/r
  // 所以: n = log(1 + g/r) / log(1+g)

  return Math.log(1 + g / r) / Math.log(1 + g);
}

// 使用示例
calculateYearsToBreakEven(5, 5).toFixed(2);
```
