## 一、今日最重要的变化

### 1. 7月CPI、PPI均低于预期，内需与价格传导继续偏弱

- **涉及公司**：股票池全部银行；美的集团、海尔智家A/H、格力电器、比亚迪、贵州茅台、泸州老窖、山西汾酒、古井贡B、海天味业、双汇发展、华润万象。
- **事实**：7月CPI同比上涨0.5%、环比下降0.1%，核心CPI同比上涨0.9%；PPI同比上涨3.5%，低于市场预期的3.8%，较6月回落0.6个百分点，环比下降0.7%。食品价格同比下降1.5%。
- **可能影响**：中性偏负面。上游成本仍高，但终端需求和提价能力不足，制造及消费企业毛利率可能承受挤压。银行面临贷款需求、贷款收益率偏弱；低通胀同时保留政策宽松空间，可能降低负债成本并缓释信用风险。
- **继续验证**：7月社融与信贷、社零、工业增加值，以及各公司实际出厂价和促销强度。宏观价格指数不能替代公司收入数据。

### 2. 行业价格呈现“煤炭强、金属环比转弱、下游继续降价”的分化

- **涉及公司**：中国神华A/H、中煤能源A/H、陕西煤业、兖矿能源A/H；紫金矿业A/H、洛阳钼业A/H、神火股份、云铝股份；比亚迪及白酒、医药公司。
- **事实**：7月煤炭开采和洗选业PPI同比上涨27.1%；有色金属矿采选、冶炼价格分别同比上涨22.6%和20.2%，但环比分别下降2.1%和1.7%。汽车、医药、酒饮料和精制茶等行业价格同比下降2.3%～5.7%。
- **可能影响**：
  - 煤企当期售价和现金流仍有支撑，但PPI同比包含基数效应，不能直接外推长协煤价。
  - 紫金、洛钼等矿企仍处于较高价格环境，但环比转弱提示铜价高位与实际结算价可能分化。
  - 汽车、白酒和医药行业降价反映终端竞争和渠道压力，对收入、毛利率和库存周转偏负面。
- **继续验证**：煤炭长协价和港口库存、铜铝现货升水及矿山结算价、车企促销、白酒批价和药品实际中标价。

### 3. 红海能源设施和港口遇袭，布伦特重新升至84.79美元

- **涉及公司**：中国海洋石油A/H、中远海控A/H、中谷物流；二阶涉及股票池港口及出口制造企业。
- **事实**：胡塞武装称以无人机袭击沙特Jazan炼厂；该炼厂处理能力约40万桶/日。沙特方面表示火灾已扑灭、无人受伤，尚未确认持续停产。同日，靠近曼德海峡的也门Mocha港遭导弹和无人机袭击，港口基础设施严重受损。今晨布伦特上涨1.44%至84.79美元/桶，霍尔木兹新航道协议仍未最终落地。
- **可能影响**：中国海油短期偏正面，航运成本端偏负面。油价反弹改善中海油实现油价和自由现金流预期；红海风险升高则可能增加战争险、绕航及燃油成本。集运企业只有在运价附加费超过新增成本时才会受益。
- **继续验证**：Jazan实际开工率、Mocha港关闭时间、曼德海峡船流、战争险报价、霍尔木兹正式协议及中海油季度实现油价。

### 4. “白海豚”登陆浙江，港口影响由预防性停运转为实际物流延误

- **涉及公司**：宁波港、上港集团、中远海控A/H、中谷物流；二阶涉及出口制造企业。
- **事实**：台风“白海豚”8月9日17:30左右在浙江玉环附近登陆，中心最大持续风速42米/秒，为2026年迄今登陆中国最强台风；超过100万人转移，上海约1,500架次航班取消。强降雨预计持续至8月10日，洋山港此前已清空泊位并组织500余艘船舶避风。
- **可能影响**：短期负面、当期利润影响有限。靠泊、堆场、集疏运和船期可能延误，增加等待及重排成本；如未出现设备损毁或长时间封港，主要是季度内吞吐时点平移，而非需求永久消失。
- **继续验证**：宁波舟山港和洋山港复航时间、泊位及堆场损毁、船舶等待时间和后续吞吐补回速度。

## 三、行业雷达

- **CPI、PPI低于预期** → 企业提价和居民需求偏弱 → 消费制造利润率、银行信贷需求及资产端收益率承压。  
  涉及：股票池银行、家电、汽车、白酒食品及商业消费公司。

- **煤炭PPI同比大涨、有色价格同比高位但环比下降** → 煤企当期利润支撑强于金属价格动量 → 周期企业现金流改善程度出现分化。  
  涉及：中国神华A/H、中煤能源A/H、陕西煤业、兖矿能源A/H；紫金矿业A/H、洛阳钼业A/H、神火股份、云铝股份。

- **水电发电增加、行业价格环比下降10.3%** → 发电量增加但市场化电价可能走低 → 水电企业收入取决于量价净效应。  
  涉及：长江电力、国投电力。行业PPI不能替代公司实际上网电量及结算电价。

- **红海港口和能源设施遇袭** → 油价、战争险及绕航成本上升 → 中海油现金流获得支撑，集运及出口企业成本增加。  
  涉及：中国海洋石油A/H、中远海控A/H、中谷物流及股票池港口、出口制造企业。

- **强台风登陆华东** → 港口暂时停运及陆侧集疏运受阻 → 港航吞吐延后、船期可靠性下降。  
  涉及：宁波港、上港集团、中远海控A/H、中谷物流。尚无证据表明形成长期产能损失。

## 五、结论

需要升级或更新研究：

- **国内价格传导矩阵**：把PPI拆分为上游售价、下游出厂价和终端CPI，识别煤炭、有色、汽车、白酒、医药、家电中“收入增长但毛利率被挤压”的公司。
- **中国海油及全球航运风险**：红海袭击与霍尔木兹协议反复并存，需要同步跟踪实物出口、船流、油价曲线和战争险，避免仅按新闻标题调整现金流预测。
- **腾讯、中国移动业绩预检**：两家公司本周披露业绩，分别建立“AI投入-利润-自由现金流-回购”和“资本开支-现金流-分红覆盖”的验证表。
- **华东港航暂不升级专题**：先等待港口复航和设施检查；只有停运显著延长或出现设备损毁，才需要调整季度吞吐量预测。
