# OODA循环，对信息进行及时的分析与调整

## 原文

《柏基投资之道：近20年跑赢巴菲特的投资哲学》

OODA循环的核心是基于信息的及时分析和调整。投资与战场有许多类似之处，两者都面对大量信息以及迅速变化的环境。信息传播、环境变化让资本市场处于随时变化的状态。重要的是，柏基倾向于投资技术变革行业，该行业的特点就是瞬息万变。即便是柏基这样的长期主义投资者，也很难提前判断未来一定会发生什么。柏基需要接收信息，随时进行迭代优化并决策，OODA循环是适用于投资分析的思考工具。在投资应用中，OODA循环体现为以下步骤。

• 观察：OODA循环第一阶段涉及观察，需要了解各方面信息，评估公司基本面，并监控市场趋势。柏基投资还拥有自己的科学家和企业家等具有优势的信息渠道。通过“观察”阶段，投资者可以收集关于公司所在行业的发展前景、技术突破进展等各方面信息。

• 调整：调整阶段可以筛选出对判断最重要的信息并进行分析，充分研究公司、行业和市场，具体涉及竞争格局分析、行业趋势确定，以及投资标的潜在的内在价值评估等方面。

• 决策：决策阶段，投资者利用分析做出投资决策，建立高质量公司的投资组合。这需要纪律和信念，因为短期市场波动可能会考验投资者的决心。

• 行动：投资者根据决策，执行买卖交易，完成自己的工作。

步骤完成一遍后，旧循环结束，新循环开始，往复循环，不断加深对企业和行业的认知，追踪行业趋势，并纠正上个循环中的错误。循环嵌套在团队决策中也可以发挥作用，投资决策需要不同分析师的OODA循环不断更新，帮助团队在大的OODA循环中进行决策分析。

OODA循环为应对金融市场的复杂性提供了结构化思考框架，通过在投资决策过程中观察、调整、决策和行动的循环迭代，柏基可以持续提升对未来趋势的预判能力，做出客观决策，最终实现投资目标。

OODA循环对于柏基判断潜在被投企业也有很大的指导作用。挑选投资标的时，柏基也希望找到那些具有全方位视野，能够及时做出应对的企业。因为在一个技术呈指数级进步的世界里，企业必须不断适应变化和创新。硅谷的高科技企业已经普遍将OODA循环作为企业战略决策和产品研发迭代中核心的方法论。

## SKILL 名称

**OODA 循环：动态投资决策与适应性分析框架**

## SKILL 描述

OODA 循环（Observe-Orient-Decide-Act）源于军事战略家约翰·博伊德提出的空战决策模型，后被硅谷科技企业和 Baillie Gifford 等长期投资机构引入投资决策流程。该框架强调在高度不确定和快速变化的环境中，通过持续的“观察-调整-决策-行动”循环迭代，不断修正认知、优化策略，从而比对手更快、更准确地适应现实。本 SKILL 将 OODA 循环适配于投资分析与企业评估两大场景。

## 核心哲学

- **速度与适应性**：在信息过载与技术变革环境中，比竞争对手更快的 OODA 循环速度是核心优势。
- **认知迭代**：投资不是一次性的预测，而是持续修正假设的过程。
- **嵌套循环**：个体分析师的微循环驱动团队大循环，企业自身的 OODA 能力也是选股关键标准。

## 第一部分：投资决策中的 OODA 循环（内部使用）

### 阶段一：观察（Observe）

**目标**：收集原始信息，不做过滤与评判，建立信息全景图。

**信息维度建议**：

- **基本面数据**：财报、业务分拆、用户数据、研发管线进展。
- **市场信号**：股价与成交量异常、估值分位、机构持仓变化、空头头寸。
- **行业动态**：技术突破新闻、监管政策草案、上下游供应链变化。
- **替代数据**：招聘岗位数量与类型、用户论坛情绪、专利引用图谱。
- **独特信息源**：学术专家网络、行业科学家、离职员工访谈（合规前提下）。

**输出形式**：信息简报（Bullet Points），仅记录事实，禁止加入任何解读。

### 阶段二：调整（Orient）

**目标**：筛选、分析、赋予信息以意义，更新或摧毁原有假设。

**分析动作**：

1. **信息权重分配**：哪些观察到的变化属于“信号”，哪些属于“噪音”？
2. **竞争格局重绘**：新进入者/替代品威胁是否发生了质变？
3. **隐含假设检验**：投资备忘录中哪些前提条件已被动摇？
4. **情景权重调整**：重新评估乐观/中性/悲观情景的发生概率。

**核心提问**：

- “这个新信息让我最惊讶的一点是什么？它挑战了我过去的哪个认知？”
- “如果我相信这个新趋势，那么估值模型里哪个参数必须修正？”

**输出形式**：一份“认知更新备忘录”，对比当前判断与上一个循环周期的判断差异。

### 阶段三：决策（Decision）

**目标**：基于调整后的认知，形成具体、可执行的投资指令假设。

**决策选项库（非穷举）**：

- **增持**：逻辑强化且市场尚未充分定价。
- **减持/清仓**：核心逻辑破坏或估值透支未来5年以上增长。
- **持有观望**：逻辑未变但短期噪音过大，设定下一次检查的触发条件（如股价下跌X%或下季度财报）。
- **做空对冲**（如适用）：识别出显著高估的泡沫成分。

**决策原则**：

- 必须明确写出**触发行动的价格或时间条件**，避免模糊的“再看看”。
- 决策需包含**纠错机制**：如果什么情况发生，证明这个决策是错的？

**输出形式**：决策卡片，包含“指令 + 仓位区间 + 逻辑摘要 + 纠错触发条件”。

### 阶段四：行动（Act）

**目标**：执行交易或保持跟踪，并立即开启下一个 OODA 循环。

**行动要点**：

- 执行层面考虑流动性、交易成本、合规限制。
- 行动完成后，立即回到“观察”阶段，收集市场对本次决策（如大宗交易）的反应。
- **切记**：不行动也是一种行动，同样需要进入下一循环的观察。

## 第二部分：企业评估中的 OODA 循环（选股标准）

在评估潜在投资标的时，需考察企业自身是否具备高效的 OODA 能力。拥有高速 OODA 循环的企业在指数级技术变革中生存概率更高。

### 评估企业 OODA 能力的访谈/尽调清单

| 阶段     | 针对企业的评估问题                                    | 正面迹象示例                                                          |
| :------- | :---------------------------------------------------- | :-------------------------------------------------------------------- |
| **观察** | 公司如何感知外部环境变化？是否有独特的信号获取渠道？  | 拥有独立研究院、用户行为数据中台、创始人定期与一线员工/客户交流机制。 |
| **调整** | 收到负面反馈后，管理层修正战略的速度有多快？          | 季度战略会能调整年度预算；某产品线数据不佳后半年内关停或转向。        |
| **决策** | 决策权是否下放至听得见炮火的一线？决策链条有多长？    | 事业部具备独立预算权；审批流程不超过2级；推崇“Two-Pizza Team”。       |
| **行动** | 从立项到MVP（最小可行产品）或到市场反应的时间有多短？ | 软件企业周迭代；硬件企业原型机周期短于行业平均；营销活动能借势热点。  |

**输出结论**：将企业归类为“高速 OODA 适应者”、“机械线性执行者”或“官僚迟缓者”。

## 第三部分：OODA 循环与长期主义的兼容性

- **长期主义 ≠ 长期不动**：长期主义锁定的是“终局愿景”，OODA 循环调整的是“路径假设”。
- **避免过度交易**：OODA 的调整频率取决于信号的**信噪比**。对于长逻辑标的，调整阶段的结论往往是“无需改变决策”，而非频繁进出。
- **对抗熵增**：OODA 是投资组合保持“反脆弱”的工具，防止认知僵化。

## 第四部分：AI 使用提示与输出模板

### 调用指令

```
请以 OODA 循环框架分析 [公司名称/行业/投资观点]。
1. 观察阶段：列出3-5条近期关键事实信息。
2. 调整阶段：指出这些信息对原有投资假设的冲击程度（无影响/修正参数/动摇根基）。
3. 决策阶段：给出一个附带触发条件的下一步建议。
4. 行动阶段：建议的具体操作及下一轮观察的重点指标。
```

### AI 输出模板示例

```
【OODA 循环分析报告：XXX公司】

**🔄 循环周期标识**：2026年Q2 财报季后

**👀 观察（Observe）**
1. 最新季报收入同比+25%，但经营现金流同比下降10%，应收账款周转天数升至历史高位。
2. 行业头部客户A宣布自研竞品，预计2年后内部替换。
3. 公司官网招聘Java工程师数量骤减，AI算法岗招聘量翻倍。

**🧭 调整（Orient）**
- **冲击评估**：中等冲击（修正盈利预测参数）。
- **认知修正**：此前假设“客户转移成本极高”，但头部客户自研行为暗示该护城河可能在AI重构技术栈下被削弱。
- **情景权重**：悲观情景概率从20%上调至30%。

**⚖️ 决策（Decide）**
- **指令**：持有，但仓位上限下调至5%。
- **纠错触发条件**：若下一季度现金流未见改善，或第二个大客户出现自研信号，则无条件清仓。

**🏃 行动（Act）**
- **交易计划**：暂不操作。
- **下轮观察重点**：关注下月技术峰会是否有针对客户A自研的应对产品发布；跟踪AI岗位入职员工的上一家雇主背景。
```

## 附注：OODA 循环的历史渊源

- **军事起源**：朝鲜战争空战中，美军飞行员约翰·博伊德发现，驾驶性能稍逊的 F-86 能击败性能更强的米格-15，核心原因在于 F-86 座舱视野更好、液压操控反应更快——本质上是 **OODA 循环更快**。
- **商业迁移**：被 Jeff Bezos、Reed Hastings 等企业家引入战略管理，成为亚马逊“高速决策”、奈飞“情景规划”的底层思维模型。
- **投资适配**：Baillie Gifford 将其用于平衡“长期持有”与“动态纠偏”，确保不对“沉没成本”产生情感依恋。
