# 价投高手Flushz——谈怎样做到成功的价值投资

[价投高手Flushz——谈怎样做到成功的价值投资（2026.11.09 职投者茶馆）](https://mp.weixin.qq.com/s/AtPW1S6JaMLb2BE6EaAtJA?scene=1&click_id=1857867153)

**资水注**：今天邀请一位草根出身的价投高手来分享。之所以强调“草根出身”，是区别于“科班出身”。科班出身主要指公募和大私募的基金经理，他们有信息优势，即可以拿到深度报告、可以赴企业进行调研，这些优势是散户所不具备的。草根出身的价投者，就是要在信息不充分的背景下做投资决策，他们的方法论对我们散户更有参考价值。

价值投资是非常困难的投资方法，我认为是“地狱级”难度，我本人就没有掌握，国内的投资者中我也没看到多少人真正掌握。我眼中的草根出身的价投高手有三位，吾知讲乜、安全饕、Flushz。吾知讲乜和安全饕都是通过价投从十几万做到上亿的顶尖高手，证实了在A股做价值投资虽然难，但确实是一条可以走通的通天大道。

今天邀请的嘉宾Flushz，他是集思录论坛公认的价投高手，在我的书《不亏》中（P34页）曾经整节引用了他的行业周期的帖子，论述非常精彩。我和他在一个小群中，大概知道他的投资是瞄准十倍股（tenbagger）的，是一位“买股票就是买公司”的实践者。群友们抄他作业买的股票，很多赚了2倍3倍的，让我羡慕。他去年选择离开职场，成为一名职业投资人。我请他来谈一谈，怎么做到成功的价值投资。

读者掏钱来看付费文章，有问题可以在评论中提出，我们尽量回答。考虑到回答的工作量，每人限提一个问题，我们每期最多回答15个问题。考虑到合规风险和他本人意愿，请勿提问关于个股、当前行情方面的问题。

以下是正文。

---

**我重仓做过的股票**

我是以个股价值为锚来做投资的，2013年-2025年之间的年化复合收益率是32.5%，除2018年外均保持正收益，不过今年的成绩不好，目前还是浮亏的。

我重仓做过的股票，有长安汽车、永辉超市、紫金矿业、保利地产、中国神华、长江电力、藏格矿业等。长安是300亿左右买的，拿到了850亿；永辉也是300亿左右买的，拿到了将近1000亿；紫金是2019年末，我买了后公司增发，我觉得是利好，但二级市场跌停了，我只好又买了2笔，均价3元，拿了一年多，接近7元卖掉的。后面4个保利、神华、长电、藏格，那几年在集思录都有写过，保利大概是50%的盈利，但仓位很重，还加了杠杆，长电也差不多。神华拿的时间很长，从新冠疫情一直拿到24-25年，25年才彻底卖完，这笔投资收益率很高，3倍以上的收益还是有的。我拿的时间最长的公司是太阳纸业，拿了快10年了，现在是行业景气度低点，这笔收益率一般，10年3倍。藏格目前也在持有当中，2024年中买的，应该还会拿几年吧。

我持股的标准，是根据公司过往的经营情况、当下的财务状况、未来的经营计划等因素，来判断未来公司的盈利能力，进而判断当前的估值是否低估。基本上就是DCF那一套，但我觉得个人投资没必要那么教条，因为估值本身就不是绝对准确的。

**A股非常适合价投**

我一直觉得A股非常适合价值投资，因为价投虽然名气很大，但实际上非常小众，竞争相对小一些，这从公私募基金的新注册类型上就能看出来。我有时候和一些券商或者私募的朋友聊天，能深切的感受到在拥挤的赛道里，赚钱太难了。这两年看上去如日中天的量化基金，其实内卷的非常厉害，市场里就那么一点超额流动性，大家都想来吃，算法的核心竞争力很难维持多久，就被迭代超越了。而且一旦市场冷下来，靠流动性吃饭的模式就很难维系。价值投资因为是主观风格，机器甚至人工智能抢不到这口饭，相对来说可以活的安逸一些，但是对人的要求自然就不低，需要持续的学习和成长。

（资水注：A股适不适合价投？这个问题是我请Flushz专门进行阐述的，因为A股波动巨大，我认为投资者是难以承受这个巨幅波动的。但是反过来想，如果在A股市场买在底部，那就是胜率极高的策略。而价投正好是买在底部的好方法。

另外，我的策略中博弈和量化占了很大一部分，这两年很多策略失效，自己资金量大了以后博弈和量化也有转不动的感觉了。确实如flushz所言，市场在迭代和进化，很多策略失效，而价投是唯一长期有效、不受AI影响、又匹配大资金的策略。就是说，对于资金量大的投资者，必须掌握价投技能。）

**价值投资要从董事长或收购方的视角**

价值投资的门槛看上去很低，其实很难。价值投资的核心思想的确是价格低于价值买入，等于或者高于价值卖出，但看上去浅显易懂的一句话，执行起来却比什么都难。因为价格大家都看得到，而股权背后的价值，如何定价？这才是考验一个投资者非常核心的一个能力。换一种表达方式，一个工厂、一块地皮、一个特许经营权、一座矿山、一套供应链、一个或数个专利，让普通人去给他们定价，是不是很难？

**如果你想做一个价值投资者，那你就要把自己放在公司董事长的位置，或者是收购公司的买方的角度，来对待这个公司。**这家公司值不值得买？我出多少钱买？（资水注：我第一眼看到flushz的重仓股，敏锐地发现他的表述是“长安从300亿拿到850亿“，而一般投资者的表述是“长安从3元拿到7元”，单位的不同正好表明flushz看待一个公司是从收购者的视角。）

经常有人念叨的PE和PB，可以作为参考，但权重不高。过去的经营数据和财报数据，不能线性推导到未来，也与未来的投资回报没有必然的关系。公司的商业模式、竞争地位、国家甚至国际政策法规、科技发展趋势等等，很多因素都远比PE/PB重要的多。

**价投的进阶**

**一、从财报起步。**价投者读财报是必读的，这是公开市场去了解一个公司最可靠也是最详实的一份资料，没有之一，财报造假是违反刑法的。我应该是2009-2011年前后吧，买到了19.92的中国平安，然后我就开始研究保险公司，研究保险公司的钱都是哪来的，获取这些本金的成本是什么，研究这些钱怎么产生利润，投入债券的部分是怎么运作，如何计算盈利或者亏损，投资权益市场的部分靠什么稳定盈利，何时计入盈利，亏损如何界定浮亏或实亏，投入股权市场和不动产市场的部分又怎么计算盈亏，等等。

财报一年要读多少篇？数量因人而异吧，我一年读几百份是有的，按公司算，一年读100家公司吧，持仓的、关注的、以及新拓展的，都读。

**二、搞明白商业模式。**当你终于搞明白一个公司或者一个行业是如何经营的时候，大概就算是入门了。需要做的就是搞明白公司的上下游，因为只有理解了上下游的变化，你才能对公司当前及未来的景气度有自己的判断。比如一个保险公司，上游就是保户，保户投保的意愿和金额，也是变化的，获取成本也是不同的。下游就是投资端，债券收益、权益市场收益和其他投资收益，就是保险公司的下游，这些收益的波动，也是有迹可循的。综合上下游的变化，才能对公司的经营成功有一个方向性的判断。

对企业的研究要达到什么程度？我认为，要对公司未来一年的经营情况有一定的展望，对未来1季度的财报核心数据有个定性的判断、不精确的核算，这是保底要求。至于进阶的要求，那就是按董事长和收购方的标准，方方面面都要掌握了。

**三、实地考察。**这是我学习的经验。大概2013年前后，我在研究整车行业，期间在300亿市值前后，买了徐留平总掌舵的长安汽车。当时我对于整车行业还仅仅是个初学者，我冒充本地4S店的员工，潜入了一个微博汽车大V的Q群，在里面学习整车制造和销售的知识或者一些行业内部的常识。然后去理解和寻找长安自主车亏损的原因，计算合资车的单车利润和分成，根据公司的销售数据，以及公司未来1年的新车推广计划，尝试计算未来财报季甚至完整财年的经营数据。

当然，我只是举一个当年的例子，学习的方法和渠道各式各样不一而足。我还听过，有去和某某行业和公司的销售人员交朋友，到公司当地去蹲点，或者自己去做某产品的代理商，反正是通过各式各样的渠道去了解和学习一个行业或公司。价值投资学习的过程，其实是一个脚踏实地循序渐进的过程，而不是在互联网上看看帖子吹吹牛这么简单。

**四、理解市场逻辑。**价投者并不是只研究企业基本面，也要去理解市场定价的逻辑。除了极少数只具有纯粹博弈价值的公司，二级市场对其他每一个公司的定价，从某种角度来说，都是准确的。这个定价，是市场结合公司现有情况，以及未来预期，给出的阶段性定价。但这个定价会根据宏观、行业、公司的变化，不断的在做修订甚至重估（当然，有上修也有下修）。长远来看，市场的定价是不会错的，泡沫破灭的时间还可以说不确定，但一定不会出现长期低估的情况。如果你买入的公司，长时间（我自己给定的时间是1年）没有价值回归，那出错的一定是自己，而不是市场。不管是宏观的还是微观的甚至是台面之下的阴暗面，一定有你判断失误的地方。

理解市场的逻辑，判断其对公司未来的影响，有助于构建和寻找更优的买入/卖出时点，也有助于在市场短期的情绪波动中做好自己的情绪管理和投资决策。更重要的是，及时发现自己逻辑或者决策中的问题或者失误，可以很大程度的减少损失。和朋友聊天的时候，我经常自嘲，我买入并长持的股票并不一定是大牛股，但我买入之后未达预期而卖出的股票，短期甚至中期，一定会跌不少。

**五、先理解本行，再拓展到其他行业。**我是不建议年轻人走价值投资这条路的。因为刚从象牙塔里走出来的年轻人，对这个社会的了解和理解是单纯的。人生对商业最初的理解，其实是在工作当中发生的，至少我是这样的。当你在工作中，积累了足够多对各行业的了解和理解，这份财富非常宝贵，远不是书本或者互联网可以给到的。

如果你能在职场中走到足够高的位置，你会发现你不但可以对本行业或者相关行业比较熟悉，甚至在学习一个陌生的行业，也可以在较短的时间上手，因为商业的本质是相通的。如果你弄明白了一个钢铁厂的商业模式，那么恭喜你，诸如玻璃、造纸、水泥等行业，你也可以在非常短的时间内上手。你如果弄明白茅台的商业模式，那么恭喜你，诸如伊利、东鹏、农夫山泉甚至泡泡玛特，理解起来也不是那么难了。

**六、根据景气周期，自上而下选股。**周期是价值投资绕不开的话题，因为行业周期会导致公司的基本面剧烈变化。但这个话题太宏大了，不是几段话就可以说清楚的，今天就不展开详细说了。我自己的风格是自上而下来寻找投资的标的，根据宏观的展望来做基本的判断，即大方向上哪些行业景气，哪些行业低迷。然后从景气度较差的行业里去找中短期可能向上走的行业。找到合适的行业，再去分析行业中的龙头公司或者有核心竞争力的公司，如果行业预期、公司质地、市场估值都能接受，我就会开始买。景气度的起点和终点很难判断，即便自己有一些想法，我也不会据此作为核心投资依据，相对于行业何时复苏，我更关心的是如何买到更低的成本，我是典型的左侧选手。

我举一个相对简单的行业，煤炭。最近的一次投资，我是疫情刚开始的时候买的。背景是动力煤期货已经在疫情之前，已经跌到FGW指导价格500-650的底部区间，这个指导价格区间，已经平稳运行了4年多。当时东北、河南和其他地区有很多老的井工矿已经大幅亏损了。疫情的到来，加速了市场煤价的下跌，迅速跌破500，表达了市场足够的悲观。2019年年报神华的EPS是2.174，而在2020年初，市场的出价是15.56，市值3100亿，PE7倍多点。静态的分红是1.26元，股息率高达8%。即便是全年煤价在底部徘徊，考虑到神华的长协煤比例比较高，受到市场价格冲击会有一个缓冲垫，，公司2020年盈利也只会出现小幅度的倒退，综合考量了公司的现金流和负债情况，我认为现金分红的压力很小（实际当年的分红还增加到1.81元）。在行业极度低迷，大部分企业出现亏损的时候，持仓的公司仍可以保持不错的盈利，并有5%+的股息入账，在当时的市场环境下（考虑竞品和机会成本）我认为是一个可接受安全的价格。（市场里经常有人说周期股要在高PE买入，低PE卖出，我也不能说这句话不对，但我觉得时代在变化和进步，要具体问题具体分析，没有什么固定的模版可以套用。）

我国的煤炭产量和消费量均占到全球比例的5成以上，基本不用考虑太多国际因素的影响。而当时国内还有很多老的井工矿，尤其是东北和中东部地区，采掘成本较高，且逐年提升。市场煤炭价格的下行，加速了这些老矿的退出。以及当年环境保护和安全生产监管的日趋合理化、正规化、常态化，没记错的话，十九大的时候绿水青山就是金山银山还写入了党章，这些都大大提高了中西部地区很多中小煤矿的合规生产成本，同期也退出了很大一批表外产能。行业的供求关系从供大于求，到平衡，再到供应紧张，行业迎来了一个新的上升周期。二级市场自然也就对盈利能力强的资产进行了重估，期间发生了一些诸如极端天气保供、俄乌战争等干扰因素，在短时间内放大了供求关系的矛盾，给二级市场带来很大的波动，但行业自身供求关系的变化，才是周期演变的核心因素。

（资水注：周期和选股也是我请Flushz专门阐述的。周期其实也是价投的精华，我的书《不亏》曾引用Flushz的行业周期的帖子，他的价值投资显然是包含了行业周期的。周期的话题太大，这里谈不透，以后我会物色周期方面的高手，专门谈一下周期。

关于周期，我谈一个感想。就是Flushz的重仓股的持仓周期都是以年计的，而大部分人的持股周期都短得多，按统计数据，A股市场平均持股周期是120天，这个是包括机构在内的。那就是说，绝大部分像我这样尝试价投的普通投资者，都低估了价投的兑现周期，这或许就是我做不了价投的主要原因吧。）

**七、关于止损和止盈。**止盈是很简单的，在做一笔投资的时候，我基本上都是圈定了买入和卖出的逻辑，这里包含了价格的区间，有些也会有时间的条件，以及基本面的展望和逻辑，如果这些条件满足了，也该离场了，去寻找下一个有缘的公司。

止损的情况有两种，一种是自己对价值的判断或者说对安全边际的判断出现了重大偏差，我会止损，不过这个值我设定的有点大，50%，即如果市场价格跌到我买入成本的50%，那我才会认定自己出问题了，要么是我对价值的判断出现了问题，要么就是我对安全边际的判断出现重大误差，就应该无条件止损。历史上我还没有出现过价格止损的情况，最接近的一次是2021年投保利，当时的仓位很大，还有些杠杆，最多的时候浮亏应该有接近40%，而且跌的很快。底部的时候我认真思考了止损的问题，但还是坚持了纪律，结果当年保利在二级市场是一个深V反转的走势。

另一种止损的情况是买入的逻辑破了，这种情况有一些，最近的一次是今年的海尔智家，买海尔是考虑到国补退出之后，是一个多年经营或者业绩的低点，公司在出海的优势，以及分红率可能提高的空间等等。但买入之后实际的情况是内销并不是一个L型的趋势，而是逐季45°下行，虽然有气候的偶发因素。但异常的高油价推升海外的通胀，人民币大幅升值，这些都是对于白电出口不友好的环境。叠加油价、工业金属价格高企大幅推升了原材料成本，这些都是我在买入时无法完全预期的。逻辑破了，所以就清掉了仓位，无关乎成本和亏盈。

**结语：**价值投资很难，这是一个门槛在门内的行当。并且，门槛后还有无穷尽的台阶，每上一级都不容易。但我可以确定的说，做一个合格的价投，回报也非常丰厚，毕竟复利的威力非常匹配价值投资的风格。其实在我们这个资本市场，因为国家的强盛、因为市场流动性、因为参与者的结构、因为全社会的风险偏好，甚至市场制度等等，都是对价值投资是非常友好的。希望可以有朋友能从文中得到些许的共鸣或者启发，进而可以收获一些知识或者财富，那么也就不枉我写下这段文字了。

Q：难得的好文章，有一个问题想请教一下：作为普通散户，对于行业的分析，公司的商业模式其实都是很偏定性的。像商业模式其实相对好理解，但行业和周期，普通散户很容易成为大v的复读机，请资水老师能不能找一个具体的行业案例来详细分析，就像文章中的煤炭一样，或者有什么好的书籍推荐一下。还有就是文章中说的PE和PB问题，我能理解只看这两个不靠谱，但这个比起预测公司未来的增长率，行业天花板是不是要容易一些。尤其是投成长的公司，如果行业天花板和增长率过于离谱了，很容易大几十倍pe往里冲，然后被挂在山顶上？这个点Flushz老师如何解决的呢？

A：好问题，说的也是对的。行业天花板对于普通投资者来说，是一个相对容易理解的数据，也是对行业乃至公司增长空间比较直观的参考。一点建议，行业天花板大多是动态的，不是静态的。对于动态的行业，尤其是扩张中的行业，尤其要审慎。比如电商侵蚀线下市场，比如电车的渗透率。这种扩张的速度一定不能线性外推，要考虑和尊重市场的多样性。

Q：请问在寻找十倍股的过程中，最核心的是要看哪些指标？

A：1、核心的指标两个，一个是业绩弹性，一个是买入时的估值。业绩弹性决定了可能的预期收益上限，买入时的估值决定了倍数的基准。市场中多数投资者只关心被除数（业绩弹性），容易忽略除数（买入时的估值）的重要性。其实从简单的算术公式里我们能发现，除数更重要。另外，普通的价值股基本上不可能满足这么高的业绩弹性，这种业绩弹性只会出现在成长股当中，不管是内生性成长，还是周期性成长。

Q：我想问问老师 作为一个普通散户，在专业的行业知识方面几乎没什么优势，这种短板和机构可以找行业专家甚至自己就是行业专家没法比，但是我们价投企业又涉及五花八门的行业，到底是基本了解行业知识就可以，还是说要把自己弄成半个专家？到底要研究到什么程度？不知道老师有没有什么心得体会。

A：一点建议：
1、从自己熟悉的行业开始。每个人都会有自己熟悉的行业，每个人都有亲戚、朋友，把自己放在一个旁观者的角度重新去观察和审视。
2、从身边的行业开始，消费类是相对容易学习和提高的。我们身边有商贸公司（各种品牌代理），有XX超市，有4s店等等。作为投资者，去思考他们的经营。多观察，要考虑市场的多样性，不要轻易下结论。
3、制造业几乎是相通的，采购原料，加工，卖出成品。收入-成本-费用-税收=净利润。找自己最熟悉的来入门。
4、千鸟在林不如一鸟在手，对行业的研究要深入。一年能弄懂1/2个行业，我觉得就是很厉害了。我们没必要弄懂360行，能深入3-5个行业，入门8-10个行业，我觉得足够在市场里稳定的盈利了。

Q：请教一下，价投就可能止损，仓位持有的股票数量有没有要求，如何分配，才能保证止损不会伤筋动骨？

A：我自己是没有要求的，买入的逻辑破了，我就会清掉。仓位管理方面，按照自己的理解大概分三种，低风险低收益、低风险中收益、中风险高收益。双低品种比如水电、一些收息股，这种预期年化收益4%-8%，这类几乎不会产生止损。低风险中收益多是一些困境反转或者有确定但不高内生性成长的品种，这种风险会高一些，核心在于买到相对安全的估值，因为已经是困境买入，即便产生止损也不会有你说的伤筋动骨。第三种，如果是周期性品种，买在景气度底部，顶多是输时间，不会产生较大的本金亏损。如果是成长性的品种，就只能靠观察公司和行业的经营情况来及早做出判断，没有其他捷径。
战术层面，网格买入可以稍微减轻一些交易的压力。
