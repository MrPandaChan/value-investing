# 沃尔特·施洛斯

## 资料

-《沃尔特·施洛斯资料集》

## 一、核心理念

### 1. 买得便宜是根本

> “买股票要像买菜一样买，不能像买香水那么买。”

- **核心追求**：价格远低于价值，而不是追逐热门或成长
- **三条后路**：盈利改善股价上涨、被收购、公司回购
- **下跌保护**：买入时就把风险控制在最小，先想好怎么不亏钱

### 2. 买资产，不买盈利

- 盈利短期波动大，容易被操纵，预测难度高
- 资产变化缓慢，更稳定可靠
- 每股净资产25美元，第二年几乎不可能跌到15美元；但盈利预期落空，股价可能腰斩

### 3. 逆向投资 + 长期持有

> “别人不要的、陷入困境的，我们买。”

- 喜欢创新低、创两三年新低的股票
- 平均持股周期：**4年左右**
- 在下跌过程中分批买入，上涨过程中分批卖出

## 二、选股标准（定量）

| 标准         | 具体要求                                                             |
| ------------ | -------------------------------------------------------------------- |
| **价格**     | 股价最好低于净资产；极端便宜时曾买入低于营运资金2/3的股票（NET-NET） |
| **负债**     | 负债越少越好，不能等于或超过净资产——**最核心原则**                   |
| **历史**     | 公司经营20年以上，有长期业绩记录可查                                 |
| **管理层**   | 持有足够股份，诚实正派；不一定要聪明但必须诚实                       |
| **行业**     | 制造业为主（鞋、汽车零件、钢铁等），回避高科技、银行、餐饮           |
| **股息**     | 最好有分红，等待期间有收入                                           |
| **资本结构** | 简单清晰，没有复杂的债务层级                                         |

### 当前（1985年后）实际操作标准

- 找不到NET-NET后，退而求其次：**股价接近净资产**
- 价格最好在历史低点附近，远离历史高点
- 市盈率不作为主要依据

## 三、组合管理

### 1. 高度分散

- 通常持有 **60-100只** 股票
- 最大持仓不超过组合的10-15%（极少数情况可达20%）
- 原因：买的是问题股，不知道哪个能成，分散是对不确定性的保护

### 2. 仓位管理

- 非常看好的先买计划仓位的50-70%
- 不太确定的先买10%“试水”，买入后才真正关注
- 下跌时加仓（前提是负债低、基本面没根本变化）

### 3. 换手率

- 每年约 **20-25%**，每4年周转一次
- 追求长期资本利得（持有一年以上，税负更低）

## 四、卖出纪律

> “卖出比买入难得多。”

| 卖出信号               | 说明                                         |
| ---------------------- | -------------------------------------------- |
| **达到合理估值**       | 涨了50%-100%后重新评估，分批卖出             |
| **翻倍后变得脆弱**     | 上涨越多越脆弱，容易大幅回撤                 |
| **盈利恢复到正常水平** | 困境反转完成                                 |
| **发现更便宜的标的**   | 可换股，但一般不这么做（换股需要重新熬几年） |
| **公司做愚蠢收购**     | 若管理层开始乱花钱，考虑卖出                 |

**重要经验**：他们经常卖得太早（克拉克石油9美元买、27美元卖，后来涨到260美元；浪琴-咏雅华10美元买、20美元卖，后来涨到200美元）。对此坦然接受——**“桌上的钱换来睡得安稳。”**

## 五、研究方法

### 使用的工具

- 《价值线》（Value Line）——核心数据来源
- 公司年报、委托书（特别注意附注和表外负债）
- 标普股票手册
- 没有电脑、没有报价机

### 不做什么

- ❌ 不拜访管理层（认为会影响判断，且太耗时）
- ❌ 不做盈利预测
- ❌ 不预测市场走势和经济
- ❌ 不做空（心理上难受）
- ❌ 不买期权、衍生品
- ❌ 不买外国公司（SEC保护不足、政治风险）
- ❌ 不买烟草股（道德原因）
- ❌ 不用杠杆

## 六、客户与风控

### 保护客户利益

- 不收管理费，只从利润中分 **25%**；亏损时按比例承担
- 每年将实现收益全部分红（合伙人可要求再投资）
- **不公开持仓**——避免客户因看到“垃圾股”而恐慌赎回
- 拒绝新资金：2000年因找不到便宜股票而清盘解散基金

### 控制情绪

- 远离市场情绪（办公室没报价机）
- 不因贪婪留在高估市场
- 不因恐惧在底部割肉
- “小事不守纪律，大事也不会守纪律”

## 七、一句话总结

> **“买便宜的、负债少的、有资产打底的，分散买入，耐心持有，涨了就卖，跌了敢加。不预测，不跟风，不贪心，不亏钱。”**

### 适合谁

- 愿意长期持有（4-5年）
- 能忍受孤独和逆势（买入别人不要的）
- 对数字敏感，但不想做大量实地调研
- 追求稳定复利（目标15-20%/年），不是暴利

### 72法则

> 每年赚12%，6年翻倍；用72除以年收益率，即得翻倍年数。
