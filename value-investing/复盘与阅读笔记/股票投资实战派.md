**实战含义（决策规则）**
| 推论 | 操作含义 |
|---|---|
| 收益呈幂律分布，少数标的决定组合命运 | 组合必须给高质量头部标的足够权重；"分散持有平庸公司"无法战胜市场 |

## 工具 1-2｜基准收益率标尺：回报分解与机会成本锚

**书中证据（书页 8，标普 500 近 120 年回报分解，CrestmontResearch）**：

- 1909—2022 年，标普 500 指数**每 10 年年化回报率均值约 10%**，构成如下（图 1-5）：

| 回报来源 | 年化贡献 | 说明                                                                     |
| -------- | -------- | ------------------------------------------------------------------------ |
| EPS 增长 | ≈ 5%     | 一部分来自盈利增长，**另一部分来自回购缩股变相增厚 EPS**（美股特有结构） |
| PE 变化  | ≈ 2%~3%  | 估值波动贡献，长期为小幅正贡献但波动极大                                 |
| 分红派息 | ≈ 2%     | 股息再投资的复利贡献                                                     |

- 图 1-4「资本市场与社会的大循环」：回报的宏观来源是企业部门盈利（一/二/三产业），经由金融市场（银行债券=间接融资，VC/PE/股票=直接融资）连接居民部门（储蓄/投资/消费）与政府部门；不同国情（社会文化、法律环境、大国关系）决定循环形态差异。

**用法**：

1. **机会成本检验**：任何一笔投资的隐含问题——"预期回报是否显著优于宽基指数 10% 量级的长期复合收益？"若一只股票的预期回报 = EPS 增速 − 估值收缩 + 股息率的算式算出来低于基准，持有它就是负和决策；
2. **回报预期算式**：`个股长期年化回报 ≈ EPS 增速 + PE 变化年化 + 股息率`——用该算式拆解自己过去持仓的真实回报来源，识别自己是赚了盈利的钱还是估值的水；
3. **A 股对照**：A 股回购缩股贡献远小于美股，回报更多依赖 EPS 增长与股息——对 A 股"高增长 + 低分红"标的，EPS 增速的可持续性权重应给得更高。

## 工具 1-3｜分布特征对策略的约束（幂律 + 肥尾）

| 分布特征 | 对策略的约束                                                                                                                                       |
| -------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| 幂律分布 | 投资收益率由极少数标的贡献 → "错过头部"本身就是巨大的机会成本；选股策略的胜负手在识别质变型公司                                                    |
| 肥尾分布 | 极端收益与极端亏损并存 → 仓位管理不可用正态假设；单票仓位上限、尾部事件预案（不可控事件：国际冲突、政策突变等）必须前置                            |
| 时间维度 | 多数短期数据是噪声；对价值投资者而言要过滤噪声，对追逐边际趋势的人而言短期数据才是信号——**先明确自己赚哪一段的钱**（书中：投资本质是世界观的运行） |

# 二、中观与商业模式工具（第二章、第五章）

## 工具 2-1｜企业生命周期投资决策矩阵（第二章核心）

| 策略                      | 进入的临界点（书中判定标准）                                                                                           | 关键信号                                                                                                                         | 核心风险                                                         | 典型案例                                                                                                      |
| ------------------------- | ---------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| **主题投资 → 成长股切换** | **有标杆性产品实现跨越鸿沟**：从 0 到 1 的机遇遍地都是，经**验证可规模化**的屈指可数                                   | 渗透率 5%→50% 是成长股黄金阶段；标杆产品放量（iPhone、特斯拉 Model 3、光伏平价上网）                                             | 在验证前买入 = 风投逻辑（"VC 的疆界在此之前，股票投资在此之后"） | 光伏平价上网前是主题，平价后是成长                                                                            |
| **成长股 → 价值股切换**   | 渗透率见顶、增速换挡。**高成长行业 ≠ 好投资**：高增速吸引进入者→竞争恶化→资本开支吞噬回报                              | 行业 capex 潮、新玩家涌入、价格战开启；估值切换依赖盈利而非梦想                                                                  | 用成长期的估值买价值期的公司                                     | 亚马逊：2000 年泡沫破裂后近 10 年未回前高，三次回撤近 50%——"与其担心错过技术变革快车，不如担心所投公司被替代" |
| **高股息 / 红利策略**     | **本质是低 PE 策略**。成熟期公司：新业务投入少、格局稳定、现金流大额留存                                               | 分红率持续、capex/折旧比下降、行业增速≈GDP                                                                                       | "价值陷阱"：低 PE 可能是衰退期而非成熟期                         | 成熟期企业以分红作为股东回报的主要方式                                                                        |
| **困境反转**              | **要看到好的边际变化**：修复时点 + 修复后的竞争格局                                                                    | 被替代行业中的幸存龙头（行业出清后份额与价格修复）；研究重点是"行业内部预计什么时候修复、该公司能否在第二个业绩增长一波幅中受益" | 没有边际验证的"低估值"持续恶化                                   | 歌尔股份的第二曲线：TWS 耳机（苹果高端站稳后增加低配版本拓展收入）                                            |
| **周期股**                | 供需长期共存的行业。**大周期内的巨大波动**：供需平衡→成本加成定价；供需失衡→**拍卖定价**（价高者得），价格弹性远超想象 | 见工具 2-2 三层周期跟踪表                                                                                                        | 需求永久消失 → 直接进入衰退期（不再是周期）                      | 化工：2016.6–2018.1 去产能周期；2019.5–2021.10 纯碱/工业硅/磷化工/化肥价格周期                                |

## 工具 2-2｜周期股三层周期跟踪表（书页 46）

**理论内核**：周期存在的原因 = 供给端或需求端的异常 → 供需错配 → 价格飙升/暴跌。

| 周期层级       | 时间尺度 | 驱动                   | 投资对象                  |
| -------------- | -------- | ---------------------- | ------------------------- |
| 短期：供需周期 | 1~3 年   | 所有产品都有           | 短周期机会：价格弹性      |
| 中期：资本周期 | 3~10 年  | 少数产品低成本产能扩张 | 周期成长：量增 + 成本领先 |
| 长期：创新周期 | 10 年+   | 少数创新型公司         | 周期成长 + 创新成长       |

**供给端异常清单（跟踪表）**：自然灾害停产（地震/火灾/设备故障）｜电力短缺停产｜环保与监管加强（如 2016 年供给侧改革）｜战争冲击（原油）｜产能大规模释放（价格下行）
**需求端异常清单**：新兴需求爆发（如新能源车 → 上游锂矿需求飙升）
**核心跟踪指标**：

1. **资本开支战略**——长期投资看行业代表性公司的 capex 决策，价格表现是 capex 战略的结果；
2. **成本曲线位置**——高度同质化品类（纯碱、有机硅、磷化工）中**成本是竞争的关键点**，较少受商业模式与技术路径影响；
3. **定价方式切换信号**——现货价与成本脱钩（拍卖化）= 周期顶部征兆之一。

### A. 平台型公司

| 分析要点               | 工具/公式                                                                                                                                          |
| ---------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| 核心变现：佣金         | 分品类佣金率对标表（书中：抖音/天猫/京东 SOP/京东 FBP/视频号 × 家电/食品饮料/母婴/玩具乐器/保健品医药/手机通讯，如家电类 0.5%~10%）                |

### B. 订单型公司

**为什么中国订单型公司多（书中三原因）**：①工程师红利（平均年薪 15~20 万元 vs 美国工程师 5~7 万美元）②低成本产业集群（广深电子产业带）③政府支持（就业与产业升级）。
**生意特点**：

- 特点 1：**聚焦细分领域 + 产品部分定制化 + 客户与供应链积累**——先绑定几个大客户，"帮他们做麻烦又不太赚钱的事"，做到优质低价 + 良好交付；
- 特点 2：**客户特性决定盈利能力与空间**，下游客户景气度 = 公司景气度；
- 订单结构：一次性订单（需持续获客与营销投入）vs 持续性订单（客户留存型，模型更优；客户分散优于集中）。
- 代表公司：华利集团、申洲国际（鞋服）；立讯精密、歌尔股份、工业富联（消费电子）；和而泰、拓邦股份（控制器）；台积电、中芯国际（半导体）。

### C. 连锁型公司

**赛道优选**：产品满足**社交需求**（"一群人一起消费"优于"一个人消费"——存在社会链接，如白酒）。
**三阶段分析框架（图 5-11）**：
| 阶段 | 核心问题 | 检查项 |
|---|---|---|
| 0→1：单店模型 | 固定成本后的量价分析能否盈利 | 门店运营（量）× 产品创新（价）× 供应链差价 × 营销费用 × 其他费用 → 单店净利与回收期 |
| 1→50：复制逻辑 | **可复制性 = 规模化的前置条件** | 天花板高（市场容量/渗透率/可提价扩品类）× 可复制强（人才、SKU、供应链、加盟管理）|
| 竞争分析 | 格局与盈利持续性 | 价格—产品力—价值三角；规模效应对抗 |

**复制瓶颈与解法**：品类天然瓶颈（东北菜/浙菜/粤菜的师傅瓶颈；便利店/酒吧的店长瓶颈）→ 观察"去瓶颈机制"：海底捞师徒制（利益机制+文化绑定）对抗反规模效应；信息化与设备标准化让龙头突破千店、冲击万店。

### D. 项目型公司（以 IT 服务为例，图 5-17 三类模式对照）

| 维度         | 项目型                                                                                           | 软件产品型               | SaaS 型            |
| ------------ | ------------------------------------------------------------------------------------------------ | ------------------------ | ------------------ |
| 客户模式     | 大中型企业/政府，定制开发                                                                        | 垂直行业标准化产品       | 订阅制、云化       |
| 财务特征基准 | 人均创收约 100 万；毛利率约 27%；净利率约 7%；应收周转约 100 天；销售费用率约 4%；研发占比约 10% | 毛利率更高，研发投入更重 | 高毛利但获客成本高 |
| 估值体系     | PE                                                                                               | PE/PS 兼用               | PS 为主            |
| 主要风险     | 客户集中、回款                                                                                   | 产品一致性、竞争         | 获客成本、续费率   |

# 三、微观与公司分析工具（第三章、第四章、第八章）

## 工具 3-1｜供给端竞争优势检查表（第三章第一节）

**规模效应的本质**：产量越大 → 新增 1 单位成本越低。来源：固定成本摊薄、自动化与工艺、单位研发/广告费用摊薄。
**学习曲线**（书中引 1926 年美国飞机装配案例）：产量翻倍 → 单位劳动成本显著下降。

**关键证伪规则（书页 59，最重要的一段）**：

> **"有规模 ≠ 有规模经济"**。要用单位经济模型验证整体盈利增加到底是"量的增加"还是"单位成本的下降"；行业进入成熟期后，规模效率的改进空间有限。

| 场景                        | 判定                                                                           | 结论                                                                                                                                          |
| --------------------------- | ------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------- |
| 场景 1：行业性降本          | 半导体、光伏、LED、电网、锂电池近十年降本快，但**降本来自行业技术进步**        | 跟随者同样受益 → **不构成公司个体竞争优势**                                                                                                   |
| 场景 2：规模效应 + 区域属性 | 产品**存放周期短、重量大、价值低**（运输半径受限）：水泥、啤酒、家居、部分化工 | 布局 + 规模 = 区域壁垒。案例：海螺水泥（上游石灰石资源 + 华东华南 T 型战略 → 单位成本更低）；关注各公司的生产基地分布（鲁西化工、欧派家居等） |
| 新建基地研究                | 公司宣布扩产/新基地                                                            | 必答三问：为什么建？靠近市场还是降本？对单位经济模型的影响测算过吗？                                                                          |

## 工具 3-2｜需求端竞争优势检查表 + 政策变量（第三章第二节）

**总纲**：需求端优势 = **更懂用户、更获得用户喜欢、更低成本地触达和链接用户**。

### 需求端优势的四类机制（书页 78-83 精读补充）

| 机制             | 运作逻辑                                                                                     | 书中案例                                                                                                                | 检查问题                                                   |
| ---------------- | -------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------- |
| **网络效应**     | 用户↑ → 互补者（开发者/商户）↑ → 产品价值↑ → 更多用户（正循环）                              | 操作系统（用户多→软件商多→系统更强）；Java 因普及成为事实标准；微信（服务器成本被摊薄，游戏/广告/增值服务边际收益递增） | 用户增长是否带动互补生态增长？边际用户的服务成本是否递减？ |
| **边际成本结构** | 高固定成本 + 近零边际成本的产品，规模带来利润率跳升                                          | 微软软件：第一张盘承担全部研发成本，后续复制近乎零成本                                                                  | 每多服务一个客户，增量成本是多少？                         |
| **客户锁定**     | 使用有学习成本，一旦投入培训/迁移，再切换代价高                                              | 空客客机的维护与飞行员培训投入 → 航司持续复购                                                                           | 客户的转换成本是什么？体现在钱还是习惯？                   |
| **品牌**         | 供给过剩时代消费者无从识别 → 品牌 = **认知上的规模效应**（抢占"系统 1"快思考，降低选择成本） | 谷歌默认搜索习惯；屏幕空间有限的 App 展示位；《思考，快与慢》双系统理论                                                 | 消费者不假思索选它的概率有多大？品牌能否溢价？             |

**两类收益递增（书页 80 收尾框架）**：①规模驱动的收益递增（生产端成本递减）②知识驱动的收益递增（研发/网络效应）——大多数高科技公司两者兼有，分析时分开验证。

**注意事项**：虚拟网络（软件、平台）比物理网络（电网、铁路、通信）更容易跨越与重建——网络效应的护城河深度要区分载体。

### 政策变量（书中以电动自行车新国标为例）

- GB 17761—2024（2025-01-13 发布，2025-09-01 强制实施，8 个月生产过渡期）；
- 硬性约束：塑料件总质量 ≤ 整车 5.5%、铅酸电池车型整车限重 55→63kg、北斗定位与动态安全监测、电池组/控制器/限速器防篡改；
- **研究转化**：强制性标准 = 一次供给侧洗牌——合规成本淘汰小厂、利好头部。政策跟踪应进入"供给端异常清单"（工具 2-2）。

## 工具 3-3｜资本周期跟踪框架（马拉松资本方法，图 3-19）

**逻辑链**：高回报 → 资本涌入 → 竞争恶化 → 回报下降 → 资本撤离 → 供给收缩 → 回报修复。

| 方向                   | 领先信号（关注供给）                       | 跟踪动作                                               |
| ---------------------- | ------------------------------------------ | ------------------------------------------------------ |
| 资本涌入（回报将恶化） | IPO 潮、增发潮、扩产公告潮、跨界进入者     | 下修长期回报预期；警惕"成长股估值 × 行业 capex 潮"组合 |
| 资本撤离（回报将修复） | 去产能、破产出清、并购整合、capex 连续收缩 | 困境反转与周期左侧的关注窗口                           |

**均值回归的不对称性（书页 87）**：市场倾向于把均值回归看得太快——**价值股的回报均值回归确实较快；成长股的高回报可能在高位停留更久**。估值含义：对低估值修复不要过度乐观，对优质成长的高 ROE 持续期可以给更多耐心。
**供需判断优先级（书页 87）**：**供给的逻辑比需求的逻辑有更多确定性线索**——需求预测误差大且常被高估；供给变化（产能投放表、在建工程）是可以数出来的。

## 工具 3-4｜单位经济模型：价·量·本拆解表（第四章核心）

**总公式**：`净利润 = 收入 × 净利率 = (量 × 价) × (毛利率 − 费用率)`

### 价（定价方式四分类 + 跟踪）

| 定价方式  | 特征                                                               | 跟踪要点                                                                                                                                          |
| --------- | ------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| 成本加成  | 供需平衡时的常态                                                   | 成本曲线位置（谁的成本低谁赢）                                                                                                                    |
| 协议/长协 | 锁量锁价，平滑波动                                                 | **现货 vs 长协价差**（图 4-3：秦皇岛动力煤 Q5500 现货 vs 年度长协 675 元基准+月度长协，2020-2024 现货大起大落、长协平稳）——长协占比决定盈利波动率 |
| 竞争导向  | 博弈定价，品牌/规格分层（化工多技术路线、化妆品/白酒的品牌价格带） | 价格带位置与品牌力                                                                                                                                |
| 拍卖定价  | 供需失衡时出现                                                     | 出现即周期极端信号（工具 2-2）                                                                                                                    |

### 量（产能利用率与渗透率拆解）

**公式组**：

```
产能利用率 = 实际产量 ÷ 设计产能 × 100%
产销率     = 实际销量 ÷ 实际产量 × 100%
收入       = 行业天花板 × 渗透率 × 公司市占率   （简化框架）
```

**五点注意事项（书页 110）**：

1. 设计产能是动态的——达产率弹性（班次 1→2→3）、技改扩产、开工天数受环保限产影响（如河北高耗能行业）；
2. **产能先进性 = 竞争力**：先进产能可以"低价格、高毛利"并存。书中案例（表 4-5）华熙生物透明质酸：**医药级约 11 万元/kg、毛利率 90.03%** vs **食品级约 0.17 万元/kg、毛利率 53.49%**——同一公司内产品档次决定价格与毛利；培育钻石同理（大克拉=高技术+高毛利，小克拉=同质化竞争）。

### 本（成本结构与获客）

| 成本性质 | 体现       | 诊断问题                                                                                                                                                                                          |
| -------- | ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 靠人     | 管理费用高 | 人效指标（人均创收/创利）改善路径？                                                                                                                                                               |
| 靠技术   | 研发费用高 | 研发方向可行性、技术领先时长（创新药=风投模式，"烧钱"换产品）                                                                                                                                     |
| 靠渠道   | 销售费用高 | **获客成本趋势**（图 4-18：2016-2021 阿里/拼多多/京东单用户营销成本——阿里从约 40 元升至 150+ 元，拼多多从约 10 元升至 60+ 元，京东 60~80 元相对平稳）；互联网公司"一旦拉新成本下降，利润明显改善" |

### 产业链利益分配（书页 116）

- **必查项：产业链条中是否存在占比较高的利润分配者**。例：原材料占比 > 60% → 毛利率天花板仅 40% → 公司受上游摆布；若原料是石油/天然气/煤炭/钢铁等大宗，公司很难具备上游溢价能力。
- 对高毛利环节追问：**收益来源是真价值，还是信息不对称？是否持久？**（用芒格三情形检验，工具 2-3A）

## 工具 3-5｜实控人与管理层评估框架（第八章）

**为什么关注（变现通道理论）**：舞弊与掏空的收益最终要通过**高位减持、股权质押、关联交易、并购套现**变现——这些事项既是舞弊的"原动因"，也是二级市场投资者最应盯住的信号。

| 评估维度                 | 检查清单                                                                                                                                                                                                                                                                                                      |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 股东结构                 | 国资（稳定与收入诉求，不激进）/ 民企（增长诉求，造假与激进动机并存，需辨别真伪）/ 金融资本（回报诉求，易资本运作而轻主业经营）/ 无实控人（治理稳定性）                                                                                                                                                        |
| 交易行为                 | 大额股权质押比例及变化；上市以来大股东增减持节奏；关联交易金额与定价公允性；资金占用痕迹                                                                                                                                                                                                                      |
| 行为模式                 | "讲故事的节奏"：并购与商誉、跨界转型、追逐风口的频次；"赶红线"记录（监管处分、财务更正）                                                                                                                                                                                                                      |
| 战略推演（阿里案例框架） | 管理层战略选择 ≈ f(利益结构, 组织基因)。阿里倾向消费升级而非降级的三因素：①高端市场利润池更厚（天猫佣金+品牌广告变现效率高）；②与低端玩家价格战损害平台品牌与商家生态；③组织基因与历史路径（服务品牌商起家的能力圈与经验）。**用法**：预判管理层下一步动作时，先画"利益结构 × 组织基因"矩阵，而非只听公开表态 |

### 书中四原则（书页 240 精读补充）

1. **三色分级，而非选主人**：红线（有舞弊污点、道德风险者直接排除）→ 蓝线（无大错的普通管理层，业绩有运气成分）→ 绿线（卓越管理层）。**清醒剂：多数公司的业绩主要靠公司运势与行业 beta，不要把行业红利误认为管理层的阿尔法。**
2. **股东结构在 A 股优先级更高**：A 股实控人对上市公司影响力极大，股价结构常被实控人行为塑造——股东结构分析应置于管理层个人能力分析之前。
3. **资本配置能力与业务战略同等重要**：围绕公司核心区域与业务特征评估资本配置——顺势扩张（如牧原、天齐的行业景气期投入）、并购整合（如爱尔眼科、通策医疗），以及克制不乱并购不加杠杆（如涪陵榨菜）都是能力。
4. **战略选择要与组织管理、激励制度互相验证**：仅代表过去业绩的履历不足为凭，需看产业分配机制、组织内外部的激励与权力结构是否支撑新战略。

### 柯林斯"第 5 级经理人"清单（书页 239，吉姆·柯林斯《从优秀到卓越》）

**双重人格：平和而执着，谦逊而无畏。**

| 业绩面                                                     | 人格面                                   |
| ---------------------------------------------------------- | ---------------------------------------- |
| 创造杰出业绩，在跨越中起催化剂作用                         | 令人折服的谦虚，回避公众追捧，不自吹自擂 |
| 为长期业绩勇往直前，不惧困难                               | 依靠崇高标准而非个人魅力驱动组织         |
| 为长盛不衰树立标准，决不降低                               | 培养接班人，为公司离开自己仍能成功打基础 |
| **功劳看向窗外（归功外部与团队），失败照镜子（自己担责）** | 平庸经理人的镜像行为恰相反               |

# 四、财务与估值工具（第六章、第七章）

## 工具 4-1｜财务舞弊预期净收益模型（第六章核心模型）

**书中公式**：

```
舞弊预期净收益 T = E1 × P1 + E2 − C1 − C2 × P2

E1 = 虚增业绩；P1 = 市场估值倍数
E2 = 关键利益相关者的其他收益（高位减持、股权质押、保壳、融资便利）
C1 = 造假直接成本（体外资金循环、配合方利益输送、税务成本）
C2 = 被查处的风险与处罚成本；P2 = 被发现概率
```

**四问排查法（由公式直接推导）**：

1. **变现通道存在吗？**（E1×P1 动机）——高估值 + 大市值 = 造假激励更大；有无高位减持/质押/并购重组计划？
2. **业绩压力大吗？**（E2 动机）——保壳、业绩对赌、融资续命、避免退市，是四大造假动因；
3. **造假直接成本高吗？**（C1）——业务越复杂、体外循环越难搭建、成本越高；若预期收益低于成本，动力不足；
4. **行业容易藏吗？**（P2 低 → C2×P2 小）——高发特征：①现金交易为主（资金流加速、审计难度大，如餐饮/零售）；②商品真实价值难评估（水产养殖的"水体里的鱼虾"）；③个人客户为主、交易笔数巨大；④个人业绩依赖型组织（高额销售费用驱动）。

## 工具 4-2｜财务风险排查清单（可粘贴进备忘录）

| 类别   | 排查项                  | 红旗信号                                                                                                  |
| ------ | ----------------------- | --------------------------------------------------------------------------------------------------------- |
| 动因类 | 保壳/对赌/融资/退市压力 | 连年微利保壳、大股东高比例质押、并购对赌临近到期                                                          |
| 利益类 | 大股东行为              | 高位减持、频繁质押补仓、资金占用、异常关联交易                                                            |
| 行业类 | 造假易发特征            | 现金交易、难估值资产、个人客户为主、审计难度大                                                            |
| 指标类 | 报表勾稽                | 净利润与经营现金流长期背离；应收/存货增速 >> 收入增速；毛利率显著高于同业且无解释；货币资金与有息负债双高 |
| 口径类 | 收入确认                | 总额法 vs 净额法；电商、经销、平台类公司尤其要先确认口径（书页 170：高毛利率必须先统一口径再比较）        |

**行业基准对照法（表 6-9）**：书中按申万一级行业汇总了毛利率/销售费用率/管理费用率/研发费用率/净利率的多年度均值——**用公司指标 vs 行业基准的偏离度做第一层筛查**，异常偏离必须找到商业解释，否则按红旗处理。

| 投资活动现金流净额 | -3.9  | -22.5 | -187.4 | -62.7 | -45.6 | -0.1  |
| 筹资活动现金流净额 | 11.1  | 96.4  | 297.1  | 167.1 | 56.4  | 1.5   |

2018-2020 呈"亏损 + 经营净流出 + 筹资净流入"（初创期肖像）；2021-2023 转为"扭亏 + 经营净流入 + 投资流出收窄"（成长期肖像）——**现金流结构比利润表更早讲出生命周期真相**。

**用法**：

1. 对任何标的画三行现金流 5 年趋势表，与上表比对定位阶段；
2. **阶段与估值方法匹配**（呼应工具 2-1）：初创/主题期不适合 PE；成长期看 PEG 与渗透率；成熟期看分红与自由现金流；衰退期现金流为正（投资回笼）恰是价值陷阱高发区；
3. 警惕"利润为负但经营现金流强劲改善"的拐点信号（理想 2020-2021）——这是困境反转与成长切换的财务证据。

## 工具 4-4｜ROIC-WACC：用财务数据验证商业模式质量（书页 182）

**判据**：

- `ROIC > WACC` → 生意在创造价值；`ROIC < WACC` → 生意在毁灭价值（增长越快毁灭越快）。
- **口径纪律（书中强调）**：分子剔除投资收益、政府补贴等非经营项；分母**剔除超出经营需要的现金与非主营资产**——ROIC 衡量的是纯粹主营业务回报。

**书中实证（表 6-20 代表性公司 ROIC，按商业模式分组，2016-2023）**：

| 商业模式        | 公司                           | ROIC 区间（大致）                         |
| --------------- | ------------------------------ | ----------------------------------------- |
| 网络效应        | 腾讯控股                       | 约 18%~28%                                |
| 网络效应        | 拼多多                         | 波动极大（-105%→94%），盈利模型跑通后跃升 |
| 网络效应        | 京东 / VISA / 爱马仕           | 约 10%~40%                                |
| 品牌与心智      | 贵州茅台 / 农夫山泉            | 约 23%~52%（长期高位极稳）                |
| 品牌 + 规模效应 | 海螺水泥 / 美的集团 / 可口可乐 | 约 10%~30%                                |

**两个警示**：

1. Wind 等平台的 ROIC 是机械公式计算，**无法区分主营与非主营资产**，异常值（如极低净资产导致的畸高 ROIC）需手工调整后重算；
2. ROIC 的**稳定性比绝对水平更有信息量**——茅台 8 年稳定在 23%~52%，而强周期公司在 5%~50% 间摆动，后者的高 ROIC 是周期而非商业模式。

**用法**：Step 2 做完商业模式定性（工具 2-3）后，用 5~8 年 ROIC 序列做定量交叉验证——"说是网络效应/品牌护城河，ROIC 长期却在 WACC 附近晃"，定性结论作废。

## 工具 4-5｜财务预测四步法（书页 190 起）

| 步骤               | 操作要点                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ① 建立企业数据底稿 | 汇集招股书、年报、交流纪要、行业产业政策、上下游数据、募集说明书、路演纪要。**规范：黑色字 = 公司披露值，蓝色字 = 自行预测/估算值，全部标注来源与公式**——底稿可审计是置信度的前提                                                                                                                                                                                                                                                                                                                                                     |
| ② 三大报表拆解     | 按经营性/非经营性拆分（利息收支、投资收益单列）；**驱动因素相同的分散小科目合并**，重要科目细分（收入按类型、成本按结构）；先拆出"收入的量价结构、成本率和费用率概貌"再谈预测。**利润表拆解骨架（图 6-8）**：营业收入 → 毛利（业务相关）→ 销售/管理/研发/财务费用、减值损失 → 营业利润 → 营业外收支/投资收益/公允价值变动（营业外影响）→ 净利润——**把"业务利润"与"营业外影响"分开列示**，防止一次性损益污染对主业的判断。书中以 Boss 直聘 2019-2023 拆解为示范（2023 年营收 59.2 亿、扭亏至净利 11.0 亿，逐项列示费用占比与改善来源） |
| ③ 三情景假设       | 悲观/中性/乐观三档联动假设。书中敏感性表的变量：增速 g、销售增速、信用政策（应收）、毛利率、滞销减值率、**估值倍数本身**——注意"估值底"也是情景变量（同一家公司不同情景下 PE 区间可以差 60%+）                                                                                                                                                                                                                                                                                                                                         |
| ④ 与估值衔接       | 三情景净利润 × 估值方法区间 → 估值矩阵（工具 4-6）                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |

**书中警示**：财务预测必须有对企业的理解深度作前提，否则就是"数字游戏"。

## 工具 4-6｜估值三步法：估值矩阵（第七章核心落地工具）

**前提一：先判断"估值的前提条件"（图 7-2 衣服定价类比）**
同一件衣服：奢侈品溢价 → 品牌溢价 → 正常价格 → 促销低价（新款上市/过季打折/尾货清仓）→ 古典藏品级（脱离时间与人群定价）。
**推论**：估值前必须先回答——公司处于生命周期的哪个阶段？市场把它当"哪件衣服"定价？

**前提二：估值是区间，不是绝对值（图 7-10）**
市场价格围绕内在价值区间波动：悲观时向下大幅偏离、乐观时向上大幅偏离，**大部分时间估值正常——投资者只需关注非正常估值的时刻**（即买卖点）。

**前提三：估值方法的参数纪律（书页 207/210）**

**DCF 折现率三档（经验法）**：按公司确定性与竞争地位分档设置——高波动/新商业模式档约 12%~15%；稳健型约 10%~12%；竞争格局差/低确定性约 8%~10%（方向按风险递减）。**简化基准**：以理财收益率（约 6%）为机会成本底线，大部分投资者按 **8%~10%** 设置即可。
**两阶段结构**：显性期约 6 年逐年预测收入/利润/现金流；永续期 `TV = CF₁ × (1+g) / (r − g)`，要求 **g < r**；若公司从现在起就是低速稳态，直接用永续模型。终值也可用相对法（第 6 年净利润 × 行业常态 PE 折回现值）——即"简易 DCF"。

**倍数体系的使用规则（书页 210）**：
| 规则 | 要点 |
|---|---|
| 跨品类不可互比 | 周期股、消费股、科技股商业模式不同，倍数不可直接横向对比；同类内部再分层（如消费品按格局与稀缺度 PE 区间约 20~30 / 15~20 / 10~15） |
| 重折旧行业换倍数 | 面板等折旧摊销侵蚀利润的行业，用 **P/EBIT、P/EBITDA**（图 7-7：EBIT = 净利润+所得税+利息；EBITDA = EBIT+折旧摊销） |
| 成长股用 PEG | `PEG = PE ÷ g`，**g 必须用未来 3 年综合增速，而非当年增速** |
| 未盈利公司用业务指标 | PM 估值：用户数、交易金额、矿石数量、管理面积等（表 7-2） |

**书中重要警示（原话大意）**：市场上的一个重要规律是——**"发明某个指标或概念来解释当前的高估值"（估值切换、流量价值、消费降级叙事等）往往发生在企业生命周期的成长后期与衰退期**，此时投资者应关注的是负向风险（现金流恶化、净利润降速）；对现金流良好、净利润稳健的公司，指标才可靠。

**核心公式与矩阵**：

```
预估市值 = 估值方法 × 估值基准

估值方法（如 PE 区间）：由竞争优势与行业特性决定
    书中示例：悲观 15x / 中性 20x / 乐观 25x
估值基准（净利润三情景）：由悲观/中性/乐观假设得出
    净利润 = 收入 × 净利率 = 量 × 价 × (毛利率 − 费用率)

→ 3×3 估值矩阵（表 7-6）：每格 = 该情景净利润 × 该档 PE
   决策依据：当前市值落在矩阵的哪个区域
```

|                    | 净利润-悲观 | 净利润-中性 | 净利润-乐观 |
| ------------------ | ----------- | ----------- | ----------- |
| **PE 15x（悲观）** | 极端底部    | 深度低估    | 明显低估    |
| **PE 20x（中性）** | 低估        | 合理中枢    | 合理偏高    |
| **PE 25x（乐观）** | 合理偏高    | 偏贵        | 泡沫区      |

## 工具 4-7｜三大案例的工具映射

### 案例 1｜瑞幸 VS 星巴克（书页 226-229）——相对估值的正确打开方式

**工具运用**：

- **指标 1：营业利润率的质量与稳定性**。星巴克 FY2018-2023 净利润率 18.3% / 15.2% / 9.3%（疫情） / 18.1% / 15.5% / 16.2%——高且稳；瑞幸同期营业利润率波动剧烈、长期为负，2023 年才艰难转正（后续约 -4%~+7% 区间波动）。**利润率的"质量差"决定相对估值的折价幅度**——同为咖啡连锁，不能套同一倍数。
- **指标 2：单杯经济与回本周期**。咖啡店合理回收期约 1.5~2 年；中国单杯价格低于美国 + 9.9 元价格战 → 单店模型回收期拉长 → 对单店盈利能力的评估"要较为谨慎"。
- **格局变量**：中国竞争烈度高于美国（M Stand 等品牌分层竞争）→ 增长要用更多费用换 → 估值时对"增速"打折扣。
  **启示**：相对估值先比"单位经济的质量"（利润率稳定性、回收期），再谈倍数高低。

### 案例 2｜腾讯音乐（书页 230-235）——绝对估值 + 相对估值的跟踪底稿

**时点**：2023-05-17 前后（市值约 900 亿），最新一季报 + 年报披露后做估值。
**工具运用（表 7-16 的跟踪表结构，可直接复制为 Excel 模板）**：

```
分部收入：在线音乐 | 社交娱乐  （每分部：收入绝对值 + YoY）
在线音乐量价拆解：MAU（趋势↓）× 付费率（8.8%→20%+ 持续↑）× ARPPU（小幅波动）
订阅收入占在线音乐收入比重（持续提升 = 商业质量改善的核心证据）
社交娱乐：MAU 大幅收缩 + 付费率/ARPPU 变化（衰退分部单独建模）
```

**方法论**：①底稿表把"结构转换"（付费率提升对冲 MAU 下滑）可视化——这是普通投资者最容易漏掉的非线性变化；②在分部拆解基础上，绝对估值（现金流折现假设各分部不同生命周期）与相对估值（对照同业倍数）交叉验证。
**启示**：对多业务公司，估值单位必须是"分部 × 量价拆解"，而不是合并报表的 PE。

### 案例 3｜阿里巴巴（书页 249-252）——管理层评估工具的应用

见工具 3-5"战略推演"一栏：**利益结构 × 组织基因** 双因子推演管理层战略选择。此案例的价值在于示范"第八章的管理层评估"如何落地为可论证的结论，而非印象分。

# 五、基本面投资全流程工具箱（One-Page Checklist）

> **用法**：每只新标的从 Step 0 走到 Step 5；每个 Step 全部 ✓ 才进入下一步。持仓股每季度重跑 Step 2-5 的跟踪项。

## Step 0｜自我定位（开工前）

- [ ] 资金属性：久期、收益率要求、最大回撤承受（工具 1-4①）
- [ ] 策略选型与边界：主题/成长/价值/红利/困境反转/周期——我只赚哪一段钱？（工具 1-4②）
- [ ] 基准锚：预期回报是否明显优于宽基指数长期回报？（工具 1-2）

## Step 1｜生意定性（是什么生意）

- [ ] 生命周期定位：渗透率位置 + 标杆产品验证状态（工具 2-1）
- [ ] 商业模式归型：平台/订单/连锁/项目（工具 2-3）+ 生意四分类：价格/销量/价差/政策主导（工具 2-4）
- [ ] 一句话生意描述：这家公司靠什么赚钱？客户为什么选它？别人为什么抢不走？

## Step 2｜竞争优势与公司分析（为什么赢）

- [ ] 供给端：规模效应真实性（单位经济证伪"有规模≠有规模经济"）；区域属性；新建基地逻辑（工具 3-1）
- [ ] 需求端：更懂用户/更低成本触达；政策变量清单（工具 3-2）
- [ ] 资本周期位置：供给在涌入还是收缩？IPO/增发/capex 信号（工具 3-3）
- [ ] 单位经济拆解：价（定价方式+现货长协价差）/ 量（产能利用率+渗透率×份额）/ 本（成本性质+获客成本）/ 产业链利润分配者（工具 3-4）
- [ ] 实控人与管理层：股东结构、变现通道、战略推演、三色分级与红线指标（工具 3-5）

## Step 3｜财务验证（数字可信吗）

- [ ] 舞弊四问：变现通道？业绩压力？造假成本？行业可藏性？（工具 4-1）
- [ ] 红旗清单过筛：动因/利益/行业/指标/口径五类（工具 4-2）
- [ ] 现金流肖像定位生命周期：经营/投资/筹资三流 5 年组合 vs 四阶段基准表（工具 4-3）
- [ ] ROIC-WACC 交叉验证：5~8 年 ROIC 序列 vs 商业模式定性结论，稳定性优先（工具 4-4）
- [ ] 行业基准对照：毛利率、费用率 vs 申万行业均值，偏离须有商业解释（工具 4-2）
- [ ] 数据底稿建立：黑字披露值/蓝字预测值、来源与公式全标注（工具 4-5①）

## Step 4｜财务预测与估值（值多少钱）

- [ ] 三大报表拆解：经营/非经营分离、"业务利润"与"营业外影响"分列（工具 4-5②）
- [ ] 三情景假设：g、增速、信用政策、毛利率、减值率、估值倍数联动（工具 4-5③）
- [ ] 估值前提判断：公司被当"哪件衣服"定价？生命周期阶段匹配吗？（工具 4-6 前提一）
- [ ] 参数纪律：折现率三档或 8%~10% 简化基准；PEG 的 g 用未来 3 年；重折旧用 EBITDA；警惕"新概念解释高估值"（工具 4-6 前提三）
- [ ] 估值矩阵计算：方法区间 × 三情景净利润，定位当前市值所在格（工具 4-6）

## Step 5｜决策与跟踪（何时买卖、盯什么）

- [ ] 买卖点纪律：只在"市场悲观/乐观导致的非正常估值时刻"行动；大部分时间等待（工具 4-6 前提二）
- [ ] 核心跟踪变量（按生意类型选 2~3 个）：价格/价差（价格主导）｜渗透率与份额（销量主导）｜capex 与供给出清（周期与资本周期）｜付费率/ARPPU（平台与订阅）｜单店回收期（连锁）｜修复时点（困境反转）
- [ ] 仓位约束：肥尾分布下设单票上限与尾部预案（工具 1-3）
- [ ] 持仓季度复检：重跑 Step 2-5；幂律警示——头部标的要敢给权重，尾部红旗要敢清仓（工具 1-1）
