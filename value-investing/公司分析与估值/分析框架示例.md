# 分析框架示例

## 0. 核心原则

分析不同事物，不是简单的“先有框架，再分析”，而是一个迭代过程：

> **明确目的与对象边界 → 列候选框架 → 选择主框架与辅助框架 → 明确模块接口 → 按维度找证据 → 记录反例 → 修正框架 → 形成可检验结论。**

框架像地图：没有地图容易迷路，但地图不等于领土；框架能防止分析散乱，也可能遮蔽例外。

在价值投资场景中，更实用的做法不是把框架拆成多个互不相干的“独立框架”，而是做成：

> **一个主决策框架 + 若干子分析模块 + 一个跟踪与反证层。**

拆分的关键不是多写几个标题，而是每个子框架只回答一个主问题，并定义清楚它向下一层输出什么。否则会变成“商业模式很好、财务一般、估值贵、但赛道好”的拼盘式结论。

---

## 1. 通用分析流程

### 1.1 明确目的与要回答的问题

同一个事物，目的不同，框架就不同。

- 分析一家公司：战略框架、财务框架、组织框架、产业链框架都不同。
- 分析一个社会现象：经济学、社会学、历史制度、博弈论框架会给出不同切面。
- 价值投资分析：重点不是预测短期股价，而是判断生意质量、护城河、资本配置、自由现金流、估值与安全边际。

更完整的顺序是：

> **目的 → 对象边界 → 候选框架 → 主辅框架 → 模块接口 → 分析 → 修正 → 结论。**

### 1.2 界定对象边界

必须写清楚：

- 分析对象是什么；
- 分析期限多长；
- 市场范围是什么；
- 不分析什么；
- 关键约束是什么。

价值投资中尤其要避免把“行业好”直接等同于“公司有投资价值”，也要避免把单一技术路线当作确定事实。

### 1.3 列候选框架

常见来源：

- 已有理论/学科框架：SWOT、PEST、波特五力、供需分析、制度分析、DCF、EV/EBITDA 等；
- 对象自身结构：流程、层级、生命周期、利益相关者、收入成本结构；
- 问题类型：诊断型、比较型、预测型、决策型、解释型；
- 约束条件：时间、数据、成本、可操作性、可跟踪性；
- 反例和异常：用来检验框架是否遗漏维度。

### 1.4 选择框架的标准

一个好框架至少看：

- **适配性**：是否匹配问题和对象；
- **解释力**：能否解释关键现象；
- **可操作性**：能否落到指标、证据和行动；
- **可检验性**：能否被事实推翻或修正；
- **成本**：是否值得花这么多时间和数据；
- **可跟踪性**：关键变量能否持续验证；
- **能力圈**：是否看得懂，是否在一尺栏内。

### 1.5 常见误区

- 把框架当结论，而不是工具；
- 框架过早封闭，忽略例外；
- 维度很多，但没有主次；
- 用指标替代本质；
- 只找支持框架的证据，形成确认偏误；
- 不同问题硬套同一个框架；
- 多个框架并列使用，却没有接口和汇总规则；
- 没有写下“什么证据会推翻结论”。

## 2. 价值投资场景的模块化框架树

不建议把“商业模式分析、财务分析、估值框架、价值框架”做成完全并列的独立王国。更合理的结构是分层模块化：

### 第 0 层：价值投资元框架 / 能力圈与一尺栏过滤器

**核心问题**：我是否看得懂？是否在一尺栏内？关键变量是否可跟踪？管理层是否可信？最坏情况能否承受？

**看什么**：

- 生意是否可理解；
- 关键变量是否可跟踪；
- 技术路线、政策、客户结构是否带来不可承受的不确定性；
- 管理层诚信与资本配置记录；
- 是否存在一票否决项。

**输出**：

- 进入深度研究 / 观察 / 排除；
- 关键跟踪变量；
- 一票否决条件。

### 第 1 层：商业模式与护城河框架

**核心问题**：这是不是好生意？优势能否持续？

**看什么**：

- 收入从哪来、成本结构如何；
- 客户是谁、客户集中度如何；
- 规模效应、转换成本、网络效应、产业链议价权；
- 资本强度、周期性、技术迭代速度；
- 护城河来源、宽度、趋势和削弱因素。

**输出**：

- 好生意判断；
- 关键驱动变量；
- 护城河强弱与趋势；
- 主要风险。

### 第 2 层：财务验证框架

**核心问题**：生意质量是否被财务数据验证？现金流是否真实？

**看什么**：

- ROIC/ROE、毛利率、经营现金流/净利润；
- 自由现金流、资本开支/经营现金流；
- 应收、存货、在建工程、负债结构；
- 会计质量与折旧政策；
- 正常化盈利和正常化 ROIC。

**输出**：

- 财务是否验证商业模式；
- 资本配置纪律；
- 正常化 ROIC 与自由现金流判断；
- 财务否决条件。

### 第 3 层：估值与安全边际框架

**核心问题**：当前价格是否提供足够安全边际？

**看什么**：

- 三情景 DCF、EV/EBITDA、PE/PB 交叉验证；
- 正常化盈利而非单一年份利润；
- 保守、中性、乐观情景；
- 估值成立需要多乐观的假设。

**输出**：

- 内在价值区间；
- 安全边际判断；
- 估值所需关键假设；
- 是否进入可投资区间。

### 第 4 层：跟踪与反证框架

**核心问题**：结论如何被持续检验？什么证据会推翻结论？

**看什么**：

- 季度/年度可验证指标；
- 反例和异常；
- 框架解释不了的地方；
- 复盘与修正规则。

**输出**：

- 监控清单；
- 推翻条件；
- 修正规则。

### 汇总规则

最终结论不是各模块简单拼接，而是：

> **质量判断 + 财务验证 + 估值判断 + 可跟踪性 → 可投资区间 / 观察 / 排除。**

同时保留少数一票否决条件，例如：ROIC 长期低于资本成本、自由现金流长期为负且依赖融资、管理层诚信问题。

## 3. 子框架接口表

| 子框架          | 核心问题                   | 关键输出                      | 停止/否决条件                                 |
| --------------- | -------------------------- | ----------------------------- | --------------------------------------------- |
| 能力圈/一尺栏   | 是否看得懂、可跟踪         | 是否继续；关键变量            | 关键变量不可跟踪且影响生死                    |
| 商业模式/护城河 | 好生意和优势持续性         | 关键驱动、护城河强弱、风险    | 护城河持续削弱且无替代                        |
| 财务验证        | 是否真赚钱、现金流是否真实 | 正常化 ROIC/FCF、资本开支纪律 | ROIC 长期低于资本成本；FCF 长期为负且依赖融资 |
| 估值            | 价格是否够便宜             | 三情景价值区间、安全边际      | 只有极乐观假设才成立                          |
| 跟踪/反证       | 结论如何被检验             | 监控指标、推翻条件            | 关键假设被证伪                                |

## 4. 演示：作为价值投资者研究宁德时代的投资价值

说明：这是分析框架演示，不是投资建议；财务与估值数据需以最新年报、季报和当前股价核实，不使用虚构精确数字。

### 4.1 题目与角色设定

**题目**：作为价值投资者，研究宁德时代的投资价值。  
**角色**：长期价值投资者，关注生意质量、护城河、资本配置、自由现金流、估值与安全边际，不做短期择时。  
**输出**：不是“买/不买”的结论，而是“用什么框架、看哪些证据、如何形成可检验结论”。

### 4.2 明确目的与核心问题

**分析目的**：判断宁德时代是否属于可长期理解、可估值、具备持续竞争优势的企业，以及当前价格是否提供足够安全边际。

核心问题：

1. **生意质量**：动力电池和储能电池是不是好生意？资本回报率、现金流、周期性如何？
2. **护城河**：成本、规模、技术、客户认证、产业链布局是否可持续？哪些正在被削弱？
3. **成长与再投资**：增长来自哪里？再投资的边际回报是否足够高？
4. **估值与安全边际**：在保守情景下，当前价格是否低于内在价值？

**不回答的问题**：短期股价涨跌、技术路线押注、宏观择时。

### 4.3 界定对象边界

- **公司**：宁德时代，主营动力电池、储能电池及电池材料/回收等。
- **分析期限**：5—10 年，匹配价值投资视角。
- **市场范围**：全球动力电池与储能市场，重点看中国、欧洲、北美及新兴市场。
- **不分析什么**：不把“新能源赛道好”直接等同于“公司有投资价值”；不把单一技术路线当作确定事实。
- **关键约束**：技术迭代快、政策与地缘政治影响大、客户集中、资本开支高。

### 4.4 候选框架与选择

| 候选框架             | 能回答什么                         | 局限                   |
| -------------------- | ---------------------------------- | ---------------------- |
| 价值投资模块化框架树 | 能力圈、商业模式、财务、估值、跟踪 | 需配合技术情景         |
| 波特五力             | 产业链议价权、竞争格局             | 偏静态，难覆盖技术路线 |
| DCF/情景估值         | 内在价值与安全边际                 | 对假设敏感             |
| 产业链分析           | 上游锂镍、下游车企、同行二供       | 易忽略组织能力         |
| 技术路线情景分析     | 磷酸铁锂/三元/固态等               | 难以精确预测           |

**选择**：主框架用“价值投资模块化框架树”，辅助用“波特五力 + 技术路线情景 + 地缘政策情景”。原因：价值投资需要先判断生意和护城河，再谈估值；宁德时代技术迭代和地缘政治太重要，必须加情景。

### 4.5 第 0 层：能力圈与一尺栏过滤

**判断点**：

- 电池制造可理解，但技术路线、地缘政治、客户二供、资本开支节奏使关键变量较多；
- 可跟踪性中等偏难，不属于典型“一尺栏”简单生意；
- 需要情景分析而非单点判断；
- 最坏情况包括技术路线切换、海外项目回报低、价格战压缩 ROIC。

**输出**：可以进入深度研究，但必须带着情景和反证条件；不是高确定性、低跟踪难度的标的类型。

### 4.6 第 1 层：商业模式与护城河

- **优点**：规模全球领先，动力电池和储能双赛道，客户认证壁垒高，研发投入大，产业链布局增强议价权。
- **护城河来源**：成本、规模、客户认证、研发迭代、产业链布局的组合护城河。
- **削弱因素**：车企“二供/三供”策略、自研电池、技术路线变化、海外本地化要求。
- **生意属性**：高增长但重资产、资本开支大、技术迭代快、周期性增强。
- **判断**：护城河存在，但不是“躺赢型”护城河，需要持续用研发和成本优势维护。

### 4.7 第 2 层：财务验证

重点看：

- 正常化 ROIC 是否高于资本成本；
- 经营现金流是否覆盖资本开支；
- 自由现金流能否持续转正；
- 应收、存货、在建工程是否异常；
- 负债结构是否稳健；
- 资本开支是否带来高回报，还是只带来份额扩张。

**判断点**：不能只看收入利润增速。高增长公司最容易在产能过剩和价格下行时暴露存货与应收风险。若自由现金流长期为负且依赖融资，应下调生意质量判断。

### 4.8 第 3 层：估值与安全边际

建议做三情景：

- **乐观**：海外份额提升、储能高增、毛利率稳定；
- **中性**：行业价格竞争，份额稳定但 ROIC 下行；
- **悲观**：产能过剩、技术路线切换、地缘限制加剧。

估值用 DCF 或 EV/EBITDA 交叉验证。周期成长股用单一年份 PE 容易误判，要结合正常化盈利和自由现金流。安全边际来自“即使中性偏悲观也不亏大钱”，而不是依赖最乐观假设。

### 4.9 第 4 层：跟踪与反证

重点跟踪：

- 海外项目回报与资本开支纪律；
- 车企二供/自研电池份额趋势；
- 技术路线变化；
- 资本开支/经营现金流、自由现金流；
- 毛利率与 ROIC 趋势；
- 政策与地缘限制。

**推翻条件**：

- ROIC 持续低于资本成本，下调护城河判断；
- 自由现金流长期为负且依赖融资，下调生意质量；
- 海外项目回报低于预期，下调成长质量；
- 估值假设需要非常乐观才成立，安全边际不足；
- 技术路线突变使现有产能和优势重估。

### 4.10 结论模板

> 宁德时代具备规模、成本、研发和客户认证组成的组合护城河，动力电池与储能提供成长空间；但电池制造重资产、技术迭代快、竞争与地缘政治会压缩 ROIC 和自由现金流。作为价值投资者，应重点验证三件事：**正常化 ROIC 是否高于资本成本、自由现金流能否持续转正、保守情景估值是否留出安全边际**。若三者不能同时满足，则不属于高确定性价值投资标的；若满足且价格折价足够，才进入可投资区间。

## 6. 最终表述

更准确的表述是：

> **分析不同事物，应先明确分析目的和对象边界，再选择或构建适配框架，并把框架拆成有接口的模块；分析过程中用事实修正框架，用反例检验框架，最后形成可检验、可跟踪、可推翻的结论。框架是分析的起点，不是终点。**
