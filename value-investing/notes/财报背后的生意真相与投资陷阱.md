## 前言：本期讨论框架

本期是永庆与财务出身的资深董秘饶钢围绕新书《简明财务分析》展开的长篇对话，聚焦三条主线：

1. **不同视角看财报**：经济评价（卖方）→ 风险投资（甲方）→ 企业财务总监（内部）→ 二级市场研究（外部观察者），同一份财报在不同角色眼里指向完全不同的"真相"。

2. **简明财务分析方法论**：用"估值导向好公司、四步分析驱动力、投入产出双循环、七看八问两分钟"四句话，把会计常识转化成二级市场可以快速落地的分析工具。

3. **从财务分析到投资决策**：怎样把"看清生意"和"管住人性"结合起来——为什么基本面研究的最大功能其实是让投资者"睡得着觉"。

## 一、嘉宾画像与"两进两出"的财务视角

### 1. 饶钢的多重身份与转折

- **89 年大学毕业**，进机械部四院做了 11 年工厂设计，工作核心是"建设方法与参数"——用 DCF 做项目可行性研究和经济评价。这给他奠定了**"现金流刻在骨子里"**的底层视角。

- **96 年自学注会通过**（一个"本本会计"）。

- **00 年下海**到上海，加入风险投资基金，做了 4 年早期 VC（外部看企业、甲方视角）。

- **04 年阴差阳错进入企业财务**：跨国集团老板让他去松江工厂当财务经理，理由是"集团里最优秀的财务分析师"。从此完成"本本会计 → 真实会计"的转变。

- **后续 5 年外企财务经理/财务总监 → 08 年至 21 年做了 4 家民营企业的董秘 CFO**，目标都是冲 IPO。十几年报材料 6 次、失败 5 次、成功 1 次——成功的是**凌志软件 688588.SH（对日软件外包）**。

- **20 年凌志上市，21 年离职**。同时在交大高金读完博士，正式进入"会计科班 + 金融科班"。

- **21 年后**与梁玉峰博士的基本面研究团队合作，研究了几百家公司，深度研究几十家，把"内部财务视角"和"二级市场外部视角"打通。

> 他自我定位为"两进两出"：从外部经济评价进入企业内部，再走出来做二级研究。这是本期所有方法论的人格化基础。

### 2. 三种圈子的画像差异

饶钢用一组对比刻画了财务/金融人群的思维差异，这也是本期不断强调"视角错配"的根源：

| 圈子                       | 第一印象词   | 反面           |
| -------------------------- | ------------ | -------------- |
| 会计科班（财务出身）       | 严谨         | 呆板           |
| 金融科班（投资出身）       | 奔放、敢想象 | 风险意识弱     |
| 本本会计（投资人懂点会计） | 自信         | 不知道真实财务 |

> 隐含判断：**优秀的二级研究员需要把"严谨"和"奔放"拼起来**——既知道报表是怎么"做"出来的，也敢于做估值意义上的飞跃。这也是为什么饶钢这本书在两类读者中都有市场。

### 3. 上市后的"反路演"经历——一级二级思维巨大差异

- 凌志上市后两周没人来访，饶钢主动找朋友介绍，1 年内见完了**所有投计算机方向的基金经理和分析师**，做了上百场反路演。

- 体会：他能让分析师改变对"凌志=对日外包"的认知，但**改变认知 ≠ 买入决策**。

- 推论：**一级市场是"我不让你看你就不投"——拿时间和深度换信息**；**二级市场是"信息就这么多，必须在很短时间内判断"——本质是个筛选机制**。

> 隐含结论：二级市场分析的有效性，不是看你能挖多深，而是看你能在有限信息、有限时间、跨行业切换下还做出**可重复、可复用**的判断框架。

## 二、视角转换的"第一课"：会计世界与真实世界并不对称

### 1. "咔嚓大师"的故事

饶钢入职跨国制造业子公司当财务经理第一天，总经理告诉他：ERP 存货账与财务账每月差几百万对不上。

- 他作为本本会计的认知是"账实相符、账表相符、表表相符"——会计逻辑必须闭环。

- 现实是成本主管每月**两次"咔嚓"**：月底把差额扔进暂估科目把账平掉，月初再咔回来。差额永远在，但每张报表永远平。

- 由此**得名"咔嚓大师"**。普华永道审计的跨国企业都如此，更何况其他企业。

### 2. 从"规则导向"到"原则导向"

- 工业时代会计是**规则导向**：1+1=2，怎么处理写得清清楚楚。

- 过去 30 年全球会计准则转向**原则导向**：只规定大类处理原则，**具体怎么做由职业判断**。

- 后果：**一个会计数据可以来自多个商业原因**——不可逆地从"对称"变成"非对称"。

- 数学比喻：原本是 y = a + bx，知道 a、b 和 x 就能求出 y，反之知道 y 也能求出 x；现在 y 反推 x **不唯一**。

> **关键论点**：财务分析的本质是用一个**非对称、被高度抽象到一维（货币）**的投影，去倒推一个高维、动态的商业活动。"事的过程"是把企业活动做成会计；"道的过程"是从会计倒推回企业。前者由企业内部的人完成，后者由分析师勉力完成。

### 3. 柏拉图"会计洞穴"之喻

饶钢在《资本市场的会计逻辑》中提出：

- 真实商业活动 = 矮墙后举着东西跑动的人；

- 企业财务系统看到的 = 投影（ERP 数据、HR 报表）；

- **外部分析师看到的更进一步——是投影的抽象画**（毕加索抽象派意义上的财务报表）。

外部分析师**既看不见真实商业活动，也看不见原始投影**。这天然要求分析方法不能是"还原"，而必须是**信号识别**——下一节展开。

## 三、《简明财务分析》方法论：四句话 16 个字

饶钢承认自己曾抗拒"提炼口诀"，但教学反馈逼迫他妥协：人最多记住两个词。最终保留下来的四句话是：

> **估值导向好公司 · 四步分析驱动力 · 投入产出双循环 · 七看八问两分钟**

### 1. 估值导向好公司——目标层

- 不是要算出精确的内在价值，而是**两件事**：
  1. **发现好公司**——值得继续深入研究；
  2. **排除坏公司**——一眼看完就远离。

- 暗含三分类：**好公司 / 坏公司 / 看不懂的公司**。看不懂占比往往最大，是常态而不是失败。

- 这一思路源自芒格的能力圈观——"不知道自己不知道"是最大的风险。

### 2. 投入产出双循环——底层逻辑

- 饶钢的财务分析底层模型是**DCF 思维**，但不是为了搭模型，而是为了把握一句话：**"投入了什么、产出了什么"**。

- 任何企业 = 投入产出系统。德鲁克："企业唯一目标是创造客户。"客户满意 → 付钱 → 形成现金回流闭环。

- "双循环"指：
  - **财务报表内部的循环**：三张表互相校验；
  - **财务与非财务信息的循环**：财务数据 ↔ 生意模式 ↔ 管理层讲话 ↔ 行业格局 ↔ 行研报告，**反复互证**。

- 关键观点：**光看财务报表没意义，必须财务/非财务循环验证**。

### 3. 四步分析驱动力——动作流程

| 步骤          | 内容                              | 作用                           |
| ------------- | --------------------------------- | ------------------------------ |
| 1. 财务分析   | 看三张表、关键指标                | 找异常、找惊艳                 |
| 2. 非财务分析 | 看年报、董事长讲话、行研、产业链  | 解释财务异常的商业原因         |
| 3. 同行比较   | 同行业、同规模、最优秀对手        | 解决"二级跨行业、缺常识"的问题 |
| 4. 结构化表述 | 写 100~200 字纪要，必要时讲给别人 | 暴露"伪结论"                   |

- **第三步比较法是二级市场最简效的工具**：拿两家公司一比，立刻知道哪个数据是正常 / 异常 / 惊艳。

- 例：宁德时代占全球电池份额 1/3，但毛利率只有约 20%——说明动力电池行业本身就是惨烈竞争；反观爱美客或茅台，毛利率轻松超过 80%。比较之中见真知。

- **第四步是反伪结论装置**：写不出来等于没研究清楚；讲不清楚等于自己都没说服。这一步与他的另一本书《故事的力量》一脉相承——研究/沟通/自我管理都是同一套心理学。

### 4. 七看八问两分钟——动作总和

- 教学发现：四句话最后被记住的只有"七看八问"。

- "两分钟"指：研究一家公司之后**必须能用 2 分钟讲清楚它做什么生意、好在哪、风险在哪、未来怎么样**。

- 这一节饶钢说"花了一章讲方法，剩下大部分章节都在讲价值与价格的关系"——暗示方法只是手段，**真正的难点是认知与人性**。

## 四、二级市场财务分析的边界条件

饶钢反复强调"离开场景谈方法就是耍流氓"。本书严格限定在**二级市场投资场景**下：

| 维度           | 二级市场分析                                 | 一级市场分析                   |
| -------------- | -------------------------------------------- | ------------------------------ |
| 信息来源       | 公开公告、电话会、董秘交流（机构）、调研报告 | 可现场尽调，看 ERP/HR/管理会计 |
| 时间窗口       | 短，几小时到几天                             | 长，几个月到几年               |
| 行业范围       | 跨行业，每家公司可能横跨能力圈               | 通常聚焦一个行业               |
| 分析目标       | 不要精益求精，超过有效信息量都是冗余         | 可以精益求精，把底翻过来       |
| 决策机制       | 选择/筛选机制                                | 单点深度判断                   |
| 分析水平天花板 | 70 分（外部财务分析极限）                    | 80~90 分                       |

> 隐含判断：**二级研究员的真正"功夫"在于知道什么时候停下来**。继续研究没有增量信息，就要等待下一轮增量；与其耗在一家公司，不如把比较视野铺开。

## 五、财务造假识别：三维框架

### 1. 一个保代来电的故事——市场对识别造假的真实需求

- 24 年底某资深保代发来一份在审材料，饶钢一看就是造假，写了篇文章 "店门大"（指"店大欺客"）。

- 第二天电话被打爆，请托从他**最早的财务老师、复旦发小、原公司助理**等各路熟人发起，最终把文章撤了。

- 信号：当年 IPO 环境差，**会里要求"零负面"**——一篇质疑文章就可能让批文卡掉一轮。这从侧面说明造假识别在监管中权重极高。

- 法院、上海金融法院和高金都开始让饶钢讲这门课：**财务造假诉讼大量上升 → 法官需要判断"投资者本应识别"** → 决定赔付范围。

### 2. 与黄世忠/叶新华路线的差别

- 黄世忠（厦门大学）+ 叶新华（中国反舞弊研究中心）的方法是**大数据五维度财报可信度分析**——交易所和证监会用的就是这套。

- 饶钢的差别：**不从财报指标下手，而从"造假理论"下手**。

### 3. 三个维度

| 维度                       | 内涵                                 | 信号举例                                                                      |
| -------------------------- | ------------------------------------ | ----------------------------------------------------------------------------- |
| **生意好不好**             | 好公司不会造假，烂公司+压力才会造假  | 比亚迪/宁德这类好公司分析造假毫无意义；财务操纵（如研发资本化）和造假是两回事 |
| **有没有压力**             | 造假必然源于业绩压力                 | IPO、并购对赌、KPI、领导升迁；国企造假动机也多在 KPI                          |
| **财报可信度（信号理论）** | 把财务、非财务、治理多维信号当作红灯 | 业务异常、财务异常、治理异常、CFO 频繁离职                                    |

### 4. 单一指标不构成结论——长江电力反例

- 饶钢曾写过"现金覆盖率"分析，给一家公司打了 39 分（覆盖率低）。

- 评论区有人留言"坚决不碰"。这家公司其实是**长江电力**——典型的现金流稳定、垄断地位、负债可融性极强。

- **教训**：单一信号是线索，不是判决。要看到处冒烟还是只一处冒烟。

- 这与他的"非对称结构"基础逻辑一致——一个数据可以来自多个原因，不能反推。

### 5. 比亚迪案例：操纵 ≠ 造假

- 比亚迪曾在困难期把研发投入资本化，是合规框架下的**操纵**而非造假。

- 业绩好转后又转回费用化处理——"放下屠刀立地成佛"。

- 比亚迪的融资模式被饶钢的导师张春教授（公司金融专家）称为**"千古未有"**：5 年 capex 投入 3000~4000 亿，融资现金流为负。资金来源主要是：
  1. 供应链占款（应付账款）；
  2. 大额其他应付款（数千亿、账期长）。

- 隐含推理：**今年"反内卷"+ 60 天付款规则** → 比亚迪很可能从这种极致占款模式撤回，把利润让给供应商。饶钢明确预测："王董事长会放下屠刀立地成佛。"这是对管理层资本配置道德的押注。

### 6. 洞察 vs 证实——人性陷阱

- 财务分析的核心动作不是逻辑三段论，而是**洞察飞跃**——看完很多材料后，"突然就觉得"它的优势是什么。

- 人的下一步是**证实**：找证据装到 idea 里，给领导/朋友讲。

- 这是黑天鹅的温床——证据全部是"对自己结论有利"的。

- **正确做法**：找一个朋友，不是听他赞成，而是**听他不同意的地方**。VC 阶段他们的规矩是"全员一致同意要暂缓表决"——没人反对，就一定有什么没看到。

> 这与下文"找芒格""妈妈法则"形成完整闭环——心理学防御机制贯穿了整套财务分析方法。

## 六、价值投资：信仰、三碗面与人性

### 1. 价值的哲学定义

- 饶钢引用约翰·密尔：**价值 = 个人的重要性感受**。

- 推论：价值不是客观、不是科学，而是**一种排序，一种私人感受**。

- 价值投资是一组**信仰**而非定理：
  1. 买股票就是买公司；
  2. 公司有内在价值；
  3. 内在价值由未来现金流决定；
  4. 价格最终由价值决定。

- 即使尤金·法玛和希勒在 2013 年因资产定价理论同获诺奖，他们的成果是**"经验法则"**，仍非自然科学。

- 林奇原话：在很长时间内价格不回归价值的情况比比皆是，**但坚持这一信仰是值得的**。

### 2. 比特币与艺术品——只有交易价值，没有内在价值

- 比特币不创造现金流，价值来源于"下一个买家会出更高的价"——是**交易价值**，不是内在价值。

- 毕加索的画也是。基本面派关注的是有内在价值的资产；交易价值的资产并不是"假价值"，但**不是基本面派的研究对象**。

- 这是为什么饶钢和永庆都强调：研究 vs 交易、内在价值 vs 交易价值，要先认清自己**赚的是哪一种钱**。

### 3. "三碗面"——价格的形成机制

| 碗         | 内涵                     | 作用机制                                                                        |
| ---------- | ------------------------ | ------------------------------------------------------------------------------- |
| **基本面** | 企业未来创造现金流的能力 | 长期锚                                                                          |
| **市场面** | 交易行为本身、反身性     | 索罗斯：人类系统不像物理系统，**观察者影响被观察对象** → 必然形成泡沫和泡沫破灭 |
| **心理面** | 人类决策的非理性         | 顶着原始人大脑的现代人，一有风吹草动就跑                                        |

- 反身性的关键：物理系统抛物线公式不会改变抛物线轨迹；人类系统中"我买了" → 别人看到 → 跟买 → 反馈循环 → 必然泡沫和破灭。

- 希勒的诺奖工作：把美股内在价值算出来与价格对比，**价格围绕价值波动，但从来不等于价值**。等于的瞬间立即过去。

### 4. 两个错误观念

- **错误观念 1：知道是泡沫就不参与**
  - 反例：谢国忠 2001 年就说上海房子有泡沫，听他话的朋友 24 年来一辈子没上车。"我们这一辈子挣的钱不如上海一套房。"
  - 教训：**泡沫一定会破灭，但你不能因此放弃参与**。

- **错误观念 2：相信泡沫永远不破灭**
  - 不会涨到天上去，**见好就要收**。
  - 反例：博士同学的美股操作——4 块建仓、补仓 3 块、涨到 7 块只割了一部分（认为还会涨）；第二天跌了不卖；最终一路跌到 1 块多；反弹到 4 块才割。整个过程是"澳洲人抓火鸡"的反向版——抓了一只想等第七只，结果全跑了。
  - 关键判断："你是因为看好这个公司，不是看好它的股价。**机构投资者怎么能以交易结果作为决策依据？**"

### 5. 反例：思科与英伟达——光环效应

- 思科 2000 年涨到顶时，管理学圈把它的成功归因于：
  1. CEO 强；
  2. 一年 500 次收购都是科学收购。

- 网络泡沫破灭后市值跌掉 80%，同一批人换了说辞：CEO 不行、不研发瞎收购。

- **本质是光环效应**：先看到结果，再倒推原因，归因永远跟着股价走。

- 饶钢的提醒："我们看到业绩涨了就找原因——这个原因是你构建的。"做研究时要时刻警惕自己被光环效应裹挟。

- 英伟达和黄仁勋当下面临同样的叙事循环。

### 6. 价值投资的三句话——普通投资者实战版

> 1. **不投资**——忍住，把钱拿在手上。这是价值投资的王道。
> 2. **坚持不懈等风来**——长期跟踪、坚持研究，但**不买**，留着钱等错误定价。
> 3. **股灾时下手**——这几年每年至少 1~2 次全局性股灾，那就是机会。

- 错误定价两个来源：
  - **个人前瞻力**（要求极高，例如前两年看好银行的人）；
  - **市场恐慌**（股灾），更容易抓。

- "9·24"行情（2024 年 9 月 24 日 A 股普涨）当晚饶钢和朋友吃饭，他说"明天全仓干"，朋友们犹豫——等真正下决心干的时候股票已经涨上去了。**知易行难**。

### 7. 应该自我 vs 想要自我

- "应该自我" = 理性、知道该做什么；
- "想要自我" = 冲动、要立即满足。

- 美国出口冰箱的"时间锁"——晚上 8 点到早上 8 点不能开，是为了减肥的医嘱（应该自我事先约束想要自我）。但手机外卖让这套防御失效。

- 投资中的等价物：**事先把买入卖出的理由写下来；决定要卖时拿出来念一遍，认真思考一小时**。这是"给未来的自己写信"。

### 8. 找一个芒格

- 巴菲特和芒格的合作模式：巴菲特决策前给芒格打电话；多数情况芒格说"干"；偶尔芒格说"不能干"，巴菲特如果听了就好，没听就吃亏。

- **关键：芒格不一定比巴菲特更理性，但芒格"不在巴菲特此刻的情绪里"**。任何另一个人，只要不在你的情境里，就是你的"应该自我"。

- 推论延伸——"妈妈法则"：重仓之前必须把逻辑讲给妈妈听，妈妈听懂才说明研究清楚。讲不清就是研究没到位。

- 这与四步分析里的"结构化表述"互为镜像——**讲清楚是研究是否完成的最终验证机制**。

### 9. 索罗斯的故事

- 朋友拜访索罗斯，听他讲完重仓逻辑后睡不着觉，第二天一早敲门说"风险太大"。

- 索罗斯说"昨天已经全部卖掉了"——他对自己的过去判断**毫无包袱**。

- 普通人有巨大包袱，因为我们**经常要证明自己是对的**：现在卖等于承认自己错了，于是不卖、继续套住。

### 10. 永庆的补充：四个关键词与一种"内在计分卡"

- 永庆从二级实战角度补充三点：
  1. **生意理解 + 竞争优势**：没有竞争优势的公司无法做 DCF，因为无法判断持续时间；
  2. **能力圈认定**：大多数公司无法判断时，做排除法已经很好；
  3. **价格判断**：知道市场价才知道是否便宜；公允定价的公司难以赚大钱，除非未来超出所有人预期。

- 永庆指出多数股票投资者的失败原因是**看的公司太少**：好不容易研究清楚一个，舍不得不买，不然就是浪费。但研究 ≠ 必须投资。

- 大多数普通投资者能赚到的钱主要来自：
  - 公司基本面正常发展；
  - 估值低位（市场情绪打折）；
  - 分红收益；
  - 这三项叠加大致就是 8~10% 的预期回报。

- 高质量成长（如 15 倍 PE 时的泡泡玛特）需要超级洞见，能落到自己头上的概率不高。

- **管理层评估**：资本配置能力 + 是否骗子，要有底线思维。

- **资本市场周期思维**：知道其他类型投资者怎么想——困境反转、新产品、新市场、二代接班、估值切换、行业轮动……这些故事路径有限，不同投资者赚不同的钱。

## 七、财务预测：不是预测数字，而是管理风险

### 1. 财务预测的真正用途

- 饶钢的核心论断：**财务预测不是为了预测那个数字，而是用来做场景化决策、控制场景风险**。

- 没有人真的能预测准确数字，但**搭建模型的过程把所有变量分解出来**，迫使你思考：
  - 价格上涨/下跌 5%、10%、20%？
  - 产量上下波动？
  - 原材料波动？
  - 在哪个组合下利润为负？
  - 你能否承受这种场景？

- **结果：你对场景风险的判断从"笼统感觉"升级到"分项可控"**。

### 2. FA 实战例子——业绩承诺被模型证伪

- 饶钢做 FA 时，企业家通常先给一个 3 年 6 亿利润承诺。

- 第一件事就是和老板一起搭模型：拆产品、拆价格、拆竞争对手、拆未来产品线、拆扩张节奏。

- 大部分老板搭完模型自己就承认"做不到"——**所有假设都是他自己提的**。

- 推论：**企业家本人对自己企业的认知很多停留在"情绪化期待"层面，没有拆开就看不清自己**。

### 3. 商业原型——明年第三本书的内容

- 财务分析最难的是"对一个陌生行业有常识"。

- 饶钢的解决路径：**把不同业态的"商业原型"做成模板**——每种原型对应一组核心竞争力特征和典型财务结构特征。

- 套模板 + 同行比较 = 跨行业研究的脚手架。

- 限定条件：他不熟金融业（没在银行待过），所以他的财务分析是非金融业的。

## 八、永庆与饶钢的方法论合流

最后阶段两位整合出几条共识：

1. **价值投资 = 内在计分卡**——背后是基本面研究 + 估值锚 + 市场周期 + 等到合适时点。

2. **不要硬杠某一只票**——好公司多得是，今天太贵就等下一只或者等下一次股灾；研究 ≠ 必须投资。

3. **接受市场是市场、自己是自己**——投资者能做的就是把自己该做的做完，做出 OK 的决策；股价后续怎么走是市场的事。

4. **公司"正常发展+合适估值"就能满足预期回报**——不需要它涨得很好，只要正常运行就够回本，超额是命好。

5. **基本面研究的最大价值**：不是赚最多的钱，而是**让你能睡着觉**——跌了你不慌，涨了你不飘。

6. **没有锚的人最容易被市场情绪左右**。索罗斯的锚是反身性、是宏观；价值投资者的锚是企业内在价值。

## 九、隐含结论与未点明的推理

下面这些判断在节目中没有直接说出，但从嘉宾整段叙事中可以稳定地推导出来：

### 1. "好公司不会造假" 是一种供给侧逻辑判断，蕴含中国 IPO 质量的衰退

饶钢明确：好生意根本没动机造假。但他同时表达了对 24 年 IPO 申报材料质量"很差"的震惊——他原本相信"中国 IPO 是全世界数据质量最高的"。这两条合在一起暗示：**当前 IPO 池里的标的质量结构已经变化，造假比例提升的背后是好生意供给减少 + 上市压力增大**。这也解释了他为什么把第二本书全部用于"识别造假"——这是对市场**未来 3~5 年信息质量持续走弱**的押注。

### 2. 比亚迪的"占款融资"模式是不可持续的政治金融模型

饶钢只说"千古未有"，没明说为什么没人能复制：

- 这种模式要求企业**既有规模优势压制供应商，也有分红能力安抚股东，还有资本市场不质疑的信用**——三者同时具备的公司极少。

- 一旦"反内卷"+60 天付款新规出台，模型会被强制调节。

- 他押注王传福"放下屠刀立地成佛"——本质是押注**头部企业在政治压力下的资本配置道德转向**。这一判断的前提是：监管对标杆企业不会真撕破脸，企业也愿意让利换政治信用。如果反过来，比亚迪的资金链可能比报表显示的更脆弱。

### 3. "内在价值是信仰"是对中国投资者认知短板的安慰

中国普通投资者偏好"价值规律 = 唯物主义教育"，所以最容易接受"价格围绕价值波动"。饶钢说这是信仰、不是科学，等于**给信仰留出退路**——林奇都说过价格可能很久不回归，**坚持信仰是值得的**。这句话隐含的意思：**价值投资在中国市场的执行难度比美股更高**——市场情绪、政策、流动性多次让"价值"长期不兑现，普通投资者必须接受"信仰"层面的安慰才能坚持，否则会在中途崩溃。

### 4. "一级市场尽调更深，但 alpha 反而难"

饶钢花了大量篇幅强调一级 vs 二级的区别。一个被压住没说但能推出来的判断：

- 一级因为信息深度和决策时长，对错经常拖很多年才确定，且无法切换；

- 二级因为筛选机制和比较视野，可以**用速度对冲深度**，且能赚到市场情绪的钱。

- 因此饶钢从"董秘+一级 VC"两条路线进入二级研究，**本质是用更短的反馈循环放大自己的财务直觉**——如果他做一级，可能 10 年只能验证两三个判断；做二级一年可以验证几十个。

### 5. "找一个芒格" 比"做一个芒格" 容易得多

- 巴菲特承认自己做过情绪决策（如那次买伯克希尔股权他自称"损失两万亿"）；芒格的价值并不在于自己永远理性，而在于**不在巴菲特此刻的情绪里**。

- 推论：**普通投资者要的不是导师，而是"任意一个不被你情绪传染的伙伴"**——找朋友、写信、讲给妈妈听，本质是同一回事。

- 这也解释了为什么饶钢花了大篇幅写《故事的力量》并要求读者反着读——一个会说服别人的人也最容易说服自己，**写作和讲述是把"想要自我"暴露给"应该自我"看的最便宜手段**。

### 6. 财务预测的"反 Excel 主义"

- 主流培训行业把财务预测当成 Excel 输出技能。饶钢直接否定："Excel 模型是帮你思考问题的，不是产出数字的。"

- 暗含批评：**多数券商研报、机构内部模型、企业 BP，把假设藏在表格里、用结果数字替代过程论证**——这正是企业家、分析师、机构经理共同的盲区。

- 真正的财务预测能力 = 在不同假设下读出**自己能不能承受**——是一种**心理风险管理工具**，不是预测工具。这是把财务模型从"业务岗工具"重新拉回"投资决策工具"的根本性主张。

### 7. 整本书的隐藏论点：财务分析与心理学是同一件事

- 七看八问 → 检查分析是否完成；
- 写下买入卖出理由 → 检查决策是否完成；
- 讲给妈妈听 → 检查认知是否完成；
- 找一个芒格 → 检查情绪是否被识别；
- 财务预测建模 → 检查风险是否被分项化。

> 这五件事都是"把内在不可见的东西暴露给外部可观测的载体"。表面上是财务分析方法，**底层是同一套心理学防御机制**。这就是为什么饶钢的《故事的力量》和《简明财务分析》是同一套书的两面——**做研究 = 给自己做沟通；防忽悠 = 防止自己忽悠自己**。
